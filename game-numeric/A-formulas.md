## 1. 曲线家族

| 形式 | 公式 | 特征 | 用途 | 章节 |
|---|---|---|---|---|
| 线性 | `y = a·t` | 匀速 | 日常奖励 | 04 |
| 多项式 | `y = a·t^k` | 加速（k>1） | 属性成长 | 04 |
| 指数 | `y = a·b^t` | 复利 | **成本曲线、战力** | 04 |
| 对数 | `y = a·ln(t)` | 快速趋缓 | 需软上限的属性 | 04 |
| S 型 | `y = L/(1+e^(-k(t-t₀)))` | 慢-快-慢 | 单个版本的整体节奏 | 04 |
| **饱和** | `y = M·x/(x+k)` | 渐近 M，永不到达 | **软上限的标准工具** | 04、05 |

**感知成长 = 相对增量：**

```
感知成长 = d(ln y)/dt
```

| 曲线 | 相对增量 | 含义 |
|---|---|---|
| 线性 `a·t` | `1/t` | 快速衰减 |
| 多项式 `a·t^k` | `k/t` | 衰减 |
| **指数 `a·b^t`** | **`ln b`（常数）** | **唯一能维持恒定成长感的** |
| 对数 | `1/(t·ln t)` | 衰减最快 |

**饱和公式的参数含义（04 §4.2）**：`y = M·x/(x+k)` 中，`x = k` 时 `y = M/2`。**`k` 就是"半效点"** ——回答"多少防御能减伤 50%"就定了参数。

## 2. 成本曲线与节奏

| 形式 | 公式 | 说明 |
|---|---|---|
| 纯指数 | `cost(L) = a·g^L` | 一个参数控制陡峭度 |
| 幂函数 | `cost(L) = a·L^k` | 比指数温和，k 常取 2~3 |
| **分段指数** | 每段一个 `g` | **推荐**，可精确对齐时间锚点（04 §3） |

**时间换算（04 §4.3）：**

```
到达 L 级所需天数 ≈ Σ cost(i) / 日产出       (i = 1..L-1)
```

**指数成本下的付费压缩（00 实验 C）：**

```
资源 ×k  ⇒  领先级数 = log(k) / log(成本增长率 g)
```

例：`g = 1.35`，付费 10 倍 → 只领先 `log(10)/log(1.35) ≈ 7.7` 级。

**关键比值（04 §2.2）：**

```
成本增速 / 产能增速  > 1  → 成长逐渐放缓（多数游戏，主流区间 1.1~1.3）
                     ≈ 1  → 接近线性
                     < 1  → 发散（数值溢出）
```

## 3. 战斗

**三种伤害公式（05 §2）：**

| 公式 | 表达式 | 防御边际收益 | 长线适配 |
|---|---|---|---|
| 减法 | `dmg = atk − def` | **递增（危险）** | 差 |
| 乘法 | `dmg = atk × (1 − r)`，`r` 有硬顶 | **递增（需硬顶）** | 中 |
| **除法/饱和** | `dmg = atk × K/(K + def)` | **递减（健康）** | **优** |

饱和公式的 `K` 通常写成等级函数：`K(L) = c · L^1.5`。

**战力（05 §4）：**

```
EHP = 生命 / (1 − 减伤率)
DPS = 攻击 × 攻速 × (1 + 暴击率 × (暴击倍率 − 1)) × 命中率
战力 ∝ EHP × DPS          （显示战力常用 √(EHP × DPS)）
```

**胜负条件推导：**

```
我赢 ⟺ EHP敌/DPS我 < EHP我/DPS敌 ⟺ EHP我 × DPS我 > EHP敌 × DPS敌
```

**战斗时长（05 §3）：**

```
回合数 ≈ EHP / DPS        主流区间 5~15 回合
```

**属性最优配比**：乘积在因子相等时最大（AM-GM）。示例参数下约为 **攻 43% / 防 13% / 血 43%**（防御占比低是因为它经饱和公式边际递减）。

## 4. 经济

**存量-流量（03 §3）：**

```
d(存量)/dt = 流入 − 流出
```

**比例型 sink 的稳态（08 §3.3）：**

```
设日投放 I，日损耗率 d
稳态存量 = I × (1 − d) / d
存量 ÷ 日产出 = (1 − d) / d          ← 只取决于 d，与投放量无关
```

反解：想让"存量/日产 = X 天"，则 `d = 1/(X+1)`。

**通胀三指标（09 §3）：**

| 指标 | 公式 | 健康区间 |
|---|---|---|
| 存量水位 | `全服存量 / 日投放` | **5~20 天**（分层看） |
| 累计回收率 | `Σ回收 / Σ投放` | **≥85%**，看趋势 |
| 货币流速 | `当期消费额 / 平均存量` | 下降 = 先行警报 |

**物价（无市场时用影子价格，09 §3.2）：**

```
影子物价 = 获得 1 单位目标物所需的资源量
达标时长 = 玩家从 A 状态到 B 状态的中位数天数     ← 最实用
```

**费雪方程（09）：** `M·V = P·Q`，即 `物价 P = 货币量 M × 流速 V / 商品供给 Q`。
⇒ **通胀有两个来源**：M 上升（货币侧）或 Q 不足（供给侧）。

## 5. 概率

**几何分布（13 §2.1）：** 概率 `p`，出货抽数 `X ~ Geom(p)`

```
E[X] = 1/p        SD[X] ≈ 1/p        ← 标准差 ≈ 期望，离散度极大
P(X > n) = (1−p)^n
```

**硬保底（截断）：** `E[X] = (1 − (1−p)^N) / p`，最坏 = `N`

**软保底：** 第 `n` 抽的概率

```
p(n) = p₀                                        n < S
p(n) = p₀ + (1−p₀)·(n−S+1)/(N−S+1)               S ≤ n ≤ N
```

**PRD（伪随机分布）：** 第 `n` 次未出货后概率 `= min(c·n, 1)`。给定目标期望反解 `c`。

**UP / 歪机制（13 §3）：**

```
获得 UP 的期望抽数 = 1.5 × 单个稀有的期望抽数
获得 UP 的最坏情况 = 2 × 单个稀有的最坏情况
```

**优惠券收集者（13 §6）：** 集齐 `N` 种

```
E[次数] = N × (1 + 1/2 + ... + 1/N) ≈ N·ln N
```

例：集齐 50 种约需 **225** 次，不是 50 次。

**设计顺序（13 §4）：** 最坏情况预算 → 硬保底位置 → 期望（保底的 50~60%）→ 基础概率 → 软保底起点（保底的 ~80%）

## 6. 留存与 LTV

**留存曲线（15 §2）：**

```
幂律（推荐）：   R(t) = A · t^(−b)
幂律 + 底盘：    R(t) = A · t^(−b) + c        ← c 是假设，不是拟合出来的
指数（不推荐）： R(t) = A · e^(−kt)            ← 系统性低估 LTV
```

**判断形状**：双对数坐标下是直线 → 幂律。

**LTV：**

```
LTV(T) = Σ_{t=1}^{T} R(t) × ARPDAU(t)
净 LTV = 毛 LTV × (1 − 商店抽成) × (1 − 渠道分成)
回本天数 = min{ t : 净LTV(t) ≥ CPI }
```

**指标关系：**

```
ARPU = ARPPU × 付费率
LTV ≈ ARPU × 平均生命周期天数        （粗略估算，误差大）
```

**外推规则（15 §3）：外推窗口 ≤ 观测窗口 × 3。** 有 30 天数据最多谈 LTV90。

## 7. 博弈与竞争

**Elo（17 §3.1）：**

```
E_a = 1 / (1 + 10^((R_b − R_a)/400))
R_a' = R_a + K × (S_a − E_a)
```

分差 400 → 期望胜率 ≈ 91%；分差 200 → ≈ 76%。

**零和博弈的混合策略均衡（16 §2）：** 收益矩阵 `A`，用线性规划

```
max v   s.t.  Σ_i x_i·A[i][j] ≥ v  ∀j ;  Σx = 1 ;  x ≥ 0
```

**支撑集奇偶定律（16 §3）：** 对称零和博弈（收益矩阵反对称）的均衡支撑集**必为奇数**。
⇒ **偶数个兵种的纯克制系统，注定有一个没人用。**

**集结叠加（18 §3）：**

```
总战力 = (Σ 个人战力)^α        或等价地   有效战力 = 人数^α × 人均战力
打赢一个强者需要的人数 = (强者/弱者战力比)^(1/α)
```

| α | 生态 |
|---|---|
| 1.0 | 人多的赢（组织主导） |
| 0.85~0.95 | 平衡 |
| <0.8 | 钱多的赢（个人战力主导） |

**战争节奏（18 §4）：**

```
两次开战的间隔 ≈ 单次作战兵力损失率 / 日兵力再生产率      健康区间 1~3 天
```

**负反馈平衡点（03 §5.2）：**

```
平衡存量 = 日产出 / 损耗率
```

## 8. 数值膨胀

**版本膨胀 `r`（每版本战力价值 ×r），累计 V 个版本（21 §2）：**

```
老玩家总战力 = Σ_{v=0}^{V} r^v = (r^(V+1) − 1)/(r − 1)
最新版本占比 = r^V / 总和 ≈ (r−1)/r        （V 较大时）
新人补 k 个版本的覆盖率 = 1 − r^(−k)
⇒ 达到 85% 需要 k ≥ ln(1/0.15) / ln(r)
```

例：`r = 1.35` → 需补 7 个版本；`r = 1.10` → 需补 20 个版本。

**权衡**：`r` 越大 → 新人越容易追上，但老玩家积累贬值越快。**两者不可兼得**（21 §2）。

    for _ in range(n):
