# 13 - 概率系统

> **本章目标**：搞懂抽卡和掉落的数学，尤其是**为什么方差比期望更影响体验**。学完你应该能设计一套保底机制，并算清楚它对最坏情况的保护力度。
> **本章有模型**：`models/m13_gacha.py`

---

## 1. 先看一个数字

一个 1.6% 出货率的卡池，期望 62.5 抽出一个。听起来还行。但是：

```
纯随机下，抽 10 次一无所获的玩家占比：85.1%
纯随机下，抽 50 次一无所获的玩家占比：44.7%
纯随机下，抽 200 次才出货的玩家占比： 3.99%
```

**44.7% 的玩家抽了 50 次（接近期望）还什么都没有。** 而 4% 的玩家要抽 200 次以上——按 15 元一抽算就是 3000 元。

> **这就是概率系统的核心问题：期望是给策划看的，方差是给玩家体验的。**

一个只看期望做设计的策划会说"平均 62 抽就能出，很良心啊"。而实际上有相当比例的玩家会经历远超预期的挫败——**而且这些人会去论坛发帖，形成"这游戏概率有问题"的舆论**。

## 2. 四种机制的对比

```bash
cd models && python m13_gacha.py
```

模型对比四种机制（TRIALS = 20 万次模拟）：

```
机制                       期望   标准差  中位数   P90   P99   最差
--------------------------------------------------------------
A 纯随机 1.6%（无保底）     62.6   62.0    44    143   285   730
B 硬保底 90 抽             47.9   31.8    43     90    90    90
C 软保底（74 起爬升）       44.7   27.8    44     79    82    88
D PRD（c=0.0008）         44.7   23.2    42     76   108   176

单价 15 元/抽，"最惨的 1% 玩家"要花：
  A 纯随机      4,275 元
  B 硬保底      1,350 元
  C 软保底      1,230 元
  D PRD         1,620 元
```

### 2.1 A 纯随机：几何分布

出货抽数服从**几何分布**，期望 `1/p`，标准差约也是 `1/p`。

**关键性质：标准差 ≈ 期望。** 这意味着体验的离散程度极大——中位数是 44，但 P99 是 285，最差跑到了 730。

**而且几何分布是无记忆的**：你已经抽了 100 次没出，第 101 次的概率还是 1.6%。这在数学上没问题，但玩家的直觉完全不接受——"我都抽这么多了，该出了吧"是最自然的人类推理，而纯随机恰恰否定它。

> **纯随机不适合高价值物品**，因为它的尾部会制造出一批极度愤怒的玩家，而这批人的声量远大于他们的人数。

### 2.2 B 硬保底：砍掉尾部

"第 90 抽必出"。数学上就是把几何分布截断在 90。

效果立竿见影：**最差情况从 730 抽降到 90 抽**，P99 从 285 降到 90。期望也顺带从 62.6 降到 47.9。

**硬保底的真正价值不是降低期望，是让最坏情况变得确定。** 玩家知道"我最多花 1350 元一定能拿到"，这个确定性本身就极大地降低了焦虑——**并且它把付费决策从"赌博"变成了"分期付款"**，这在商业上也更健康。

**缺点**：90 抽这个点太"硬"了。玩家会精确地卡在 89 抽，体验上有明显的台阶感。而且在 1~73 抽区间内，玩家的心理是"反正还早"，缺乏张力。

### 2.3 C 软保底：主流做法

从第 74 抽起概率线性爬升，到 90 抽必出。

结果是四种里**综合最好的**：期望 44.7（最低之一），标准差 27.8，**最差 88 抽**（比硬保底的 90 还低）。

**软保底同时解决了两个问题**：

1. **砍掉尾部**（和硬保底一样）；
2. **在临近保底时制造张力递增**——玩家进入 74 抽之后，每一抽的期待值都在上升。这正好利用了第 02 章的**目标梯度效应**。

这也是为什么主流抽卡游戏几乎都用软保底。

### 2.4 D 伪随机分布（PRD）：暴雪的做法

**PRD** 的规则是：第 n 次未出货后，下一次的出货概率为 `c × n`（线性递增）。它源自 War3 / Dota 的暴击机制——暴雪发现纯随机暴击会导致"连续五次暴击"和"二十次不暴击"这种极端体验。

模型里通过二分反解 `c`，让 PRD 的期望恰好等于软保底（44.7），这样才能公平对比。

**结果很有意思：PRD 的标准差最低（23.2），但 P99（108）和最差（176）反而比软保底差。**

原因：软保底在 90 处有硬截断，尾部被完全切掉；PRD 没有截断，概率虽然一直涨但理论上可以拖很久。

> **这个对比说明"降低方差"和"砍掉尾部"是两件不同的事。**
> 玩家的愤怒来自**尾部**，不是来自方差。所以设计时应该优先保证"最坏情况有上界"。

**PRD 更适合高频小额的随机事件**（暴击、闪避、单次掉落），因为那里没有"保底计数器"这个 UI 概念，而 PRD 不需要显式的计数器就能让手感变均匀。

## 3. 复合机制：UP 与"歪"

真实卡池通常还有一层：出的 5 星有 50% 概率是当期 UP 角色，"歪"了的话下一个 5 星必定是 UP。

**期望的算法**：

```
获得 UP 所需的 5 星个数期望 = 0.5 × 1 + 0.5 × 2 = 1.5
获得 UP 的期望抽数 = 1.5 × 单个 5 星的期望抽数
最坏情况 = 2 × 单个 5 星的最坏情况
```

代入软保底的 44.7 和 88：

```
UP 期望抽数 ≈ 67
UP 最坏情况 = 176 抽
```

**这层机制的设计意图**：它在不改变基础概率的前提下，把期望和最坏情况都放大了 1.5~2 倍——**是一个隐蔽但强力的深度控制旋钮**。

**同时它也是一个典型的"体验陷阱"**：歪掉的那一刻是整个抽卡流程里挫败感最强的时刻。所以几乎所有采用这个机制的游戏，都会把"下次必中"的状态**显式地显示在 UI 上**——把损失转化成一个可见的进度，缓解挫败。

## 4. 设计一套概率系统的检查清单

**① 先定最坏情况，再倒推概率。**

不要从"基础概率定多少"开始，要从"**我希望最惨的玩家花多少钱**"开始。

```
目标：最惨的玩家不超过 1500 元 → 单价 15 元 → 硬保底 100 抽
然后：期望希望在保底的 50%~60% → 期望约 50~60 抽 → 基础概率约 1.5%~2%
最后：软保底起点设在保底的 80% 左右 → 第 80 抽
```

**这个顺序保证了体验的上界是设计出来的，而不是算出来的。**

**② 保底计数必须可见。** 玩家能看到"还差 N 抽保底"，焦虑会显著降低。藏起来只会让玩家自己数，数错了就是投诉。

**③ 保底要不要跨池继承？** 继承对玩家友好（不会因为换池损失进度），但会降低你的收入。**这是明确的商业取舍，没有标准答案。**

**④ 十连要不要有额外保底？** "十连必出 4 星"这类小保底的作用是提供**高频的小正反馈**，防止玩家在长周期里完全没有反馈。它对期望的影响很小，对体验的影响很大。

**⑤ 算清楚复合机制的总期望和总上界**（第 3 节）。多层机制叠加时，人的直觉会严重低估总成本。

**⑥ 一定要跑蒙特卡洛，不要手推。** 复合机制的解析解很容易算错，而模拟 20 万次只需要几秒。

## 5. 合规

**概率公示是强制要求，不是可选项。**

- **中国**自 2017 年起，主管部门要求网络游戏运营方公示虚拟道具的抽取概率；
- **日本、韩国**及部分欧洲国家也有各自的披露或限制要求，且规则在持续演变（部分辖区对"开箱"机制有更严格的立法动向）。

**实操上必须做到的几件事：**

| 要求 | 说明 |
|---|---|
| **公示的概率必须和代码一致** | 这是底线。不一致 = 欺诈，风险极高 |
| **公示要包含保底规则** | 只公示基础概率而藏保底，会被认为是误导 |
| **软保底的动态概率也要说明** | 至少要说明"第 N 抽起概率提升" |
| **保留抽取日志** | 用于争议处理和监管核查，**服务端必须记录每一次抽取的随机种子和结果** |
| **面向未成年人的限制** | 各地规则不同，必须和法务确认 |

> **给制作人的一条硬建议**：**不要在概率上做任何"小动作"**——比如对特定玩家动态调整概率、首抽必中之后暗中降低后续概率、公示概率与实际不符。
>
> 这类做法一旦被玩家用大样本统计出来（他们一定会统计），产品的信任会瞬间崩塌，而且现在的法律风险是实质性的。**这不是道德劝告，是风险管理。**

**一个合规且有效的替代方案**：如果你想给新玩家更好的体验，就**公开地**给——"新手池前 10 抽必出 5 星"，写在公告里。效果一样，风险为零。

## 6. 掉落系统：同样的数学，不同的场景

关卡掉落、装备打造、宝箱开启，本质上都是同一套数学，但有几个额外考虑：

| 场景 | 特点 | 建议机制 |
|---|---|---|
| **高频低价值**（普通掉落） | 每天几百次 | PRD 或纯随机都行，方差会被大数定律抹平 |
| **低频高价值**（稀有装备） | 玩家会记住每一次 | **必须有保底**，且计数可见 |
| **强化/升星** | 失败有挫败感 | 失败累积成功率（本质是 PRD），或"失败不降级"保护 |
| **多目标收集**（集齐 N 种） | 优惠券收集者问题 | 后期会极度缓慢，**必须提供定向兑换渠道** |

**最后一条值得展开**：集齐 N 种不同物品所需的期望次数是 `N × (1 + 1/2 + ... + 1/N) ≈ N ln N`。收集到最后几个会慢得离谱——集齐 50 种大约需要 225 次而不是 50 次。

**所以任何"集齐一套"的设计都必须配一个定向获取渠道**（碎片兑换、自选箱），否则尾部体验会崩掉。这也是"碎片系统"存在的根本原因。
