# 08 - 回收设计

> **本章目标**：这是整门课最重要的一章。行业里绝大多数经济事故的唯一原因就是回收不足。学完你应该能设计出**没有上限的 sink**，并判断一份方案的回收结构撑不撑得住三年。
> **本章有模型**：`models/m08_sinks.py`

---

## 1. 为什么回收比投放难十倍

投放很容易设计——加个奖励就行，玩家还会感谢你。回收难，难在三个地方：

**① 玩家天然厌恶失去。** 第 02 章的损失厌恶：失去的痛苦是获得的快乐的两倍多。所以同样一笔资源，"给你 100"和"扣你 100"在玩家心里不是对称的，后者的负面情绪是前者正面情绪的两倍。

**② 回收必须伪装成获得。** 好的 sink 从来不叫"回收"，它叫"强化"、"升级"、"抽卡"、"建造"。**玩家必须觉得自己是在换取什么，而不是在被拿走什么。**

**③ 最难的一点：回收的规模必须跟着投放一起增长。**

这是新手最容易漏掉的。投放是随着玩家等级指数增长的，如果你的 sink 是固定的（"修理费 100 金币"）或有上限的（"建筑最高 20 级"），那么随着时间推移，**回收占投放的比例必然趋近于零**。

> **绝大多数经济崩盘不是因为"投放太多"，而是因为"回收有天花板而投放没有"。**

第 00 章的实验 A 已经演示过一次。本章要给出系统的解法。

## 2. sink 分类学

按**玩家的感受**分类，因为这决定了它能被接受到什么程度。

| 类型 | 机制 | 玩家感受 | 能否无上限 | 例子 |
|---|---|---|---|---|
| **成长消耗** | 资源换永久属性 | 最愉快 —— "我变强了" | **看设计**（关键） | 升级、强化、突破、科技 |
| **概率消耗** | 资源换随机结果 | 刺激 + 挫败 | **天然无上限** | 抽卡、开箱、锻造 |
| **损耗** | 按比例持续消失 | 温和，习惯后无感 | **天然无上限** | 兵损、耐久、维修、饲料 |
| **时限失效** | 到期清零 | 焦虑（损失厌恶） | 天然无上限 | 限时代币、赛季货币、时装租期 |
| **税** | 交易/转移时抽成 | 几乎无感 | **天然无上限** | 交易税、拍卖手续费、公会抽成 |
| **门票** | 参与活动的入场费 | 可接受 | 可以 | 副本门票、报名费、挑战券 |
| **炫耀性消费** | 换外观/称号/特权 | 愉快，且无副作用 | 可以 | 时装、坐骑、称号、特效 |

### 2.1 判定一个 sink 是否合格

三个必须通过的检查：

**检查 1：它真的让资源消失了吗？**（第 03 章）——如果资源换成了另一种资源，那是转换器不是 sink。

**检查 2：它有上限吗？**——有上限的 sink 迟早会失效。

**检查 3：它的规模会随投放一起增长吗？**——这是最容易漏的一条。

## 3. 跑模型：四种回收策略的 360 天对比

```bash
cd models && python m08_sinks.py
```

同一套投放，四种 sink 策略：

```
方案                        末存量    回收率  存量/日产  末等级
---------------------------------------------------------------
A 有上限（12级封顶）        904,576   29.2%    238.3     12
B 无限层级                  119,916   91.4%     25.0     16
C 比例损耗（每天 6%）         31,333   95.6%     15.7      1
D 混合（层级 + 损耗）         49,941   95.5%     15.7      9
```

### 3.1 方案 A：有上限——灾难

第 120 天左右升到 12 级封顶，之后 240 天**回收完全归零**。最终回收率只有 29.2%，存量堆到相当于 **238 天的产出**。

这时候的服务器是什么样？每个玩家兜里揣着八个月的产量，你卖任何资源礼包都没人买，你出任何新内容都会被瞬间打穿，你的定价体系全线失效。

**而且这个过程是不可逆的**——你不可能把已经发出去的资源收回来。

### 3.2 方案 B：无限层级——可行但不够好

成本按 `1.35^L` 指数增长且永不封顶，回收率 91.4%。**这是大多数游戏的主力 sink 形态**：升级、强化、突破，层数无限往上加。

它的问题是**锯齿越来越大**（看图 ① 的蓝线）：后期玩家要攒很久才能升一级，攒的过程中存量持续走高。第 00 章第 5 节讲过这个"牙缝变宽"的体验问题。

而且它有一个隐藏的运营成本：**你必须持续产出新层级**。玩家推到当前上限时，如果新版本没跟上，方案 B 就退化成方案 A。

### 3.3 方案 C：比例损耗——数学上最优雅

每天损失存量的 6%，回收率 95.6%，存量稳定在 **15.7 天的产出**。

**它会自动收敛到一个平衡点**，推导很简单：

```
设日产出 I，损耗率 d，稳态存量 gold*
gold* = (gold* + I) × (1 − d)
=> gold* = I × (1−d)/d
```

代入 `d = 6%`：`(1−0.06)/0.06 ≈ 15.7` 天的产出。模型实测 **15.7，完全吻合**。

**三个了不起的性质**：

1. **自动伸缩**。投放涨十倍，存量的平衡点也涨十倍，但"存量相当于几天产出"这个比值**恒定不变**。你不需要随版本调整任何参数。
2. **永不失效**。没有上限，不需要你持续产出新内容来喂它。
3. **玩家无感**。持续的小额损耗比一次性大额扣除的心理冲击小得多。

**它的缺点也很明显**：纯损耗不提供成长感（方案 C 的等级停在 1 级）。**所以它不能单独使用。**

### 3.4 方案 D：混合——真实游戏的做法

层级消耗（提供成长感）+ 比例损耗（提供稳定的回收底盘）。回收率 95.5%，存量稳定在 15.7 天，同时等级正常增长到 9 级。

> **这是本章的核心结论：你需要至少一个"无上限的比例型 sink"作为底盘，再叠加层级型 sink 提供成长感。**
> 只有层级型 sink 的经济，迟早会因为内容产能跟不上而退化成方案 A。

注意方案 D 的末等级（9）低于方案 B（16）——**这是必要的代价**。损耗吃掉了一部分本可以用于成长的资源。设计时要把这部分算进投放预算（第 07 章）。

## 4. 「存量 / 日产出」：真正的通胀温度计

看图 ③。这个无量纲指标比"存量的绝对值"有用得多：

> **存量 ÷ 当前日产出 = 玩家兜里的钱相当于几天的收入**

为什么它更好用：

- **绝对值没有可比性**。第 10 天的 10 万金币和第 300 天的 10 万金币完全是两回事；
- **它跨版本可比**。数值膨胀 100 倍之后，这个比值仍然可以和历史对比；
- **它直接对应玩家的主观感受**：这个数越大，玩家越觉得"钱多得花不完"。

一个经验参考区间 `【推导】`：

| 存量/日产出 | 状态 |
|---|---|
| < 3 天 | 过紧。玩家永远缺钱，容易挫败 |
| **5~20 天** | **健康区间**。有攒钱的目标感，也不至于浮财泛滥 |
| 20~60 天 | 偏松。开始出现"钱没处花"的反馈 |
| > 60 天 | 通胀。定价体系正在失效 |

**这是你在数据看板上应该盯的第一个经济指标**（第 23 章）。而且要**分层看**——大 R 的这个数往往是免费玩家的十倍以上，这本身就是一个重要信号（见第 6 节）。

## 5. 实证：EVE Online 的回收结构

EVE 是全行业唯一可长期追踪的真实虚拟经济样本——CCP 雇了专职经济学家，**逐月公开** ISK 的投放、回收、物价指数，到 2026 年仍在更新。`【实证】`

**最值得学的一点**：EVE 最大的 ISK sink 不是某个消费项目，而是**交易税和经纪费**——两者合计常年位居回收榜首。

而交易税的形式是：**销售额的 7.5%**（通过 Accounting 技能最低可降到 3.37%）。

> **注意这是一个比例，不是一个固定数。**

这正是第 3.3 节那个原理的真实世界验证：**EVE 之所以能运转二十年而经济不崩，很大程度上是因为它最大的 sink 是自动伸缩的。** 物价涨十倍，税收也涨十倍，不需要 CCP 做任何调整。

这个结构对你的启示：

1. **如果你的游戏有交易系统，交易税就是你最好的 sink**——它规模自动跟随经济体量，且玩家几乎无感（第 10 章会讲税率怎么定）；
2. **如果没有交易系统（大多数 SLG 和卡牌），你必须找到别的比例型 sink**——下一节讲 SLG 的答案。

**可查的数据源**：
- 官方月报：[EVE Online 新闻页](https://www.eveonline.com/news)搜 "Monthly Economic Report"，每月一篇，附原始数据文件
- 第三方历史查询：[Adam4EVE 的 Sinks/Faucets History](https://www.adam4eve.eu/mer_sinks_faucets.php)

**强烈建议你现在就去翻一份月报。** 看真实经济体的投放回收表长什么样，比读十篇教程有用。

## 6. SLG 的答案：兵损

SLG 大多没有自由交易（第 10 章会讲为什么），所以用不了交易税。它的比例型 sink 是**兵损**——打仗必然损兵，损兵就要重新训练，训练就要消耗资源。

**为什么兵损是一个近乎完美的 sink：**

| 性质 | 说明 |
|---|---|
| **按比例** | 损失量正比于参战部队规模 → 自动伸缩 |
| **无上限** | 只要还在打仗，就一直在消耗 |
| **规模跟随投放** | 玩家越强、兵越多、损失越大 |
| **玩家不反感** | 打仗死人是天经地义的，不需要任何包装 |
| **同时是负反馈** | 兵越多损失越多，自动收敛（第 03 章 5.2 节） |
| **推动核心玩法** | 想回收就得打仗，而打仗正是你希望玩家做的事 |

**最后一条是精髓**：绝大多数 sink 是"消耗资源"，而兵损是"消耗资源的同时产生玩法"。它把经济需求和玩法需求统一了。

**兵损的两个关键参数：**

**① 损失比例。** 太低则回收不足；太高则玩家不敢打仗，整个战争系统被冻结。这是 SLG 数值里最敏感的参数之一。

**② 死亡 vs 重伤的比例。** 现代 SLG 通常把损失拆成"彻底阵亡"和"进医院可治疗"两部分：

- 彻底阵亡 → **真 sink**，资源永久消失；
- 重伤可治疗 → **只是延迟和部分损耗**，治疗要花资源和时间。

调节这两者的比例，就是在调节"回收强度"和"玩家参战意愿"之间的平衡。伤兵营容量上限则是另一个旋钮——超出容量的伤兵直接阵亡，这变相惩罚了"一次性投入过多兵力"的莽撞打法。

> **率土-like 的兵役/征兵冷却是同一个思路的另一种表达**：不是让你损失资源，而是让你损失"时间"——而时间是不可购买的（第 06 章），所以它同时是 sink 和公平性保障。

## 7. 大 R 的 sink 问题

第 00 章实验 C 的那个发现，现在可以正式讨论了：**大 R 的资源溢出比免费玩家严重得多，回收率反而更低。**

原因是结构性的：**你的 sink 是按免费玩家的资源量设计的。** 一个消耗 10 万金币的强化，对免费玩家是三天的积蓄，对大 R 是十分钟的零头。

后果有三个，一个比一个严重：

1. **大 R 的资源没处花** → 他会觉得"充钱没意义"；
2. **他会去找别的出路** → 黑市、代练、跨服交易、工作室（第 24 章）；
3. **最终流失** → "我充了钱却没什么可买的"是高付费用户流失的头号原因之一。

**解法是设计"深度 sink"——专门吃高付费玩家资源的回收口：**

| 手段 | 说明 | 风险 |
|---|---|---|
| **超线性成本曲线** | 高等级的强化成本增速陡然提高 | 中低付费玩家会撞墙，要设计好分界点 |
| **概率型深度消耗** | 高阶强化有失败率、可降级 | 挫败感强，需要保底（第 13 章） |
| **炫耀性消费** | 顶级外观、称号、专属特效 | **最安全**，不影响战力平衡 |
| **组织性消耗** | 联盟建设、集体项目需要大额捐献 | **一举两得**：回收 + 提升大 R 的组织地位 |
| **竞争性消耗** | 拍卖限量物品、排名争夺战 | 只在有足够多大 R 时有效 |

**最后两条是 SLG 的最优解。** 让大 R 把资源投进联盟建设，他获得的是**地位和影响力**——这恰好是他真正想要的东西（第 02 章：大 R 的主导动机是 Power + Competition，不是资源本身）。

> **这就是第 02 章那条原理的应用：转换链条末端的锚点必须是玩家真正在乎的东西。**
> 对大 R 来说，"更多资源"早就不是锚点了，"被人需要、说了算"才是。

## 8. 回收不足的诊断清单

拿到一份经济方案，或者接手一个线上项目，按顺序检查：

- [ ] **每种资源都有 sink 吗？**（孤儿资源检查，第 03 章）
- [ ] **每个 sink 有上限吗？** 列出所有有上限的 sink，估算触顶时间
- [ ] **有没有至少一个比例型（无上限、自动伸缩）的 sink？** 没有就是定时炸弹
- [ ] **回收率跑满 360 天是多少？** 低于 85% 要警惕
- [ ] **「存量/日产出」的曲线是收敛还是发散？** 发散 = 通胀已经开始
- [ ] **分层看**：大 R 的「存量/日产出」是免费玩家的几倍？超过 5 倍要设计深度 sink
- [ ] **主力 sink 依赖内容产能吗？** 如果 sink 全是层级型，你的内容产出速度就是经济的生命线
- [ ] **付费买的东西进入了哪个 sink？** 如果付费直接买资源而资源没有对应 sink，那是纯通胀
