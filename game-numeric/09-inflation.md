# 09 - 通货膨胀与经济健康

> **本章目标**：学会诊断一个线上经济体是否健康。学完你应该能说清楚该监控哪几个指标、服务端要埋什么日志、以及发现通胀之后有哪些治理手段可用（按代价从低到高）。
> **本章有模型**：`models/m09_inflation.py`

---

## 1. 游戏通胀不是"数字变大"

先纠正一个常见误解。数值膨胀（战力从 1 万涨到 1 亿）**不是通货膨胀**，那只是计量单位的变化，第 04 章讲过它是维持成长感的必然。

**通货膨胀是购买力的下降**：

> 同样一份劳动（打一小时怪），换到的**真实价值**（能买到多少稀缺物品）变少了。

判断标准不看货币数量，看**兑换比**：

| 现象 | 是不是通胀 |
|---|---|
| 全服金币总量从 1 亿涨到 100 亿 | **不一定**。如果同期玩家数和商品供给也涨了 100 倍，购买力没变 |
| 一件顶级装备的市价从 1 万涨到 100 万 | **是**（如果玩家的日收入没涨 100 倍） |
| 玩家的日产出从 1 千涨到 10 万 | **不是**，这是正常的成长曲线 |
| 玩家兜里的存量相当于 200 天的产出 | **是**，浮财泛滥 |

## 2. 通胀有两个独立来源

```bash
cd models && python m09_inflation.py
```

```
场景                        末货币量      物价涨幅   存量/日产
--------------------------------------------------------
A 回收 6% + 供给跟随     245,398,008      1.1×      13.9
B 回收 6% + 供给固定     245,398,008     15.8×      13.9
C 回收 2% + 供给固定     621,302,385     24.3×      35.3
```

**注意 A 和 B 的对比——这是本章最重要的发现：**

> **场景 B 的「存量/日产出」是健康的 13.9 天，但物价涨了 15.8 倍。**

A 和 B 的货币总量完全一样，回收率也一样。唯一的区别是：A 的稀缺商品供给随经济体量一起增长，B 的供给固定不变。

所以：

| 来源 | 机制 | 治理手段 |
|---|---|---|
| **货币侧通胀** | 投放 > 回收，货币总量膨胀 | 加 sink（第 08 章） |
| **供给侧通胀** | 稀缺商品的供给跟不上货币增长 | **增加商品供给**，或增加新的消费出口 |

### 2.1 这修正了第 08 章的说法

第 08 章说「存量/日产出」是"该盯的第一个经济指标"。现在你知道**它不够**——它只能发现货币侧通胀，对供给侧通胀完全失明。

> **必须同时监控三个指标，缺一不可：**
>
> 1. **存量 ÷ 日产出** —— 货币侧的水位（第 08 章）
> 2. **物价指数** —— 玩家实际感受到的购买力
> 3. **货币流速** —— 钱是在流转还是在囤积

### 2.2 供给侧通胀在真实项目里长什么样

这是最容易被忽略的一类事故，因为所有的货币指标都是绿的。典型形态：

- **稀缺物品的产出量是硬编码的**（"每天全服掉落 100 个"），而玩家数量和财富在增长；
- **顶级材料只从固定的几个副本产出**，副本每天次数有限，供给天然封顶；
- **限量道具**（一天卖 5 个的商店商品），供给恒定但需求指数增长。

**症状**：玩家抱怨"什么都买不起"、"物价疯了"，但你看货币存量指标一切正常。

**解法通常不是加 sink，而是加供给**——增加产出渠道，或者提供替代品。**加 sink 反而会让玩家更买不起。**

> **诊断口诀：存量高 → 加回收；物价高但存量正常 → 加供给。**

## 3. 三个核心指标怎么算

### 3.1 存量 ÷ 日产出

```
指标 = 全服该货币总存量 / 全服该货币的日投放量
```

第 08 章讲过，健康区间 **5~20 天**。**必须分层看**——大 R 和免费玩家的这个数差十倍是常态，混在一起算会掩盖问题。

### 3.2 物价指数

**如果有玩家市场**：选一篮子代表性商品（像 CPI 那样），加权计算它们的成交均价，以某个基准日为 100。EVE 就是这么做的（它公布 Mineral Price Index、Ship Price Index 等多个分项指数）。

**如果没有玩家市场**（大多数 SLG 和卡牌），用**影子价格**：

```
影子物价 = 玩家获得 1 单位"目标物"所需的资源量
```

比如"练 1 万兵需要多少粮"、"把一个英雄升 1 级需要多少经验"。这个数如果在涨，说明玩家的实际购买力在降。

**更实用的一个替代指标**：

```
达标时长 = 玩家从 A 状态到 B 状态所需的天数
```

比如"从 40 级到 50 级的中位数天数"。这个数逐月拉长，就是购买力在下降。**它的好处是直接对应体验**，而且不需要市场系统。

### 3.3 货币流速

```
流速 V = 当期交易/消费总额 / 当期平均货币存量
```

来自费雪方程 `MV = PQ`。它衡量的是"钱转得快不快"：

| 流速 | 含义 | 风险 |
|---|---|---|
| 高 | 钱一到手就花掉 | 健康，但要确认玩家不是被逼着花 |
| **下降** | 玩家开始囤积 | **危险信号**——通常意味着"没有值得买的东西"或"在等版本" |
| 极低 | 货币淤积 | 经济停滞，任何新投放都会直接变成浮财 |

**流速下降是通胀的先行指标**，通常比物价上涨早一到两个月出现。原因很直观：玩家发现钱没处花 → 停止消费 → 存量堆积 → 之后一旦出了新消费点，堆积的存量会一次性冲击物价。

## 4. NPC 固定价格：一个经典事故

看模型的图 ④。NPC 商店以固定价 8,125 卖某物品：

```
A 回收 6% + 供给跟随    360 天内未被套利
B 回收 6% + 供给固定    第 72 天起市场价超过 NPC 固定价 → 套利开始
C 回收 2% + 供给固定    第 30 天起市场价超过 NPC 固定价 → 套利开始
```

**一旦市场价超过 NPC 固定价，NPC 商店就从"sink"变成了"faucet"**：玩家可以无限地从 NPC 买入、在市场卖出，凭空产生利润。

这个事故的恶劣之处在于**它会自我加速**：套利产生更多货币 → 通胀加剧 → 套利空间更大。而且它通常是工作室最先发现的（第 24 章）。

**三条防范措施**：

1. **NPC 商店的售价不要固定**，挂钩某个动态基准（近期市场均价、玩家平均日产出、版本系数）；
2. **NPC 收购价（回收方向）也同理**——如果 NPC 以固定价收购玩家的东西，通缩时它会变成无限 sink，玩家会觉得东西全变废品；
3. **给 NPC 商品加每日限购**——限购把"无限套利"变成"有限补贴"，损失可控。

> **推广一下：任何写死在配置表里的绝对数值，都是一颗定时炸弹。**
> 经济系统里的价格、门槛、奖励，都应该表达成"相对于某个基准的比例"，而不是绝对数。

## 5. 服务端要埋什么

这一节是给你和程序团队对齐用的。**没有正确的埋点，上面所有指标都算不出来。**

### 5.1 经济流水日志

**每一笔资源变动都必须记一条**，字段至少包括：

| 字段 | 说明 | 为什么必须有 |
|---|---|---|
| `时间戳` | 精确到秒 | 时序分析 |
| `玩家ID` | | 分层统计 |
| `货币/资源类型` | | 分资源记账（第 03 章：跨资源求和无意义） |
| `变动量` | 有正负号 | |
| `变动后余额` | | **对账**：能检测出漏记的变动 |
| **`原因码`** | 枚举，如 `QUEST_REWARD` / `BUILD_UPGRADE` | **最重要的字段**，见下 |
| `来源系统` | 哪个模块触发的 | 定位问题 |
| `关联ID` | 订单号/战斗ID/任务ID | 追溯具体事件 |

**原因码是整套日志的灵魂。** 这就是第 03 章 `econ.py` 里"所有池变动都经过 `_give`/`_take` 并自动归属节点"那个设计的现实版本——有了原因码，你才能生成第 03 章那张收支平衡表。

**原因码的枚举必须在设计阶段就定好，并且和数值方案里的渠道一一对应**（第 07 章的预算表里每个渠道，就是一组原因码）。补记原因码是极其痛苦的。

### 5.2 日终快照

流水能算"流量"，但算"存量"需要快照。每日固定时间对全服玩家做一次余额快照，记录：

- 各资源的总存量、中位数、各分位数（P10/P50/P90/P99）；
- **分层的分布**（按付费档、按活跃度、按注册时间）。

**为什么要分位数而不只是平均值**：经济数据是极度长尾的，均值会被少数大 R 拉得完全失真。**P50（中位数）才代表典型玩家，P99 反映头部**，两者的比值本身就是一个重要的分化指标。

### 5.3 一个常被忽略的点

**流水日志的数据量非常大**（一个中等体量的手游每天几亿条）。设计时就要考虑：

- 热数据（近 7 天）保留全量明细，用于排查；
- 冷数据按"玩家 × 资源 × 原因码 × 天"预聚合，保留一到两年；
- 全量明细归档到廉价存储，出事故时可回捞。

**不要为了省存储而不记明细。** 经济事故的排查几乎总是需要看原始流水，而事故往往在发生几周后才被发现。

## 6. 怎么读 EVE 的月度经济报告

这是全行业唯一公开的真实虚拟经济数据源，值得你亲自去翻一次。`【实证】`

**入口**：[EVE Online 新闻页](https://www.eveonline.com/news)搜 "Monthly Economic Report"，每月一篇，附原始数据文件。历史数据可以用第三方站 [Adam4EVE](https://www.adam4eve.eu/mer_sinks_faucets.php) 查询。

**该看什么**：

| 报表 | 对应本课程 |
|---|---|
| **Top Sinks and Faucets** | 第 07、08 章。看真实经济体的投放/回收结构比例 |
| **ISK Faucets / Sinks 时序** | 本章。看两条线的间距变化 |
| **Active ISK Delta** | 净投放。持续为正 = 货币在膨胀 |
| **Price Indices**（Mineral / Ship / Module 等分项） | 本章第 3.2 节的物价指数实例 |
| **Production / Mining / Destruction Value** | 供给侧指标。第 2 节讲的供给侧通胀就靠这个诊断 |

**几条可以直接学的实践**：

1. **CCP 公布多个分项物价指数而不是一个总指数**——因为不同类别的商品通胀率差别很大，合成一个数会掩盖问题。
2. **报表里有 "Destruction Value"（毁灭价值）** ——EVE 的飞船被击毁就永久消失，这是它最大的商品 sink。**这正是 SLG 兵损的同构物**（第 08 章）。
3. **CCP 会在报告里解释异常波动的原因**（版本更新、大型战争、活动）。你的内部经济周报也该这么写——**光有数字没有解释，看的人不会有行动**。

## 7. 通缩同样致命

大家都盯着通胀，但通缩的破坏力一点不小，而且更难察觉。

**通缩的形态**：玩家的购买力持续上升，资源越来越好拿，物价下跌。

**为什么危险**：

| 后果 | 说明 |
|---|---|
| **内容被瞬间消耗** | 玩家轻易拿到一切，内容储备被打穿 |
| **付费失去意义** | 免费就能拿到，谁还买 |
| **老玩家的积累贬值** | "我攒了半年的东西现在人人都有"——这是最伤人的一类挫败 |
| **新手无差别** | 新老玩家没有区分度，成长感消失 |

**最常见的成因**：

1. **版本福利叠加**。每个版本都给"新手加速"、"回归礼包"、"追赶机制"，累积起来让后入场的玩家轻松超过老玩家。
2. **回收过度**。加 sink 加过头了，玩家永远缺钱，反而不消费（流速反常地低）。
3. **数值重置**（第 21 章）没处理好存量。

**通缩的处理比通胀难**，因为你不能把已经发出去的福利收回来。**最好的办法是不要让它发生**——每个"追赶机制"上线前都要算清楚它对老玩家积累的贬值幅度。

## 8. 治理手段清单（按代价从低到高）

发现通胀之后，按这个顺序考虑。**越靠前的手段玩家反弹越小。**

| # | 手段 | 说明 | 玩家反弹 |
|---|---|---|---|
| 1 | **出新的高价值消费点** | 新的养成线、新的强化层级、新的炫耀性商品 | **几乎为零**（玩家还会感谢你出新内容） |
| 2 | **增加稀缺商品供给** | 针对供给侧通胀（第 2 节） | 无 |
| 3 | **上调比例型 sink 的费率** | 交易税、维修费、损耗率 | 低（幅度小时几乎无感） |
| 4 | **活动奖励改发限时代币** | 到期清零 = 100% 回收 | 低 |
| 5 | **新增大额一次性 sink** | 限量拍卖、竞价活动、集体项目 | 低，且能顺带解决大 R 问题 |
| 6 | **减少活动投放** | 从预算表里扣（第 07 章） | 中 |
| 7 | **NPC 商店价格动态化** | 修补套利口（第 4 节） | 中（正在套利的玩家会闹） |
| 8 | **下调产出** | 直接砍 faucet | **高**——"策划砍产出"是舆情高发区 |
| 9 | **货币改革 / 存量削减** | 兑换成新货币、按比例削减 | **极高**，核弹级手段 |

**核心策略**（第 03 章推论三）：

> **优先加回收，而不是减投放。**
> 加回收可以包装成新内容，减投放只能被理解为削弱。

**第 1 条为什么排第一**：它同时解决了三件事——回收了浮财、给了玩家新目标、还产生了商业化机会。**一个设计得好的新养成线，本质上就是一个大型 sink。** 这也是长线运营的核心节奏（第 20、21 章）。

### 8.1 治理的时机比手段更重要

存量是流量的积分，有滞后性（第 03 章推论二）。这意味着：

- **发现问题时，问题已经积累了几个月**；
- **治理措施生效也要几个月**。

所以经济治理必须**基于趋势而不是基于现状**。看到「存量/日产出」从 12 天涨到 18 天，就该动手了——等它到 60 天，你已经只剩下第 8、9 条这种核弹选项了。
