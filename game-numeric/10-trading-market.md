# 10 - 交易与市场

> **本章目标**：这是制作人必须亲自拍板、且几乎不可逆的一个决策——**要不要开自由交易**。学完你应该能说清楚交易带来什么、代价是什么、以及为什么 SLG 大多选择不开。
> **本章有模型**：`models/m10_trading.py`

---

## 1. 一个不可逆的三岔路口

```
                    ┌──────────────────────────────────┐
                    │  玩家之间能不能转移资源和物品？     │
                    └───────────────┬──────────────────┘
          ┌─────────────────────────┼─────────────────────────┐
          ▼                         ▼                         ▼
   ┌────────────┐            ┌────────────┐           ┌────────────┐
   │  无交易     │            │  受限交易   │           │  自由交易   │
   │            │            │            │           │            │
   │ 一切绑定    │            │ 部分可交易  │           │ 几乎全可交易 │
   │            │            │ + 税 + 限额 │           │ + 拍卖行    │
   ├────────────┤            ├────────────┤           ├────────────┤
   │ 多数 SLG    │            │ 多数 MMO    │           │ EVE、传统端游│
   │ 多数卡牌    │            │             │           │            │
   └────────────┘            └────────────┘           └────────────┘
```

**为什么说不可逆**：开放容易，收回极难。一旦玩家习惯了交易，关闭交易会摧毁大量已形成的价值（囤积的商品、以交易为核心玩法的玩家、公会经济），舆情代价极高。

**反过来，从"无交易"改成"有交易"相对容易**——所以有疑虑时，默认选更保守的一边。

---

## 2. 交易带来什么

**四个真实的好处：**

| 好处 | 说明 |
|---|---|
| **经济分工** | 有人打怪、有人采集、有人做生意。**让不擅长战斗的玩家也有位置**——这是长线留存的重要来源 |
| **价格发现** | 市场价格告诉你哪些东西真的稀缺。**这是你能拿到的最真实的数值反馈**，比任何问卷都准 |
| **社交与情感连接** | 交易是最自然的社交理由，也是公会/联盟经济的基础 |
| **强大的 sink** | 交易税是自动伸缩的比例型 sink（第 08 章 EVE 的案例） |

**第二条被严重低估。** 有市场的游戏，你可以直接从成交价读出玩家对每件物品的真实估值——这相当于一套免费的、连续的、大样本的数值验证系统。EVE 的 CCP 就是靠这个来调整产出的。

## 3. 交易改变的是什么：分配规则

```bash
cd models && python m10_trading.py
```

同一批玩家（付费能力呈长尾分布），每天全服产出 300 件稀缺物品：

```
方案                        头部1%占有   基尼系数   零持有玩家
------------------------------------------------------------
A 无交易（随机掉落）              1.9%     0.17       0.0%
B 自由交易（价高者得）            35.7%     0.84      41.7%
C 绑定 50%（混合）              18.3%     0.48       0.3%
```

**核心洞察：交易本身不产生也不消灭资源，它改变的是资源的分配规则。**

- **无交易**：稀缺物品按"谁参与谁得到"分配 → 接近平均，41.7% 的人不会一无所有；
- **自由交易**：按"谁出价高谁得到"分配 → 头部 1% 拿走 35.7%，**41.7% 的玩家一件都没有**。

> **开放交易 = 把稀缺物品的分配权，从"玩法参与度"交给"支付能力"。**

这不是好坏问题，是取向问题。但你必须知道自己在选什么。

### 3.1 绑定机制是最有效的调节阀

方案 C 只是把一半物品设为绑定（不可交易），结果：

- 基尼系数从 0.84 降到 0.48（几乎腰斩）；
- 零持有玩家从 41.7% 降到 0.3%；
- 头部 1% 的占有从 35.7% 降到 18.3%。

> **"绑定比例"是你调节经济分化程度的主旋钮**，而且它是连续可调的——不像"开不开交易"那样是个二元选择。

实践中的通用规则：

| 物品类型 | 建议 |
|---|---|
| 核心成长材料（决定战力下限） | **绑定** —— 保证参与就有收获 |
| 消耗品、基础材料 | 可交易 —— 促进分工和流通 |
| 顶级/稀有装备 | 视取向；可交易则头部集中，绑定则人人有机会 |
| 付费直购的物品 | **必须绑定** —— 否则等于开放了 RMT（第 6 节） |
| 外观、称号 | 通常绑定 —— 它们的价值来自"我拥有"而非"能卖" |

## 4. 交易的代价

**四个必然出现的问题：**

### 4.1 工作室与打金

只要游戏内资源能换成游戏外的钱，就一定会出现职业打金者。这不是能不能防的问题，是规模多大的问题。

**危害不在于"他们赚钱"，而在于：**

- **他们的产出效率远高于正常玩家**（脚本 24 小时、多开、外挂），构成事实上的超额投放；
- **他们是纯 faucet**——只产出不消费，赚到的资源全部流向 RMT 市场；
- **他们会最先发现并利用一切经济漏洞**（第 09 章的 NPC 套利）。

第 24 章讲治理手段。

### 4.2 通胀加速

交易本身不增加货币，但它**提高了货币流速**，并让分散在各处的资源集中起来形成购买力。同样的货币存量，有交易的经济体物价波动更剧烈。

### 4.3 付费的意义被改变

这一点最微妙：**开放交易后，玩家的付费不再是"买内容"，而是"买别人的劳动"。**

后果是你的定价权被削弱了——你卖 648 元的礼包，玩家会拿去和"从其他玩家手上买同样东西要多少钱"作比较。**市场价成了你所有商品的天花板。**

### 4.4 数值验证的难度上升

有交易的经济体，任何一次数值调整都会通过市场传导到所有系统。你调低某个材料的产出，可能会连锁引发三个看似无关系统的价格波动。**这让"改一个数看效果"变得几乎不可能。**

## 5. 为什么 SLG 大多不做自由交易

综合上面的分析，SLG 的选择有很强的内在逻辑：

| 原因 | 说明 |
|---|---|
| **核心资源本来就是抢来的** | SLG 的资源再分配机制是**战争**，不是市场。掠夺已经承担了交易的"再分配"职能 |
| **战力必须与投入挂钩** | 如果能买卖兵和资源，大 R 可以直接收购全服产能，战争变成纯拍卖 |
| **联盟经济已经提供了分工** | 援助、捐献、集结这些定向转移，已经满足了协作需求，且**限定在组织内部**——这是关键 |
| **付费点是加速和抽将** | 这两样天然不可交易，不需要市场来定价 |
| **服务器生命周期短** | SLG 的服（尤其是赛季制）寿命远短于 MMO，市场经济来不及成熟 |

> **注意"联盟内定向转移"这个设计**：它保留了交易的社交与分工价值，同时把分化限制在组织内部，还顺带**强化了组织绑定**（你的资源只能给盟友）。
>
> **这是"受限交易"的一个极好的范式**——不是一刀切禁止，而是把交易的作用域限制在你希望强化的社会结构里。

**率土-like 的做法更进一步**：连武将都不可交易，且体力不可购买（第 01、06 章）。整套设计的一致性在于——**它要让"组织能力"而不是"付费能力"成为主导变量**。

## 6. 交易形式与税

### 6.1 五种形式

| 形式 | 机制 | 特点 | 风险 |
|---|---|---|---|
| **面对面交易** | 双方当面换 | 最灵活 | **RMT 的主要通道**，几乎无法监管 |
| **邮件附件** | 异步寄送 | 方便 | 同上，且更隐蔽 |
| **一口价寄售** | 卖家定价，先到先得 | 简单，价格透明 | 容易被脚本秒抢 |
| **拍卖行/竞价** | 出价最高者得 | **价格发现效率最高** | 加剧头部集中（第 3 节） |
| **NPC 中介收购** | 系统按固定/动态价收购 | 可控 | 定价错了就是套利口（第 09 章） |

**如果你要限制 RMT，第一件事是关掉面对面交易和邮件附件**，只保留经过系统撮合的市场——因为只有撮合市场才能留下完整的价格与流水记录，才能做异常检测。

### 6.2 交易税：你能拿到的最好的 sink

第 08 章讲过 EVE 的实证：**交易税和经纪费是它最大的 ISK sink**，形式是销售额的 **7.5%**（可通过技能降到 3.37%）。`【实证】`

它符合好 sink 的全部标准（第 08 章）：

- **按比例** → 自动伸缩，物价涨十倍税收也涨十倍；
- **无上限** → 只要还有交易就一直在回收；
- **玩家几乎无感** → 交易税是现实世界的常识，没人会觉得被针对。

**税率怎么定**：

| 税率 | 效果 |
|---|---|
| < 2% | 回收力度不足，形同虚设 |
| **3%~10%** | **主流区间**。既有回收力度，又不至于抑制交易 |
| > 15% | 开始抑制流动性，玩家转向私下交易（反而助长 RMT） |

**一个高级技巧**：把税率做成可通过玩家投入（技能、声望、公会等级）降低的——EVE 就是这么做的。这样税率本身变成了一个成长目标，玩家会主动去"优化"它，而不是抱怨它。

## 7. RMT 与工作室的经济学

**RMT（Real Money Trading）= 游戏资源与现实货币的私下交易。**

**为什么禁不掉**：只要游戏内的东西对玩家有价值，且能在玩家之间转移，就必然有人愿意用现实货币购买。**技术手段只能提高成本，不能消除需求。**

**它对经济的真实伤害：**

1. **超额投放**：工作室的产出效率是普通玩家的数十倍；
2. **纯 faucet 无 sink**：他们不消费，只变现；
3. **破坏付费转化**：本来会向你付费的玩家，转向了更便宜的 RMT；
4. **扭曲数值反馈**：市场价被工作室的供给压低，你以为某个材料不稀缺，其实只是被机器刷多了。

**几种治理思路**（第 24 章展开）：

| 思路 | 说明 |
|---|---|
| **官方化** | 提供官方的"点卡换游戏币"通道（EVE 的 PLEX 是最成功的案例），把需求引到台面上 |
| **提高转移成本** | 交易税、绑定、交易额度限制、等级门槛 |
| **提高生产成本** | 关键产出要求人工操作、行为验证、限制多开 |
| **检测与封禁** | 行为特征识别、资金流网络分析 |
| **降低需求** | 让付费路径比 RMT 更划算、更安全 |

**EVE 的 PLEX 值得单独学**：玩家可以用现实货币买 PLEX，再用 PLEX 换 ISK；也可以用 ISK 买 PLEX 来支付订阅费。这让"用钱换游戏币"完全合法且在系统内可控——**把黑市变成了官方市场**，同时 PLEX 消耗还是一个可观的 sink。

**代价**：这等于官方承认了"游戏币可以用钱买"，会改变整个游戏的价值观。**做不做这个取舍，是制作人的决策。**

## 8. 决策框架

要不要开交易？按顺序问这五个问题：

**① 你的核心竞争是什么？**
如果是"谁付费多谁强"，交易只是加速这个过程；如果是"谁组织好谁强"（SLG）或"谁技术好谁强"（竞技），**交易会稀释你的核心竞争维度**。

**② 你希望非战斗玩家有位置吗？**
需要 → 交易几乎是必须的（它是"生产者"这个身份存在的前提）。
不需要 → 交易的收益大打折扣。

**③ 你的服务器生命周期多长？**
市场经济需要时间成熟。三个月一赛季的服，市场还没形成就重置了。

**④ 你有没有能力做反工作室？**
这是持续投入，不是一次性工作。**没有专门的团队和数据能力，不要开自由交易。**

**⑤ 你的付费点会被市场价压制吗？**
如果你的主要商品是资源和材料，开放交易后你的定价权会被市场夺走。

**如果决定"部分开放"，从最保守的组合起步：**

- 只做撮合市场（关闭面对面和邮件）；
- 核心成长材料绑定；
- 付费直购物品全部绑定；
- 交易税 5% 起；
- 有交易额度和等级门槛。

**然后逐步放开。** 记住第 1 节：放开容易，收回极难。

## 9. 动手

### 9.1 改模型

**任务 A：找到你要的绑定比例。** 二分搜索 `bound_ratio`，找出让基尼系数落在 0.3~0.4 的绑定比例。这个数字给你的直观感受是什么？

**任务 B：加交易税。** 给方案 B 加一个 5% 的税（每次转移损失 5%），观察它对分配的影响。**你会发现税几乎不改变分配格局**——它是 sink，不是再分配工具。这个结论很重要：**不要指望用税来解决分化问题，那是绑定机制的活。**

**任务 C：加时间维度。** 让付费能力分布随时间变化（新玩家不断加入，老大 R 逐渐流失），看头部集中度是收敛还是发散。
