# 12 - 付费结构与玩家分层

> **本章目标**：理解 F2P 的收入到底从哪来，以及"付费深度上限"这个必须由你拍板的决策该怎么做。
> **本章有模型**：`models/m12_payment_dist.py`

---

## 1. F2P 收入的基本事实：极度长尾

```bash
cd models && python m12_payment_dist.py
```

模型用对数正态分布模拟 100 万玩家、4% 付费率的收入结构：

```
总流水 8,462,802 元   ARPU 8.46 元   ARPPU 211.6 元
付费额中位数 36 元   均值 212 元   ← 均值是中位数的 6 倍

=== 收入集中度 ===
  付费玩家 Top  0.1%（    40 人）贡献 10.9% 的流水
  付费玩家 Top  1.0%（   400 人）贡献 32.2% 的流水
  付费玩家 Top  5.0%（ 2,000 人）贡献 58.8% 的流水
  付费玩家 Top 10.0%（ 4,000 人）贡献 72.3% 的流水
```

**四个必须内化的事实：**

**① 付费额的中位数（36 元）和均值（212 元）差 6 倍。** 所以"平均每个付费玩家花 200 元"这句话是误导性的——**典型付费玩家只花了几十块**。任何用均值做的付费设计都会跑偏。

**② 4000 人（占总玩家 0.4%）贡献了 72% 的流水。** 你的商业模式实际上是由极少数人支撑的。

**③ 但这 0.4% 的人需要另外 99.6% 的人存在。** 第 02 章讲过大 R 的主导动机是 Power + Competition——**没有观众和对手，"最强"就没有意义**。这是 F2P 最反直觉、也最容易被短视决策破坏的一条。

**④ 头部数据的波动极大。** 模型里 Top 0.1% 只有 40 个人——**几个大 R 的进出就能让月流水波动 10%**。这在真实项目里意味着：不要因为单月流水波动就慌忙改数值，要看趋势和分层。

## 2. 两条增长路径

假设你要把流水提上去，有两条路：

```
=== 两条增长路径的对比（基线 = 100%）===
  付费率 4% → 5%（+25% 付费人数）      流水 129.6%
  付费率 4% → 6%（+50% 付费人数）      流水 161.9%
  加深大 R（sigma 1.9 → 2.1）        流水 149.8%
  加深大 R（sigma 1.9 → 2.3）        流水 229.4%
  提高客单价（mu +0.2，约 +22%）       流水 125.2%
```

**"加深大 R"的杠杆率明显更高**——长尾分布的性质决定了尾部拉长一点点，总量就涨很多。

**但这是一个陷阱。** 三个理由：

| 理由 | 说明 |
|---|---|
| **可持续性差** | 大 R 的付费深度不是无限的。挖到底之后没有下一步，而且他们流失时是整体流失 |
| **生态代价** | 加深大 R 通常意味着扩大战力差距 → 中小 R 和免费玩家被碾压 → 他们流失 → 大 R 失去意义（第 19 章） |
| **合规风险** | 深度挖掘的手法（高压推送、动态定价、针对性投放）正是第 02 章第 6 节那条线的另一侧 |

**"提高付费率"虽然杠杆率低，但它是健康增长**：它扩大了商业模式的基本盘，而且新增的付费玩家往往同时提升了活跃和生态。

> **实践建议：把付费率当作长期目标，把付费深度当作短期调节。**
> 如果你连续几个季度都在靠"加深大 R"来完成流水目标，说明产品的基本盘正在萎缩——这是一个先行的衰退信号。

## 3. 付费深度上限：一个必须由你拍板的决策

"最贵的东西卖多少钱"这个决策的影响，比它看起来大得多：

```
=== 付费深度上限的影响 ===
      上限     流水占比    受影响玩家
    500元     51.0%      8.27%
  2,000元     76.1%      1.65%
 10,000元     93.7%      0.14%
 50,000元     99.5%      0.01%
     无上限    100.0%      0.00%
```

**读法**：把单人付费上限设在 2000 元，只会影响 1.65% 的付费玩家，但会砍掉 **24% 的流水**。

这个表把决策的代价量化了。**权衡的两端是：**

| 高付费深度 | 低付费深度 |
|---|---|
| 流水高 | 流水低但稳定 |
| 战力差距大 → 需要更强的生态保护机制 | 战力差距小 → 生态自然健康 |
| 大 R 生命周期短（挖穿了就走） | 玩家生命周期长 |
| 舆情和合规风险高 | 风险低 |
| 适合：短周期、买量驱动的产品 | 适合：长线、口碑驱动的产品 |

**这个决策必须在立项期定**（第 01 章第 5 节），因为它决定了：数值曲线的陡峭度、战力差距的容忍范围、生态保护机制的强度、甚至美术和世界观的调性。**上线后再改，等于重做产品。**

### 3.1 上限不一定是硬的

除了直接的"单笔最高 648"，还有几种软性的深度控制：

| 手段 | 效果 |
|---|---|
| **时间货币不可购买**（第 06 章） | 硬性限制单日进度上限，钱再多也快不了 |
| **超线性成本曲线**（第 00 章实验 C） | 付费 10 倍只领先 9 级，天然压缩差距 |
| **限购**（每人每期最多 N 份） | 直接封顶，且制造稀缺感 |
| **战力上限来自不可买的部分** | 比如顶级战力需要赛季排名/组织地位 |

**第二条最优雅**：它不需要任何显式的限制，玩家花多少钱都行，但数学上差距自动收敛。**这是 SLG 数值设计的核心杠杆之一。**

## 4. 付费漏斗：三段完全不同的问题

```
   全体玩家
      │  ① 首充转化：从"没付过费"到"付过费"
      ▼
   付费玩家（4%）
      │  ② 复购：从"付过一次"到"持续付费"
      ▼
   活跃付费玩家
      │  ③ 深度：从"小额"到"大额"
      ▼
   高付费玩家（0.4%，贡献 72%）
```

**三段的瓶颈完全不同，解法也完全不同**——最常见的错误是用一段的手段去解另一段的问题。

### ① 首充转化：心理门槛问题，不是价格问题

第 02 章讲过沉没成本：**首充的真正作用不是那点钱，是把玩家从"没付过费"变成"付过费"。** 跨过这条线之后，后续付费的心理阻力急剧下降。

所以首充礼包的设计原则是：

- **价格越低越好**（6 元档是行业默认），目标是转化率不是收入；
- **价值感越夸张越好**，让玩家觉得"不买是傻子"；
- **时机要卡在玩家第一次真正需要的时候**（第一个卡点旁边，见第 20 章）。

**首充的 ROI 不该用它自己的收入衡量**，要看"首充玩家的 30 日 LTV"和"未首充玩家的 30 日 LTV"的差值。

### ② 复购：价值感问题

玩家付过一次之后不再付，通常是因为**第一次付费的体验没有兑现预期**——买了之后没感觉到明显变强，或者变强了但没有用武之地（第 02 章的"转换链条"）。

诊断方法：看首充玩家在付费后 7 天内的战力增长和活跃变化。**如果付费没有带来可感知的体验变化，复购率就上不去。**

复购的主力形态是**周期性商品**：月卡、通行证、周礼包。它们的作用是把"每次都要做决策"变成"一次决策管一个月"。

### ③ 深度：动机问题，不是价格问题

到了这一层，钱对玩家已经不是主要约束。**大 R 不付费的原因通常是"没有值得买的东西"，而不是"太贵"。**

回到第 08 章的结论：大 R 需要的是**地位、影响力、独特性**，而不是更多资源。所以深度付费的设计重心是：

- 独特性（限定、限量、专属）；
- 组织地位（联盟建设、集体项目的主导权）；
- 可见的炫耀（外观、称号、全服公告）。

## 5. 付费点分类：你在卖什么

回到第 01 章第 3 节那张表，现在可以展开了：

| 卖什么 | 对经济的影响 | 对生态的影响 | 天花板 |
|---|---|---|---|
| **资源** | 直接通胀（第 09 章） | 差距大 | 高但不可持续 |
| **时间**（加速、体力、次数） | 温和通胀 | 差距中等 | 高。**SLG 的主力** |
| **概率**（抽卡） | 不增加总量，且抽卡本身是巨型 sink | 差距大但有随机性缓冲 | 很高。**卡牌的主力** |
| **独占内容**（限定角色、赛季通行证） | 不影响资源经济 | **加速数值膨胀**（第 21 章） | 高 |
| **便利**（队列、自动化、背包格） | 几乎无影响 | 差距小 | 中等 |
| **身份**（外观、称号、特效） | **零影响** | **零差距** | 低，但可叠加 |

**一个健康的付费结构应该同时覆盖多档**，因为它们对应不同的玩家动机（第 02 章）：

- 追求 Power 的玩家买战力（资源/时间/概率）；
- 追求 Completion 的玩家买收集（抽卡/限定）；
- 追求 Community 的玩家买组织贡献；
- 追求 Creativity/身份的玩家买外观。

**只做战力付费的游戏，商业化上限会被生态承受能力锁死**——因为战力付费的深度直接换算成战力差距，而战力差距是有生态天花板的。**外观付费没有这个约束**，这是它虽然客单价低但值得做的根本原因。

## 6. 付费墙与卡点

**付费墙**是玩家不付费就无法继续的点。**在现代 F2P 里，硬付费墙基本是禁忌**——它会直接杀死免费玩家的基本盘。

**取而代之的是"软墙"（卡点）**：

```
  硬墙：不充钱过不去              → 免费玩家流失
  软墙：不充钱要多花 5 天         → 免费玩家继续玩，部分转化
  无墙：充不充钱一样快            → 没有付费动机
```

**卡点设计的三个参数**：

| 参数 | 说明 | 参考 |
|---|---|---|
| **位置** | 在进度条的哪个百分比处卡住 | **70%~90%**（第 02 章目标梯度效应） |
| **强度** | 不付费需要多等多久 | 早期 1~3 天，中期 3~7 天，后期 1~2 周 |
| **出路数量** | 除了付费还有几条路 | **至少两条**（肝、社交），否则就是硬墙 |

**"至少两条出路"是软墙和硬墙的分界线。** SLG 的经典三出路：

1. **肝**：多花时间采集/打资源点；
2. **社交**：向联盟求援（这同时强化了组织绑定）；
3. **氪**：直接买。

> 注意第 2 条：**把"求助"设计成卡点的合法出路，是 SLG 让免费玩家留存的关键机制之一**，而且它同时服务于社交动机。

## 7. 常见坑

| 坑 | 后果 | 对策 |
|---|---|---|
| 用付费均值做设计 | 严重高估典型付费玩家的能力 | 看中位数和分位数 |
| 靠加深大 R 完成流水目标 | 掩盖基本盘萎缩，且不可持续 | 把付费率作为核心指标跟踪 |
| 首充定价太高 | 转化率上不去，整个漏斗被卡死 | 首充是转化工具不是收入工具 |
| 只做战力付费 | 商业化上限被生态承受能力锁死 | 补身份/便利/收集档位 |
| 卡点只有付费一条出路 | 免费玩家流失 → 大 R 也走 | 至少两条出路 |
| 付费深度上限上线后再改 | 等于重做产品 | 立项期定 |
| 因单月流水波动而改数值 | 头部噪声本来就大 | 看趋势和分层 |

**任务 B：加入分层的战力影响。** 把付费额换算成战力（用第 00 章的对数关系：战力优势 ∝ log(付费额)），画出付费额分布对应的战力分布。**你会发现战力分布比付费分布平缓得多**——这就是指数成本曲线的作用。
