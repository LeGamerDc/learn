# 16 - 博弈论基础

> **本章目标**：学会用收益矩阵判断平衡。学完你应该明白：**平衡的判据是"均衡使用率"，不是"胜率"**——这两者的差别会让你避开新手最常犯的平衡错误。
> **本章有模型**：`models/m16_game_theory.py`

---

## 1. 两种截然不同的平衡问题

Schreiber 和 Romero 在《Game Balance》里把平衡问题分成两类，这个分法非常有用：

| | **传递性（Transitive）** | **非传递性（Intransitive）** |
|---|---|---|
| 结构 | A > B > C，可以排出全序 | A 克 B，B 克 C，C 克 A，循环 |
| 例子 | 铁剑 < 钢剑 < 秘银剑 | 石头剪刀布、兵种克制 |
| 平衡工具 | **成本曲线**（更强就更贵） | **收益矩阵 + 博弈论** |
| 平衡目标 | 性价比大致相等 | 均衡使用率大致相等 |
| 本课程位置 | 第 04、05 章 | **本章** |

**传递性平衡的核心是"性价比"**：强的东西应该更贵、更难得到。第 04 章的成本曲线就是干这个的。它的失败形态是"某个东西又强又便宜"。

**非传递性平衡的核心是"循环"**：没有绝对最强，只有相对克制。它的失败形态是"循环被打破，出现了绝对占优的选项"。

**几乎所有游戏都是两者的混合**：兵种之间是非传递的（克制关系），同一兵种的不同等级之间是传递的（高级更强也更贵）。

## 2. 用收益矩阵求均衡

```bash
cd models && python m16_game_theory.py
```

模型把"我方兵种 × 敌方兵种"的胜率矩阵转成零和博弈，用线性规划求**混合策略纳什均衡**。

**均衡使用率的含义**：玩家在充分博弈、互相摸清底细之后，各兵种实际的使用比例。它是一个**预测**——预测这套数值上线三个月后玩家会怎么玩。

### 2.1 场景 ①：对称三角克制

```
              步兵    骑兵    弓兵
      步兵     50%    65%    35%
      骑兵     35%    50%    65%
      弓兵     65%    35%    50%

均衡使用率：步兵 33.3%  骑兵 33.3%  弓兵 33.3%
```

完美对称，各 1/3。这是标准的石头剪刀布。

### 2.2 场景 ②：把骑兵调强 5%

```
均衡使用率：步兵 44.4%  骑兵 33.3%  弓兵 22.2%
```

**一次 5% 的改动，让使用率从 33/33/33 变成了 44/33/22。**

注意一个反直觉的地方：**被调强的骑兵，使用率并没有上升（还是 33.3%），反而是克制骑兵的步兵涨到了 44.4%。**

这是博弈均衡的典型反应——**增强一个单位，最大受益者往往是它的克星**（因为大家都开始出骑兵，所以出步兵变得更有价值）。

> **实践含义：改动某个兵种的数值时，去看它的克星的使用率，而不是它自己的。**
> 这也是为什么"我们把 A 削弱了，为什么 A 的使用率没降"这种困惑在真实项目里很常见。

### 2.3 场景 ③：策略坍缩

新增一个"重甲"，对三个旧兵种的胜率都是 **55%**（看起来只强一点点）：

```
均衡使用率：步兵 0%   骑兵 0%   弓兵 0%   重甲 100%
```

**胜率 55%，使用率 100%。** 其余三个兵种全部归零，变成废设计。

> **这是本章最重要的一个数字对比。** 新手看到"55% 胜率"会觉得"稍微强一点点，可以接受"，
> 但博弈均衡的结论是：**只要它对所有选项都占优（哪怕只有 1%），它的均衡使用率就是 100%。**

这就是**占优策略（dominant strategy）**。第 01 章讲过的"所有人玩法趋同"，数学上就是这件事。

**推论：非传递性系统的平衡容差极小。** 你不能说"55% 和 50% 差不多"——在博弈意义上，它们的差别是 100% 和 33%。

## 3. 一个不那么显然的定律：支撑集的奇偶性

场景 ④ 尝试修复：给重甲一个克星（弓兵对重甲 62%）。结果：

```
均衡使用率：步兵 33.3%  骑兵 33.3%  弓兵 33.3%  重甲 0%
```

**重甲从"独霸"变成了"没人用"，还是没救活。**

模型的场景 ⑥ 揭示了原因。随机生成对称克制矩阵，统计"实际被使用的兵种数"：

```
  4 个兵种 → 被使用的数量分布：{1: 106, 3: 94}
  5 个兵种 → {1: 65, 3: 121, 5: 14}
  6 个兵种 → {1: 43, 3: 121, 5: 36}
```

**永远是奇数。从来没有出现过 2、4、6。**

这不是巧合，是一个数学事实：

> **对称零和博弈（收益矩阵反对称）的纳什均衡，其支撑集的大小必为奇数。**
>
> 直觉版的理由：反对称矩阵的秩必为偶数，而均衡支撑集的大小与矩阵的秩差 1。

**这条定律对兵种设计的直接含义：**

⇒ **偶数个兵种的纯克制系统，注定会有至少一个兵种没人用。**

这解释了一个在真实项目里非常常见、但很少被正确归因的现象：**每次加新兵种/新职业，总有一个变成"版本弃子"，而且怎么调数值都调不好。** 团队通常会归因于"数值没调好"，实际上是结构性的。

**三种解法：**

| 解法 | 说明 |
|---|---|
| **把数量设计成奇数** | 场景 ⑤ 的五兵种循环，均衡是漂亮的 20% × 5 |
| **引入造价差异** | 打破零和：贵的兵种胜率高但性价比未必高（回到传递性平衡） |
| **引入情境价值** | 不同地形/关卡/阵容下矩阵不同，玩家需要带多套（第 4 节） |

**第三种是现代游戏的主流做法**，也最有设计空间。

## 4. 打破零和：让"废兵种"活过来

纯零和克制的世界里，均衡是残酷的。但真实游戏有大量零和之外的因素，它们都是设计工具：

| 因素 | 怎么打破零和 | 例子 |
|---|---|---|
| **造价 / 产能** | 强的兵贵，弱的兵能量产 | 便宜兵种在"消耗战"中性价比更高 |
| **情境（地形/关卡）** | 不同场景用不同的收益矩阵 | 攻城用步兵，野战用骑兵 |
| **组合效应** | 兵种之间有加成 | 弓兵 + 盾兵的组合大于各自之和 |
| **信息不对称** | 你不知道对方带了什么 | 侦察的价值来源（第 18 章） |
| **时间成本** | 训练/行军速度不同 | 快速兵种在抢资源点时有独特价值 |
| **非战斗用途** | 采集、运输、建造 | 让"弱"兵种有战斗之外的位置 |

> **设计原则：当一个选项在纯战斗矩阵里必然失败时，给它一个战斗之外的理由。**

这条原则在 SLG 里尤其重要，因为 SLG 的兵种同时承担战斗和生产职能，天然有多维价值。

## 5. 判据：用均衡使用率，不用胜率

这是本章最实用的一条结论：

> **胜率 50% 不代表平衡。一个没人用的兵种，胜率也可以是 50%。**

| 你在看的指标 | 问题 |
|---|---|
| **胜率** | 有严重的**选择偏差**——用某兵种的往往是老手或者克制对手时才用 |
| **出场率 / 使用率** | 好得多，但受版本推荐、UI 位置、获取难度影响 |
| **均衡使用率（理论）** | 排除了上述干扰，是纯数值结构的预测 |

**实践做法：把三者对照着看。**

| 现象 | 诊断 |
|---|---|
| 实际使用率 ≈ 理论均衡使用率 | 玩家已经博弈到位，数值结构就是你看到的样子 |
| 实际使用率 ≫ 理论值 | 玩家高估了它（可能因为帅、易得、被攻略推荐） |
| 实际使用率 ≪ 理论值 | **玩家没发现它的价值**——这是引导问题，不是数值问题 |
| 某兵种理论均衡 = 0 | **结构性废设计**，调数值救不了，要改克制网络或加情境价值 |

**最后一条是本章的核心工具价值**：它能让你在上线前就发现"这个新兵种注定没人用"，而不是等三个月后看数据。

## 6. 游戏里的其他经典博弈结构

除了克制关系，还有几种博弈结构在游戏里频繁出现，尤其是 SLG。它们会在第 18、19 章反复出现。

### 6.1 囚徒困境：为什么停战协议总是破裂

两个联盟约定互不侵犯。对每一方：

|  | 对方守约 | 对方偷袭 |
|---|---|---|
| **我守约** | 都发展（中，中） | 我被打（**最差**，最好） |
| **我偷袭** | 我占便宜（最好，最差） | 互相消耗（差，差） |

**偷袭是占优策略**——不管对方怎么做，我偷袭都更好。所以纳什均衡是"互相偷袭"，尽管"都守约"对双方都更好。

**设计上的应用**：

- 如果你**希望**联盟之间持续冲突（这是 SLG 的核心玩法），囚徒困境结构是你的朋友，不需要修；
- 如果你希望长期同盟能形成，就必须提供**破除困境的机制**：重复博弈（长期对局让声誉有价值）、可置信承诺（正式同盟协议 + 系统惩罚背叛）、外部威胁（第三方强敌）。

> **重复博弈是关键**：一次性博弈里背叛是最优的，多次重复博弈里合作可以成为均衡。
> **这就是为什么赛季长度会显著影响外交生态**（第 22 章）——赛季太短，大家都在玩"最后一轮"，合作无从建立。

### 6.2 公地悲剧：共有资源点被打空

联盟共有的资源点，每个成员都想多采一点。个体最优 = 尽量多采，集体最优 = 节制。结果是资源点被迅速采光。

**设计上的应用**：

- 想制造联盟内部矛盾 → 保留公地结构（它是很好的社交话题和管理挑战）；
- 想避免 → 明确产权（分配到人）、配额制、或者让资源点可再生且再生速度与"节制程度"挂钩。

**SLG 常见的做法是"半公地"**：资源点归联盟，但采集需要占领和保护，从而把"采多少"的问题变成了"能守住多久"的问题。

### 6.3 协调博弈：集结时间与选边站

两个玩家都想一起行动，但选哪个时间/目标无所谓，**只要一致**。

|  | 对方选 A | 对方选 B |
|---|---|---|
| **我选 A** | 好，好 | 差，差 |
| **我选 B** | 差，差 | 好，好 |

有两个纳什均衡，问题是怎么协调到同一个。

**设计上的应用**：这正是**指挥系统、集结按钮、语音频道**存在的意义——它们是协调机制。**协调成本越低，大联盟的优势越大。** 如果你想让小联盟有生存空间，就要提高大规模协调的成本（比如限制集结人数、增加集结耗时）。

### 6.4 鹰鸽博弈：打还是不打

|  | 对方鹰（打） | 对方鸽（退） |
|---|---|---|
| **我鹰** | 两败俱伤 | 我全拿 |
| **我鸽** | 我退让 | 平分 |

均衡是混合策略——**一定比例的冲突是均衡的一部分，不是设计失败**。

**设计上的应用**：如果你的 SLG 里"从不开战"，说明鹰的收益太低（战损太重、收益太少）；如果"永远在打"，说明鸽的收益太低（不打就活不下去）。**调节战损率和掠夺收益，就是在调这个矩阵**（第 08、18 章）。
