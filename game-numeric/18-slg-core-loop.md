# 18 - SLG 的核心博弈

> **本章目标**：这是全课程 SLG 部分的核心。学完你应该能说清楚 COK-like 和率土-like 两条路线的数值差异从何而来，以及**哪几个参数决定了你的服务器是"人多的赢"还是"钱多的赢"**。
> **本章有模型**：`models/m18_slg_alliance.py`

---

## 1. SLG 的核心循环

```
       ┌──────────────────────────────────────────────────┐
       │                                                  │
       ▼                                                  │
  ┌─────────┐    需要资源    ┌─────────┐   需要地盘   ┌─────────┐
  │  发展    │──────────────►│  出兵    │────────────►│  占地    │
  │ 城建/科技 │                │ 采集/攻击 │              │ 资源点/领土│
  └─────────┘◄──────────────└─────────┘◄────────────└─────────┘
       ▲          产出资源          │       战损          │
       │                           │                    │
       │                           ▼                    ▼
       │                     ┌─────────┐          ┌─────────┐
       └─────────────────────│  补兵    │◄─────────│  被打    │
              消耗资源        └─────────┘   损失    └─────────┘
                                                        ▲
                                                        │
                                                 ┌─────────────┐
                                                 │  同盟        │
                                                 │ 组织/协调/外交 │
                                                 └─────────────┘
```

**和其他品类最大的不同**：SLG 的资源不只来自系统投放，还来自**从其他玩家那里转移**（掠夺、占地）。这意味着：

> **SLG 的经济系统和博弈系统是同一个系统。** 你调经济参数就是在调博弈规则，反之亦然。

这是本章存在的理由，也是 SLG 数值比其他品类难的根本原因。

## 2. 两条路线的结构对比

先把第 01 章那张表展开。**注意：结构性判断是 `【实证】`（游戏内可直接验证），具体配比是 `【推导】`。**

| 维度 | **COK-like**（万国觉醒等） | **率土-like**（率土之滨、三战等） |
|---|---|---|
| **地图关系** | 主城可自由迁移，位置弱绑定 | **土地连通性是核心**，需要"铺路"逐格推进 |
| **资源获取** | 采集资源点 + **掠夺其他玩家** | **占领土地持续产出**，掠夺次要 |
| **失败代价** | 损兵 + 被抢资源，可迁城逃跑 | 损兵 + **失地断粮**，跑不掉 |
| **战斗单位** | 兵种数量为主，武将提供 buff | **武将为主体，兵力是武将的 HP + 伤害加成** |
| **兵种克制** | 有，但通常影响较小 | **骑克步、步克弓、弓克骑**，三角克制显著 |
| **单日行动上限** | 主要受资源和队列限制 | **武将体力**，只随时间恢复、不可购买 |
| **付费买什么** | 资源、加速、兵、T5 解锁 | **主要买抽将**，兵和体力买不到 |
| **付费战力优势** | 大 | **中等**（体力上限锁死了单人产能） |
| **主导变量** | 付费能力 | **组织能力** |
| **长线手段** | 不断加新养成线 | **赛季重置**，土地重新分配 |

### 2.1 差异的根源只有三个设计选择

上表十几条差异，其实全部由三个选择推导出来：

**选择 1：位置是否绑定？**

- 可迁城 → 失败可以逃跑 → 战争的代价降低 → 更多冲突，但每次冲突的分量轻；
- 土地连通 → 跑不掉，且失地即断粮 → **每一次战争都是生死攸关的** → 冲突频率低但烈度高，且必须依赖组织。

**选择 2：单日行动上限受什么约束？**

- 受资源约束 → 钱能买资源 → **付费直接转化为行动量**；
- 受体力约束且体力不可购买 → **付费买不到行动量，只能买"每次行动的质量"**。

> **这是率土-like 最关键的一个设计。** 它把付费能力的作用范围从"做多少事"限制到了"每件事做得多好"。
> 大 R 的武将更强，但他一天能打的仗数和免费玩家一样多。

**选择 3：战斗的主体是兵还是将？**

- 兵为主体 → 兵可以用资源堆 → 资源可以买 → 付费直通战力；
- 将为主体、兵只是 HP → **将靠抽卡（概率），兵靠时间（征兵）** → 付费影响的是概率而非确定的战力。

**这三个选择就是 SLG 数值设计的三个总开关。** 你在做一款 SLG 时，先定这三个，其余的数值都是它们的推论。

## 3. 决定生态的那个参数：集结叠加指数

```bash
cd models && python m18_slg_alliance.py
```

第 05、17 章都提到过这个问题：**N 个人一起打，总战力怎么算？**

```
总战力 = (Σ 个人战力)^α
```

模型里的服务器，顶级大 R 的战力是免费玩家中位数的 68 倍。要打赢他需要多少人集结：

```
α（叠加指数）    所需人数      现实可行性
------------------------------------------
1.0              68        一个联盟能组织起来
0.9             110          需要全服级动员
0.8             198          需要全服级动员
0.7             421          需要全服级动员
0.6           1,156      不可能 → 大 R 无敌
0.5           4,752      不可能 → 大 R 无敌
```

**α 从 1.0 降到 0.8，所需人数从 68 涨到 198——三倍。降到 0.6，就彻底不可能了。**

> **这一个参数决定了你的服务器是"人多的赢"还是"钱多的赢"。**

| α | 生态形态 | 适合什么产品 |
|---|---|---|
| **1.0（线性相加）** | 数量完全对抗质量。组织能力主导 | 率土-like，强调联盟和策略 |
| **0.85~0.95** | 数量有效但需要更多人。**平衡点** | 大多数现代 SLG |
| **< 0.8** | 个人战力主导，人海无效 | 强付费驱动的产品 |

**它为什么这么敏感**：因为战力差距是几十倍量级的，而幂次会把这个差距放大——`68^(1/0.8) = 198`，指数运算对底数的放大是剧烈的。

### 3.1 现实中怎么实现 α < 1

真实游戏很少显式写一个 α，而是通过下面这些机制**隐式地**实现次线性：

| 机制 | 效果 |
|---|---|
| **集结人数上限** | 最直接的次线性（超过 N 人无法加入） |
| **集结部队总兵力上限** | 同上，且和战力挂钩 |
| **只有队长的武将技能生效** | 参战者的"质量"被浪费，只贡献兵力 |
| **战场同时容纳的部队数有限** | 后到的排队，等于分批被消灭 |
| **AOE 伤害** | 人越多被范围伤害打得越惨 |

> **审 SLG 方案时的一个关键动作**：把所有这些机制折算成一个等效的 α，然后对照上表判断你的生态会长成什么样。
> 团队常常在不知情的情况下把 α 压到了 0.7 —— 因为每个机制单看都很合理。

### 3.2 各分层对全服有效战力的贡献

看模型的图 ③。α 越低，大 R 在全服有效战力中的占比越高，免费玩家的贡献被压缩得越厉害。

**这直接对应第 19 章要讲的生态问题**：当免费玩家发现自己"来不来都一样"时，他们就会真的不来了。

## 4. 战损与再生产：SLG 的节奏心脏

第 08 章讲过兵损是 SLG 最优雅的 sink。本节讲它的另一个作用：**控制战争的节奏**。

```
两次开战的间隔 ≈ 单次作战的兵力损失率 / 每日兵力再生产能力
```

模型（日再生产 6%）：

```
   战损率    间隔      体验
     2%     0.3 天    兵损不掉 → 兵不是 sink
     5%     0.8 天    健康：几天一战
    10%     1.7 天    健康：几天一战
    15%     2.5 天    健康：几天一战
    25%     4.2 天    偏重：打一次要缓很久
```

**这个比值是 SLG 最重要的节奏参数之一。**

- **太低**：兵消耗不掉 → 兵不再是 sink（第 08 章）→ 资源堆积 → 通胀；而且战争没有分量，玩家随便打；
- **太高**：玩家不敢开战 → 战争系统冻结 → SLG 变成放置游戏。这正是第 16 章鹰鸽博弈里"鹰的收益太低"的情形。

**三个可调旋钮：**

| 旋钮 | 说明 |
|---|---|
| **战损率** | 单次作战损失多少 |
| **再生产速度** | 征兵速度、资源产出 |
| **伤兵比例** | 现代 SLG 把损失拆成"阵亡"和"重伤可治疗"，调节两者比例就是在调节有效战损率 |

**伤兵机制是一个非常精巧的设计**（第 08 章提过）：

- 重伤可治疗 → 降低了实际损失 → 玩家敢打；
- 治疗要花资源和时间 → 仍然是 sink；
- **伤兵营有容量上限，超出的直接阵亡** → 惩罚"一次性梭哈"的莽撞打法，鼓励分批投入；
- 治疗时间提供了一个自然的"战后恢复期"，形成战争的节奏感。

> **率土-like 的等价物是"重伤 + 兵力恢复时间"**：武将兵力归零即重伤，需要时间恢复。它把"资源损失"换成了"时间损失"，而时间是不可购买的——**这再次强化了那条主线：把付费买不到的东西作为核心约束。**

## 5. 信息不对称：侦察的价值

SLG 是**不完全信息博弈**——你不知道对方城里有多少兵、带了什么将。这不是技术限制，是核心设计。

**信息不对称创造了三样东西：**

1. **侦察玩法的价值**（以及反侦察）；
2. **虚张声势的空间**（假装很强、假装撤退）；
3. **决策的紧张感**——如果所有信息透明，每一场战斗的结果都可以预先算出来，那就不需要打了。

**数值上的抓手：**

| 参数 | 影响 |
|---|---|
| 侦察能看到多少信息（兵力？武将？装备？） | 信息越透明，博弈越接近纯数值比较 |
| 侦察的成功率与被察觉概率 | 决定侦察是否值得做 |
| 情报的时效性 | 情报越快过期，越需要持续侦察 |

**一条设计原则**：**信息应该"可获取但有成本"**。完全不可知会让玩家的决策变成掷骰子（挫败），完全透明会让决策消失（无聊）。

## 6. 同盟的组织数值

同盟不只是聊天频道，它是一套完整的数值系统。四个组成部分：

### ① 组织货币（第 06 章）

贡献度、军功。**不可交易、离开即失效** —— 它的作用是提高退出成本。

**设计要点**：贡献度的获取方式应该覆盖**所有分层**。如果贡献度只能靠打仗获得，免费玩家在组织里就没有位置。所以要设计：捐献（大 R 强）、参战（中 R 强）、采集/建设（免费玩家也能做）、在线时长/协助（人人可做）。

### ② 集体产出（第 07 章）

联盟任务、联盟领地、联盟建筑带来的加成。**这部分产出应该占日投放的相当比例**（模型建议 15%~20%），否则玩家没有加入组织的经济理由。

### ③ 定向转移（第 10 章）

援助、捐献。这是"受限交易"的范式——保留了交易的社交价值，同时把分化限制在组织内部。

**设计要点**：援助额度要有上限，且**上限与接收方的实力挂钩**（弱者能收更多）。否则大 R 会把小号当仓库。

### ④ 协调机制（第 16 章）

集结、指挥、标记、语音。**协调成本越低，大同盟的优势越大。**

> **如果你希望小同盟有生存空间，就要提高大规模协调的成本**：限制集结人数、增加集结耗时、让远距离行军慢。反之，如果你希望"大同盟统治"的叙事，就降低协调成本。

## 7. 资源点分配：公地悲剧的实战

联盟占领的资源点是典型的公地（第 16 章 6.2 节）。三种处理方式：

| 方式 | 机制 | 效果 |
|---|---|---|
| **完全公地** | 谁先到谁采 | 内部矛盾多（这可能是你想要的），但会引发退盟 |
| **明确产权** | 资源点分配到人 | 公平但缺少互动 |
| **半公地（主流）** | 归联盟，但需要占领和保护 | 把"采多少"变成"能守多久"，**问题从分配转化为对外博弈** |

**半公地是最好的设计**，因为它把内部矛盾转化成了对外的共同目标。这也是 SLG 的通用手法：**用外部压力凝聚内部**。
