# 21 - 商业化的设计面

> **本章目标**：把商业化从"数值和运营的事"拿回到系统设计里。学完你应该能判断一个付费点是"体验的延伸"还是"拦路的墙"，能按付费动机选择付费形态，能说清月卡 / 通行证 / 抽卡各自解决什么设计问题，并且能识别黑暗模式和它的代价。
> **前置**：[第 07 章](./07-loops.md)（循环）、[第 08 章](./08-goals-progression-rewards.md)（奖励）、[第 11 章](./11-social-design.md)（社交）、[第 15 章](./15-system-design-method.md)（系统案）。**所有数字**——定价、档位、概率、保底、ARPU——都在 [game-numeric 第 12](../game-numeric/12-monetization-structure.md)、[13](../game-numeric/13-probability-systems.md)、[14 章](../game-numeric/14-pricing.md)，本章一个数字都不给。

## 1. 一份系统案上的一行字

你收到一份公会系统的案子，翻到最后一节，写着：

> **商业化**：由数值定。

这一行字就是本章要处理的全部问题。它看起来像是一次合理的职责划分，实际上是系统策划把最影响体验的一批决定推了出去。因为"由数值定"的只有数字，而下面这些全部是设计决定：

- 公会里**能不能**花钱，花钱买到的是什么形态的东西（一次性道具？永久特权？外观？还是排队插队？）
- 付费点出现在**哪个流程节点**：是玩家看到"公会等级差 5 级就能开公会商店"的时候，还是他刚被公会战打输的时候？
- 付费之后，**别人看不看得见**？看得见的话，看见的是"他更强"还是"他更好看"？
- 不付费的玩家在这个系统里的**生态位**是什么？他还有没有事可做、有没有被需要？

这四个问题里没有一个是数字问题，但它们决定了这个游戏在玩家眼里是"良心"还是"吃相难看"。分工应该是这样的：

| 问题 | 谁定 | 在哪里 |
|---|---|---|
| 玩家在什么时刻会**想**付费 | 系统策划 | 本章第 3 节 |
| 付费点放在哪个界面、哪个流程节点 | 系统策划 | 本章第 2 节 |
| 卖的是什么形态（时间 / 强度 / 外观 / 便利 / 内容 / 地位） | 系统策划 | 本章第 3、5 节 |
| 付费后的体验怎么变（对自己、对别人） | 系统策划 | 本章第 4、8 节 |
| 定价档位、折扣结构、锚点 | 数值 | [game-numeric 14](../game-numeric/14-pricing.md) |
| 抽卡概率、保底、期望值 | 数值 | [game-numeric 13](../game-numeric/13-probability-systems.md) |
| 付费结构与 ARPU / LTV 的关系 | 数值 | [game-numeric 12](../game-numeric/12-monetization-structure.md)、[15](../game-numeric/15-retention-ltv.md) |
| 付费层与免费层的生态平衡 | **两者共同** | 本章第 8 节 + [game-numeric 19](../game-numeric/19-server-ecology.md) |

**一句话概括本章的立场：付费点的"位置"和"形态"是设计决定，只有"价格"和"概率"是数值决定。** 系统策划把前两件事一起推给数值，得到的结果一定是"哪里卡就在哪里卖"——因为数值手上唯一的杠杆就是数字，而调数字最有效的位置永远是玩家最难受的位置。

## 2. 一条原则：付费点是体验的延伸，不是拦路

这是本章唯一一条需要背下来的原则。它的完整表述是：

> **玩家掏钱的那一刻，应该是因为"我想要更多"，而不是因为"我想要它停下来"。**

### 2.1 两种付费点的形式定义

| | 延伸型 | 拦路型 |
|---|---|---|
| 玩家的状态 | 正在享受，想要更多 / 更深 / 更个性化 | 正在被打断，想解除这个打断 |
| 付费的时点 | **满意之后** | **受挫之时** |
| 玩家事后的感受 | "我买了个好东西" | "我被逼着花了钱" |
| 不付费的人体验到 | 完整的、只是慢一点或少一点的游戏 | 一堵墙 |
| 长期结果 | 复购、口碑、信任 | 单次转化率高，长期流失与差评 |

**三个诊断问题**，任何付费点拿来一问就知道自己在哪一边：

1. 玩家掏钱的那一刻，是"**我想要它**"还是"**我想要它停止**"？
2. 不付费的玩家在这里体验到的是"完整但更慢"还是"被打断"？
3. 这个付费点明天删掉，玩家失去的是**一个想要的东西**，还是解除了**一个厌恶**？

第三问最锋利。**如果删掉一个付费点玩家会欢呼，那它就是拦路。**

### 2.2 一组对照

| 付费点 | 玩家当时的状态 | 判定 | 说明 |
|---|---|---|---|
| 抽到心仪角色后，卖这个角色的皮肤 | 喜欢这个角色 | **延伸** | 付费加深已有的情感投入 |
| 关卡失败的结算界面弹出"复活继续，6 元" | 刚刚失败，情绪谷底 | **拦路** | 卖的是"取消你刚才的失败" |
| 扫荡券：跳过已通关关卡的重复战斗 | 已经证明自己能过，只是嫌烦 | **延伸**（偏便利） | 卖的是省掉重复劳动，不是省掉玩法 |
| 背包满了，扩容只能用钻石，没有免费格 | 想继续玩，被容器卡住 | **拦路** | 典型的"人造容器墙" |
| 通行证：先玩了两周，赛季末买下解锁已达成的进度奖励 | 已经投入，想拿到自己挣的 | **延伸**（临界） | 付费在体验之后，是对投入的确认 |
| 进度条差 3 分钟满，弹"立即完成" | 正在等待 | **拦路** | 墙是人造的，且高度可被设计任意调节 |
| 开放世界里卖一个新的可玩角色 | 探索得很开心，想要新玩法 | **延伸** | 卖的是"更多内容" |

### 2.3 诚实的灰色地带：拦路不等于禁止

体力就是一种拦路。第 00 章拆解过《率土之滨》的体力系统：它明确地打断你，让你等。但它是个好设计，因为它满足三个条件：

1. **这堵墙本身是玩法的一部分**：体力制造了"这一口体力打什么"的取舍，那是一个真正的决策（第 05 章）。
2. **墙的高度稳定且可预期**：所有人上限一样，恢复速度一样，你能规划。
3. **有非付费的绕行路径**：等待就是路径，而且等待期间还有别的事可做。

对照一下滑向拦路的版本：体力上限随 VIP 提升、体力可以无限用钻石买、恢复速度随充值加快。三条一旦破掉，同一个机制立刻从"节奏调速器"变成"付费墙"。

所以本章的原则不是"不许挡路"，而是：

> **可以挡路，但挡路的那堵墙必须先是一个好玩法，其次才是一个付费点。**

判断方法很简单：**假设这个游戏永远不收钱，你还会保留这堵墙吗？** 体力会保留（它塑造节奏）；"复活 6 元"不会（它只是把失败的后果卖回给你）。

### 2.4 买断制的对照：它根本没有拦路的动机

买断制在体验开始之前就收完了钱，所以它没有任何理由制造挫败来换收入。《哈迪斯》里你死了就是重来，死亡惩罚极轻；合理的解释是设计者需要你继续玩，而不是需要你难受【推导】。第 10 节会完整展开这个对照。

**这条差异会传导到所有设计决定上**，这也是为什么本课要求你手游和买断制交替玩：不玩买断制，你会以为"卡一下再卖"是游戏设计的自然形态。

## 3. 付费动机分类：玩家到底在买什么

玩家不是"为游戏付费"，是为七种不同的东西付费。这七种动机对应完全不同的付费形态，也对应完全不同的品类适配。**选错动机，形态再精致也卖不动。**

| 动机 | 玩家心里的话 | 典型形态 | 品类适配 | 设计要点 | 风险 |
|---|---|---|---|---|---|
| **省时间** | "我知道怎么打，只是不想再打一遍" | 扫荡券、加速道具、双倍收益卡、离线收益 | SLG、放置、卡牌日常 | 卖的必须是**已被证明掌握**的重复劳动，不是玩法本身 | 卖得太多等于承认核心玩法无聊 |
| **变强** | "我想赢 / 我想过这一关" | 抽卡、装备、等级上限、战力包 | 有 PvE 考试或 PvP 的品类 | 强度差异在**什么场合被感知**（第 4 节） | p2w 感、生态崩坏 |
| **表达** | "我想让我的角色是我的" | 皮肤、时装、头像框、家园装饰、称号 | 有他人可见性的品类 | 前提是**有人看得见** + 玩家有"我的角色"认同 | 外观通胀、限定焦虑 |
| **社交地位** | "我想让别人知道我是谁" | 稀有度炫耀、公会特权、榜单、限定标识 | 强社交（MMO、SLG、MOBA） | 地位必须**稀缺**，且获取路径公开 | 把社交变成军备竞赛 |
| **收集** | "我要集齐" | 抽卡、图鉴、限定复刻、碎片兑换 | 角色驱动品类 | 收集的**边界**要可见（图鉴总数），否则没有完成感 | 内容产能跟不上；限定错过的挫败 |
| **便利** | "我不想被这些琐事烦" | 免广告、自动战斗、多队列、仓库扩容、跳过动画 | 任何品类 | 卖便利前先问：这个不便**为什么存在** | 便利卖多了等于承认基础体验糟糕 |
| **支持 / 情感** | "这游戏值这个钱" | 买断、订阅、支持包、纪念品 | 独立、小众、强作者性的产品 | 需要玩家和团队之间有**可辨识的关系** | 规模有限，不能作为主收入 |

### 3.1 每类的手游例子与买断制对照

- **省时间**：SLG 的扫荡与加速（手游） / 买断制里几乎不存在，因为没有理由让你重复打已经通关的内容——重复的内容会被直接设计成可跳过。**这个对比本身就是诊断工具：一款手游需要卖多少"省时间"，就说明它有多少重复劳动是人为堆出来的。**
- **变强**：卡牌手游的抽卡 / 买断制的对照是《哈迪斯》的"惩罚之约"——玩家**自己加难度**换更好的奖励。同样是调节难度，一个卖简单，一个卖困难。
- **表达**：《王者荣耀》的皮肤 / 买断制里单人游戏的外观 DLC 普遍卖不动。原因很直接：**没有观众**。表达型付费的前置条件是可见性，这是一条硬约束，不是运营问题。
- **收集**：《明日方舟》《原神》的角色图鉴 / 买断制的对照是《塞尔达传说：旷野之息》的呀哈哈收集——同样是收集动机，一个靠付费加速，一个靠探索时间。收集动机本身不需要付费，是 F2P 把它接到了付费上。
- **便利**：小游戏的"免广告" / 买断制里"免广告"这件事根本不存在。

### 3.2 一个实用的判断顺序

给一个新系统设计付费点时，按这个顺序问：

```
1. 这个系统里玩家最强烈的动机是哪一种？（往往不是"变强"）
        ↓
2. 这个动机对应的付费形态，本游戏已经有了吗？
        ↓ 有 → 复用已有形态，不要新开一个付费类目
        ↓ 没有
3. 新形态和已有形态会互相蚕食吗？（月卡和通行证互相蚕食是常见问题）
        ↓
4. 这个付费点是延伸还是拦路？（第 2 节三问）
        ↓
5. 不付费的玩家在这里还有事做吗？（第 8 节）
```

第 2 步"复用已有形态"是最常被忽略的一条。**手游最常见的商业化病是付费类目过多**：月卡、周卡、季卡、基金、通行证、成长礼包、限时礼包、直购礼包，每个都是某个策划为了本季度指标加的。它们互相蚕食，还让付费界面变成一堵没人看得懂的墙（第 19 章的认知负荷）。

## 4. pay-to-win 连续谱

"这游戏 p2w"是玩家最重的一句指控，但 p2w 不是一个开关，是一条连续的轴。作为系统策划，你的工作是知道自己的产品该站在哪一格，以及**为什么**。下面这条轴是一个粗略的排序：它把"对他人的影响"当唯一坐标，把强度、获取方式、内容售卖压到了一条线上，所以相邻两格的顺序在不同品类里可能互换（比如强 PvP 品类里"时间加速"的杀伤力可能超过"内容解锁"）。更严格的做法是拆成"竞争影响 × 可付费优势"的二维矩阵，本节先用一维轴建立直觉。

```
 ┌─────────┬────────┬──────────┬──────────┬──────────┬──────────┬────────────┐
 │ 纯装饰   │  便利   │ 时间加速  │ 内容解锁  │ 概率提升  │ 强度上限  │ 直接买战力  │
 └─────────┴────────┴──────────┴──────────┴──────────┴──────────┴────────────┘
   皮肤      免广告    加速道具    新角色      抽卡保底    等级上限    战力礼包
   头像框    多队列    体力购买    新章节      十连折扣    突破材料    数值直购
 ←── 对他人无影响 ──────────────────────────────────── 直接决定胜负 ──→
```

每一格的性质：

| 格 | 卖的是 | 对他人的影响 | 玩家的典型反应 |
|---|---|---|---|
| 纯装饰 | 表达与地位 | 无（只有观感） | 接受度最高 |
| 便利 | 操作成本 | 无 | 接受，但会问"为什么本来这么麻烦" |
| 时间加速 | 进度速度 | 间接（进度差） | 视品类而定 |
| 内容解锁 | 可玩内容 | 无（PvE）/ 有（新角色进 PvP） | 接受度取决于免费内容是否完整 |
| 概率提升 | 获取效率 | 间接 | 开始出现"不公平"感 |
| 强度上限 | 能达到的最高战力 | 直接 | 竞技场合无法接受 |
| 直接买战力 | 战力本身 | 直接且即时 | 只有特定品类能接受 |

### 4.1 各品类的容忍位置【行业口径】

| 品类 | 容忍上限大致在 | 为什么 |
|---|---|---|
| 竞技 MOBA / FPS | **纯装饰** | 公平就是玩法本身，破坏公平等于破坏产品 |
| 卡牌 PvE 为主 | **强度上限** | 主要对手是关卡不是人；数值差异的受害者只有自己 |
| 卡牌带天梯 PvP | 强度上限，但需要**隔离手段** | 见 4.3 |
| 率土-like SLG | **时间加速 / 概率提升**，战力上限被赛季和体力压住 | 赛季结算会清掉领地、等级等赛季资产，但武将与进阶这类抽卡收益通常跨季保留，所以付费优势被压缩而不是消除；体力闸门则把付费收益锁在单次行动里 |
| COK-like SLG | **直接买战力** | 大 R 的碾压是产品结构的一部分，服务器生态围绕它组织【推导】 |
| 开放世界单机化（如《原神》） | **强度上限**，但感知被稀释 | 无排名对抗、PvE 为主，别人的强度不会让你输【推导】 |
| 独立 / 买断 | **不适用**（付费前置） | 见第 10 节 |

### 4.2 最关键的一条洞察

> **pay-to-win 的痛感不来自"付费能变强"，而来自"我的失败是因为别人付费"。**

这句话把问题从数值问题转成了设计问题。同样的付费强度差，放在不同的场合，玩家的感受完全不同：

- 你充钱把主线打过去了 → 没人受害，没人抱怨
- 你充钱在天梯上把我打下去了 → 我受害了，我抱怨
- 你充钱在世界 BOSS 上拿了第一 → 我看着榜，我不舒服但没直接受害
- 你充钱把我的城打下来了，我三天的进度没了 → 最强的痛感

所以**系统策划手上的杠杆不是"付费能不能变强"，而是"付费带来的强度差异在什么场合、以什么形式被感知到"**。

### 4.3 五种隔离手段（设计面）

| 手段 | 做法 | 代价 | 数值面 |
|---|---|---|---|
| **分层匹配** | 按战力 / 段位 / 付费分层匹配，让强度接近的人相遇 | 分层太细会导致匹配等待久、生态割裂 | [game-numeric 17](../game-numeric/17-pvp-matchmaking.md) |
| **非对抗场合** | 把付费强度的用武之地放在 PvE、榜单、协作，而不是直接对抗 | 高付费玩家缺少"炫耀的对手" | —— |
| **时间闸门** | 体力 / 次数上限，让付费只提升单次质量不提升次数 | 制造等待，义务感 | [game-numeric 19](../game-numeric/19-server-ecology.md) |
| **周期重置** | 赛季重置进度或排名，把付费收益的有效期锁在一季 | 老玩家的"又要重来"疲劳 | [game-numeric 22](../game-numeric/22-seasons-and-merges.md) |
| **上限压缩** | 数值天花板压低，让付费的边际收益快速衰减 | 高付费玩家的付费天花板也被压低 | [game-numeric 21](../game-numeric/21-power-creep.md) |

**这五种手段全部是系统设计决定，不是数值决定。** 数值可以告诉你"压到多少倍差距合适"，但"要不要有天梯""赛季重不重置""体力能不能买"这些是系统案里的条款。

## 5. 主要付费形态的设计逻辑

下面每一种形态，都按同一个格式讲：**它解决什么设计问题、它的副作用是什么、设计要点在哪**。定价、档位、概率、保底的数学一律见 [game-numeric 12](../game-numeric/12-monetization-structure.md)、[13](../game-numeric/13-probability-systems.md)、[14](../game-numeric/14-pricing.md)。

### 5.1 首充

**解决的设计问题**：从"零元"到"第一元"是整个付费漏斗里最陡的一跳。这一跳跨过的不是价格，是**心理状态的切换**：从"我是免费玩家"变成"我是这游戏的付费用户"。首充用一个极高性价比的一次性包降低这次切换的成本。

**副作用**：它制造了一个**极高的性价比锚点**。玩家在首充里得到的单位价值，会成为他之后评估所有礼包的参照物，于是后面所有正常定价的东西都显得贵。

**设计要点**：首充给的东西应该是**打开一扇门**，而不是给一堆资源。给一个新角色、开一个新系统、解锁一个新玩法，让玩家的游戏内容发生**质**的变化。给资源只是把进度往前推了几天，玩家感受到的是"我买了三天时间"，那是最没有黏性的一种付费。

### 5.2 月卡

**解决的设计问题**：两件事。一是提供一个**门槛极低的付费入口**（比抽卡便宜一个数量级）；二是给每日回访一个**廉价而具体的理由**——"我的东西还在那儿等我领"。

它的结构是"付一次，分 30 天领"。这个结构本身就是一台留存机器：付费的沉没成本每天提醒你上线。

**副作用**：**它是"义务化"最典型的来源**。玩家会形成"今天没上线就亏了"的感觉，而这种感觉在长期是负体验——第 22 章讲玩家疲劳时，月卡制造的每日义务是主要成因之一。

**设计要点**：月卡的内容应该是**玩家本来就要做的事的加速**（体力、日常资源），**不应该是独占玩法或独占内容**。一旦月卡里出现了"只有月卡能玩的东西"，它就从便利型付费滑向了内容解锁型，免费玩家的体验开始残缺。

### 5.3 通行证 / battle pass

**解决的设计问题**：把付费和玩法进度**绑定**。玩家先玩，进度自然累积，然后付费**确认**这份已经投入的时间。这是所有付费形态里最接近"延伸型"的一种，因为付费发生在满意之后。

它还顺带解决了另一个问题：**把 DAU 变成付费理由**。传统付费是"付钱换进度"，通行证是"玩游戏换进度，付钱解锁"，这让"每天玩"这件事本身有了金钱价值。

**副作用**：赛季末的**焦虑与打卡感**。当进度落后于时间时，通行证从"奖励"变成"债务"。这是通行证设计里最需要小心的一点。

**设计要点**：

- **免费轨必须有实质奖励。** 免费轨形同虚设的通行证就是一堵拦路的墙：玩家做了任务，但什么都拿不到。
- **任务必须能靠"正常玩"完成**，不能逼玩家去玩他不喜欢的模式。"用你不玩的这个英雄赢三把"是最招人恨的一类任务，它把玩家的游戏时间变成了别人的 KPI。
- **进度上限要留冗余**：正常玩家在赛季结束前留出几天余量能满级，而不是必须每天全勤。留冗余的代价是核心玩家提前满级后失去目标，那是可以用额外轨解决的小问题；不留冗余的代价是全体玩家的义务感，那是大问题。

### 5.4 皮肤 / 外观

**解决的设计问题**：在**完全不影响平衡**的前提下，提供表达和地位。它是商业化里平衡风险最低、可以反复售卖的形态。但"不影响平衡"不等于零成本：外观过多会稀释角色辨识度、占用美术产能，也会让"稀有外观"本身贬值。

**两个硬前提**（缺一不可）：

1. **可见性**：别人看得到。没有观众的皮肤卖不动，这是硬约束。
2. **角色认同**：玩家心里有"我的角色"。如果角色是随时可替换的数值容器，玩家不会为它买衣服。

这两条解释了一个常被误解的现象：为什么很多手游的皮肤卖不动，而《王者荣耀》的能卖。不是美术不行，是**这两个前提没有建立**【推导】。想靠皮肤赚钱，得在第 12 章（叙事与角色）和第 11 章（社交可见性）就开始铺垫，不是等到商业化阶段临时加。

**副作用**：外观通胀（新皮肤越做越花，老皮肤贬值）、限定焦虑。

**买断制对照**：单人买断制游戏的外观 DLC 普遍卖不动，原因还是可见性。这从反面印证了这条前提是结构性的，不是运营能力问题。

### 5.5 抽卡（gacha）

抽卡在设计上同时解决三件事，这也是它为什么难以被替代：

1. **内容分发**：新角色 / 新卡通过卡池发放，**把内容更新变成了一个可付费的事件**。这是它最核心的功能，也是最容易被忽略的一点。
2. **稀缺感与情绪波动**：随机制造了期待、失落、狂喜的情绪曲线（第 10 章）。
3. **付费天花板**：抽卡是最常见的高付费上限形态，在抽卡类产品里通常承担大部分收入【行业口径】。资源、加速和消耗品礼包同样可以高额重复售卖，只是单次决策的刺激弱得多。

**设计面的四个要点**（数学在 [game-numeric 13](../game-numeric/13-probability-systems.md)）：

- **抽的对象是角色还是数值？** 抽角色，主导动机是收集和表达，玩家会为"这是我喜欢的角色"付费；抽数值（装备词条、强化石），主导动机是变强，玩家会算性价比，而且一定会算出"不划算"。**抽角色的产品往往能活得更久【推导】，代价是内容产能压力巨大**——每个角色要有建模、语音、技能、剧情。
- **保底的可感知性。** 保底不只是数学机制，它是一个**信息设计**问题：玩家能不能随时看到自己离保底还有多远？看不到的保底在体验上等于不存在。
- **限定与常驻的边界。** 限定制造紧迫感和收入峰值，但也制造"错过就永远拿不到"的焦虑，并且会让新玩家看到一个满是空洞的图鉴（第 22 章的联动活动有同样问题）。
- **歪了之后怎么办。** 抽卡最负面的一刻不是没抽到，是抽到了不想要的。这一刻的体验设计（歪了给什么补偿、能不能定向兑换）比概率数字更影响口碑。

### 5.6 礼包

**解决的设计问题**：针对具体情境的定向售卖。新手礼包、卡关礼包、活动礼包、节日礼包，每一种都在一个特定的玩家状态上出现。

**副作用**：**情境触发型礼包是最容易滑向拦路和黑暗模式的形态**，因为"最容易促成购买的情境"通常就是"玩家最难受的情境"。

**设计要点**：**把触发条件写进系统案里，不要让它成为一个运营可以随意挂载的位置。** 一个案子如果只写"支持挂礼包"，那么半年后这个位置上一定会出现"连续失败三次后弹出"的配置。触发条件是设计决定，必须在案子里被评审。

### 5.7 VIP / 特权等级

**解决的设计问题**：给累计付费一个长期的、可见的激励，让付费本身变成一条进度线（第 08 章的"目标生成器"）。

**副作用**：三条，都很重。

1. 它把 p2w **摆到了台面上**：VIP 等级是公开的付费排名。
2. 它**不可逆**：VIP 特权一旦给出去就无法回收，任何后续的平衡调整都会撞上"已购买权益"。
3. 它会**绑架后续设计**：每个新系统都要考虑"VIP 在这里给什么特权"，久而久之所有系统都长出一层付费特权。

**行业趋势**：国内不少品类正在弱化或取消显性 VIP 等级【行业口径】。原因不是它不赚钱，而是它对产品形象和长期设计自由度的代价太大。

### 5.8 一张对照表

| 形态 | 解决的设计问题 | 付费时点 | 主要副作用 | 延伸 / 拦路倾向 |
|---|---|---|---|---|
| 首充 | 第一次付费的心理门槛 | 早期，情绪高点 | 制造性价比锚点 | 延伸 |
| 月卡 | 低门槛入口 + 日回访理由 | 先付后领 | 义务化 | 中性（内容独占则滑向拦路） |
| 通行证 | 把玩法进度变成付费理由 | 先玩后付 | 赛季末焦虑 | 延伸（免费轨空则拦路） |
| 皮肤 | 无平衡影响的表达与地位 | 情感高点 | 外观通胀 | 延伸 |
| 抽卡 | 内容分发 + 情绪 + 收入天花板 | 新内容发布时 | 概率挫败、产能压力 | 中性（取决于内容供给节奏） |
| 礼包 | 情境化定向售卖 | 特定状态触发 | 最易滑向黑暗模式 | 取决于触发条件 |
| VIP | 累计付费的长期激励 | 持续 | 不可逆、绑架设计 | 拦路倾向 |

## 6. 黑暗模式与伦理边界

**黑暗模式（dark pattern）**：利用玩家的认知偏差，让他做出清醒时不会做的决定的界面或规则设计。

注意定义里的关键词是"**清醒时不会**"。这不是"让人想买"（那是所有商业化的目标），是"让人在信息不完整或情绪被操纵的状态下买"。

### 6.1 清单

| 模式 | 长什么样 | 利用了什么 | 短期为什么有效 | 长期代价 |
|---|---|---|---|---|
| 虚假稀缺 | "限时 24 小时"，关掉再打开又是 24 小时 | 损失厌恶 | 制造紧迫感 | 被发现后信任归零 |
| 币中币 | 人民币 → 结晶 → 原石 → 抽卡，中间隔两层 | 心理账户 | 模糊真实价格 | 玩家算清楚之后的反弹 |
| 零头设计 | 档位永远差一点点，逼你买下一档 | 完形心理 | 提高客单 | 被识别为"算计" |
| 误触陷阱 | 购买按钮放在关闭按钮的位置；动画结束时按钮跳出来 | 肌肉记忆 | 提高误购 | 退款、差评、平台投诉 |
| 痛点定向推送 | 刚失败就弹礼包；刚被打就弹防护罩 | 情绪低谷 | 转化率最高的时刻 | 玩家事后感到被操纵 |
| 沉没成本收割 | "你已经抽了 80 次，再 10 次就保底了" | 沉没成本 | 促成追加消费 | 是所有模式里最伤信任的 |
| 社交压迫 | "你的公会成员都升级了""你排在最后一名" | 社会比较 | 制造焦虑消费 | 社区氛围恶化 |
| 逃逸困难 | 取消订阅路径极深；退会有长 CD | 惰性 | 延长订阅 | 平台合规风险 |
| 隐藏 / 嵌套概率 | 多层随机套娃，真实概率无法计算 | 概率误判 | 掩盖真实期望 | 概率公示要求下的合规风险 |

### 6.2 一条可操作的自检

判断一个机制是不是黑暗模式，用这一句话：

> **如果把这个机制的完整规则，用一句人话写在按钮的正上方，玩家还会买吗？**

- "本礼包每天都会出现" 写上去，玩家还买 → 不是黑暗模式，只是促销
- "本礼包每天都会出现"写上去玩家就不买了，而你现在写的是"限时最后 24 小时" → **是黑暗模式**
- "这一抽的概率是 0.6%，你已经抽了 80 次，期望还需要 X 次" 写上去玩家还抽 → 不是黑暗模式
- 必须靠隐藏这个信息才能促成购买 → **是黑暗模式**

这个自检的好处是它把伦理问题转成了一个**信息完整性**问题，而信息完整性是可以在评审会上讨论的具体条款，不需要争论价值观。

### 6.3 灰色地带

- **真的限时活动**算不算虚假稀缺？不算。真实的限时是内容排期，玩家可以据此规划。**区别在于信息是否真实。**
- **如实告知的保底提示**算不算沉没成本收割？不算。"距离保底还有 10 抽"是玩家需要的信息；"再抽 10 次就保底了，现在充值可享 8 折"是收割。**区别在于是不是把信息和购买按钮绑在一起、在情绪高点推送。**
- **首充的高性价比**算不算锚定操纵？不算，只要它的条件公开且一次性。

一条通用的分界线：**信息真实且完整 = 商业设计；信息缺失或情绪操纵 = 黑暗模式。**

### 6.4 本课的立场

本课反对黑暗模式，理由是三条**产品理由**，不是道德说教：

1. **它污染的是信任，而信任是长线产品唯一的复利资产。** 一款手游要活三年，靠的是玩家默认"这个游戏不会坑我"。这个默认一旦破掉，之后每一次正常的活动都会被解读为算计，而且不可逆。
2. **它会让团队的设计能力退化。** 有捷径就没人做真设计。一个团队一旦发现"在失败界面弹礼包"能提升 15% 的付费，就再也没有动力去研究"为什么这么多人在这里失败"。**黑暗模式最大的代价是它替换掉了本该做的设计工作。**
3. **合规风险在收紧**，见下一节。

## 7. 合规：策划要知道有这回事

本节只说"存在哪些约束、它们对设计意味着什么"，**不写具体条文和数字**——各地区的规定不同且会变，具体条款以法务和发行的口径为准。

| 约束类型 | 对设计意味着什么 |
|---|---|
| **概率公示** | 多个市场要求公示抽取概率。设计含义：**你的随机结构必须能被清楚地表述出来**。嵌套过深、条件分支过多的随机在合规上是负担，在体验上也是（玩家算不清就不会信）。**这是设计约束，不是运营约束。** |
| **未成年人保护** | 实名、时长、消费限额等要求普遍存在。设计含义：① 核心体验不能绑死在"必须每天在线"上，否则受时长限制的用户直接被排除；② 付费流程要有清晰的确认环节，但确认环节本身不是合规措施，实名核验、年龄分层、消费限额和风险验证才是；未成年人充值引发的退款争议是真实存在的运营成本【行业口径】。 |
| **订阅与自动续费** | 部分市场对取消路径有强制要求。设计含义：**"逃逸困难"这类黑暗模式在这些市场是合规问题，不是体验问题**。 |
| **广告与分级** | 广告内容、频次、与内购的组合会影响年龄分级。设计含义：IAA 产品尤其要注意（见 [game-solo](../game-solo/README.md) 课程）。 |
| **玩家间交易 / 实物奖励** | 一旦涉及真实价值流转或实物，会触发另一类监管。设计含义：**在系统案阶段就要标记出来**，不要等到上线前才发现。 |

**给策划的可操作做法**：在系统案里留出"可配置的口子"，让合规变更不需要改设计：

- [ ] 概率是否可公示？随机是否有嵌套？（能一句话说清楚吗）
- [ ] 是否有未成年人限额 / 时长分支？分支下的体验是否仍然完整？
- [ ] 订阅是否可自助取消？取消后的状态怎么处理？
- [ ] 是否有实物奖励？是否有玩家间交易？
- [ ] 所有付费点是否可被单独关闭？（区域差异、突发合规要求）

最后一条尤其重要：**每一个付费点都应该是可以单独关掉的**。这是工程要求，也是设计要求——如果关掉某个付费点会导致系统跑不通，说明这个付费点已经长进了玩法的骨头里，那本身就是设计问题。

## 8. 付费与免费玩家的生态关系

免费玩家不是"还没付费的付费玩家"，他们是**产品的一部分**。

- 没有观众，皮肤卖不动（第 5.4 节）
- 没有对手，战力没有意义（第 4.2 节）
- 没有人数，公会打不了仗

三种典型的生态结构：

| 结构 | 免费玩家的生态位 | 典型品类 | 风险 |
|---|---|---|---|
| **金字塔** | 大 R 在顶端，免费玩家是底座与观众 | COK-like SLG、传统页游 | 底座塌了顶端就没意义；对新服依赖大 |
| **分层隔离** | 各玩各的，付费与免费很少直接对抗 | 卡牌 PvE、单机化开放世界 | 付费玩家缺少炫耀对象，付费动机减弱 |
| **共生** | 免费玩家提供时间、人数、情报、劳动 | 率土-like SLG、MMO | 需要精细设计才能维持，最难做 |

共生结构是设计上最有意思的一种。以率土-like SLG 为例：大 R 出战力，免费玩家出人头、出情报、出铺路的地。这个结构不是自然形成的，它靠一组具体的设计条款维持：

- **联盟规模上限**：让"人数"成为稀缺资源，于是免费玩家有价值
- **集结机制**：一场战斗需要多人参与，单个大 R 打不下关键目标
- **侦查与情报**：信息是可以由低战力玩家提供的资源
- **体力闸门**：所有人每天能做的事情数量接近（第 2.3 节）

**这四条全部是系统设计，不是数值。** 数值面的生态分析（各付费层的人数比例、消费能力分布、生态崩溃的临界点）在 [game-numeric 第 19 章](../game-numeric/19-server-ecology.md)。

**设计侧的一条检查**：给任何一个新系统，都要问"**零付费玩家在这个系统里有事做吗、有被需要吗**"。答案是"他也可以玩，就是慢一点"通常不够好——"慢一点"意味着他只是一个进度落后的付费玩家，不是一个有生态位的参与者。

## 9. 贯穿案例：月卡 + 通行证 + 抽卡的分工拆解【推导】

以《原神》为例，它的三件套是**空月祝福（月卡）+ 纪行（通行证）+ 祈愿（抽卡）**。以下对设计意图的分析全部是从公开表现反推的【推导】，不是官方说法。

### 9.1 它们分工在三条不同的时间轴上

```
   日 ────────────► 周 ──────────► 版本(数周) ──────────► 长期
   │                │               │
   │ 月卡           │ 通行证        │ 抽卡
   │ 每天上线领     │ 每周任务 +    │ 版本限定角色
   │                │ 赛季进度      │
   └─ 制造日回访    └─ 制造周回访   └─ 制造版本回访 + 承担收入天花板
```

**这三件套不是三个付费点，是一个覆盖三种时间尺度、三种付费心理、三个付费门槛的组合。**

### 9.2 分工表

| | 月卡（空月祝福） | 通行证（纪行） | 抽卡（祈愿） |
|---|---|---|---|
| 付费门槛 | 最低 | 低 | 无上限 |
| 主导付费动机 | 便利 / 省时间 | 收集 + 便利 | 收集 + 变强 + 表达 |
| 付费时点 | **先付后领**（付费在体验之前） | **先玩后付**（对已投入的确认） | **情绪高点**（新角色公布 / 演示） |
| 制造的回访节奏 | 日 | 周 | 版本 |
| 解决的设计问题 | 首次付费门槛 + 日活理由 | 把 DAU 变成付费理由 | 内容分发 + 收入天花板 |
| 对不付费玩家的影响 | 几乎无（只是慢） | 免费轨仍有奖励 | 角色池有差异，但 PvE 为主可绕过 |
| 主要副作用 | 每日义务感 | 赛季末进度焦虑 | 概率挫败 + 内容产能压力 |
| 在 p2w 谱上的位置 | 时间加速 | 内容解锁（偏轻） | 强度上限 |

### 9.3 "删掉会怎样"测试【推导】

第 00 章的万能测试用在这里：

- **删掉月卡**：最低价位的付费入口消失，首次付费转化率下降；同时失去一个廉价的日回访理由。愿意花小钱的那批玩家会被迫在"不付费"和"抽卡"之间二选一，多数会选前者。
- **删掉通行证**：中间层玩家（愿意花点钱、但不愿意抽卡）失去付费出口；同时"每天正常玩"这件事失去了直接的价值回报，日常任务的动机只剩养成资源。
- **删掉抽卡**：收入天花板塌掉，同时"新角色"这个内容分发机制失去载体——角色要么变成免费发放（收入没了），要么变成直购（收集与情绪价值大幅降低）。

三条加起来说明：**它们不可互相替代，因为它们服务的是三种不同的玩家和三种不同的时间尺度。** 这是本节最重要的结论，也是评审商业化方案时的第一个问题：**你新加的这个付费形态，占的是哪条时间轴、哪个门槛、哪种动机？如果和已有的重合，它就是在蚕食。**

### 9.4 一个比数值更重要的设计细节【推导】

《原神》角色活动祈愿的核心大奖是**角色**（有建模、语音、技能、剧情、配音演员）而不是纯数值（它另有独立的武器祈愿，本节只讨论角色池）。这一个选择的连锁后果：

| 后果 | 说明 |
|---|---|
| 主导动机从"变强"转向"收集 + 表达" | 玩家会为"我喜欢这个角色"付费，而不是为战力算性价比 |
| 抽卡的挫败感被稀释 | 没抽到的是"我想要的人"，不是"我算亏了的数值" |
| 皮肤这条线被打通 | 有了角色认同，外观才卖得动（第 5.4 节的两个前提） |
| **内容产能成为核心约束** | 每个角色是一整套内容，版本节奏被产能锁死（第 22 章） |
| 剧情与角色必须同步 | 文案和系统策划的接口变得极重（第 12 章） |

**这条链的起点是一个纯设计决定（抽什么），终点是整个团队的产能结构。** 这就是为什么"商业化不能甩给数值"：抽卡概率是数值决定，抽卡的**对象**是设计决定，而后者的影响面大得多。

### 9.5 一个对照：《明日方舟》

《明日方舟》不是严格的三件套：它有月卡和寻访（抽卡），但没有常驻的战斗通行证，第三件是源石直购与组合包。抽卡对象是**干员**且核心玩法是塔防策略，PvP 成分极低。这带来一个不同：角色的**功能差异性**（能不能解决某个关卡）比数值强度更重要，于是"抽不到"的痛感更接近"我少了一把工具"而不是"我战力低了一截"【推导】。功能型角色池对内容产能的压力更大（每个干员要有独特机制），但对数值膨胀的压力更小（[game-numeric 21](../game-numeric/21-power-creep.md)）。

## 10. 对照：《哈迪斯》的"付费前置"如何改变每一个设计决定

《哈迪斯》是买断制（并且经历了较长的 Early Access 阶段，Supergiant 有多场 GDC 分享谈过它的开发与叙事系统【实证：Supergiant 的 GDC 分享】）。它和上一节的三件套形成了一组干净的对照。注意这不是因为玩法像：一个是随机 run 的动作 roguelike，一个是开放世界 RPG，品类、世界结构、角色控制方式全都不同。对照有效的原因是**两者都靠"角色 + 养成 + 长期叙事"留住玩家，却选择了相反的付费时点**，于是同一类设计问题（失败惩罚、内容节奏、外观、叙事）给出了相反的答案。下表的"同结构的 F2P"指的是一款采用了同类留存结构的 F2P 产品，不是特指《原神》。

| 设计决策 | 《哈迪斯》（买断，付费前置） | 同结构的 F2P 会怎么做 | 差异的根因 |
|---|---|---|---|
| **死亡惩罚** | 极轻：立刻重来，且带走部分资源 | 加体力 / 门票，失败消耗次数 | F2P 需要时间闸门来制造付费点 |
| **元进度速度** | 稳定给，几十小时内基本给完 | 拉长到几百天，中间插多条养成线 | 买断的收入已经收完，F2P 要把收入摊在时间上 |
| **新武器 / 新角色** | 一次性内含在本体 | 版本限定 + 抽卡 | F2P 把内容更新变成付费事件 |
| **难度调节** | 惩罚之约：**玩家自己加难度**换更好奖励 | 数值墙 + 付费越墙 | 一个卖挑战，一个卖跳过挑战 |
| **外观** | 有（宅邸装饰、武器外观），但不出售，靠游戏内资源解锁 | 大量皮肤，出售 | 单人游戏没有观众，外观只服务于自我表达，不构成付费点（第 5.4 节） |
| **叙事节奏** | 高密度，随一次次逃脱逐步展开，但全部包含在买断价里 | 稀释到版本更新里 | F2P 必须给未来版本留内容 |
| **测试方式** | Early Access（第 20 章） | 封测 + 灰度 + A/B | 都需要真实玩家，路径不同 |

**从这张表能读出的最重要一条**：F2P 的很多"设计"其实是**收入在时间上摊开**的副产物。体力、多条养成线、限定角色、赛季，本质上都在回答同一个问题：如何让收入在三年里持续发生。

这不是批评。**认识到这一点的价值在于，你能分清哪些设计决定服务于体验、哪些服务于商业结构，然后在两者冲突时知道自己在交易什么。** 一个只会说"这样体验更好"的策划做不出商业产品；一个只会说"这样收入更高"的策划做不出能活三年的产品。系统策划的位置就在这两者之间，而这个位置需要你**同时说得清两边的账**。

## 11. 常见误区

| 误区 | 为什么错 | 正确的想法 |
|---|---|---|
| "商业化是数值和运营的事" | 付费点的位置和形态是设计决定，只有价格和概率是数值 | 系统案必须写清付费点在哪、卖什么形态、不付费的人怎么办 |
| "哪里卡就在哪里卖" | 这是拦路型付费点的定义 | 先问玩家在这里是"想要更多"还是"想让它停下来" |
| "加个付费点总能多赚点" | 付费类目过多会互相蚕食，还制造认知负荷 | 新形态先问：占哪条时间轴、哪个门槛、哪种动机？重合就不要加 |
| "p2w 是数值强度的问题" | 痛感来自"我的失败是因为别人付费"，是场合问题 | 用分层匹配、非对抗场合、时间闸门、赛季重置来隔离 |
| "皮肤卖不动是美术不行" | 缺的是可见性和角色认同两个前提 | 这两个前提要在第 11、12 章就开始铺 |
| "免费玩家不赚钱，优先级低" | 他们是观众、对手和人头，是付费价值的前提 | 每个系统都问"零付费玩家在这里有事做吗、有被需要吗" |
| "黑暗模式只是运营手段，不是设计" | 触发条件、信息呈现、按钮位置全是设计 | 用"写在按钮上方还会买吗"自检 |
| "短期数据说明它有效" | 靠制造焦虑生效的改动，短期 A/B 一定赢（第 20 章） | 问它靠什么机制生效；机制是焦虑就不要看短期数据 |
| "合规是法务的事" | 概率能不能公示、限额下体验是否完整，都是设计约束 | 案子里留可配置的口子；每个付费点可单独关闭 |
| "月卡就是便宜的付费" | 它同时是留存机器和义务感来源 | 月卡内容必须是"本来就要做的事的加速"，不能独占内容 |
| "通行证任务能引导玩家玩新模式" | 逼玩不喜欢的模式是最招人恨的一类任务 | 任务要能靠正常玩完成；引导新模式用别的手段 |

## 12. 动手

### 12.1 拆解：一个具体付费点

从你正在玩的手游里，选**一个具体的付费点**（推荐：《原神》的纪行、《明日方舟》的月卡、《王者荣耀》的某个皮肤、任一 SLG 的加速道具），用 [templates/deconstruction.md](./templates/deconstruction.md) 拆解，重点回答：

1. 这个付费点**出现在什么时机**？是玩家主动找到的，还是系统在某个状态下推给他的？触发条件是什么（能观察到的）？
2. 它卖的是第 3 节七种动机里的哪一种？**是不是同时挂了两种**（比如既是便利又是变强）？
3. 用第 2.1 节的三个诊断问题判定：延伸还是拦路？给出理由。
4. 它在第 4 节的 p2w 连续谱上落在哪一格？这款游戏的品类容忍位置在哪？两者匹配吗？
5. **不付费的玩家在这个位置上体验到什么**？是"完整但慢"还是"被打断"？
6. 这个付费点和游戏里其他付费形态**有没有蚕食关系**？（列出所有付费类目，画一张"时间轴 × 门槛 × 动机"的三列表）
7. 它有没有用到第 6.1 节清单里的任何一种模式？用第 6.2 节的自检验证一遍。
8. 如果把这个付费点删掉，玩家会**失去一个想要的东西**，还是**解除一个厌恶**？（这是第 2.1 节第三问，也是本次拆解的核心结论）

意图层的判断全部标【推导】。

### 12.2 写作作业：付费点诊断与替代设计

选一个你认为**偏拦路**的付费点（可以是上一题拆的那个，也可以另选），写一份不超过两页的诊断，必须包含下面六节：

1. **现状描述**（只写事实）：触发条件、界面呈现、卖的是什么、价格档位结构（不写数值分析，只写结构）
2. **诊断**：用第 2.1 节的三问逐条判定，并说明它在 p2w 谱上的位置
3. **它替开发者解决了什么问题**：这一节是必须的。**不理解它为什么存在就提替代方案，方案一定被否。** 想清楚它服务的是哪个指标、哪个玩家分层、哪条时间轴
4. **替代设计**：给出一个"延伸型"的替代方案，要写清楚：卖什么形态、放在哪个流程节点、对应哪种付费动机、不付费玩家的体验怎么变
5. **代价**：你的替代方案会损失什么？（转化率下降？开发成本？需要前置铺垫？）**不写代价的方案是不可评审的**
6. **验证方式**：用第 20 章的方法，写出 1 条可证伪的假设 + 它的可观测指标 + 反证

**自查两条**：
- 你的替代方案有没有偷偷把问题推给"内容做得更好一点"？（那不是设计方案）
- 如果你的替代方案让收入下降 20%，你能对制作人说清楚换回了什么吗？

放进 `notes/作业/21-付费点诊断.md`，第 29 章会用到。

### 12.3 思考题

1. 第 2.3 节说"体力是一种好的拦路"。请为"体力可以用钻石购买"这条规则辩护一次（假设你是那个产品的策划），然后再反驳自己。你在什么条件下会同意这条规则？
2. 第 20 章的思考题 3 在这里重现：A/B 显示"把失败结算的'再来一次'换成'购买复活'能显著提升付费，7 日留存无变化"。现在你有了本章的框架，你会怎么回答？你需要哪些额外证据？（提示：第 6.2 节的自检、第 20 章的"靠什么机制生效"。）
3. 一款主打 PvE 的卡牌手游，主策要求加天梯 PvP 来提升付费。用第 4 节的框架说明：这个决定会把产品在 p2w 谱上推到哪里？需要配套哪些隔离手段？如果不配，会发生什么？
4. 假设你要做一款完全不含随机付费（无抽卡）的 F2P 手游，主收入靠什么？用第 3 节的七种动机和第 5 节的形态表，给出一套组合，并说明它对内容产能的要求。
