# 09 - 挑战、难度与技能

> **本章目标**：学完你应该能区分"难度"和"挑战"并说出中间隔着什么；能判断一款游戏在考哪几种技能、天花板在哪、会不会被攻略抹平；能给一个手游卡点做"考试还是墙"的诊断并重新设计它；能说清楚动态难度在什么场景下可以用、在什么场景下会毁掉游戏。
> **前置**：[第 03 章](./03-why-players-play.md)（心流与胜任感）、[第 05 章](./05-decisions.md)（决策）、[第 08 章](./08-goals-progression-rewards.md)（目标与养成线）。数值面的难度曲线与卡点节奏见 [game-numeric 第 20 章](../game-numeric/20-long-term-pacing.md)。

## 1. 开场：同一个关卡，四种"太难了"

你在做玩法测试，五个玩家打同一个关卡，其中四个说"太难了"。你把这四个人的录像调出来看，发现他们说的根本不是同一件事：

| 玩家 | 实际发生的 | 他说的"太难" 真正的意思 |
|---|---|---|
| A | 一直在往前冲，被同一个技能秒了六次 | **我不知道该干什么**（信息问题，不是难度问题） |
| B | 知道该躲，但每次都晚半拍 | **我做不出来**（执行技能问题） |
| C | 打法完全正确，但输出不够，剩 5% 血 | **我练度不够**（养成问题） |
| D | 打赢了，但花了 20 分钟 | **太累了**（节奏问题，不是难度问题） |

四个人的"太难"，对应四个完全不同的修法：A 要加信息提示，B 要放宽判定窗口或加练习环境，C 要调数值或者给他一条明确的养成路径，D 要缩短关卡。**如果你把这四种反馈笼统地读成"难度太高"然后统一调低敌人血量，只有 C 会被修好，另外三个人的问题原封不动。**

这就是本章的第一条也是最重要的一条区分：

| | 定义 | 谁拥有它 | 能不能配进表里 |
|---|---|---|---|
| **难度**（difficulty） | 系统的客观属性：敌人的血量、伤害、数量、时限、判定窗口、容错 | 系统 | **能**。它就是一堆数字和规则 |
| **挑战**（challenge） | 玩家感受到的"这件事对我来说有多难" | 玩家 | **不能**。它是难度经过玩家之后的产物 |

> **你能配的只有难度，你要的是挑战。中间隔着一个玩家。**

隔在中间的那个玩家带来了至少五个变量：他的**技能水平**、他掌握的**信息**（知不知道该怎么打）、他的**练度/资源**（在养成游戏里）、他的**预期**（他以为这关应该多难）、他的**状态**（第几次尝试、疲不疲、心情）。设计难度的工作，本质上是在这五个变量的分布上下注。

心流（Csikszentmihalyi）的经典图示——技能和挑战匹配时进入心流通道，挑战过高是焦虑，过低是无聊——是这一章的背景，第 03 章已经讲过。这里要补一个它作为设计工具的**局限**：心流模型把"技能"画成了一根一维的轴，而真实玩家的技能是多维的。一个玩家可能反应很差但策略很强，对他来说"提高敌人攻速"和"增加敌人种类"是完全不同性质的两件事，但在一维模型里它们都只是"挑战变高了"。所以下一节要先把技能拆开。

## 2. 技能的类型：你的游戏在考什么

把"技能"拆成几类，是这一章后面所有工具的基础。

| 技能类型 | 定义 | 怎么练 | 天花板 | 能否被攻略外包 | 典型品类 |
|---|---|---|---|---|---|
| **反应**（reaction） | 对突发刺激的响应速度和准确度 | 大量重复，且受生理上限约束 | 中（有生理天花板） | 不能 | 动作、FPS、音游、格斗 |
| **执行**（execution） | 把已知的正确操作稳定做出来的精度 | 刻意练习 | 高 | **不能** | 动作、格斗、竞速、音游 |
| **策略**（strategy） | 在信息不完全的条件下选择方案、分配资源、管理风险 | 反复决策 + 复盘 | **很高** | 部分可以（版本答案） | 卡牌、SLG、自走棋、Roguelike |
| **知识**（knowledge） | 记住数据、机制、套路、克制关系、版本答案 | 查、背、经历 | 低（有上限） | **完全可以** | 所有养成游戏、MMO |
| **社交**（social） | 组织、谈判、说服、读人、带团 | 只能在真人环境里练 | **最高** | **几乎不能** | SLG 联盟、MMO 公会、社交推理 |

再补一个常被漏掉的：**规划与资源管理**——它是策略技能在长时间尺度上的形态，手游养成游戏考的主要就是它（这个月的资源给谁、要不要为下个版本留、体力怎么分配）。

### 2.1 三条推论

**推论一：一款游戏"考什么技能"决定了它的天花板高度。**

知识技能的天花板最低，因为知识是有限的、可穷举的、可以被写进一篇攻略里的。一款只考知识的游戏，在攻略成熟之后所有玩家的"技能"会趋于相同，游戏对高手就失去了区分度。社交技能的天花板最高，因为它每一局的对象都是不同的人。

**推论二：能被攻略外包的技能，会被攻略外包。**

这不是"如果"，是"多久"。一款上线的手游，主流玩法的最优解通常在几天到几周内被社区解出并广泛传播。所以**只要游戏有活跃社区，依赖玩家自己摸索的知识型难度，寿命通常都很短**。设计者有三种应对：

- 接受它，把攻略当成设计的一部分（明确公示机制、鼓励社区产出攻略——这其实降低了新手的门槛）
- 增加策略维度，让攻略只能给出"框架"而不是"步骤"
- 增加不可外包的技能（执行、社交）

第三条在手游里最难，因为手游的设备和使用场景天然限制执行技能。

**推论三：本课重心的那几类手游（卡牌/RPG 养成、SLG、放置）主要考知识、策略和规划，较少考反应和执行。**【行业口径】

**例外很大，先说清楚**：MOBA、FPS、音游、动作手游恰恰把反应和执行当作核心技能，手机并非做不了操作型玩法。所以这条推论**不是关于"手游"整体的**，只对本课重心的养成/SLG/放置这几类成立。在这几类里，触屏精度低、网络延迟、单手操作、地铁上玩、随时被打断这些约束是真实的，**技能维度的难度天花板天然偏低**。这带来两个结构性后果：

1. 因为技能差异被攻略抹平，**这几类手游主要靠养成（练度）来制造玩家之间的差异**，于是难度设计很自然地变成"练度考试"。这就是第 7 节要讲的卡点。
2. **社交技能成为这几类手游里少数不可外包的维度**，这是 SLG 品类生命周期普遍长于卡牌品类的原因之一【推导】：SLG 的高手拼的是组织和谈判，那是抄不来的。

对照买断制：《黑暗之魂》考执行和知识（boss 的招式记忆），《杀戮尖塔》几乎纯考策略，《哈迪斯》考反应+执行+策略的组合，《传送门》纯考求解（属于策略里的谜题解法）。**注意"它们不需要养成"是不准确的**：《黑暗之魂》有等级、装备和强化，《哈迪斯》有镜子、武器形态这类永久成长。准确的说法是：**它们的成长不受时间闸门和投放节奏约束**（想练就练，不用等体力、不用等版本放材料），**养成也不是持续运营的主轴**，所以难度可以主要压在技能上。这背后的商业结构差异是：买断制的收入主要在售出那一刻完成，长线留存不是它的第一约束【行业口径】。

## 3. 学习曲线与难度曲线：谁跟随谁

Raph Koster 在《A Theory of Fun》里的核心论点是：**乐趣的本质是学习新模式；模式一旦被掌握，重复它就不再有趣**。把这句话翻译成难度设计的语言：

> **难度曲线应该跟随学习曲线，而不是相反。**

先把两条曲线画出来。注意学习曲线**不是平滑的，是阶梯状的**——玩家掌握一个新机制的时候会跃升一级，然后进入一段平台期（在平台期他在把新机制练熟）。

```
  能力/难度
    ▲
    │                                        ┌──── 难度（数值堆叠）
    │                             ┌──────────┘        玩家能力停在这里
    │                    ┌────────┘                   ← 焦虑 / 只能靠养成
    │           ┌────────┘  ╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌  学习曲线（阶梯）
    │   ┌───────┘  ╌╌╌╌╌╌╌
    │ ┌─┘ ╌╌╌╌╌
    └─┴──────────────────────────────────────────────────────▶ 时间
      教 练 考   教 练 考    教 练 考         教学停止后，难度还在涨
```

三个常见的错配，每一个都对应一类真实的玩家抱怨：

| 错配 | 表现 | 玩家的话 | 修法 |
|---|---|---|---|
| **难度先于学习** | 还没教就考 | "这什么鬼，我都不知道发生了什么" | 补"起"段：在安全环境里先展示新机制（第 17 章的四步教学结构） |
| **学完不考** | 教了新机制，后面再也没用上 | "那个道具我拿到之后就忘了" | 每个新机制至少复现三次：教一次、练一次、考一次 |
| **教学停了难度继续涨** | 后期只是敌人血更厚、伤害更高 | "后面就是数值了，没意思" | 先用 3.1 节的五个维度抬难度（组合、执行、信息、对手、目标约束），实在没有了就**承认这里考的是养成并明说** |

第三条是本节最需要展开的一条。

### 3.1 当教学停止，难度容易退化成数值

任何游戏在一段时间里的可教内容都是有限的。教完之后还要继续拉高难度，**最省事的一条路是加数值**：血更厚、伤害更高、时限更紧。但它不是唯一的路——下面五个维度都能在**不教任何新机制**的前提下抬难度：

| 维度 | 做什么 | 例子 |
|---|---|---|
| **组合复杂度** | 把已教过的机制叠在一起考 | 两种敌人机制互相掩护；地形 + 天气 + 词缀叠加 |
| **执行稳定性** | 收紧容错，考"能不能每次都做对" | 更短的判定窗口、更长的不许失误的段落 |
| **信息不完备** | 藏起一部分信息，让玩家自己推 | 技能不预警、迷雾、隐藏词缀 |
| **对手会适应** | 换成真人或会针对你的 AI | PvP；会换招的 Boss |
| **目标约束** | 关卡不改，只改通关条件 | 限时、无伤、限用角色/资源、低配 |

而且**数值压力本身也不是纯粹的"练度考试"**：血更厚意味着输出循环要连续打对更久，伤害更高意味着一次失误就致命——它同时在检验操作和构筑。

所以这一条准确的说法是：

> **如果既不新增机制、也不动上面这五个维度，难度就会退化成单纯的数值加压。**

而单纯的数值加压有一个必须自觉的性质：**它主要考的是"养成程度"和"资源规划"，不是"玩得好"。**这不必然是错的——养成本身就是手游的核心内容，规划技能也是真技能——但**设计者必须自觉**。自觉和不自觉的区别在于：

| | 不自觉的设计 | 自觉的设计 |
|---|---|---|
| 关卡失败时给玩家的信息 | "挑战失败" | "你的输出不足，推荐战力 XXXX" |
| 玩家能做什么 | 反复重试同一关 | 明确知道去练什么、练多久 |
| 关卡的定位 | 装作是"技巧挑战" | 明说是"练度考试" |
| 体验 | 挫败、怀疑自己菜 | 阶段性总结、有明确下一步 |

**当一个挑战实际考的是练度，却在表现上伪装成技巧挑战时，玩家会得到最差的体验**：他反复尝试、反复失败、不知道问题在自己的操作还是练度，最后既没有成长也没有方向。这是手游中期流失的一个常见原因【推导】。

数值上具体怎么排卡点、间隔多久、难度跳多高，见 [game-numeric 第 20 章](../game-numeric/20-long-term-pacing.md)。本章讲的是它的表现层和体验层。

## 4. 技能地板与天花板

两个基础概念：

- **技能地板**（skill floor）：玩这个游戏/用这个角色所需要的最低技能水平。地板高 = 上手难。
- **技能天花板**（skill ceiling）：技能水平能带来的最大收益上限。天花板高 = 有得练。

Rob Pardo 在 GDC 2010 的 *Making a Standard (and Trying to Stick to It): Blizzard Design Philosophies* 里讲过暴雪的几条设计信条，其中就包括 "easy to learn, hard to master"。用本章的词汇说，它就是**低地板 + 高天花板**。

| | **低天花板** | **高天花板** |
|---|---|---|
| **低地板** | 休闲小游戏。上手即会，玩两天腻<br>（合成类、消除类小游戏） | **目标态**。谁都能玩，高手有巨大空间<br>（《王者荣耀》《杀戮尖塔》《英雄联盟》） |
| **高地板** | **最差象限**：难上手又没深度<br>（操作繁琐但没有策略的产品） | 硬核。劝退多数人，留下的极忠诚<br>（《黑暗之魂》《星际争霸》） |

### 4.1 怎么降地板而不降天花板

这是设计上最有价值的一类手法：

| 手法 | 做什么 | 保留了什么 | 例子 |
|---|---|---|---|
| **简化输入** | 自动瞄准、一键连招、辅助转向 | 决策仍然由玩家做 | 手游 MOBA 的技能辅助瞄准 |
| **分层信息** | 新手只看必要信息，高手能展开详细面板 | 深度信息仍然存在 | 战报的"简略/详细"两档 |
| **难度选项 / 辅助模式** | 让玩家自己选强度 | 高难度档位不变 | 见第 8 节 |
| **把执行技能换成策略技能** | 取消操作要求，把挑战移到"准备阶段" | 挑战总量不变，只是换了位置 | **手游最常用的一招**，下面详细说 |
| **失败无成本** | 随便试，试到会为止 | 难关本身的难度不变 | 见第 5 节 |

**"把挑战从执行层移到准备层"这一招值得单独讲**，因为它是手游设计最核心的技巧之一，而且经常被误解成"取消挑战"。

自动战斗不等于没有挑战。它把"这一场怎么打"从战斗中的实时操作，移到了战斗前的编队、养成、build 和阵容克制。《明日方舟》是最清晰的例子：一场作战里你能做的操作很有限（部署干员、开技能、撤退），真正的挑战在**部署顺序、位置、时机和你带的这批干员的练度与能力组合**。这不是"没有挑战"，这是**把挑战从执行技能移到了策略和规划技能**。

这一招的代价是：**准备阶段的挑战是可以被攻略完全外包的**（第 2 节推论二）。你能抄别人的阵容和站位，但你抄不了别人的手速。所以走这条路的游戏必然要面对"作业化"——玩家照着攻略摆一遍。设计上的应对是：让每一关的**约束不同**，使得攻略只能给出思路而不是照抄的答案；或者接受作业化，把它当成社区内容的一部分。

### 4.2 怎么抬天花板

| 手法 | 说明 | 反例（无效的抬法） |
|---|---|---|
| **增加维度而不是数值** | 加一个需要同时管理的新变量（位置、时机、资源、风险） | 只是把敌人血量翻倍 |
| **扩大高手的选择空间** | 让熟练玩家有更多可行解，而不是更严的唯一解 | 把容错窗口收窄到只有一种打法 |
| **给"完美执行"额外回报** | 评分、无伤、限时、S 级、低配通关 | 完美和普通给一样的奖励 |
| **引入其他玩家** | PvP 的天花板由对手定义，天然没有上限 | —— |

第三条在手游里非常有用而且便宜：**给一个玩法加一套评分或额外条件，等于免费加了一层天花板**，而且不影响低技能玩家（他们只要通关就行）。这也是第 9 节"技能表达"的载体。

## 5. 失败的设计

难度是通过"失败"这件事实现的。失败有三个可调参数，它们经常被一起调，但其实应该分开考虑：

| 参数 | 是什么 | 调高的效果 | 调低的效果 |
|---|---|---|---|
| **惩罚强度** | 失败损失什么（时间、资源、进度、地位） | 成功更有分量，紧张感强 | 敢于尝试，实验成本低 |
| **重试成本** | 从失败到再次开始要多久、要点几下 | 玩家会更谨慎 | 玩家会用"试错"代替"思考" |
| **信息量** | 失败有没有告诉玩家"为什么输、下次改什么" | 玩家能成长 | 失败只是惩罚，不是教学 |

第三个参数最重要，也最常被忽略。**没有信息量的失败，就是纯粹的惩罚。**

由此可以得出一条可以直接用在评审里的准则：

> **惩罚强度 ≤ 失败的可归因程度。**
>
> 玩家越是能清楚地知道自己为什么输，你就越可以把惩罚做重；玩家越是不知道自己为什么输（输给了看不见的数值差、输给了随机），惩罚就必须越轻。

### 5.1 一个对照：《黑暗之魂》与手游

| 维度 | 《黑暗之魂》 | 典型养成手游 |
|---|---|---|
| 惩罚强度 | **高**：掉落身上的魂（可回去捡，再死就永久丢失）、回到篝火、敌人全部重生 | **低**：多数游戏失败不扣体力，进度可能保留 |
| 重试成本 | **中高**：要重新跑一段路回到 boss 门口，这段路本身是刻意的设计 | **极低**：一键重开 |
| 信息量 | **高**：每一次死你都知道自己被什么打死、什么时候该翻滚 | **中低**："挑战失败"，好一点的会给推荐战力 |
| 结果 | 高惩罚成立，因为可归因 | 低惩罚必须，因为不可归因 |

《黑暗之魂》的高惩罚之所以没有变成劝退，是因为它把可归因性做到了极致：**你死的每一次都是自己按错了什么，而且你当场就知道是什么**【推导】。跑图的重试成本也不是偷懒，它让"下一次尝试"变得郑重，从而提高了成功时的情绪强度。这一整套是自洽的：高惩罚 + 高信息量 + 中等重试成本。

手游把三个参数都调到了最低：失败不扣体力、一键重开、给推荐战力提示。这套组合的代价是**失败失去了意义，胜利也就失去了分量**。一个可以随便试一百次的关卡，通过时不会有成就感。

所以手游需要另外制造"重要的失败"。常见做法：

- **限次挑战**：一天只能打三次（BOSS 挑战、竞技场）
- **一次性结算**：赛季 PvP、公会战，输了就是输了
- **公开的结果**：排行榜、战报可被围观（社交后果本身就是惩罚）
- **消耗性门票**：用一张门票换一次机会

注意这几种做法的共同点：**它们提高的是惩罚强度，但没有降低信息量**。这是符合上面那条准则的。

### 5.2 "部分成功"：手游的默认解法与它的代价

手游几乎全部采用"部分成功"来软化失败：三星评价、进度保留、伤害排行、参与奖、"虽然没通关但拿到了 60% 进度的奖励"。

好处很明显：降低挫败、保证每次投入都有产出（第 08 章的"确定的地板"）、让玩家愿意挑战超出自己能力的内容。

代价也很明确：**部分成功稀释了"输"这个概念**。当每次失败都有收获时，玩家不再有真正的胜负体验，而胜负体验是成就感最浓的来源。这是一个真实的取舍，没有标准答案，但你要知道自己在换什么。

一个折中：**保留"部分成功"的资源产出，但不给荣誉性质的奖励**。血量打到 30% 给你材料，但称号、排名、成就只给真正通关的人。这样既保住了投入的确定性，又保住了胜利的稀缺性。

## 6. 动态难度与橡皮筋

**动态难度调整**（DDA, Dynamic Difficulty Adjustment）：系统根据玩家的实时表现自动调整难度。**橡皮筋**（rubber banding）是它在竞速和对抗游戏里的特例——落后的一方获得加成，把差距"拉回来"。

按玩家的可见程度分三层：

| 层次 | 做法 | 例子 | 风险 |
|---|---|---|---|
| **隐性** | 玩家完全不知道 | 连败 N 次后降低敌人强度或提高掉率；新手前几关暗中放水 | **被识破**，风险最高 |
| **半显性** | 系统给出建议或选项 | "要不要降低难度？""要不要跳过这一关？" | 被读作"游戏认为我菜"，伤自尊 |
| **显性** | 玩家自己选 | 难度选项、辅助模式 | 几乎无风险，见第 8 节 |

### 6.1 核心风险：被识破

隐性 DDA 的全部风险集中在一件事上：**玩家发现了**。一旦发现，两件事同时发生：

1. **成就感归零**。"我赢是因为它让我赢的"直接摧毁胜任感（SDT 的三个基本需求之一，见第 03 章）。这个伤害是不可逆的——玩家从此对自己的每一次胜利都会打折。
2. **出现策略性利用**。玩家会开始故意输：连败刷保底、故意掉分打匹配、开局送头拿加成。一旦这种行为出现在攻略里，DDA 就从"体验调节器"变成了"必须掌握的机制"。

而在有成熟社区的游戏里，**隐性 DDA 被逆向出来是迟早的事**：玩家会做记录、跑统计、对比数据。你必须假设它最终会被公开。

### 6.2 适用边界

| 场景 | 适合隐性 DDA？ | 原因 |
|---|---|---|
| 单机剧情向、休闲品类 | **适合** | 玩家的目标是体验内容，不是证明技能。被识破的代价小 |
| 手游 PvE 新手期（前几关） | **有条件适合** | 服务留存，且新玩家还没有能力和渠道识破 |
| 手游 PvE 中后期 | **不适合** | 社区已成熟，且这时玩家的目标是验证养成成果 |
| 竞技 PvP | **绝不适合** | 公平性是竞技的前提。用匹配机制代替，见 [game-numeric 第 17 章](../game-numeric/17-pvp-matchmaking.md) |
| 有排行榜/可展示结果的内容 | **不适合** | 结果必须可比，否则排行榜没有意义 |
| 有掉落/奖励差异的内容 | **不适合** | 变成"故意输能拿更多"的套利 |

### 6.3 橡皮筋的健康用法

橡皮筋的争议在于它用公平性换戏剧性。一个可用的原则：

> **把橡皮筋用在"追赶的可能性"上，不要用在"结果"上。**

| 健康 | 不健康 |
|---|---|
| 落后方获得更多**信息**（看到对手位置） | 落后方直接获得伤害加成 |
| 落后方获得更多**机会**（更多次尝试、更快刷新） | 领先方被直接削弱 |
| 落后方的**失败惩罚降低**（掉分更少） | 系统直接改变胜负判定 |
| 差距过大时提供**退出/投降**的体面路径 | 强行把比分拉平 |

区别在于：健康的做法给落后者**行动的空间**，让他有机会用技能追回来；不健康的做法直接改变结果，剥夺的恰恰是双方的技能表达。

## 7. 手游"卡点"的设计面

**先解释行话**：卡点，指玩家在推进主线/关卡/进度时被挡住、暂时无法继续的位置。在手游里卡点几乎都是刻意设计的——它是养成系统的必要配套（第 08 章 2.1 节的"意义流"）。没有卡点，玩家不知道自己为什么要养成；卡点做坏了，玩家直接流失。

**卡点的三个职责：**

1. **给养成一个理由**：告诉玩家"你练这条线是为了过这里"
2. **制造阶段感**：把连续的进度切成有节奏的段落（第 08 章的兴趣曲线）
3. **制造消耗动机**：玩家为了过卡点会消耗存量资源，也可能付费（第 21 章）

### 7.1 核心工具："考试还是墙"

这是本章最实用的一个诊断框架，作业里要用：

| 维度 | **考试**（exam） | **墙**（wall） |
|---|---|---|
| 玩家能做什么 | 有多条明确、可行动的路径通过 | 只能等，或者只能付费 |
| 失败的信息量 | **高**：知道自己差在哪（练度/阵容/操作/资源） | **低**：只知道"打不过" |
| 跨越所需时间 | 几小时到一两天 | 几天到几周 |
| 玩家的情绪 | "我知道该干什么了" | "这游戏在逼我充钱" |
| 对留存的影响 | 正：给了明确的中期目标 | 负：这是流失点 |
| 商业作用 | 引导消耗，付费是加速 | 直接付费墙，付费是通行证 |

**同一个卡点，可以是考试也可以是墙，区别不在难度，在四个设计要素。**

### 7.2 好卡点的四个要素

**要素一：可归因。** 玩家必须能看出自己差在哪。做法：

- 显示推荐战力/等级，并且这个数字要准
- 失败时给出**指向性的**信息："你的输出不足"比"挑战失败"强一百倍；"前排在第 40 秒被击破"更好
- 允许"打不过也能看到伤害百分比"，让玩家自己估算距离
- 关卡内的敌人属性、技能、机制公开可查

**要素二：出路不止一条。**这是区分考试和墙最关键的一条。

> **只有一条出路的卡点，等于墙。**

一个健康的卡点，玩家至少应该有三到四条可行动的路径：练等级、换阵容、补装备、升技能、找攻略、找朋友助战。如果所有路径最后都收敛到同一件事（"再等三天攒够材料"），那玩家实际上没有选择，只有等待。

这一条对养成体系的设计有反向要求：**你的养成线必须足够多样，卡点才可能是考试。**只有一条养成线的游戏，它的卡点几乎必然是墙。这是第 08 章 7.1 节"四种职责"的另一个理由。

**要素三：距离可估算。**玩家要能感觉"再玩两天就过了"。距离感来自两样东西：进度的可见性（第 08 章第 4 节）和产出速率的可见性（我每天能攒多少）。**估算不出距离的卡点，玩家会按最坏情况脑补，然后放弃。**具体的间隔与难度跳跃见 [game-numeric 第 20 章](../game-numeric/20-long-term-pacing.md)。

**要素四：卡点旁边放什么。**

这是最容易被忽略的一条。卡点是玩家最可能流失的位置，所以**卡点周围的内容布置比卡点本身更重要**。

必须放的四样东西：

| 放什么 | 作用 | 例子 |
|---|---|---|
| **一条明确的替代进度** | 让"卡住"不等于"没事干" | 支线、活动、其他玩法、横向养成线 |
| **产出所缺资源的玩法入口** | 把出路直接推到玩家面前 | 缺装备就把装备副本的入口放在失败弹窗上 |
| **一个低门槛的成功体验** | 恢复胜任感，避免连续挫败 | 一个简单的日常、一次必定成功的操作 |
| **一个社交出口** | 让玩家能问人、能被帮 | 公会求助、好友助战、攻略入口 |

**不应该放的**：失败后立刻弹出的"充值即可通过"。这一步把考试变成墙，而且是玩家感知最敏锐、最容易记恨的一个位置。付费应该是"加速已经存在的出路"，不是"唯一的出路"（第 21 章）。

### 7.3 卡点的密度

| 太密 | 合适 | 太疏 |
|---|---|---|
| 天天卡，玩家感觉寸步难行 | 卡点出现在养成刚好需要"下一段投入"的位置 | 玩家一路平推，不知道该养成什么，资源囤积 |
| 玩家觉得"这游戏就是逼氪" | 卡点变成阶段性的成就时刻 | 养成线失去意义流，玩家提前"毕业" |

注意右边那一列：**没有卡点也是一种设计失败**，它会让整个养成体系失去理由。新手期常见的错误是"前 30 关一路平推"，结果玩家在第 31 关第一次被卡住时既没有养成习惯，也没有养成资源。

## 8. 难度选项与辅助模式

显性难度是最安全的难度调节手段，因为它把决策交给了玩家本人，同时满足了自主性。但它有自己的设计问题：

**问题一：什么时候问。**开局就问"简单/普通/困难"是不合适的，因为**玩家在还没玩过的时候没有能力判断**，他只能靠自尊心选。更好的时机是：让玩家先玩一段，在他遇到第一次明确挫折之后再提供选项；或者允许随时切换。

**问题二：怎么命名。**难度档位的名字会影响玩家的自我认知。"简单/普通/困难"里的"简单"带有贬义；"剧情模式/标准/挑战"这类命名把选择从"你菜不菜"转成了"你想要什么体验"。

**问题三：档位之间改什么。**只改数值（血量、伤害）的难度选项是最廉价的，也最容易让高难档位变成"打得久一点"。好的难度档位改的是**机制**：更多敌人种类、更少的容错、更少的资源、更严的时限。

**辅助模式**（无敌、减速、跳过战斗、自动瞄准、自动解谜）在主机/PC 圈有争议，本课的立场是明确的：

> **在没有排名和公开比较的单人内容里，辅助模式的存在不改变没有开它的玩家的体验。**而它让更多人能接触到内容。（有排行榜、有可比成绩时另说：至少要把开了辅助的成绩单独标出来。）

用本章第 1 节的框架说得更清楚：难度是给技能设计的。**如果一个玩家的目标不是证明技能而是体验内容，那么难度对他就不是挑战，只是障碍。**

有意思的是，**手游其实是辅助模式最激进的品类**，只是它不叫这个名字：自动战斗、扫荡（不打直接给奖励）、跳过剧情、代理指挥、一键上阵、智能推荐阵容。手游把几乎所有能自动化的东西都自动化了。这带来一个值得你想清楚的问题：

**当一个游戏的所有挑战都可以被"自动"跳过时，剩下的挑战在哪里？**答案通常是"资源规划"和"付费决策"。这是一个诚实但不太舒服的观察。如果你不希望自己的游戏落到这一步，就必须在自动化的同时，保留至少一层不能被自动化的决策（第 05 章）。

## 9. 技能表达与玩家表达

两个相关但不同的概念：

- **技能表达**（skill expression）：玩家的技能水平能不能被看见——被自己看见，也被别人看见。
- **玩家表达**（player expression）：玩家能不能通过玩法表达自己的风格和偏好。

前者是"我玩得好"，后者是"我这样玩"。

### 9.1 技能没有表达渠道，天花板再高也没有意义

如果一个游戏的高手和普通玩家最终得到的东西完全一样（都是通关），那么高天花板对绝大多数玩家来说是不存在的——没人知道你玩得好，包括你自己。

表达渠道分两类：

| 对自己 | 对别人 |
|---|---|
| 评分（S/A/B）、无伤、通关时间、连击数、剩余血量 | 排行榜、战绩展示、观战、录像/战报分享、低配通关的社区认证 |

**"对别人"这一类的价值远高于"对自己"**，因为它同时满足了社会地位需求（第 08 章的社交地位奖励、第 11 章的社交设计）。这也是为什么"低配通关"在有些手游社区里能成为一种亚文化：它是玩家在系统没有提供分级的情况下，自己创造的技能表达渠道。

**给设计者的结论**：如果你做了一个有深度的玩法，一定要给它配一套表达渠道，哪怕只是一个评分。**这是抬天花板最便宜的手法**（第 4.2 节）。

### 9.2 玩家表达需要"多解"

一个只有唯一解的挑战，既没有技能表达也没有玩家表达——它只考执行。多解才有风格。

给挑战制造多解的手法：

- **多种资源可以换同一个结果**（用输出硬打 / 用控制拖 / 用治疗磨）
- **限制是软的**（有推荐属性但不是硬性门槛）
- **奖励对不同解法一视同仁**（如果只有一种解法给满分，那就不是多解）

这一条和第 08 章 3.2 节"玩家自定目标的四个条件"是同一件事的两面：多解既是玩家表达的基础，也是自定目标的基础。

## 10. 贯穿案例：《哈迪斯》的热度 vs《原神》深渊与《明日方舟》危机合约

这一节用三个"高难内容"的具体规则做对照。**所有关于设计意图的判断标【推导】；规则以公开可玩到的版本为准。**

### 10.1《哈迪斯》：把"选难度"变成一个有意思的决策

《哈迪斯》（Hades，Supergiant Games）是 Roguelite 动作游戏，一次 run 大约二三十分钟，死亡后回到冥界之家重新开始。

**核心规则（观察层）：**

1. **死亡不清空一切**。本局获得的祝福和临时资源没了，但若干种"元资源"保留下来，可以在冥界之家兑换**永久强化**（镜子）、解锁新武器、推进与 NPC 的关系。
2. **死亡推进叙事**。回到冥界之家之后，NPC 常常还有你没听过的新台词，剧情随之往前走（不是字面上"每次必有"，而是条件化对话的储备量大到长期感觉不到重复）【实证，Supergiant 的 GDC 分享】。**这套叙事系统[第 07 章](./07-loops.md)第 8.2 节已经从"循环与弧"的角度拆过，这里只取它在失败设计上的含义。**
3. **热度系统**（惩罚契约 Pact of Punishment）：通关之后解锁。玩家可以**自己勾选一组惩罚条款**——敌人血量/伤害提升、增加额外敌人、限制资源、加时限等等，**每条条款有自己的分值和若干可调档位**，勾选出来的总热度决定这次 run 算在哪一档。
4. **每把武器在每个热度档位上，奖励（悬赏）只能领一次**。想继续拿奖励，就得继续往上加热度或者换武器。
5. **但奖励是有尽头的，挑战没有**。全部条款拉满的总热度是一个固定的有限值（六十出头），而**悬赏只发到 20 热度左右为止**，再往上除了一件纯装饰性的奖品之外不再有新奖励【实证，游戏内悬赏列表与社区规则整理】。所以热度实际上分成三段：**有奖励的一段、只有装饰的一段、纯粹自我挑战的一段**。

**用本章的框架读：**

| 概念 | 在《哈迪斯》里 |
|---|---|
| 考什么技能 | 反应 + 执行 + 策略（build 构筑与风险管理） |
| 惩罚强度 | 中：损失一局的时间和本局进度 |
| 重试成本 | **极低**：死了立刻可以再开 |
| 失败的信息量 | **高**：你知道自己是被什么打死的 |
| 难度的形态 | **不是一个滑块，是一组带价格的条款** |
| 天花板 | **奖励封顶得早，挑战空间还很长**：悬赏发到 20 热度左右就停了，可勾选的总热度是它的三倍 |
| 技能表达 | 热度数值本身就是一个可展示的分数（游戏内不做排名，比较发生在社区） |
| 玩家自定目标 | 通关之后的长期目标**由玩家自己造**（第 08 章 3.2 节） |

**最值得学的两点【推导】：**

**第一，把"选难度"从一个下拉框变成了一个有意思的决策。**普通的难度选项是一维的（简单/普通/困难），玩家只能选"我要多痛苦"。热度系统是多维的：你不是选难度，你是选**在哪个维度受苦**。有人加敌人血量，有人加敌人数量，有人限制资源——每个人的配置不同，这直接变成了玩家表达（第 9 节）。**用第 05 章的语言说：它把一个无意义决策改造成了有意思的决策。**

**第二，它把"失败"接进了两条推进链。**死亡既推进元进度（永久强化），又推进叙事（新对话）。这意味着**每一次失败都有产出**，但产出的不是"部分成功的资源"，而是**内容和能力**（第 08 章的六类奖励里最抗贬值的两类）。这是"部分成功"的高级形态：不把失败打折成一点资源，而让失败本身承载别的类型的价值。

### 10.2 对照：《原神》深渊与《明日方舟》危机合约

| 维度 | 《哈迪斯》热度 | 《明日方舟》危机合约 | 《原神》深渊 |
|---|---|---|---|
| **谁定难度** | 玩家（完全自由组合） | 玩家（在赛季给定的条款池里组合） | **系统固定** |
| **难度的形态** | 一组带热度值的条款 | 一组带分值的条款（敌人属性、干员限制、地形变化等） | 固定的敌人配置 + 时限 + 层数 |
| **考什么技能** | 反应 + 执行 + 策略 | **策略 + 知识 + 练度**（排布、干员理解、阵容深度） | **练度 + 知识 + 有限的操作** |
| **失败成本** | 一局的时间（二三十分钟） | **几乎为零**（可以无限重试） | 低（可重试），但周期性结算 |
| **天花板** | **奖励早早封顶，自设挑战空间还很长** | **风险值有上限**（条款池有限），奖励也发到指定风险档为止；但"用更少更便宜的干员打到同样风险"没有尽头 | **满星就到顶**（12 层全星之后没有更高目标） |
| **技能表达** | 热度值（比较发生在社区） | **强，但主要在游戏外**：游戏内不做玩家排名榜，作业分享、低配认证是社区自发的文化 | **弱**：满星是二元的，只有"满没满" |
| **卡点性质** | 考试（出路很多：练操作、换 build、降热度） | **纯考试**（失败无成本 + 出路极多） | 偏考试，但对练度不足者接近墙 |

**版本说明**：上表是危机合约"自选条款 + 累计风险值"这一代的形态；后来改版成给定目标档位的形式，但**条款池有限、风险有上限、奖励发到指定档为止**没变，结论不受影响。

**这张表里最重要的一行是"天花板"。**

> **同样是"高难内容"，完成状态是二元的还是连续分级的，服务的人数和时长差一个数量级。**【推导】
>
> 深渊的完成状态是二元的（满星 / 没满星），所以对高手来说它在满星的那一刻就失去了意义，剩下的时间它只是一个周期性的领奖任务。热度和危机合约的完成状态是**连续分级**的：**即使官方奖励早就发完了**，"我这次开了多少热度""我用什么阵容打到了多少风险"仍是一个能继续往上走的数字，于是它对高手长期有效，而且这个数字成了技能表达的载体和社区内容的来源。
>
> **注意"分级"不等于"官方要一直发奖"。**两个例子都是**奖励发到某一档就停，分级本身继续往上**：奖励保证普通玩家有产出，分级给高玩留空间。**抬天花板因此几乎不花产能**——你不需要为第 40 热度的玩家再做一份奖励。

这条结论可以直接用在你的设计里：**任何一个你希望长期服务高玩的玩法，都要给它一个连续的分级，而不是一个二元的通关状态。**代价是分级会带来比较和攀比压力（第 11 章），所以通常的做法是把"及格线奖励"和"分数排行"分开：及格线给资源（人人可得），分数给荣誉（第 08 章的社交地位奖励，靠稀缺性生效）。

**另一个值得注意的对比是"失败成本"。**危机合约把失败成本压到几乎为零，这使得它可以放心地把难度做得极高——因为按第 5 节的准则，**低惩罚允许高难度和高不可归因性**。而深渊有周期结算（错过这一期就没了），失败成本更高，所以它的难度上限被压住了。**失败成本和难度上限是一对绑在一起的参数，改一个必须动另一个。**

## 11. 常见误区

| 误区 | 为什么错 | 正确的想法 |
|---|---|---|
| "玩家说太难，就把血量调低" | "太难"至少有四种含义（第 1 节），只有一种是数值问题 | 先看录像/数据定位是信息、执行、练度还是节奏问题 |
| "难度就是敌人的数值" | 数值难度主要考养成程度，不是技巧。教学停止后它是最省事的手段，但不是唯一手段 | 先用 3.1 节的五个维度（组合/执行/信息/对手/目标约束），数值是兜底 |
| "手游玩家不需要难度" | 手游玩家不需要的是**不可归因的挫败**，不是难度。高难内容是留存高玩的主要手段 | 把难度做成"可分级、失败便宜、出路很多"的形态 |
| "自动战斗等于没有挑战" | 自动战斗把挑战从执行层移到了准备层，挑战总量没变 | 要保证准备层确实有决策，否则才是真的没挑战 |
| "DDA 能同时照顾新手和高手" | 一旦被识破，胜任感归零；而在有活跃社区的游戏里，被识破基本只是时间问题 | 用显性的难度选项和分级内容代替隐性调节 |
| "卡点就是逼氪" | 卡点是养成的意义来源。做成考试是好设计，做成墙才是逼氪 | 用"考试还是墙"的六个维度诊断 |
| "失败就该有惩罚才紧张" | 惩罚强度必须匹配可归因程度，否则只是折磨 | 惩罚强度 ≤ 可归因程度 |
| "难度选项会让玩家都选简单" | 玩家选难度是在选体验，多数人会选自己认为合适的 | 命名和给出时机比档位本身更重要 |
| "把每个挑战都做出唯一最优解才平衡" | 唯一解消灭了玩家表达和技能表达 | 多解是天花板和表达的基础 |

## 12. 动手

### 12.1 拆解：一款手游的高难内容

选一款你在玩的养成手游里的**高难/挑战性内容**（危机合约、深渊、爬塔、限时挑战、高难副本都行），用 [templates/deconstruction.md](./templates/deconstruction.md) 拆解，必须回答：

1. 这个内容**考什么技能**？按第 2 节的五类给出占比估计（例如"知识 40% + 策略 40% + 练度 20%"）。
2. 它的技能**地板**和**天花板**分别在哪？一个从没打过的玩家需要什么才能打第一次？一个顶级玩家还有多少提升空间？
3. 它是**可分级的还是二元的**？如果是二元的，高玩打完之后还会回来吗？
4. **失败成本**是多少？（时间、资源、机会）失败时给了多少信息量？用第 5 节的三参数打分。
5. 它的**难度是谁定的**？系统固定、玩家自选、还是动态调整？
6. 有没有**技能表达渠道**？玩得好的人怎么被看见？
7. 打开社区，找一份这个内容的攻略。攻略能覆盖多少？**看完攻略之后还剩什么是抄不来的**？
8. 【推导】这个内容如果加一个"分数/评级"系统，会变好还是变坏？为什么？

写进 `notes/拆解/09-高难内容-游戏名.md`。

### 12.2 写作作业："考试还是墙"诊断与重设计

选一个**你自己被卡住过**的手游卡点（主线某一关、某个副本、某个进阶门槛），产出一份诊断+重设计文档，放进 `notes/作业/09-卡点诊断.md`。要求三部分：

**第一部分：诊断表。**用 7.1 节的六个维度逐条打分，判定它是考试、墙、还是中间态。每一行都要写证据，不能只写结论。

| 维度 | 这个卡点的实际情况 | 证据 | 偏向考试还是墙 |
|---|---|---|---|
| 玩家能做什么 | | | |
| 失败的信息量 | | | |
| 跨越所需时间 | | | |
| 玩家情绪 | | | |
| 对留存的影响 | | | |
| 商业作用 | | | |

**第二部分：四要素检查。**用 7.2 节的四个要素逐条检查，明确指出**缺了哪一个**：

- 可归因：玩家能看出差在哪吗？看到了什么信息？
- 出路：列出所有可行的出路。**如果少于三条，写出为什么**
- 距离：玩家能估算出"还要多久"吗？靠什么估算？
- 旁边放了什么：把失败弹窗和卡点前后的界面都列出来，对照 7.2 节的四样必备内容，缺了哪几样

**第三部分：重设计。**用 [templates/system-spec.md](./templates/system-spec.md) 的第 1、2、3.3、5 节格式，写出你的改法。要求：

- 明确写出体验目标（玩家在这个卡点应该感受到什么）
- **不改数值**。你的改动必须全部是设计层的（信息、路径、布置、表现），这是刻意的约束：先穷尽设计手段再谈调数值
- 至少补上一条新的出路，并说明它从哪条养成线来（对应第 08 章 7.1 节的四种职责）
- 写出"卡点旁边放什么"的具体布置方案
- 写出成功标准：改完之后，你会看哪个指标知道它变好了（指标体系见 [game-numeric 第 23 章](../game-numeric/23-metrics.md)）

### 12.3 思考题

1. 第 5 节的准则是"惩罚强度 ≤ 失败的可归因程度"。抽卡失败的可归因程度是多少？按这条准则，抽卡的"惩罚强度"应该有多高？现实中的抽卡符合这条准则吗？（这个问题第 10 章和第 21 章还会回来。）
2. 第 8 节说手游是"辅助模式最激进的品类"。如果一款手游把战斗、资源采集、日常全部自动化，玩家剩下的唯一决策是"资源分配和付费"，这还是不是一个游戏？用第 02 章的定义回答。
3. 危机合约把失败成本压到零，深渊有周期结算。如果让深渊也变成"失败无成本 + 分数分级"，《原神》会变好吗？会失去什么？
4. 你所在项目（或你玩的游戏）里，有哪一个玩法的天花板明显高于它的表达渠道？如果给它加一个评分系统，最便宜的做法是什么？
