# 规则书模板（Prototype Rulebook）

> 用法：你的原型从第一次给别人玩开始，就需要一份规则书。文件名建议 `notes/原型-名字-规则-v版本号.md`。
> 原则（第 30 章）：**规则书是 API 文档**。读者是一个从没见过这个游戏、身边没有你可以问的人。每条规则都要回答"什么时候、谁、能做什么、做完之后状态怎么变"，并且每个容易误解的地方都配一个例子。
