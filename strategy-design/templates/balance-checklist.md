# 平衡检查清单（Balance Checklist）

> 用法：原型能完整跑一局之后，每次大改都过一遍。对应 [第 15 章](../15-strategy-space.md)、[第 17 章](../17-balance.md)、[第 20 章](../20-tension-arc.md)。
>
> **这是一张提问清单，不是合格线。** 下面每一条都写的是"多数竞技向策略游戏的常见目标"，你的游戏不一定要这样。例如以政治谈判为核心的游戏，造王可能正是体验的一部分；一款 15 分钟的轻策略，可能本来就只设计了两条路线。所以每条先问"这条目标适用于我的游戏吗"，再看证据。

## 怎么填

每一条按五栏填写：

| 栏 | 写什么 |
|---|---|
| **本作目标** | 这一项你希望游戏是什么样，用自己的话写。可以和下面的"常见目标"不同 |
| **适用性** | 适用 / 不适用（写一句为什么） / 有意保留（这是体验的一部分，写清它服务哪个目标） |
| **证据** | 来自哪里：账面推演、人格卡模拟、真人对局、访谈；写局数和版本 |
| **判断** | 达到 / 部分达到 / 没达到 / **不知道** |
| **下一步** | 判断为"没达到"或"不知道"时，打算用哪种测试或改动回答它 |

"不知道"比"没达到"更危险——它说明你还没测过。"不适用"和"有意保留"不是逃避：写得出理由，就是一个设计决定；写不出理由，就当作"不知道"。

## 1. 策略空间

- [ ] **路线数量**。常见目标：有几条不同的可行路线，并且每条都在测试中赢过。几条算够，取决于游戏长度和重玩目标，不是固定的 3 条
- [ ] **极端策略测试**：让一个玩家只做某一件事（只拿最便宜的、只攻击、只囤积），他不会稳定获胜
- [ ] **镜像测试**：所有玩家都走同一条路线时，游戏仍然有意思（没有变成纯拼运气或纯拼先手）
- [ ] 没有一张牌 / 一个动作是"永远应该拿"或"永远不该拿"的
- [ ] 一条路线被大家识破之后，存在可行的反制（策略地图里没有全行都赢的路线）

## 2. 先手与座位

- [ ] 记录过先手胜率，并且没有明显偏离（2 人局远超 50%、N 人局远超 1/N 都要查）。局数少时只当试测触发线
- [ ] 后手补偿（如有）是能在测试中被调的数值；如果补偿藏在别的规则里（比如平局规则），写清它的强度会随什么变化
- [ ] 多人局里，坐在"强玩家下家"的人没有明显劣势

## 3. 运气与技巧

- [ ] 熟手对新手的胜率明显高于随机（技巧有用）
- [ ] 新手偶尔能赢熟手、输了不会觉得"完全是运气"。这一条取决于目标人群：面向竞技玩家的游戏可以有意不追求
- [ ] 最大的单次随机事件不会单独决定胜负

## 4. 张力与终局

- [ ] "知道谁会赢"的时刻出现得足够晚。多晚算够取决于目标体验；很短的游戏用"最后 20% 时间"这种比例可能不到一轮，要换成"最后一轮之前"之类的具体说法
- [ ] 落后的玩家仍有有意义的决策（不是"陪玩"）
- [ ] 追赶机制不会让领先者觉得"做得好反而被惩罚"
- [ ] 终局触发对所有人可预期（不会有人突然发现"游戏已经结束了？"）
- [ ] 最后一轮的决策是有意思的，不是机械地算分

## 5. 多人政治（3 人以上）

- [ ] **造王**：一个已经不可能赢的玩家，他的选择能否单方面决定谁赢？发生频率多高？对竞技向游戏这通常是问题；对谈判、政治类游戏，它可能是有意保留的体验，要写清理由
- [ ] 打压领先者是可能的，但不是唯一的策略
- [ ] 领先者的身份在多数时间里不是一目了然的（或者规则限制了针对）

## 6. 可读性

- [ ] 新玩家在第一局结束时能说出至少一条"下次我会换个打法"
- [ ] 每个回合的平均思考时间在可接受范围内（记录最长的一次长考，以及它发生在什么决策上）
- [ ] 规则书里没有被问过两次以上却没写进 FAQ 的问题

## 7. 一条规则有没有"新增决策"

改了一条规则、想说它"让玩家多了一个决策"时，分开回答三个问题，**分别报告**，不要合成一个"三项都是才算"的总开关：

1. **影响计分吗？** 它改变了谁赢——这只说明它有分量。所有玩家的选择都不变，只改终局加分，也可能翻转赢家。
2. **改变了局面里的取舍吗？** 拿**能走到的同一个局面**，规则前后各推演一次：原来一好一坏的两个动作现在要权衡了，才算新的取舍。"原来固定选甲、现在固定选乙"只是换了一个固定答案。
3. **玩家发现并使用它了吗？** 真人或人格卡在相关局面里是否真的因为它改了选择。

没观察到的写"尚无证据"，不写"没有"：取舍可能已经存在，只是小样本里还没翻转胜负，或者玩家还没发现。
