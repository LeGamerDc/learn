# 策略游戏拆解模板（Strategy Game Analysis）

> 用法：拆解一款策略桌游/卡牌游戏时复制一份。文件名建议 `notes/拆解-游戏名.md`。
> 和 [game-design 的五层拆解模板](../../game-design/templates/deconstruction.md) 的区别：那份关注体验与系统，这份关注**决策、策略空间与玩家之间的博弈**。
> 原则：规则只写事实；对设计意图、对"高手会怎么玩"的概括一律标 `【推导】`。
