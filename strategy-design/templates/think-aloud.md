# 出声思考记录（Think-Aloud Log）

> 用法：每局游戏挑 **2~3 个关键回合** 填一份，不要每回合都填（会把一局拖到三小时）。文件名建议 `notes/思考-游戏名-日期.md`。
> 原则：**先写当时脑子里真实的想法，哪怕是"不知道，随便拿一个"**。复盘栏留到对局结束后再填。真实的糊涂比事后编的清晰有用十倍。
> 详细方法见 [第 00 章](../00-how-to-learn.md) 和 [第 08 章](../08-review-and-thinkaloud.md)。

## 2. 赛后复盘（对局结束后填）

| 回合 | 我的选择 | 事后看更好的选择 | 错误类型 | 我漏掉了什么信息 / 哪一步 |
|---|---|---|---|---|
| | | | 计算 / 估值 / 读人 / 计划 / 规则不熟 / 无错 | |

错误类型说明（第 08 章）：
- **计算错**：推演时漏了一个对手的回应，或算错了数
- **估值错**：算对了，但对局面的好坏判断错了（例如低估了永久折扣的价值）
- **读人错**：对对手想要什么、会怎么做判断错了
- **计划错**：每一步都合理，但整体路线不成立或转型太晚
- **规则不熟**：不知道某条规则或卡牌效果

## 3. 设计师视角（可选，从第 15 章起建议填）

- 这局里最有意思的一个决策是哪个？是哪条规则制造了它？
- 有没有哪个回合"其实没得选"？为什么？
- 如果把某条规则改掉，这局会怎样变化？
