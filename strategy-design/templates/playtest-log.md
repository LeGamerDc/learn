# 测试记录表（Playtest Log）

> 用法：每次测试一份。文件名建议 `notes/测试-原型名-v版本-日期.md`。方法见 [第 30 章](../30-playtest-balance.md)。
> 原则：**先记行为，再记解释，最后才记你的改法。** 测试时你最想做的事是解释规则和辩护设计，这两件都别做。

## 0. 基本信息

| 项 | 内容 |
|---|---|
| 原型 / 版本 | |
| 日期 / 时长 | 计划 __ 分钟，实际 __ 分钟 |
| 测试类型 | 自测（单人多手）/ 熟人测 / 盲测（只给规则书）/ 破坏者测试 |
| 玩家 | 编号 + 背景（例：P1 熟悉欧式桌游；P2 第一次玩策略游戏） |
| 本次要验证的主假设 | 只写一个（例："后手拿 2 枚硬币补偿后，先后手胜率接近"） |

## 2. 行为观察（对局中记，只记看到的）

| 时间 / 回合 | 谁 | 做了什么 / 说了什么 | 我的初步解读（可空） |
|---|---|---|---|
| | | 例："P2 盯着手牌想了 3 分钟" | 例：选项太多？信息不够？ |
| | | 例："P1 说'这张牌根本没人会拿'" | 例：伪选择 |
| | | 例："第 6 回合大家开始一起打 P3" | 例：打压领先者，是否符合预期 |

重点留意（第 08、19、20 章）：
- **长考**（分析瘫痪）出现在哪里
- **没人犹豫的决策**（可能是伪选择）
- **玩家问的规则问题**（原样记下，写进规则书 FAQ）
- **情绪**：谁在什么时候兴奋、沮丧、无聊、生气
- **"已经知道谁赢了"**的那一刻是第几回合

- "哪条规则你觉得最别扭？"
