# 验算证据（拓展，可选）

> **这个目录不是必读内容。** 课程的定位是纯推演与写作，读者不需要写或运行任何程序，正文和附录 C 已经把需要的结果写成表格。这里放的是作者用来验算正文数字的 Python 脚本，给两类人用：想追查某个数字从哪来的人，以及想在自己的原型上照着做模拟的人。

## 运行方式

- 只用 Python 3 标准库，不需要安装任何包。在课程根目录下运行，例如 `python3 -I evidence/ch15/market_rewrite.py`。
- 大部分脚本几秒内跑完；带大规模模拟的（第 15 章的 `market_rewrite.py`、第 31 章的脚本、附录 C 的模拟）要几十秒到几分钟。
- 模拟脚本都用固定随机种子，重跑应得到同样的数字；换种子后百分比会有小幅波动，量级见各章说明的样本量。

## 证据的口径

读任何一个模拟数字之前，先记住三件事：

1. **规则版本**：脚本实现的是正文里写明的那一版规则。《小集市》以第 04 章起的版本为准（A~6 各 4 张、市场 3 张、起始 3 币、收入 = 面前张数、≥15 分的那一轮结束、平分后手胜、牌堆用完不补）；《庙会》各版本见第 31 章第 3~6 节。
2. **行为模型**：胜率描述的是**写死的人格卡**之间的对局（第 15 章 §2.3、第 31 章第 2 节的人格表），不是真人，也不是最优解。人格换了，数字会变。
3. **精确枚举和模拟要分开**：标【数学】的博弈树、均衡、概率是精确计算；标"模拟"的胜率是抽样结果，有误差。

## 这些脚本证明不了什么

它们只证明"在这套规则和这几张人格卡下，结果是这样"。玩家会不会这样想、觉不觉得有意思、会不会读人和谈判，脚本都回答不了，要靠真人测试（第 30 章）。
