# 第一部分 玩家的工具（第 02~08 章）

## 1. 四问扫描

**一句话**：轮到你时，按固定顺序问四个问题，不让局面里最显眼的东西抢走注意力。出处：[第 02 章](./02-four-questions.md)第 2.2 节。

| 顺序 | 问题 | 具体要问的子问题 | 对付哪种错误 |
|---|---|---|---|
| ① | **目标与距离** | 怎么赢？我离赢还差多少？对手差多少？还剩多少回合？ | 把"拿得多""分数高"当成目标 |
| ② | **合法动作全集** | 我一共能做哪些事？哪些本质相同可以合并？有没有常忘的动作？ | 只看到第一眼看到的动作 |
| ③ | **威胁与机会** | 对手下一步能做什么让我更接近输？我能做什么更接近赢？**我的动作会改变对手的选项吗？** | 忘了对面也在想 |
| ④ | **两个候选，推一两步** | 挑两个最有希望的动作，各推"我做 → 对手最好的回应 → 结果"，比较 | 选了第一个不错的动作就停 |

**三条附加规则**：
- **默认对手走对他最好的一步**，至少当作下限。给对手安排一个"对我方便"的回应，叫一厢情愿的推演。
- **宣布双威胁之前**，先确认对手没有一步马上能赢的棋。
- **强制着可以"免费"多推一步**：对手只有一个应手时，往下推几乎不花成本。

**设计师用法**：你写的每一条规则，最终都表现为玩家四问中某一问变容易或变难。拿四问逐条检查规则：这条规则让哪一问更有意思了？（[第 02 章](./02-four-questions.md)第 6 节）

## 2. 博弈树与倒推

**一句话**：从终局往回标胜负，每个节点都假设轮到的人会挑对自己最好的那一步。出处：[第 03 章](./03-game-trees.md)第 3 节。

**两条标注规则**【数学】：
- 一个局面是**必胜**的，当且仅当**存在一步**能把对手送进必败局面。
- 一个局面是**必败**的，当且仅当**每一步**都把对手送进必胜局面。

**手算步骤**：
1. 画出所有走法，或者改用表（同一局面只算一次，即记忆化）。
2. 给叶子标结果。
3. 从叶子往回，按上面两条规则逐层标注；有收益时，每个节点只按**轮到的那个人自己的收益**取最好。两人零和（如只论胜负）时，这就是极小化极大（minimax）：我的节点取最大，对手的节点取我的最小；一般收益的博弈里，对手取他自己的最好不等于让我最差，不能这样简化（[第 11 章](./11-sequential-commitment.md)第 2.2 节）。
4. **逐支验证**：对每个候选，把对手的最好反击推完，而不是凭"差不多对"的规律走。

**设计师的三个用法**（[第 03 章](./03-game-trees.md)第 8 节）：
- 对自己游戏的**残局**做倒推：最后一两轮是否"领先者必胜，其他人怎么走都一样"。
- 做一个**缩小版**（更少的牌、更小的棋盘）完全倒推，找占优动作或死胡同。
- 对称游戏查后手能否镜像保底；"多一个行动永远无害且无平局"的游戏，预期先手有优势。

## 3. 选择性搜索

**一句话**：算不到底时，只展开少数候选、推到局面平静处，再用估值截断。出处：[第 03 章](./03-game-trees.md)第 7 节、[第 04 章](./04-evaluation.md)第 2 节。

| 剪刀 | 做法 | 新手的样子 | 高手的样子 |
|---|---|---|---|
| **剪宽度** | 每个节点只展开两三个候选（用四问 ①~③ 筛） | 只看第一眼的动作，或者全想一遍想不过来 | 候选经过筛选，常含新手没看到的那个 |
| **剪深度** | 推到某层停下，用估值代替推演 | 随便停，常停在强制着中间 | 等局面平静下来再停 |
| **估值** | 给截断点一个"对我大概多好"的数 | 只看一个指标 | 看多个因素，并知道每个因素何时失效 |

**截断纪律**：对手还有被迫的应手、马上能执行的威胁、一串没吃完的子时，**不要截断**，否则会撞上地平线效应——坏事就在你的搜索深度之外一点点。

## 4. 估值

**一句话**：给"现在还不是终局"的局面打一个快速、方向大致对的分，并记住它在哪里不准。出处：[第 04 章](./04-evaluation.md)。

**好估值的三个要求**（第 2.3 节）：快；方向大致对；**知道自己在哪些局面不准**（最重要）。

**估值 = 基础分 + 局面修正**。三种常见估值和它们怎样骗你：

| 估值 | 基础分 | 会在什么时候骗你 |
|---|---|---|
| 子力价值 1/3/3/5/9【行业口径】 | 子力多少 | 战术不平静时；死局面（多一个象也赢不了）；升变等局面因素 |
| 卡坦岛的点数 | 期望产量 | 资源种类、兑换率、波动、强盗、对手的反应 |
| 永久折扣（璀璨宝石） | 每次省下的量 | 以后还有几次购买用得上它 |

**估值看期限**（第 6 节）：

| 东西 | 价值 |
|---|---|
| 一次性的（现金、分数） | 名义数量不随时间变，实际价值仍看局面 |
| 持续性的（收入、产量、引擎） | ≈ 每次的量 × **还能有用地工作的次数** |
| 达到门槛的一次性奖励（贵族） | 看离门槛多远、会不会被抢先 |

**三条推论**：持续性的东西越晚拿越不值钱；只数"有用的"次数；**期限不由你一个人决定**，按"对手大概何时结束游戏"去数。

**期望**：每种结果 × 概率，再加起来。它不告诉你波动，也不告诉你能不能跨过门槛（见第 18 节）。

## 5. 行动经济与机会成本

**一句话**：行动是最硬的预算；一个动作的真实收益 = 它带来的东西 − 你放弃的最好的东西。出处：[第 05 章](./05-action-economy.md)。

**四步比较**：
1. **数行动**：你一局大约有几个行动？这个动作占几个？
2. **找保底动作**：总能做的那个动作（《小集市》进货 2 币、七大奇迹弃牌 3 金币）就是一个行动的最低价。每个动作先问"它比保底多赚多少"。
3. **算单价，再算整套计划**：收益 ÷ 占用的行动数只是第一步，单价高的格子可能只能用一次。
4. **算机会成本**：被放弃的**最好的**另一个选择的价值。

**机会成本的三个来源**（越往下越容易漏）：

| 来源 | 例子 |
|---|---|
| 同一回合的另一个动作 | 选大集市就不能去小摊 |
| 未来的动作或时机 | 这回合进货，下回合市场可能已经变了 |
| **对手因此得到的东西** | 你不买那张 1 点牌，对手下回合就买走了 |

**口令**：想说"这步不错"时，换成"这步比 ___ 好 ___ 分"。填不出空格，说明还没比较。

**现金回本粗估**【推导】：每回合带来 r 的投资，大约要（价格 + 这个行动的机会成本）÷ r 个回合回本。剩余回合明显少于它，就怀疑这项投资。它只算现金，只能筛掉明显不划算的投资；**剩余回合由对手共同决定**。

## 6. 读对手：对手三问与层级思考

**一句话**：读人大多是替对手算账，最后才是猜心思。出处：[第 06 章](./06-reading-opponents.md)。

**对手三问**（按顺序，越往后越不可靠）：

| 问题 | 怎么回答 |
|---|---|
| **他想要什么** | 规则上的目标 → 当前的需求（缺什么、买得起什么）→ 个人偏好。不要直接跳到第三层 |
| **他看得见什么** | 他手里有哪些信息；**他也看得见你**，你的每个公开行为都是他的输入 |
| **他会怎么想** | 选一个对手模型：随机 / 固定习惯 / 理性 / 层级 |

**先问"这可能是巧合吗"**：一个均匀随机出手的人，10 局里某一种手势出现 7 次以上的概率约 6%【数学】。先算巧合的概率，再结合事先信念决定信多少（算法见第 12 节）。

**层级思考**（level-k）：第 0 层按锚点行动；第 k 层假设对手都是第 k−1 层，选对此最好的应对。**最好的层级取决于对手实际在哪一层**，"比典型对手多一层左右"只是经验近似；方向也取决于规则（猜数 p = 4/3 时多想一层是往上写）。在三元克制循环里，层级每走三步回到原点（Sirlin 的 Yomi 层级）。

**利用的账**【数学】：在石头剪刀布里押对手的偏差赚每局 0.25，若他有 r 的概率读到你，期望 = (1 − r) × 0.25 + r × (−1)。**r 到 1/5 就不再赚钱。** 利用偏差时你自己也出现了偏差。

## 7. 计划与转型

**一句话**：决定一条路线时，同时写下它的退路和转型条件。出处：[第 07 章](./07-planning-adapting.md)第 2、4 节。

| 阶段 | 主要问题 | 主要工具 |
|---|---|---|
| 开局 | 往哪个方向走，怎么不把路走死 | 估值、行动经济、**保留选项** |
| 中盘 | 计划还成立吗，对手在走哪条路 | 读信号、数资源、比预算、转型 |
| 残局 | 还剩几步，每一步精确地怎么走 | 倒推、精确计算 |

**三个转型信号**：资源（路线依赖的东西还剩多少）、竞争（有没有人走同一条路、谁的预算多）、时间（剩余行动够不够）。都还好就坚持；一个明显恶化就**重新估值**（不等于转型）；两个以上恶化通常该转型。

**路线卡**：路线 / 为什么 / 转型条件（两三条可检查的条件）/ 退路。已投入的是沉没成本，不是理由；只问"从现在起，继续和换路线哪个未来更好"。

## 8. 复盘：四格表与错着分类

**一句话**：把决策质量和结果分开，再按固定顺序给错着找根因。出处：[第 08 章](./08-review-and-thinkaloud.md)第 2、3 节。

**四格表**：

| | 结果好 | 结果坏 |
|---|---|---|
| **决策好** | 应得的奖励 | **运气不好**：最容易让人放弃正确做法 |
| **决策坏** | **侥幸**：最容易让人强化错误做法 | 应得的惩罚 |

**判断一个决定**看做决定那一刻的三样东西：**信息**（当时能看到、本来能推出的）、**目标**（累计分、胜率还是名次）、**过程**（有没有列候选、推对手回应、估值）。复盘句式："在当时的信息下，按这局的目标，有没有更好的选择？如果有，我是在哪一步错过它的？"

**错着分类：从最底层查起，找到第一个成立的就停**

```
 1. 规则：我对规则的理解对吗？                       错 → 规则不熟（回第 02 章 ②、重读规则）
 2. 计算：列全动作、算对数了吗？                     错 → 计算错（回第 02 章 ③、第 03 章）
 3. 估值：算都对，"哪个局面更好"判断对吗？          错 → 估值错（回第 04、05 章）
 4. 读人：对对手的预测按当时证据合理吗？             错 → 读人错（回第 06 章）
 5. 计划：单步都对，连起来的路线成立吗？             否 → 计划错（回第 07、05 章）
 6. 都对                                              → 无错，是结果不好（也要记下来）
```

**两个常见分类错误**：把"读人错"当垃圾桶（先问"如果对手是只走最优解的程序，我能预测到吗"，能才是读人问题）；把"计划错"当运气不好（要把相隔较远的关键回合连起来看）。

**设计师用法**：很多测试者犯同一类错，就是一条设计诊断（[第 08 章](./08-review-and-thinkaloud.md)第 6 节）。

# 第二部分 博弈论概念卡（第 09~14 章）

## 9. 收益矩阵、占优与纳什均衡

**一句话**：把一个同时出手的瞬间写成一张表，先划掉被占优的动作，再找没人想单方面改的格子。出处：[第 09 章](./09-simultaneous-games.md)。

**写矩阵的四个要素**：玩家、策略（这一次的动作）、结果、收益。**收益必须反映真实目标**（分数、分差、胜率），写之前先过一遍四问第 ①。**把简化写下来**：保留了哪几个动作、后续影响怎么折算、假设谁不动。

**占优**：
- **严格占优**：X 在对手每一种选择下都严格比 Y 好。
- **弱占优**：X 在每种选择下都不比 Y 差，至少一种情况更好。
- 重复剔除严格劣势策略，要求"相信对手也理性"。

**划线法找纯策略均衡**：
1. 对列玩家的每个选择，在行玩家收益最高的格子的行玩家数字下划线。
2. 对行玩家的每个选择，在列玩家收益最高的格子的列玩家数字下划线。
3. 两个数都被划线的格子是纯策略纳什均衡。**逐格验算**："你改，从 a 变 b，没变好；对方改，从 c 变 d，没变好——没人想动。"（改了一样好也不破坏均衡，所以条件是"都不能变得更好"，不是"都变差"。）

**四种经典结构**：

| 结构 | 纯策略均衡 | 桌上的玩家在想什么 | 典型设计用途 |
|---|---|---|---|
| 囚徒困境 | 一个：都背叛 | 能不能信任，谁先背叛 | 谈判与背叛的张力 |
| 胆小鬼 | 两个：一硬一软 | 他会让吗，要不要虚张声势 | 对峙、诈唬、读人 |
| 猎鹿 | 两个：都合作 / 都单干 | 他会不会退缩 | 合作与联盟的风险 |
| 性别战 | 两个：协调到 A 或 B | 谁先表态，怎么让步 | 盟友之间的分歧 |

**结算冲突规则**（两人抢同一格）：都落空 → 胆小鬼，鼓励谈判；优先权 → 决策转向"怎么拿到优先权"；比大小 → 资源投入比拼；平分 → 常让"都去最好的格子"占优，冲突决策消失；让冲突不可能 → 只保留猜别人；平局本身是结果 → "刚好打平"成为目标。**选哪种看你想要哪种思考，不看公平感。**

**三条设计判断**：发现占优策略，先问它取消了哪个决策（核心决策才修）；均衡 ≠ 最好的结果 ≠ 预测，它是"结构的引力方向"；**调收益数字就是调博弈结构**，算出结构成立的参数区间。

## 10. 混合策略与无差异原理

**一句话**：在混合均衡里，你用到的每个动作对上对手的均衡混合期望都相等，所以你的比例由对手的收益决定。出处：[第 10 章](./10-mixed-strategies.md)。

**2×2 手算**（第 3.2 节）：
1. 设对手以 q 选第一列；写出你选第一行的期望 q × 左上 + (1 − q) × 右上。
2. 写出你选第二行的期望 q × 左下 + (1 − q) × 右下。
3. 两者相等，解出 q（**对手**的均衡概率）。
4. 对对手做同样的事，解出**你**的 p。
5. 检查 p、q 都在 0 和 1 之间；不在，说明不存在两人都混合的均衡。

**速记**：算自己的比例看对手的表，算对手的比例看自己的表。

**三元循环**【数学】：X 克 Y 得 a，Y 克 Z 得 b，Z 克 X 得 c（零和），均衡里 X ∝ b、Y ∝ c、Z ∝ a。**加强一个单位，均衡里变多的是它的克星。** 非循环结构（如点球）强化后该多用还是少用，要看改的是哪一格，用无差异条件重算。

**诈唬频率**【数学，河牌模型】：只在这些假设下成立——单条街、底池 P、下注额 b 已给定；下注方只有坚果和空气两类牌；跟注方只能跟或弃、没有加注；空气数量足够多（第 5 节思考路径 10.3）。此时下注范围里诈唬应占 **b / (P + 2b)**，对手应跟注 **P / (P + b)**。在这个模型里，下注越大，可以诈唬得越多，对手应跟得越少。下注额可选时各档要联合求解，不能把几个固定下注的结果拼起来。

**两个提醒**：①"按均衡出就保底、不怕被针对"**只属于两人零和博弈**；非零和博弈里均衡策略和保底策略是两回事，要分别算（第 3.4 节）。即使在零和博弈里，对有偏差的对手偏离均衡也赚得更多（均衡是读人的基准线）。②"均衡支撑集为奇数"只对**对称零和**的克制系统、且在**非退化**条件下成立；退化时可以有偶数支撑。均衡唯一时支撑集必为奇数，所以先查均衡是否唯一（第 6.4 节）。

## 11. 序贯博弈、承诺与先手补偿

**一句话**：后手看得见时，把局面画成树倒推；威胁要过"假如真走到那一步"，承诺的价值来自对手回应的改变。出处：[第 11 章](./11-sequential-commitment.md)。

**可信性检查**：站到兑现那个节点，按他当时的收益判断"他还会这么做吗"。只在没走到的分支里成立的威胁，纳什均衡查不出来，**子博弈完美**要求每个分支都说得通。可信的威胁常常正因为可信才不用执行。

**承诺生效的三个条件**：撤不回、看得见、对手算得进去。分析时画**两棵树**：不承诺时对手怎么回应，承诺后对手怎么回应。

| 承诺的来源 | 要检查什么 |
|---|---|
| 规则强制（标记、交进公共区、打出不能收回） | 规则里是否真的没有撤回的动作 |
| 后续利益（"下一轮还要你帮我"） | 兑现那一刻后续利益是否还在（最后一轮常常不在） |
| 口头表态 | 违背之后实际损失什么 |

**先手优势的三个来源和一个反作用**：节奏（先启动、多行动一次）、先挑（稀缺选项先拿）、先表态（先承诺逼后手适应）；后手的反作用是**信息**。

**补偿工具箱：先定位优势在哪个时点产生，再把补偿放在能影响那个时点的地方**（"例子"一列是规则事实【规则】；"作用时点"是本课的分析；七大奇迹换方向是不是为了补偿、补偿什么，是对设计意图的推测【推导】，见[第 11 章](./11-sequential-commitment.md)第 5 节）

| 补偿 | 例子 | 作用时点 |
|---|---|---|
| 终局折分 | 围棋贴目（日韩 6.5 目；中国 3¾ 子） | 终局计分 |
| 让先手自己定价 | 六角棋交换规则（就是"我分你选"） | 开局第一手 |
| 蛇形顺序 | 卡坦岛 A-B-C-D-D-C-B-A，只有第二个定居点给资源 | 开局选位 |
| 换方向 | 七大奇迹三个时代传牌左、右、左 | 选秀过程 |
| 加强后手 | 炉石后手多一张起手牌 + 一张幸运币 | 开局资源 |
| 削弱先手 | 万智牌两人局先手跳过首回合抓牌；政变两人局先手只拿 1 金币 | 开局资源 |
| 判定规则 | 《小集市》轮末才判终局、平分后手胜 | 终局判定 |

**补偿前的三步**（第 7 节）：①写一张**权利时间表**（谁先看到、先拿、先付钱、何时失去反悔机会、何时判终局）；②逐条拿掉已有补偿，量出各自贡献和剩下的优势；③检查**粒度**：最小补偿单位比要补的优势还大时，任何整数补偿都会过头，改用拆掉来源、条件补偿、让玩家定价或交替先后手。补偿也有教学成本。

**读模拟结果的三条纪律**：样本降低抽样误差，不降低打法偏差（要跨打法复核）；同一批牌序也不让两局"一样"；发现和解释分开写。

## 12. 证据更新

**一句话**：后验和"先验 × 似然"成正比；两种世界比较时，后验赔率 = 先验赔率 × 似然比。出处：[第 12 章](./12-information.md)第 3 节。

**先分清是哪种"不知道"**（第 2.3 节）：

| 你不知道的 | 属于 | 靠什么改善 |
|---|---|---|
| 已发生但没看见的事（暗牌） | 不完美信息 | 推断、侦察、记牌 |
| 对手的收益和目标（身份、私人估值） | 不完全信息 | 从行为推断类型 |
| 还没发生的随机结果 | 未来的随机 | 概率 |
| 看得见却算不清的后果 | 计算复杂度 | 估值、经验 |

**三步更新**（用频数树最不容易错）：
1. **先验**：看到证据之前，每种世界各占多少。先给实体牌编号，列出等可能的情况再数，不要给标签平均分。
2. **似然**：每种世界里出现这个证据的可能性。**它经常要带一个行为假设**："他是怎么决定给我看这张的？"
3. **后验**：只留下出现证据的那些次，重新算比例。

**赔率形式**【数学】：后验赔率 = 先验赔率 × 似然比。似然比为 1 证据没用；大于 1 支持甲；小于 1 支持乙；比较强弱时把小于 1 的数取倒数。例：一份对局记录的似然比约 7.2，先验 1 : 1 → 约 88%；先验 1 : 4 → 约 64%；先验 1 : 9 → 约 44%。

**三条纪律**：一条证据不要算两遍（口头禅不是第二条证据）；给证据标来源——**规则必然 / 随机产生 / 对手主动选择**，只有主动选择承载意图；给信息加**时间戳**（亮完洗回牌库的牌会过期）。

**信号可信度**：问"**如果真相不是这样，他还会发出这个信号吗？**"做法是比较**不同真相下发这个信号的成本和收益**，看假的一方有没有动机照发。利益冲突时，常见的可信办法是让信号对假的一方更贵，或被识破的代价更大【推导】；利益一致时（猎鹿、性别战），不花钱的廉价信号也能帮忙协调。花了钱的信号不一定可信：弱的一方骗成功收益更大时，同样愿意付。

**信息刻度表**（第 7 节，给原型写一份信息协议）：内容 / 对谁 / 何时 / 精度 / 来源 / 成本 / 有效期 / 可验证。先写"谁在什么时候知道什么"，再写卡牌效果；信息的价值看它能不能改变决定。

## 13. 多人政治诊断

**一句话**：三人以上，先记清行动者、被攻击者、受益者三方，再用一组残局卡审查政治结构。出处：[第 13 章](./13-multiplayer-politics.md)。

**四个术语的边界**【行业口径】：造王 = 已经赢不了的人决定别人谁赢（先用完整终局枚举证明他赢不了）；打压领先者 ≠ 系统给落后者加资源；领先者失控 = 领先本身让后续行动更强；多人单机 ≠ 没有任何互动。

**一次攻击的三本账**：自己的收益、被攻击者的损失、旁观者的免费收益。打第一名可能只是替第二名清路。

**联盟检查**：公平（Shapley 值）和稳定（核）分开查。空核只说明不存在能挡住所有联盟偏离的分配，不是完整的行为预测。

**残局卡审查**（第 8 节）：每张卡写清当前分数、隐藏信息范围、剩余行动顺序、合法动作、终局和平局规则。
1. **按规则枚举**：谁还有获胜路径？谁已经赢不了但能改变胜者？谁付拦领先者的成本，谁免费获益？
2. **按体验询问**：玩家当时以为谁可能赢？他知道自己的动作能改变什么吗？他还在追求本局胜利吗？
3. 规则事实、数学结果、玩家理解分三栏记；用一组**相邻分差**的残局卡检验，调小一个数修好一个残局不算数。

**三种设计手段，各改了什么**：隐藏分数（玩家不知道自己在造王，但权力可能还在）、终局突然性（最后一手没那么"最后"）、限制针对（改变谁能影响谁）；第四种思路是让落后者有自己的目标。**不要三种一起上。**

## 14. 合作、谈判与承诺检查

**一句话**：先分清是哪种"一起"，再算退路、区间和暴露。出处：[第 14 章](./14-cooperation-negotiation.md)。

| 关系 | 该问的问题 |
|---|---|
| 完全合作 | 我们还缺哪一条事实？谁最适合做这一步？ |
| 临时联盟 | 等共同威胁消失，他还有什么理由守约？ |
| 互利交换 | 谈不成的话，我和他各自会怎样？ |

**合作失败的三层诊断**：利益（没有互利空间 → 改收益）、信息（看不到互利空间 → 改呈现）、协调（不敢先付出 → 改交付顺序）。

**谈判三步**：
1. 写下双方的 **BATNA**（谈不成时真的能执行的最好选项）。卡坦岛里银行 4:1、港口 3:1 / 2:1 就是规则写出的退路。
2. 算**可接受区间**：双方都不比退路差的方案；再区分"严格互利"的部分。
3. 焦点（对半分、按上次的价）能降低谈判成本，但先查它还在不在区间内。

**暴露三问**（任何不是当场同时交付的协议）：我先交出什么、交出后能收回吗？到他该兑现的那一刻，兑现和违约各让他得到什么？他违约时我最坏损失多少、承受得起吗？（押金的算法见[第 28 章](./28-asymmetry-negotiation.md)思考路径 28.4。）

**重复博弈两条**：以牙还牙的表现依赖对手池和失误率，要和对手池一起报告；每轮继续概率 δ 不变、"背叛就永不合作"时，本章收益表下合作成立需 δ ≥ 1/2【数学】。轮数确定时，若双方都完全理性、都知道轮数，且这些是共同知识，倒推会让合作从最后一轮一路瓦解【数学】；这是该模型的结论，不是对任意一桌真人的预测，桌上有以牙还牙的人时"先合作、临近终点才背叛"可能拿得更多（第 3.4~3.5 节）。

**设计检查表**（第 7 节）：共同收益是什么 / 谁掌握哪条事实 / 信息怎样流动、代价多少 / 谁做最终决定 / 谁先承担收不回来的代价 / 谈不成或沟通失败时怎样。完全合作游戏另拆四项：共同失败的钟、信息分散、通信受限、决定权。

# 第三部分 设计分析（第 15~20 章）

## 15. 策略空间

**一句话**：分清动作、路线、完整策略，用三问抓伪选择，用地图看路线关系，用极端打法撞漏洞。出处：[第 15 章](./15-strategy-space.md)。

**三个对象**：

| 对象 | 是什么 | 工程类比 |
|---|---|---|
| 动作 | 一个决策点上实际做的一件事 | 一次函数调用 |
| 路线（打法、流派） | 对一组倾向的压缩描述，不回答所有局面 | 一句需求描述 |
| 完整策略 | 对**每一个**决策点都规定怎么做的条件计划，包括永远走不到的分支 | 写完所有边界的实现 |

**人格卡**：把路线补全成别人能照着执行的固定打法，至少写清**买不起时做什么、同点怎么选、门槛是几张**。人格卡故意不看对手，所以不是最优策略。

**伪选择检测三问**：
1. **出口**：攒下的东西能在终局前转成胜利条件吗？要几个动作？通常还剩几个？
2. **存在**：在游戏**实际会出现**的条件里，有没有至少一种情况让它严格最好？
3. **区别**：它和另一条名字不同的路线，后果真的不同吗？（反过来也查：一个名字下是否其实是两条路线。）

**伪选择的五种样子**：无法兑现、后果等价、被占优、条件极少出现、**玩家看不见条件**。前四种改规则，最后一种改组件、布局或教学。

**结论能下多硬**：一个精确反例能推翻"永远最好"；"在我测过的情况里都输"只能说"在这些情况里它是伪选择"。

**策略地图的五条做法**（行 = 我的路线，列 = 对手路线）：
1. 先写版本、人数、终局、平局规则和格子里记的是什么。
2. 路线用行为命名，写停止条件和最怕的局面。
3. 每一对路线交换座次。
4. 每格记一个分岔：最能解释差别的那一刻。
5. 允许空白，标证据强度（精确求解 / 固定打法模拟 / 真人小样本 / 尚未验证）。

地图不是排行榜：每格补"待核实的原因、可能推翻它的局面、证据强度"。

**极端策略测试**：让一个人只做一件事并认真求胜。**能证伪**：简单打法稳定打败认真思考的对手（取舍不存在）、打法让游戏卡死（规则漏洞）。**不能证明**：几种极端打法都输，不证明平衡，也不证明有深度。

**三种策略寿命**：理论上可解（解是否已知、能否被执行）/ 玩家实际掌握（攻略终结了判断，还是打开了新判断）/ 环境不断更新（新内容是否真的改变了核心判断）。

**修空间之前**（第 8 节）：先写"我希望玩家在**什么情况下**认真考虑另一个选项"；一次改动连起三层（规则变了什么 → 候选关系怎么变 → 玩家嘴里多出哪句话）；把关键局面留作回归测试，再摆一个不想受影响的局面查误伤。

## 16. 深度与复杂度检查

**一句话**：先把"复杂"拆成五种负担，再问每种负担有没有帮玩家区分本来难以区分的后果。出处：[第 16 章](./16-depth-complexity.md)。

| 维度 | 玩家在为什么付出 | 可以记录的证据 |
|---|---|---|
| 规则复杂度 | 概念、条件、例外、时序 | 教完还反复被问的条款 |
| 状态复杂度 | 要知道多少变量才能确定合法动作和结果 | 桌面一样、历史不同时局面是否不同 |
| 执行负担 | 为合法完成一次行动要算多少、搬多少 | 数钱、挪标记、漏结算 |
| 记忆负担 | 哪些必须记在脑子里 | 忘了上一手、看漏公开信息 |
| 搜索负担 | 比较候选要展开多少后果 | 出声思考里列出的分支 |
| **策略深度** | 学习能否持续发现新的、影响结果的区别 | 不同水平的人对同一局面给出不同理由 |

**只量能定义的东西**：走法总数、一条走法上的选择点数、局面数、每回合要多知道的信息。不要编一个统一的"深度分数"；精确量化最有用的地方，常常是推翻一个错误解释（树深 ≠ 深度，局面多 ≠ 选择多）。

**规则预算账**（每条新规则一行）：独有收益 / 触发频率 / 学习代价 / 执行代价 / 删掉会怎样 / 反例。写不出具体局面，只写得出"更有策略"，就不合格。

**删除测试**：摆两个局面（它制造的独有选择、它带来的最大执行负担），删掉它重摆；再用极端打法查它是否在防退化。温和版本：**只改呈现，不改规则**。

**三步测**（第 9 节）：让同一个玩家先列合法动作，再说最怕对手哪一手，最后比较两个候选。第一步就错 → 修规则或显示；第二步漏 → 加教学局面；两步都好却没有可比较的候选 → 才怀疑结构太浅。

**呈现三原理**：公开但算不出来，等于隐藏；一个图标一个意思；布局决定计算量。

## 17. 平衡检查

**一句话**：先说清楚你想让什么相等，再设计能把混淆分开的测试。出处：[第 17 章](./17-balance.md)。

| 平衡的对象 | 问的问题 | 能回答它的记录 |
|---|---|---|
| 座次 / 阵营的机会 | 水平相当的人坐不同位置、用不同阵营，机会是否接近 | 换座、换阵营后的胜负，按水平分层 |
| 路线可行性 | 每条承诺的路线是否存在让它成为好选择的局面，玩家认得出 | 策略地图 |
| 参与体验 | 每个位置上的人是否一直有会影响结果的决定 | 出声思考；"你从哪一回合开始觉得没机会了" |

**先写分母**：几人、几局、谁坐哪、平局怎么算、公平值多少（五人局公平值是 20%）。

**三个常见陷阱**：规则对称 ≠ 处境对称（时点差）；对全场胜率 50% 的阵营可能每场都不是五五开（不传递，看阵营 × 阵营的对局表）；用得最多 ≠ 最强。

**成本曲线三关**：共同单位、期限、不可加性（两张 2 币牌 ≠ 一张 4 币牌）。比较时列全合法买法，包括"不买"。

**人数缩放五个维度**：资源供给、市场刷新、争夺密度（两两关系 2 人 1 对、5 人 10 对）、等待时间、联盟结构。每个人数单独签字，把座位胜率列为第一观察项。

**问题 → 测试设计**（第 7 节）：座位优势 → 按事先排好的表轮换座位；路线可行 → **指定**路线并轮换；有没有"永远该做"的事 → 极端策略测试；某张牌是否超值 → 写清单位和期限，在几个不同回合比较；人数 → 测最少、最多、最佳人数；改动是否有效 → 回归局面重摆。

**四句话结论**：我们怀疑什么；哪些记录支持它；什么结果会推翻它；下一版只改什么。

## 18. 运气与技巧

**一句话**：先写清目标在对什么取期望，再逐个决定审计随机是输入还是输出、玩家能改什么。出处：[第 18 章](./18-luck-and-skill.md)。

| 你在乎的 | 该取期望的是 |
|---|---|
| 累计积分、联赛总分 | 分数（期望分） |
| 这一局赢不赢 | 赢记 1、输记 0（胜率） |
| 赢 1、平 1/2、输 0 | 比赛积分 |

**门槛附近的那一点概率决定胜负**。每个有随机的候选写三行：最坏结果；哪些结果达到当前目标；失败之后还有没有补救。"领先求稳、落后求险"只在固定门槛、对手不再行动的残局里大致成立。

**随机制造决策的两条路**（至少走通一条）：
- **作为输入**：随机先发生，不同结果让不同动作成为最好。
- **作为输出**：玩家能选承担多少风险，**而且目标是非线性的**（门槛、生存、名次）。

**输入 / 输出要指明是哪个决定**：同一颗骰子，对本回合交易是输入，对开局放置是输出。把随机挪到决定之前、其他条件不变时，看见后可以拒绝，最优的平均收益**不会降低**；只有不同结果让不同动作成为最好时才**严格提高**（第 3.2 节的例子从 3.5 提到 4；若看见什么都选同一个动作，前移不增值，见第 3.3 节）。提高了就要重新定价，而且不一定提高胜率。

**随机审计表**（每处随机一行）：随机点 / 抽什么 / 何时发生 / 对哪个决定是输入或输出 / 看见之后能改什么 / 怎样影响胜利门槛。**五条纪律**：一次只改一处随机的一个属性（时点、分布、选择权三选一）；同时看期望和门槛概率；准备事先写好的随机序列复现差别；记理由不只记结果；算实体成本。

**技巧差与随机的模型**【数学，《加骰决胜》：强者稳定多 d 分，终局各掷 k 颗独立的公平六面骰，掷完没有任何决定，总分高者胜，**同分抛硬币**（各算半胜）；平局规则一改表就变，例如 d = 1、k = 1 改成同分判强者负，强者胜率是 58.3% 而不是 65.3%】：

| d \ k | 0 | 1 | 2 | 4 |
|---|---|---|---|---|
| 1 | 100% | 65.3% | 61.0% | 58.0% |
| 3 | 100% | 87.5% | 80.1% | 72.8% |
| 5 | 100% | 98.6% | 92.4% | 84.6% |

读法：随机让优势更难在一局里体现，但不让它消失；**没有脱离玩家群体的"运气百分比"**；水平相同的两人无论有没有骰子都是 50%。各局独立、单局胜率固定为 p 时，三局两胜强者赢整场的概率是 p² × (3 − 2p)。

**一条规则对胜负影响大、却和玩家选择无关，它就接近一笔运气分**。初筛【推导】：比较"认真对待它的人格"和"无视它的人格"的结果差多少，结论只对所测的人格成立；更严格的检验是在**同一个局面**里比较两个动作的结果，初筛没差别不能直接认定"选择无关"（[第 31 章](./31-end-to-end-lab.md)思考路径 31.2）。

## 19. 互动与多数决

**一句话**：说清一个动作改变了对手的哪样东西，并用"固定自己、只改对手"的反事实测试找多人单机。出处：[第 19 章](./19-interaction.md)。

**多数决的三个定义**（改任何一个，玩家争的东西就变了）：

| 定义 | 要回答的问题 |
|---|---|
| 门槛 | 至少要有多少才有资格？平局怎么算？ |
| 相对数量 | 和谁比、比什么（独得、分档、比邻居） |
| 计分时点 | 什么时候比，比完之后数量还算不算 |

**算一个增兵选择**：分开写"你多拿"和"对手少拿"，不要把平局起点算成两倍摇摆；对手还有回应时列全组合，取每个选择的保底净差。三人局重算平局规则：追平可能从打压变成搭车。

**四种互动通道**：直接冲突（改变已有资源）/ 抢占与阻挡（改变可用位置、行动）/ 公共市场（改变剩下的选项和时机）/ 交易（改变资源归属与条件）。

**互动强度五维**：频率、幅度、指向性、可预见性、可恢复性。它是找原因的地图，不是处方。

**反事实测试五步**：
1. 固定我：手牌、资源、随机结果不变。
2. 换对手：只改对手的需求、资源或可见状态，摆两三种版本。
3. 看我的最佳动作：所有版本都一样 → 对手的状态没进入我的决定（**线索，不是判定**）。
4. 反过来做一次：我的动作能否改变对手的最佳动作。
5. 换阶段再做：开局和残局常常不同。

排除假阳性：最佳动作不变还可能是占优策略，再查别人是否改变我的**可选动作、收益、获胜机会**（[第 13 章](./13-multiplayer-politics.md)第 7 节）。

**互动链四段**：行动、影响、回应、反作用——"我拿了某物，所以你失去了某个候选；你可以改走另一条路，但要付某种代价；我也因此暴露了自己的需求。"只写得出第一段，说明还没检查受影响的人接下来做什么。多人局再写"谁付成本、谁受损、谁得利"。

## 20. 张力弧与终局

**一句话**：说清纵轴是什么，把"早就知道谁赢"分成两种病，把终局规则写成一份收尾协议。出处：[第 20 章](./20-tension-arc.md)。

**三种纵轴，不能互相代替**：结构（领先者最终获胜的概率）、选择（还能改变名次的候选动作数）、感知（玩家觉得胜负已定的时刻）。测试时分开问"你觉得还有机会赢吗"和"你下一步准备靠什么争取"。

**两种病**：结构锁定（改反馈结构）vs 尾巴太长（缩短尾部）。每局记：大家答案一致的回合、之后还打了几轮、这几轮里还有几个能改变名次的决定。

**锁定点**：领先者胜率第一次达到 90% 的轮次。它是结构指标，不说明每一局都在那一轮锁死。

**追赶手段**（每种改变的东西不同）：给落后者资源（增长速度，防资格被操纵）、让领先者扩张变贵（斜率）、落后者先行动（抢资源的顺序）、给落后者不同路线（替代方案）、多次计分（早期成果的保存）。每条都写清谁有资格、何时判定、能否储存、能否被操纵、领先者怎样回应。

**终局触发三类**：固定期限型（轮数、阶段）/ 达标竞速型（谁能关门、何时关门）/ 资源耗尽型（拿收益时也在消耗大家的时间）。"立即获胜""打完本轮""所有人再走一回合"留给对手的窗口完全不同。

**终局七问**：何时检查、谁标记、触发后谁还能行动、还有没有收入、市场还补不补、终局奖励何时结算、平分怎么判。另写清触发能否撤销、检查的粒度。混合时钟写成一个统一的收尾流程。

**不确定终局的门槛**【数学，《收摊》模型】：投资要等 m 轮兑现 4 分、对比立即得 1 分，每轮继续概率 q。自动兑现时需 q^m > 1/4；兑现要占一个动作时需 q^m > 1/3。兑现越久的引擎越怕不确定的终局。

**最后一轮的四本账**：分数账（已兑现 / 未兑现分开）、资源账（只给窗口关闭前还有用途的存货估值）、行动账、顺序账。**两人局**里，一张公共牌带来的相对分差改善 = 自己得分 + 对手因此少得的分；算完还要对照胜负门槛和平局规则，分差不同的两招可能同样保证获胜（思考路径 20.3 揭示三）。多人局要对每个对手分开算，并看谁是第三方受益者，不能直接相加。

**分析瘫痪：先分辨他在等什么**：

| 停顿原因 | 先试的修法 |
|---|---|
| 不懂合法动作 | 改规则书和提示卡（限时只会让错误更快发生） |
| 看不清资源 | 改组件摆放，公开计数 |
| 比较大量相近的小兑换 | 合并动作、减少重复结算 |
| 计划被别人的行动推翻 | 调整信息公布时点，让他能在等待时提前想 |
| 末局穷举 | 可能正是想要的深度，只在等待明显过长时处理 |

**终局审计五步**（第 7 节）：写三段预期体验并各找一条规则支撑；找反馈回路并估锁定点；站在领先者和落后者位置各看一次；把终局规则写成七问并构造一个"触发者反而输"的残局；检查终局时大家手里常剩下什么。

# 第四部分 原型、测试与交付（第 29~31 章）

## 21. 原型方法

**一句话**：从一个可测试的决策出发，先证明纠结存在，再扩成一局完整的游戏，用人格卡自测找漏洞。出处：[第 29 章](./29-prototyping.md)。

```
 ① 核心决策句      ② 最小决策循环     ③ 策略空间草图     ④ 最小可玩原型      ⑤ 单人多手自测
   X 与 Y 纠结  →    2~3 个动作     →   希望出现哪几条  →   开始/进行/结束/  →   漏洞、卡死、退化、
   因为 Z，对手      验证纠结是真的      路线（第 15 章）     分胜负                时长；记下测不出的
                                                                                  │
          ⑥ 熟人测 / 盲测 / 破坏者测试 → ⑦ 平衡迭代与人数缩放 → ⑧ 规则书（第 30 章）→ ⑨ 端到端（第 31 章）
```

**核心决策句**：玩家在 ___ 和 ___ 之间纠结，因为 ___；对手的 ___ 会改变这个权衡。前两空是同一时刻互斥的两件事；第三空是代价；第四空写不出来，你做的可能是单人谜题。

**三个检验问题**：两边都会有人选吗（否则伪选择）？权衡会随局面变化吗（否则算一次就解掉）？对手能改变它吗（否则多人单机）？三个都过，才值得做原型——这一步的判断仍是【推导】。

**最小决策循环**：2~3 个动作、1 种资源、1 种计分、固定回合数，只回答"这个纠结在桌上存在吗"。

**可玩的四个条件**：能开始（摆法、起始资源、先手）、能进行（回合顺序、每个动作的条件和效果）、能结束（**能机械判断**的终局）、能分胜负（计分和平局）。另查边界：牌堆空了、付不起、所有人都不想做某件事。

**一小时原型检查表**：一页纸规则；四个条件能机械执行；想过至少 3 个边界情况；每人一张参考卡（回合顺序 + 动作列表）；核心决策句写在规则页最上方。

**布局五条规矩**：状态放在桌上不放脑子里；一个状态只有一个位置；公开信息的计算成本也是成本；把"要算的数"变成"要数的东西"；把要比较的东西放在一条视线上。

**单人多手自测五步**：开局前写好人格卡，局中不许改；每个座位按人格卡行动，不替喜欢的那边变聪明；每局换座位；至少 5 局，填测试记录；一次只验证一个主假设。

| 自测能发现 | 自测发现不了（结论标"未验证"） |
|---|---|
| 规则漏洞、卡死、时长、退化策略、经济量级、先手苗头 | 读人与诈唬、多人政治、谈判、可学性、分析瘫痪、情绪 |

**补丁纪律**：防卡死的补丁要检查触发频率，频繁触发的"边界规则"实际上是核心规则。主题可以改，承载核心决策的规则不为主题改（主题负债靠换主题和改呈现来还）。

## 22. 测试规程

**一句话**：一次测试只用一种形式，每种形式只回答它那一列的问题。出处：[第 30 章](./30-playtest-balance.md)第 2~6 节。

| 测试 | 你在做什么 | 能回答 | 不能回答 |
|---|---|---|---|
| **首次教学** | 口头讲规则，然后旁观 | 5 分钟能否教会；第一局卡在哪；核心决策是否出现 | 规则书质量；平衡 |
| **熟人测** | 回答规则问题，记录行为，赛后访谈 | 决策是否有意思；伪选择；张力弧；平衡苗头 | 新手学习曲线；规则书质量 |
| **盲测** | **只给规则书和组件，一句话也不说** | 规则书能否独立教会人；会怎样误读 | 高水平策略深度 |
| **破坏者测试** | 给破坏清单，鼓励钻空子 | 退化策略、卡死、可利用的歧义、造王 | 普通玩家的体验 |

**5 分钟教学顺序**：怎么赢（一句话）→ 轮到你时能做什么 → 桌上这些东西是什么（只讲和动作有关的）→ 示范一个完整回合 → 开始玩，特殊情况遇到再讲。

**盲测规程**：找 2~4 个没见过的人；开场白"我不能回答任何问题"，然后闭嘴；记准备用时、他们**互相问的问题**、每一次误读及对应的规则书行、反复翻看的段落；只在游戏无法继续时介入并标"致命缺陷"；玩错了但能继续，不纠正；结束后再访谈。

**误读四类**：缺失（补写 + 例子）、歧义（改成只有一种读法 + 能区分两种读法的例子）、埋没（移到第一次需要它的位置，参考卡加一行）、冲突（删一处，统一术语）。

**破坏者清单**：只做一件事、拖延、囤积与封锁、送分与造王、钻规则字眼、无限循环。**算"找到了"要两个条件**：可复现、有后果（卡死、稳定获胜、或让某人失去所有有意义的决策）。存在普通玩家能想到的反制，就留着当一条被克制的路线；不存在反制，或者**反制需要所有其他玩家联手**，就要修（第 5 节）。

**每局记录**：8 个字段（人数、先手、胜者、各家分数、回合数、各家主要路线、终局由谁或什么触发、备注）；行为观察五项（长考、没人犹豫的决策、规则问题原话、情绪、"知道谁赢了"的时刻）。汇总只需要画正字。两个廉价的实验设计：**轮换座位、指定路线**。

**三类问题的指纹**（思考路径 30.1）：规则问题——不知道规则是什么或读出两种意思；呈现问题——知道规则，被提醒后立刻承认，错误方向一致；策略问题——知道、也执行对了，判断它不值得。先修执行错误，再看策略。

## 23. 平衡测试与小样本

**一句话**：10 局只能发现大偏差，而且发现的机会也不高；小样本里先看行为，再看比例。出处：[第 30 章](./30-playtest-balance.md)第 7 节、[第 17 章](./17-balance.md)思考路径 17.1。

**真实先手胜率 50% 时，你会看到什么**【数学】：

| 局数 | 先手至少赢 | 概率 |
|---|---|---|
| 10 | 7 局 | 17.2%（约每 6 次测试 1 次） |
| 10 | 8 局 | 5.5%（精确值 7/128） |
| 20 | 14 局 | 5.8% |
| 100 | 60 局 | 2.8% |

**反过来也会漏看**：真实 60% 时，10 局里先手只赢 5 局或更少的概率是 36.7%；真实 70% 时仍有 15.0%。

**95% 区间（Wilson）**：8/10 → 约 49%~94%；16/20 → 约 58%~92%；60/100 → 约 50%~69%。按每局独立、胜率固定，双侧 5%、检出率 80% 的常规标准：把 50% 和 60% 分开约需 190~200 局，把 50% 和 55% 分开约需 780 局。

**四条用法**：
1. 真人测试只能发现大偏差；小偏差交给模拟或结构分析，模拟结论只在"这几种打法互打"的范围内成立。
2. 先改测试设计（换座、指定路线），再加样本量；座位不变时多打只是重复同一个混淆。
3. **行为是小样本里最可靠的信号**：赢家每次都在同一回合用同一个组合拉开差距，比胜负比例更值得警惕。
4. 警惕"东张西望"：同时看 3 条路线、4 个座位、5 个指标，总有一个看起来异常（3 条一样强的路线，3 局里同一条连赢 3 局约 11%）。

## 24. 调参顺序与规则书

**一句话**：按依赖关系从底层往上调，一次只改一个；规则书按 API 文档的标准写。出处：[第 30 章](./30-playtest-balance.md)第 8、10 节。

**调参顺序**：

| 顺序 | 调什么 | 为什么在这里 |
|---|---|---|
| 1 | 规则漏洞、卡死、歧义 | 规则不确定，数据都不可信 |
| 2 | 时长与终局 | 几乎所有数字都依赖回合数 |
| 3 | 经济总量（起始资源、收入、供给） | 路线强弱的地基 |
| 4 | 路线可行性 | 经济稳定之后才能比较 |
| 5 | 座位与先手 | 依赖前面的一切；补偿先写成可调的数，最后定值 |
| 6 | 单张牌、单个数值 | 最局部的最后调 |

**怎么改一个参数**：一次只改一个；先大步试探方向和大小，再回调；改数值改不出结构（问题是"缺少对手"时调回合数没用）；每次改动写进日志——改了什么、依据哪条证据、预期效果、实际效果。

**规则书 = API 文档**：动作对应接口；"什么时候、谁可以做"对应前置条件；状态变化对应副作用；不能做时怎么办对应错误处理；例子对应示例请求；一个概念一个词；版本号与变更记录。

**每个动作按四段写**：条件 / 效果（分步）/ 例子（具体的牌和硬币）/ 注意。被问过两次的问题进 FAQ，但**能改正文就改正文**；示例回合故意包含一两个容易误读的地方。

**规则书坏味道**：同一个东西两个名字；规则藏在例子里；条件和效果混在一句话；用"等等""之类"；例外写在前面；终局条件不能机械判断；没写平局。

## 25. 端到端交付物清单

**一句话**：交出去的不是"一个好玩的游戏"，而是四件别人能接手验证的东西，外加失败的尝试和"不知道"。出处：[第 31 章](./31-end-to-end-lab.md)第 9、13 节。

| 交付物 | 合格的样子 |
|---|---|
| **规则书** | 按[规则书模板](./templates/prototype-rules.md)九个部分齐全；每个动作有条件、效果、例子；终局七问都能找到答案 |
| **策略地图** | 每格写结果、原因（标【推导】）、可能推翻它的局面；没测的格子写"未测"；和动手前画的"预期地图"对照 |
| **测试记录摘要** | 按[测试记录模板](./templates/playtest-log.md)，写清测试类型（自测 / 模拟 / 真人）、规模、数据、行为观察，以及每个主假设被支持还是被推翻；放弃的尝试和没解决的问题另列一节 |
| **自评审清单** | 按[平衡检查清单](./templates/balance-checklist.md)逐条先写本作目标和适用性（可以"不适用"或"有意保留"，要写理由），再写证据和判断；每个"达到"附证据，每个"不知道"写要用哪种测试回答 |

**交付前自问**：
- 我的"测试证据"能证明什么、不能证明什么，各写出三条了吗？（固定策略模拟测结构，测不到读人、谈判、情绪、学习。）
- 每一次诊断，有没有一个**只改动假设原因**的对照实验支持？"两组数字同步变化"不算。
- 每个补丁查过触发频率和**所有人数**了吗？
- 平局规则对座位公平的贡献单独报告了吗？
- 一条影响很多局胜负的规则，"认真对待它的人"有没有多拿到回报？
- 某个人格赢了所有人时，有没有公平改进其他路线、写出针对它的人格再比？还没比之前标"不知道"。
- 每次改动后，整张清单重过了吗？

**[第 20 章](./20-tension-arc.md)的 v0.1 验收**可以当中途检查点：流程验收 F1~F7（规则书齐全、终局可机械判断、平分唯一读法、至少 5 条边界情况、冷读走完第一轮、连续两局零补丁、账本可复算）全部通过；设计证据 D1~D4 至少有三项记录。
