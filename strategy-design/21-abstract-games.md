# 21 - 抽象策略：什么都看得见，难在哪里

## 1. 开场：所有东西都摆在桌上，你还会漏掉什么

上一章你交出了一个能完整玩一局的原型。从这一章起进入阶段四：每章挑一个机制族，看它让玩家反复想什么，再用扑克牌做一个该机制族的小样机。

第一个机制族是最"干净"的一类：抽象策略。没有暗牌，没有骰子，对手能走哪里你随时可以数出来。很多人因此觉得这类游戏只考验"算得多不多"。但如果真是这样，那么只要你足够耐心，就不该犯错。

先下一个只有九个格子的小棋盘。你会发现，最常见的错误发生在"算"之前：你没把某个格子当成候选，或者把"离终点近"当成了"离胜利近"。

### 思考路径 21.1：《三阶六角棋》——九个格子，下在哪里

局面来源：按六角棋（Hex）的连接规则构造的教学小盘面，三行三列，不使用交换规则。真实的六角棋传统用 11×11 的棋盘，这里缩小是为了让每一个分支都能算到底。下文"熟练者 / 专家的想法"是作者按策略原理重建的思考过程，不是真人口述。

**规则（这就是全部）**：A、B 轮流在空格放一枚自己的棋子，放下后不移动、不被吃【规则】。A 要用自己的棋子连通第 1 行和第 3 行；B 要连通 a 列和 c 列。连通指同色棋子沿相邻的格子连成一条链，可以拐弯。谁先连通谁立即获胜。

**六角格的相邻关系**：每个格子最多有六个邻居：同一行的左右、同一列的上下，再加上**右上**和**左下**两个斜角（**不**包括左上和右下）。把每一行比上一行往右错开半格画，就能看到这六个邻居都和它共用一条边。比如 b2 的邻居是 a2、c2、b1、b3、c1（右上）、a3（左下）。

**你能看到的信息**：

```
          a     b     c
行1      [A]   [A]   [B]
行2         [B]   [ ]   [ ]
行3            [ ]   [ ]   [ ]

A 的目标边：行1 和 行3      B 的目标边：a 列 和 c 列
已落子顺序：A a1，B a2，A b1，B c1。现在轮到 A。
空格：b2、c2、a3、b3、c3
```

**轮到你（A）。先在纸上写下三样东西再往下看**：① 你下在哪里 ② 一句话理由 ③ 你预测 B 接下来会下在哪里。

> [!tip]- 提示（只给一个方向，不给答案）
> 先别想"我离第 3 行有多远"。第 02 章四问的第 ③ 问：B 下一步能不能直接赢？如果能，在哪一格？

> [!example]- 揭示一：专家怎么扫描和列候选
> 1. **目标与距离**：A 的 a1、b1 都在第 1 行，还没有任何棋子到第 2 行，至少还要两手才能连到第 3 行。所以 A **这一手不可能赢**。
> 2. **合法动作**：5 个空格，5 个动作。
> 3. **威胁**：B 的 a2 在 a 列，c1 在 c 列。b2 同时是 a2 的邻居（同一行右边）和 c1 的邻居（c1 是 b2 的右上）。所以 **B 下一手放 b2 就形成 a2—b2—c1，立即获胜**。
> 4. **候选**：既然 A 这一手赢不了，又不能放任 B 下一手赢，凡是不占 b2 的动作都可以直接排除。只剩一个候选：**b2**。
>
> 新手在这里最常犯的错是盯着第 3 行，觉得"a3 或 b3 离目标近"。这一步漏掉的不是计算，而是第 ③ 问：他没有先看对手下一步能做什么。

> [!example]- 揭示二：推演与决定
> 5. **推演 b2**：A 放 b2 之后，a1—b1—b2 已经连成一条链，链的末端 b2 有两个邻居在第 3 行：**a3（左下）和 b3（正下）**。A 下一手占任何一个都能赢。
>
>    把 B 的四个回应全部列出来【数学】：
>
>    | B 下在 | A 的获胜应手 |
>    |---|---|
>    | a3 | b3 |
>    | b3 | a3 |
>    | c2 | a3 或 b3 |
>    | c3 | a3 或 b3 |
>
>    B 这一手也没有任何一格能让自己立即连通 a 列和 c 列（b2 已被 A 占住）。所以 B 怎么下都输。
> 6. **其他四个候选**：c2、a3、b3、c3 都让 B 下一手在 b2 立即获胜。程序穷举确认：**b2 是唯一的必胜着，其余四手全部必败**【数学】。
> 7. **决定**：**b2**。把握：完全确定，因为这棵树已经算到底了。
>
> 这一手同时做了两件事：**堵住对手唯一的获胜点，并给自己造出两个入口**。对手每次只能放一枚，堵不住两个入口。这种局面叫**双威胁**（double threat），第 02 章的井字棋里你已经见过它。

> [!example]- 揭示三：如果你原来选的不是 b2
> - 如果你选了 a3 或 b3，理由是"先占终点边"：你的估值依据错了。接触终点边不等于接通起点边，而且你给了 B 一步获胜的时间。
> - 如果你选了 b2，理由是"中间的格子通常好"：答案对了，但理由撑不住。换一个棋形，中间那格可能毫无用处。请补写一句可以检查的理由："b2 堵住 B 的 a2—c1，同时让我的链有 a3、b3 两个入口。"
>
> 两个人可能下出同一手，掌握的东西却完全不同。

**三层对照**：

| 层级 | 会怎么做 | 漏看了什么 |
|---|---|---|
| 初学者 | 下 a3 或 b3，"离第 3 行近" | B 下一手就赢；自己的子还没和第 1 行连上 |
| 熟练者 | 下 b2，"必须堵住" | 只看到防守的一面，没意识到这一手已经赢了，可能在下一手犹豫 |
| 专家 | 下 b2，并列出 B 的四种回应和 A 的应手，确认已经必胜 | 这个结论依赖六角邻接；换成只有上下左右相邻的方格棋盘，b2 和 c1 根本不相邻，整道题不成立 |

**复盘**：用到的是第 02 章四问的第 ③ 问（威胁），以及第 03 章的"把树算到底"。初学者差在第 ③ 问；熟练者差在第 ④ 问：他比较了候选，但没有把自己的那一手推到底，所以不知道自己已经赢了。

**设计师旁注**：制造这个决策的是三条规则：落子不可撤销、双方目标交叉（A 的上下线必然穿过 B 的左右线）、**每次只能放一枚**。最后这条最容易被当成理所当然。假如改成"每回合放两枚"（双方都是），A 这一手直接下 b2 + a3 或 b2 + b3 就连通了，B 根本没有回合可以堵【数学】。整个局面的问题也变了：在每手两子的游戏里，对手一次能堵两个入口，"双威胁"就不够用了，要同时造出三个入口才能压垮防守【推导】。一条看似不起眼的"每次一枚"，定义了这个游戏里什么叫"威胁"。

## 2. 机制族：什么算抽象策略

### 2.1 一个工作定义

本章把**抽象策略**（abstract strategy game）当作一个工作分类【行业口径】：

- 轮流行动，所有影响决策的状态都公开；
- 结算是确定的，没有骰子或翻牌决定动作的结果；
- 主题（如果有的话）不参与判断哪一步合法、哪一步更好。

边界并不绝对。《驯兽师》每局开始时随机抽出 5 张移动卡，但抽完之后所有卡始终公开；《圣托里尼》有希腊神话的外观和可选的神力卡。本章仍把它们放在一起讨论，因为对局中的思考主要来自空间关系和对手的回应。

术语提醒：本章说的"完全公开"，博弈论里叫**完美信息**（perfect information）：轮到你时，之前发生过的一切你都知道。它和"完全信息"（complete information，知道对手的收益和类型）是两个概念，第 12 章已经区分过。

### 2.2 七款代表作，各让你反复问什么

下面只列和思考有关的规则骨架【规则】，完整规则见附录 D。右栏是【推导】：这条规则让玩家每回合反复面对的问题。

| 游戏 | 核心规则 | 它让你反复问的问题 |
|---|---|---|
| 围棋 | 19×19 共 361 个交叉点，黑先，交替落子；终局按所用规则计分（含贴目） | 这里还能多得一点，但别处是不是更急？ |
| 国际象棋 | 白先；将死对方国王获胜；逼和（无子可动且未被将军）是和棋 | 子力、王的安全、行动节奏，哪个此刻最重要？ |
| 中国象棋 | 9×10 交叉点，现代比赛通常红先；将死**或困毙**对方获胜；两将不能照面 | 一条纵线怎样同时影响进攻和自己的合法着法？ |
| 六角棋 | 菱形六角格棋盘（传统 11×11），轮流放子，不移动不被吃；连通己方两条对边获胜；正式对局通常用交换规则 | 哪条连接可以先不管，哪一处必须现在争？ |
| 蜂巢 | 没有棋盘，每方 11 枚六角棋片；所有棋子必须始终连成一体；把对方蜂后六面包围获胜 | 这枚棋子能走，但它离开后蜂巢还连着吗？ |
| 驯兽师 | 5×5 棋盘，每方 5 子；从 16 张移动卡中取 5 张用，用过的卡轮转给对手；吃掉对方师父或师父走到对方神殿获胜 | 我现在用的这张走法，什么时候会变成对手的走法？ |
| 圣托里尼 | 5×5，每人 2 个工人；选一个工人先移动再建造；最多上升 1 层；自己回合里登上 3 层获胜 | 我盖的这层楼，是给自己的台阶，还是给对手的终点？ |
| 步步为营 | 9×9；每回合走一步或放一块墙；不得把任何棋子通往目标边的全部路径封死 | 我花一手放墙，耽误对手的比耽误我自己的多吗？ |

两种"象棋"要分开看：国际象棋里，轮到对手走、对手没有任何合法着法**且国王未被将军**，是逼和，即**和棋**（如果国王正被将军，那就是将死，对手输）；中国象棋里，轮到的一方无子可动就判负（困毙），即**对手输**【规则】。同一个"把对手封死"的计划，在两个游戏里通向不同的结果。这是一个好例子：**无合法动作时怎么判，不是规则末尾的补丁，它会改变玩家主动追求什么**。

### 2.3 去哪里玩

本章的小游戏都可以在 Board Game Arena（BGA）上找到：六角棋（含交换规则）、蜂巢、驯兽师、圣托里尼、步步为营，以及国际象棋和中国象棋【规则，据规则库所列 BGA 页面】。围棋常用 OGS（online-go.com）等专门平台，新手常从 9×9 小棋盘开始，这是惯例不是规则。

如果只有一个晚上，推荐顺序是：驯兽师（约 10 分钟一局）→ 圣托里尼（不选神力）→ 六角棋。每局都用第 08 章的出声思考记录，至少记一个"我没看到对手这一步"的时刻。

## 3. 完全公开，深度从哪里来

第 03 章已经算过一笔账：围棋、国际象棋、11×11 六角棋的博弈树都大到不可能穷举，所以人和程序都只能"选择性搜索 + 估值截断"。这是深度的第一个来源：**树太大**。

但树大不足以解释一切。一张 19×19 的空白方格纸，让两个人轮流在上面打勾、打满为止，树也很大，却没有任何深度。真正让抽象游戏耐玩的，是下面几种规则结构。它们决定了玩家在树上的每一个节点要权衡什么。

### 3.1 交叉目标：一个格子同时改写双方的局面

思考路径 21.1 的 b2 不是"天生值几分"的格子：它的价值来自 A 的链要经过它，B 的链也要经过它。六角棋的两条目标线必然交叉，所以**几乎每一手都同时是进攻和防守**【推导】。

围棋里也有同样的结构，只是更大：在这里多走一手，就意味着别处少走一手。棋盘再大，每次也只能交出一次行动。所以围棋玩家常常面对"这里还没结束，但那里更急"的选择。本章不编造具体棋形和目数，只指出这种权衡来自"每回合一手"与"多个局部同时存在"这两条规则的组合【推导】。

这对应第 02 章四问的第 ③ 问里那个加粗的子问题："**我的动作会改变对手的选项吗？**"在抽象游戏里，答案几乎总是"会"。

### 3.2 公共的东西：谁都能用的地形和走法

第二种结构是**公共资源**：你创造的东西，对手也能用。

《圣托里尼》的楼是公共地形：你盖的一层，对手的工人同样能爬【规则】。所以每次建造都要问两遍："它让我离 3 层更近了吗？它让对手离 3 层更近了吗？"

《驯兽师》把同样的结构用在**动作**上：你用过的移动卡交给对手，成为"等待卡"，对手在他的下一个回合结束时拿到它【规则】。所以检查一张卡时至少要问三件事：我现在用它能做什么；用完之后我手里剩下什么；对手拿到它以后，他的哪个棋子能用它打到我。这里没有任何隐藏信息，但有一条可以推算的时间线。

对设计者，这是一条比"加更多种走法"更省规则的造深度方法：**让有限的能力在双方之间流动**，同一张卡就会因为"现在在谁手里"而价值不同【推导】。代价是呈现要跟上：等待卡要放在一个固定、显眼的位置，否则玩家的注意力会花在"这张现在归谁"上。

下面用《圣托里尼》做一次完整的推演。

### 思考路径 21.2：《圣托里尼》——给自己盖楼，还是封掉公共的终点

局面来源：构造的教学盘面，不是实战复刻。规则采用 Roxley 版双人基础规则，不用神力。下文思考过程为作者重建，不是真人口述。

**本局用到的规则**【规则】：5×5 棋盘，每人 2 个工人。每回合选一个工人，**先移动、再建造**：移动到相邻（含斜向）的空格，最多上升 1 层，可以平移或下降任意层，不能进入有工人或圆顶的格子；然后在**这个工人移动后**的相邻空格上加一层：地面 → 1 层 → 2 层 → 3 层 → 圆顶。圆顶格不能进入。在自己的回合里，工人从 2 层**向上**移到 3 层，立即获胜。

**你能看到的信息**：列 a~e，行 1~5，轮到 A。

```
高度（数字）与工人（A/B）。没标高度的格子都是地面（0 层），没有圆顶。

        a      b      c      d      e
行5     0      0      0      0     0 B
行4     0      0     2 B     0      0
行3     0      1      3      0      0
行2     0     1 A     0      0      0
行1     0      0      0      0     0 A

A 的工人：b2（站在 1 层）、e1（地面）
B 的工人：c4（站在 2 层）、e5（地面）
```

两个最先想到的候选：

- **甲**：b2 的工人平移到 b3（1 层 → 1 层），再把刚离开的 b2 从 1 层盖到 2 层。"我终于有一个 2 层台阶了。"
- **乙**：同样移到 b3，再给 c3 加圆顶。

你也可以提出别的动作，但必须写全"哪个工人、移到哪、盖在哪"。

**轮到你（A）。先在纸上写下三样东西再往下看**：① 你的完整动作 ② 一句话理由 ③ 你预测 B 下一手做什么。

> [!tip]- 提示（只给一个方向，不给答案）
> 先别数自己的楼。B 有一个工人站在 2 层，它旁边有没有空着的 3 层？

> [!example]- 揭示一：专家怎么扫描和列候选
> 1. **目标与距离**：A 的两个工人都不在 2 层，这一手不可能登顶。
> 2. **威胁**：B 的 c4 站在 2 层，相邻的 c3 是空的 3 层。**B 下一手 c4 → c3 就赢了**，登顶即胜，不需要再完成建造。
> 3. **合法性**：甲和乙都合法。b2 → b3 是 1 层到 1 层；移走后 b2 空了，可以在上面盖；c3 是 b3 的邻格，而且是 3 层，再盖一层就是圆顶。
> 4. **候选**：既然 A 这一手赢不了，又存在 B 的一手必胜威胁，所有不能消除这个威胁的动作都可以先排除。

> [!example]- 揭示二：推演与决定
> 5. **推演**：
>    - **甲**：b2 变成 2 层，c3 仍是空的 3 层。B 走 c4 → c3，立即获胜。A 的新台阶永远用不上。
>    - **乙**：c3 变成圆顶，不能进入。场上再也没有 3 层的格子，B 下一手不可能登顶。
>
>    还能不能用别的方法挡？比如把工人走进 c3 占住它？b2 的工人在 1 层，c3 是 3 层，一次上升了 2 层，不合法；e1 的工人离 c3 太远。所以唯一的办法是在 c3 上盖圆顶。
>
>    程序把 A 的**全部 56 个合法动作**都枚举了一遍：只有 3 个动作之后 B 没有一手登顶，它们是 b2→b3 盖 c3、b2→c2 盖 c3、e1→d2 盖 c3，**全部都是给 c3 加圆顶**【数学】。
> 6. **读对手**：甲之后，不要指望 B 看不见一个公开的获胜机会。乙之后，B 会去找新的楼和新的封锁机会，我们没有算后续。
> 7. **决定**：**选乙**（或另外两个盖 c3 的动作之一）。它避免了已知的立即失败；**并没有**证明 A 之后能赢，三个盖 c3 的动作之间哪个更好，也还没有比较。

> [!example]- 揭示三：56 个动作是怎么变成 3 个的
> 你不需要真的把 56 个动作写出来。专家做的是：**先问"对手下一步能不能赢"，再问"我哪些动作能阻止它"**。第一个问题的答案是"c4 → c3"，第二个问题立刻把范围缩小到"让 c3 不能进入"，而唯一能做到的方法是盖圆顶。
>
> 这就是第 03 章说的**剪宽度**：剪刀不是"随便少看几个"，而是用威胁扫描把绝大多数动作一次性排除。初学者看到的是 56 个动作里自己最喜欢的那个；专家看到的是"必须满足的条件"。

**三层对照**：

| 层级 | 会怎么做 | 漏看了什么 |
|---|---|---|
| 初学者 | 选甲，"我终于有 2 层了" | 楼是公共的，对手已经站在终点旁边 |
| 熟练者 | 选乙，"先防守" | 可能把"防住这一手"当成"局面好了"；没想过另外两个盖 c3 的动作哪个更好 |
| 专家 | 先找出唯一的威胁，把候选缩到 3 个盖 c3 的动作，再比较它们之后谁的工人位置更好 | 后续没有算到底，"哪个盖 c3 的动作更好"仍然只是估值 |

**复盘**：甲让 A 的资产增加了，但来不及用。这和第 20 章的终局窗口是一回事：在空间游戏里，"窗口"表现为对手离终点还有几步。初学者差在第 ③ 问；熟练者差在把证明的范围说大了。

**设计师旁注**：制造这个决策的是"**楼是公共的**"。假如改成"只有盖楼的人能爬自己的楼"，被取消的是"把台阶送给对手"这一种风险；但互动不会因此消失：对手进不去的楼反而成了现成的路障，地形封锁可能更强，圆顶和工人占位也照样在挡路。而且这条改法还欠着新规则：一栋楼由两个人先后加层时归谁，要先定义清楚【推导】。圆顶则把"更高"变成"不能进"：同一条建造序列的最后一步，价值方向反转。这让同一个"建造"动作既能当台阶、又能当路障，规则数量没有增加，动作的含义却翻了一倍。

### 3.3 合法性本身要计算：蜂巢与步步为营

第三种结构是：**判断一步棋合不合法，本身就要思考**。

《蜂巢》里，一步移动至少要过这几道检查【规则】：

1. **蜂后放下了吗？** 蜂后必须在自己的前 4 个回合内放下；放下之前，不能移动场上任何己方棋子。
2. **拿走这枚，蜂巢还连着吗？**（"一个蜂巢"规则）任何时刻所有棋子必须连成一体，移动不能把蜂巢断开。
3. **按这个棋种的走法，它能到哪里？** 蜂后滑 1 格，蜘蛛恰好沿蜂巢走 3 格，兵蚁沿蜂巢滑任意格，蚱蜢沿直线跳过一排棋子，甲虫走 1 格并能爬到其他棋子上。蜂后、蜘蛛、兵蚁的滑行还要受"自由移动"限制：不能挤过两枚相邻棋子之间的窄缝。蚱蜢是跳过去、甲虫可以爬上去，二者不受这条滑行缝隙限制。
4. 以上都过了，才轮到"走到那里好不好"。

新手常常只看第 3 步的前半句："兵蚁能滑很远，所以它很灵活。"熟练者会先看第 2 步：这只兵蚁是不是正好连着蜂巢的两半？如果是，它哪里都去不了。**一枚棋子的能力，被它在整体结构中的职责锁住了**【推导】。

还有一个反直觉的地方：包围蜂后的棋子**可以是任意一方的**【规则】。你自己的棋子挤在自家蜂后旁边，也在帮对手完成包围。"己方棋子靠近蜂后更安全"不是可靠的原则。

《步步为营》则把合法性约束用在放墙上：墙不能把任何一枚棋子通往目标边的**全部**路径封死【规则】。这条规则保证游戏一定有路可走。于是放墙永远是"让对手绕路"，不是"把对手关起来"。

放墙时，一个完整的问题是：**这块墙让对手的最短路线变长了几步？让我自己的路线变长了几步？我为了放它，少走了一步。**净收益 = 对手多走的步数 − 自己多走的步数 − 1【推导】。新手常把对手固定在"他原来打算走的那条路"上算，但对手会换路。另外，规则里还有相邻时跳过对方棋子的走法【规则】，所以不能只拿格子距离代替真实的步数。

对设计者，这两个游戏说明了同一件事：**一条合法性约束可以同时是深度的来源和负担**。"一个蜂巢"让每枚棋子都有了位置职责；但如果大部分棋子长期被锁住，玩家每回合只剩一两个可动的棋子，深度就变成了"找唯一能走的那一步"【推导】。

### 3.4 估值截断：经验让你快，也让你看不见

大棋盘算不到终局。第 03 章讲过，玩家只展开少数候选、推几步、在局面平静的地方停下来估值；第 04 章讲过估值本身怎么做。抽象游戏把这件事推到了极端：没有运气帮你掩盖估值错误，也没有运气替你分担责任。

经验能让你一眼认出"这个形状危险""那个位置好"，从而省掉大量无效搜索。但经验也是一把剪刀：它会把"看起来不像好棋"的候选在算之前就剪掉。如果某个好着法恰好长得不像好棋，经验丰富的人反而最难看到它。下一节 AlphaGo 的例子可以从这个角度读，但要记住，这只是对它的一种可能解释。

一个实用的习惯：把你的判断分成两栏，**"已经证明的"** 和 **"暂时估计的"**。思考路径 21.1 的 b2 必胜属于前者；21.2 里"三个盖 c3 的动作哪个更好"属于后者。这种边界感对设计评审同样重要：测试报告里"我们证明了 X"和"我们观察到 X"是两种分量的话。

## 4. 平局与先手：先分清是哪种证据

抽象游戏的讨论里，"和棋太多""先手必胜""白方赢得多"经常出现在同一段话里。它们可能分别在说三件不同的事：规则的结构、数学上的完美对弈、某个玩家群体的实际战绩。三种证据不能互相替代。

### 4.1 三种"平局"

| 类型 | 例子 | 证据性质 |
|---|---|---|
| 结构上不可能平局 | 六角棋：棋盘拓扑决定了不可能平局（第 03 章 5.3 节） | 【数学】 |
| 规则允许、并规定了平局 | 国际象棋：逼和、死局面、三次重复局面、五十回合规则、双方同意；蜂巢：双方蜂后被同一步同时包围，或双方陷入无限循环 | 【规则】 |
| 规则用来**避免**平局 | 围棋：贴目带 .5（如中国规则 7.5 目、日本规则 6.5 目），就是为了不出现同分 | 【规则】 |
| 样本里的平局比例 | 国际象棋某数据库中 34.90% 的对局是和棋（见 4.2） | 【实验】，只对那个样本成立 |

把这几行混排成一张"各棋类和棋率排行"，表格会很整齐，但没有意义：六角棋的 0 是定理，国际象棋的 34.90% 是一个历史数据库的统计，蜂巢的平局是规则给出的一个结局。

平局本身不说明游戏浅。有时它给劣势方一个值得争取的目标，让防守有意义；有时它让双方早早进入一个已知安全的局面，然后停止争胜。设计时要观察的是：**玩家是通过困难的防守拿到平局，还是很早就不想赢了。**

### 4.2 国际象棋：得分率不是胜率

资料清单核实的一个口径【实验：历史数据库统计】：Chessgames.com 截至 2015-01-12 收录的 739,769 局中，白胜 37.50%，和棋 34.90%，黑胜 27.60%。

按"胜 1 分、和 0.5 分、负 0 分"，白方的**得分率** = 37.50% + 34.90% ÷ 2 = **54.95%**【数学】。

| 口径 | 这个样本里的数值 | 不能改写成 |
|---|---|---|
| 白方获胜的对局比例 | 37.50% | 白方得分率 |
| 和棋比例 | 34.90% | 所有水平、所有时限下的平局率 |
| 黑方获胜的对局比例 | 27.60% | 后手的理论失败概率 |
| 白方得分率 | 54.95% | "白方胜率 54.95%" |

第 11 章说过，各种数据库里白方得分率通常在 52%~56% 之间。这里只是把其中一个数据拆开，让你看清"得分率"和"胜率"差在哪里：差的正是那 34.90% 的和棋。这也不是对照实验：数据库收录哪些对局、棋手水平如何、什么时限，都会影响数字。

### 4.3 先手补偿：贴目和交换，以及交换的前提

第 11 章已经比较过两种先手补偿：**贴目**把先手优势在终局换成分数（围棋），**交换规则**让后手决定要不要接手先手的第一手（六角棋），后者和"我分你选"是同一个机制。这里补一个那一章没展开的区分：理论上谁必胜，和实战中谁赢，是两回事。

先说理论层。六角棋是有限、确定、完美信息、不可能平局的游戏，而且第一手不会立即结束对局。所以第一手下完之后的局面一定有确定的值：要么对执这一方的人必胜，要么必败。后手只要站到必胜的那一边：第一手对下的人必胜，就交换接手；必败，就不交换。所以**有交换规则时，后手理论上必胜**【数学】。这个结论不要求棋盘已经被人算透，11×11 上同样成立。

那交换规则为什么在实战中还能起平衡作用？因为"后手必胜策略存在"和"后手真的赢"之间还隔着两层能力：

| 层次 | 后手需要什么 | 证据性质 |
|---|---|---|
| ① 必胜策略存在 | 什么都不需要，由游戏结构决定 | 【数学】，任何尺寸都成立 |
| ② 知道该选哪个阵营 | 能判断这一手开局对下的人是必胜还是必败 | 取决于玩家的知识 |
| ③ 会执行获胜策略 | 选边之后，在接下来的每一手都走对 | 取决于玩家的计算和经验 |

在 11×11 的棋盘上，第 ② 层就很难：没人知道每个开局的确切值，先手可以挑一个"连自己都说不准"的开局，让后手难以判断。第 ③ 层同样难，选对了边也可能下输。交换规则的平衡作用来自这两层的困难，而不是来自理论值【推导】。在你自己设计的小棋盘上，这两层都可能很快被跨过。这正好引出下一个思考路径。

### 思考路径 21.3：《方格双桥》v0.1——十六格填满却没人连通，改哪条规则

局面来源：本章自定的扑克牌原型（完整规则见"动手"一节），这里是一次设计决策。所有数字由程序穷举得出。下文思考过程为作者重建。

**v0.1 规则**：4×4 的方格，列 a~d，行 1~4。红方用 8 张红色扑克牌，黑方用 8 张黑色牌，红先，轮流把一张牌放进一个空格，放下不动。红方要连通 a 列和 d 列，黑方要连通第 1 行和第 4 行；**只有上下左右算相邻**。先连通者立即获胜；16 格填满都没人连通，平局。

**你能看到的信息**（几次试玩后，你让程序算出的数据）：

- 完美对弈下，v0.1 是**和棋**；红方 16 种第一手，每一种在双方都走对的情况下都是和棋【数学】。
- 如果把 8 红 8 黑随机填满棋盘（所有 12,870 种填法），有 6,038 种（46.92%）双方都没连通【数学】。这不是对局结果，只说明"堵住彼此"在这个棋盘上非常容易。
- 试玩感受：两个人很快学会互相堵，然后一起把格子填满。

四个候选改法：

- **A**：平局判黑方（后手）胜。
- **B**：除上下左右外，每格再连**右上**和**左下**两个斜角。
- **C**：每格连全部 8 个方向（上下左右 + 四个斜角）。
- **D**：棋盘扩大到 5×5（红 13 张、黑 12 张），邻接不变。

**设计目标**（选之前先看清）：要的不是"平局变少一点"，而是同时做到两件事：
1. **每局都以某一方真正连通而结束**：不能靠"都没连通时判给谁"来分胜负；
2. **一方的连接本身就是挡住对方的墙**：保住"一手既攻又守"的交叉结构。

**轮到你（设计师）。先在纸上写下三样东西再往下看**：① 你选哪个改法 ② 一句话理由 ③ 你预测改完之后最先暴露的新问题是什么。

> [!tip]- 提示（只给一个方向，不给答案）
> 对每个改法分别问两个问题：棋盘填满时，是否必然有一方真正连通？一方连通之后，另一方是否必然连不通？可以先在纸上各摆一个反例试试。

> [!example]- 揭示一：专家怎么扫描和列候选
> 1. **目标**：按上面的两条设计目标逐个检查。
> 2. **逐个看**：
>    - **A（平局判黑胜）**：v0.1 完美对弈是和棋，也就是说红方无法强行连通。把平局判给黑方，黑方理论上就必胜，而且只要**纯粹堵截**、永远不用自己连通。平局没有消失，只是被改名为"黑胜"，目标 1 没有达到；先手的劣势还被放大了。
>    - **D（5×5）**：红黑相间的棋盘格摆法里，任何两张同色牌都不上下左右相邻，谁都连不起来，5×5 照样可以填满成平局【数学】。扩大棋盘只增加了计算量，没改掉导致平局的结构，目标 1 没有达到。
>    - **C（八方向）**：12,870 种填满方式里没有一种是双方都没连通，目标 1 达到了；但有 6,038 种是**双方同时连通**【数学】：红链和黑链可以在斜角处互相穿过。两条链仍然要抢同一批格子，一格被我占了你就不能用，所以抢点和封堵还在；失去的是"我连通了，就等于把你挡住了"——连接不再自动构成阻断对方的屏障，目标 2 没有达到。至于游戏会不会因此更偏向"各连各的、比谁快"，那是【推导】，要靠测试。
>    - **B（加右上、左下）**：这正是六角棋的相邻关系。4×4 方格加这两条斜向，和 4×4 的六角棋是**同一张图**：每格的邻居一一对应。所以六角棋"不可能平局"的定理直接适用；穷举 12,870 种填法，每一种都**恰好**一方连通：没有人都不连通，也没有双方同时连通【数学】。两条目标都达到。
> 3. **候选**：B 是唯一同时满足两条设计目标的改法。

> [!example]- 揭示二：推演与决定
> 4. **推演 B 带来的新问题**：既然 v0.2 就是 4×4 的六角棋，第 03 章的策略窃取论证也适用：先手存在必胜策略。程序算出了更具体的结果：**红方先手必胜，但 16 种第一手里只有 d1、c2、b3、a4 这 4 手（从右上角到左下角的那条斜线）是必胜的，另外 12 手都是必败**【数学】。
> 5. **要不要立刻加交换规则？** 按 4.3 节，加交换规则后后手理论上必胜，这一层与棋盘大小无关。在 4×4 上要担心的是另外两层被跨过得太快：后手只要记住那 4 个格子，就知道该选哪边（第 ② 层）；棋盘这么小，选边之后把必胜局面下完也不算难（第 ③ 层）。所以交换规则在 4×4 上能撑多久，取决于你的测试者多快发现"那条斜线"，以及选对边之后能不能稳定地赢下来。
> 6. **决定**：**选 B，出 v0.2**；同时把"先手优势"列为下一个要测的问题，并准备两个方案：小棋盘上的交换规则（测它多久失效），以及扩到 5×5 的六角邻接（六角棋的定理仍然保证不可能平局、无交换时先手存在必胜策略，但人手算出必胜开局要难得多）。
>
> 把握：B 消除平局是确定的（定理 + 穷举）；"玩家会觉得 v0.2 更好玩"只是【推导】，要靠测试。

> [!example]- 揭示三：如果你选了 A 或 C
> - 选 A 的理由多半是"最省事，只改一句话"。省事是真的，但你可以用一个问题检查任何"平局判给某一方"的改法：**原来的游戏在完美对弈下是什么结果？** 如果是和棋，那么平局判给谁，谁就理论必胜。改法 A 让 v0.1 变成了"黑方只要会堵就赢"。
> - 选 C 的理由多半是"连接更容易，平局自然少"。满盘时确实总有人连通，但代价是"连接即阻断"不再成立。可以亲手摆一下：红 a1、b2、c3、d4 一条斜线和黑 d1、c2、b3、a4 一条斜线，在八方向邻接下两条都连通。双方仍然在抢同一批格子，只是谁先连通都不再意味着把对方挡住了。

**三层对照**：

| 层级 | 会怎么做 | 漏看了什么 |
|---|---|---|
| 初学者 | 选 A 或 D，"规定一下就行""棋盘大了就不容易堵" | A 只是给平局改名；D 没有动导致平局的结构 |
| 熟练者 | 选 C 或 B，"让连接更容易" | 没区分 C 和 B：C 让双方链条可以斜着穿过彼此，连接不再自动阻断对方 |
| 专家 | 选 B，认出它与六角棋同构，引用定理，并预告先手优势这个新问题 | 小棋盘被算透的速度：测试者可能三五局就找到那条斜线，专家也说不准是几局 |

**复盘**：这是一个设计层面的四问：① 目标是"每局由真正的连通分出胜负，且连接即阻断"，不是"减少平局"；② 候选要全；③ 每个改法的"威胁"就是它带来的新问题；④ 比较时把 A、C 的副作用推到底。这里用到的工具是第 03 章的"完美对弈下的结果"和策略窃取论证：**先问理论值，再决定平局规则**。

**设计师旁注**：六角棋最值得学的不是它"规则少"，而是它用**一条邻接规则**同时解决了两个问题：两条目标线必然交叉（所以每一手都攻守兼备），以及不可能平局（所以不需要任何平局规则）【推导】。方格纸上的一条斜线，就能把这个结构借过来。但也要注意：借来的是定理的前提，定理才跟着来。如果你在 v0.2 上再加一条"可以移走对手的牌"，"多一颗子永远不会有害"就不再显然成立，策略窃取论证要重新检查；"任意满盘必有一方连通"这条拓扑结论仍然成立，但"游戏一定会走到满盘"不再有保证，终止性要重新证明。

## 5. AlphaGo 第二局第 37 手：证据能撑到哪里

前面的局面都能算到底，所以你可以证明自己对。现在看一个算不到底的真实例子。把它放在小局面之后，是为了让你先知道"证明"长什么样，再看"没有证明时能说什么"。

**史实**【规则库史实条目】：2016 年 3 月 9~15 日，AlphaGo 在首尔与李世石下了五番棋，AlphaGo 4:1 获胜。第二局（3 月 10 日）AlphaGo 执黑，第 37 手是一手**肩冲**（shoulder hit），当时职业解说普遍感到意外。

DeepMind 官方页面（deepmind.google 的 AlphaGo 介绍页）说，第二局的第 37 手是 "a move that had a **1 in 10,000 chance of being used**"（一手只有万分之一被使用几率的棋）。

引用这句话时有三个容易犯的错：

1. **不要替它补上技术解释。** 官方原话里没有说这个概率是怎么来的，本章也不替它补。
2. **不要和第四局第 78 手混淆。** 第四局李世石下出的第 78 手也常被冠以"万分之一"的说法，那是李世石的棋，不是 AlphaGo 的棋。
3. **不要把"使用几率"读成"胜率"。** 一手棋很少被下，说明它不常见，不说明它好或坏。

这个例子**能支持**的结论是：**人类熟悉的估值习惯可能被挑战。** 一手让当时的职业解说普遍感到意外的棋，出现在一盘 AlphaGo 最终获胜的对局里，说明人类对这类棋的通常评价至少值得重新检查。

至于人类为什么没想到它，现有证据分不出来。一种可能是 3.4 节说的经验剪刀：这类棋在计算之前就被当作"不用考虑"剪掉了；另一种可能是想到了、也算了，但估值估错了。本章把前一种当作**教学上的一种可能解释**来用，它不是对当时任何人思考过程的事实描述【推导】。

它**不能支持**的结论是：

- "第 37 手是那个局面唯一最优的一手"：没有人把那个局面的所有候选算到终局，获胜也不等于其他候选都更差。第 08 章讲过：结果好不等于决策被证明。
- "罕见的棋往往是好棋"：罕见和价值是两个维度。一个例子说明罕见的棋**可以**是好棋，说明不了罕见的棋**往往**是好棋。
- 某个具体的胜率数字或棋盘坐标：本章没有核实过的数字一律不写。

对你有用的是这个态度：**面对算不到底的局面，扩大候选、检查估值依据、承认没有证明**。不要把"陌生"直接升级成"天才"，也不要直接判成"错误"。回到 3.4 节的两栏：第 37 手到底多好，仍然属于"估计"那一栏；它提醒你检查的，是自己的估值习惯和剪枝习惯会不会把某类着法过早排除。

一个练习方法：每次复盘时，在你的候选之外，刻意加一个"看起来不顺眼但合法"的动作，问它改变了哪条关系。大多数时候你会把它排除，排除本身就是有效的结果；偶尔你会发现自己的经验剪刀剪掉了不该剪的东西。

## 6. 设计师视角：做一款小型抽象游戏

1. **从一个关系出发，不从棋子名单出发。** 先写一句你想让玩家反复面对的问题，例如"占这里能接上我的线，但会不会放出对手的另一条线？"再用最少的棋子和格子实现它。每加一种走法，都要能摆出一个**原来没有的新判断**，而不是只多一种动画（第 16 章的规则预算）。
2. **每条约束都在干活。** "每次只放一枚"定义了什么叫威胁（思考路径 21.1）；"楼是公共的"让建造有了两种含义（21.2）；"不能封死全部路径"让墙只能拖延不能关押（3.3 节）。改规则前先问：这条约束现在在承担什么工作？
3. **先保证会结束，再保证结束得有意思。** 只往空格放子的游戏，格子用完就一定结束。棋子能来回移动的游戏，就要处理循环：国际象棋有三次重复局面和五十回合规则，中国象棋禁止长将，蜂巢允许把无限循环判和【规则】。终止性只是底线：最后几手可能全是没有意义的填空，也可能每一手都还在争，这要靠测试记录尾段（第 20 章）。
4. **平局规则要在知道"理论值"之后再定。** 如果你的游戏在完美对弈下是和棋，那么"平局判给某一方"就等于宣布那一方理论必胜（思考路径 21.3 的改法 A）。能从结构上消除平局（六角邻接），通常比事后指定胜者更干净【推导】。
5. **先手补偿要看可算性。** 有交换规则时后手理论上必胜；交换规则在实战中的平衡作用，靠的是后手难以判断第一手的值、也难以把必胜局面下完。棋盘越小、越容易被算透，这两层难度消失得越快，交换规则就越快变成"后手稳赢"（4.3 节）。小棋盘可以先用"交换座次、成对记录"观察先手优势，再决定补偿方式；两种做法不要混在同一批记录里（第 17 章）。
6. **公开信息要一眼可读。** 抽象游戏没有隐藏信息可以帮你藏复杂度，所有负担都落在"看懂盘面"上。目标边要画线，驯兽师式的等待卡要有固定位置，相邻关系要画在纸上而不是靠记。如果测试者总是问"这两格算不算连着"，先修呈现，不要先修规则（第 16 章第 7 节）。
7. **为新手准备台阶。** 一个可用的学习顺序是：看出自己的立即获胜 → 防住对手的立即获胜 → 造双威胁 → 比较算不到底的长期结构。这是教学建议，不是所有抽象游戏都遵循的规律【推导】。给每一级准备一个小盘面，让测试者先下再看答案，就像本章的三个思考路径。

## 7. 常见误区

| 误区 | 为什么错 | 正确理解 |
|---|---|---|
| 没有随机就没有不确定 | 你仍然可能算不清后果、估错局面 | 不确定来自计算和估值的极限，不只来自骰子 |
| 离目标边近就是离胜利近 | 接触终点不等于连通起点；对手可能下一手就赢 | 先查双方的立即胜负，再谈位置 |
| 防住对手一手就说明局面好了 | 消除一个威胁不等于解完后续 | 分清"已证明"和"暂时估计" |
| 先手存在必胜策略 = 先手一定赢 | 存在性证明不给出走法；玩家会走错 | 理论值和实际胜率是两件事 |
| 白方得分率约 55% = 白方赢了约 55% 的对局 | 和棋按半分计入得分率 | 同时报告胜、和、负和样本来源 |
| 平局太多，规定"平局后手胜"就好 | 如果完美对弈是和棋，这等于宣布后手理论必胜 | 先求理论值，优先从结构上消除平局 |
| 有交换规则，先手优势就消失了 | 理论上它把必胜方换成了后手，任何尺寸都如此；在小棋盘上后手很快学会选边和执行，就会稳赢 | 交换规则的平衡作用来自"判断第一手的值"和"执行必胜策略"这两层难度 |
| 第 37 手罕见，所以它是唯一最优 | "使用几率"不是胜率，获胜不证明其他候选更差 | 只能说它挑战了人类的估值习惯 |
| 加棋种、扩棋盘就能加深度 | 可能只放大了计算量和记忆负担（如 5×5 方格仍可平局） | 先摆出新规则制造的新判断 |

## 9. 动手：用扑克牌和纸格做《方格双桥》

这是本章自定的小型连接游戏，目的是让你亲手经历一次"发现平局问题 → 改一条邻接规则 → 处理随之而来的先手问题"。它是一个机制族小样机，不要求并入你从第 15 章开始做的原型；做完后把发现带回去即可。

### 9.1 材料与 v0.1 规则

**材料**：一副扑克牌、一张纸、一支笔。

**棋盘**：在纸上画 4×4 的方格，每格能放下一张扑克牌（或者把牌竖着压一角，保证格号看得见）。列标 a~d，行标 1~4，第 1 行在上方。用红笔描出左右两条边（a 列外侧、d 列外侧），用黑笔描出上下两条边。**呈现本身就是规则的一部分**：目标边画清楚，能省掉一半的规则提问。

**v0.1 规则**【规则：本章自定】：

1. 红方拿 8 张红色牌（红桃、方块），黑方拿 8 张黑色牌（黑桃、梅花）。点数和花色没有作用，只有颜色。所有牌公开放在各自手边。
2. 红方先。双方轮流把一张自己的牌放进一个空格。不能移动、覆盖、拿走，也不能跳过。
3. **相邻**：只有上下左右四个方向。
4. 红方要用红牌连通 a 列和 d 列，黑方要用黑牌连通第 1 行和第 4 行。链可以拐弯。
5. 每次放牌后检查放牌的一方是否连通，连通者立即获胜。16 格填满仍无人连通，平局。
6. 下一局交换颜色。

一次放牌只会增加自己颜色的牌，所以不会出现"一手同时让双方都连通"的情况；16 次放牌之后游戏一定结束【数学】。

**先玩 3 局 v0.1**，每局记下：谁赢了、或者是不是平局；平局的话，是从第几手开始两人都在"只堵不连"。

### 9.2 v0.2：加两条斜线

**唯一的改动**：每格除上下左右外，还和**右上**、**左下**两个斜角相邻（左上、右下**不**相邻）。在纸上把每个格子的右上角和左下角用一条短斜线"/"连起来，让所有人一眼看见。

这就是 4×4 的六角棋（思考路径 21.3）。它保证：**不可能平局**；红方先手在完美对弈下必胜，但 16 种第一手里只有 4 种必胜【数学】。先别告诉测试者是哪 4 种。

**一段示范对局**（用来检验规则理解，不是最佳着法）：

```
1. 红 b3     2. 黑 c2     3. 红 c3     4. 黑 d3
5. 红 d2     6. 黑 a3     7. 红 a4  → 红胜：a4—b3—c3—d2

最终盘面（行1在上）：
        a    b    c    d
行1     ·    ·    ·    ·
行2     ·    ·    黑   红
行3     黑   红   红   黑
行4     红   ·    ·    ·
```

摆完让另一个人解释：a4 和 b3 为什么相连（b3 的左下）？c3 和 d2 为什么相连（c3 的右上）？再看第 3 手之后的局面：红的 b3—c3 往左有 a3、a4 两个入口，往右有 d2、d3 两个入口。黑方每次只能堵一个，红方就在同一侧补另一个。这和思考路径 21.1 的"两个入口"是同一个结构，在六角棋玩家里常被叫作"桥"——这也是这个小游戏名字的由来。

**玩 4 局 v0.2**，交换先后手。每局记录红方第一手下在哪里、谁赢；挑一个关键回合，按思考路径的格式写下两个候选和你对对手的预测。

### 9.3 v0.3：处理先手

如果 4 局里先手赢得明显多，加交换规则（练习题 7）：红方第一张牌放下后，黑方可以选择接手红方阵营。然后**专门观察**：先手开始故意下在哪里？后手靠什么判断要不要交换？多少局之后有人发现了"那条斜线"？发现之后，选对边的一方能不能稳定地赢下来？

如果你想让游戏活得更久，可以试 5×5 的六角邻接（红 13 张、黑 12 张）。定理照样保证不可能平局、无交换时先手存在必胜策略，但手算出必胜开局会难得多。注意这是另一个版本，记录要分开。

### 9.4 交付物与验收

1. **一页规则 v0.3**：写明邻接、胜负、交换规则，附一张画好斜线的棋盘图。
2. **完整记录**：v0.1 至少 3 局、v0.2 至少 4 局、v0.3 至少 4 局；每局写结果和先手的第一手。
3. **一张局面卡**：从你的对局里挑一个"轮到某方、有唯一正确着法"的中间局面，写出全部状态、答案和理由（像练习题 6 那样）。如果你不确定答案唯一，就写"暂时估计"，不要写"已证明"。
4. **一段反思**（200 字左右）：v0.1 → v0.2 改了一条规则，测试者的行为变了什么？先手问题是怎么暴露的？哪个结论是你算出来的，哪个只是观察到的？

验收标准不是"像围棋一样深"，而是：别人只看你的规则页就能开局并下完；你能指出至少一个"受对手影响的选择"；你声称的每一个短变化，别人都能在纸上复算出来。最后问自己一个问题，带回你的原型：**你的原型里有没有一条规则，像 v0.1 的"只有上下左右"一样，在悄悄制造你不想要的结局？**

## 11. 练习题参考答案

> [!example]- 第 1 题
> (a) a2、c2、b1、b3、c1（右上）、a3（左下）。最容易漏的是两个斜邻 c1 和 a3。
>
> (b) B 下 **b2**，形成 a2—b2—c1，连通 a 列和 c 列，B 获胜。A 下 a3 时自己的链（a1、b1）还没到第 2 行，a3 和它们不相连，所以 A 也没有抢先获胜的可能。
>
> (c) A 的链 a1—b1—b2 已经连到第 2 行，b2 在第 3 行有两个邻居 a3 和 b3。B 每次只能放一枚，堵 a3 则 A 下 b3，堵 b3 则 A 下 a3；B 下别处，A 任选一个。B 自己也没有一手获胜的格子。

> [!example]- 第 2 题
> (a) 三个动作都是**给 c3 加圆顶**（b2→b3 盖 c3、b2→c2 盖 c3、e1→d2 盖 c3）。威胁只有一个：B 的 c4（2 层）走上 c3（3 层）。能消除它的方法只有让 c3 不能进入，而唯一的办法是在 3 层上盖圆顶。
>
> (b) b2 的工人站在 1 层，c3 是 3 层，一次要上升 2 层，规则只允许上升 1 层；e1 的工人和 c3 不相邻。所以"占住终点"这个想法在这里不合法，只能"封住终点"。

> [!example]- 第 3 题
> (a)【数学】（规则库记载为由棋盘拓扑决定的定理，第 03 章 5.3 节）。(b)【实验】，具体说是一个历史数据库的统计，不是对照实验；白方得分率 = 37.50% + 34.90% ÷ 2 = 54.95%，它不是白方胜率（胜率是 37.50%）。(c)【规则】。(d) 证据不足：官方只说这手棋"只有万分之一被使用的几率"，没有人证明它是唯一最优。
>
> 判断的要点是分开问两件事：这个说法的**输入**从哪里来，**结论**是怎么从输入推出来的。

> [!example]- 第 4 题
> **每回合两枚**：A 直接下 **b2 + a3** 或 **b2 + b3**，这一手就连通第 1 行和第 3 行，立即获胜【数学】。原来的问题"怎么防住 B 同时造双威胁"消失了，因为 A 有足够的子在一回合里完成整条链。决定变了，是因为"每次能做多少事"变了：在每手两子的规则下，B 的一手威胁（b2）也不再是 A 必须单独处理的问题。
>
> **必须下第 3 行**：A 只能在 a3、b3、c3 中选一个，这三格都不能立刻把 A 的链连到第 1 行，也都没有堵住 b2。B 下一手 b2 获胜。三个选择全部必败【数学】。决定"变了"是因为合法动作的全集变了：第 ② 问的答案里没有 b2。
>
> 两次改动都说明同一件事：同一个局面的答案，由"合法动作是什么"决定。

> [!example]- 第 5 题
> **现在乙危险，甲安全。**
>
> c3 变成 2 层后，场上没有 3 层的格子。甲把 b2 盖到 2 层，场上仍然没有 3 层，B 下一手无法登顶。乙在 c3 上盖一层，把它从 2 层变成 **3 层**（不是圆顶，圆顶只能盖在 3 层上），B 的 c4 工人（2 层）正好可以走上去获胜。
>
> 程序枚举：这个变体里 A 有 63 个合法动作，60 个安全，3 个不安全，而那 3 个恰好就是原题里那 3 个"盖 c3"的动作【数学】。原来"必须盖 c3"的理由完全翻转。
>
> 要点：同一个建造动作，盖在 2 层上是"给对手造终点"，盖在 3 层上是"封死终点"。这就是 21.2 设计师旁注说的"价值方向反转"。

> [!example]- 第 6 题
> **原局面：下 c2。** 理由分两半：
> - **防守**：黑的 c1（第 1 行）、c3、c4（第 4 行）只差 c2 就连成一列，黑下一手 c2 就赢。
> - **进攻**：红的 a1—b1—b2 已经从 a 列伸出来，c2 和 b2 相邻；c2 往 d 列有两个入口：**d2**（右边）和 **d1**（右上）。黑只能堵一个。
>
> 程序确认 c2 是唯一的必胜着，其余 9 个空格全部必败【数学】。这就是思考路径 21.1 的同一个结构，换到了 4×4 上。
>
> **把黑 c4 改到 d4**：黑不再有一手获胜的威胁（c3 还没连到第 4 行），但答案**仍然是 c2**，也仍然是唯一必胜着【数学】。决定没变，**理由变了**：现在 c2 不再是"非堵不可"，而是"抢要点"。如果红不下 c2，黑下 c2 后，c1—c2—c3 往第 4 行有 c4 和 b4 两个入口（c3 的正下和左下），轮到黑来造双威胁。同一个格子，对双方都是双威胁的枢纽，谁先占谁赢。
>
> 熟练者在第二问里容易犯的错是："黑没有威胁了，我可以先下别处"。没有立即威胁，不代表没有一手之后的威胁。

> [!example]- 第 7 题（一个合格答案的样子）
> ① **假设**：没有交换规则时，熟悉棋盘、也会把局面下完的先手，可以靠那 4 个必胜开局稳定获胜。加交换规则后，只要后手还不能可靠地判断开局的值（4.3 节的第 ② 层），或者选对边之后还下不赢（第 ③ 层），座次带来的优势就会变小：两个座次的胜率更接近 50%。
>
> ② **反例**：按 4.3 节，有交换规则时后手理论上必胜，这一点和棋盘大小无关。4×4 的问题是第 ②、③ 层太容易跨过：后手记住那条斜线就知道该选哪边，棋盘这么小，选对边之后把必胜局面下完也不难。一旦测试者既会选边又会执行，"更平衡"会变成"后手稳赢"：偏离 50% 的方向换成了后手，偏离的程度不一定变小。
>
> ③ **测试方案**：同一对测试者（都已经下过 v0.2 的 4 局，熟练程度相近）做**配对对照**：有交换、无交换两种条件各 12 局，按 4 局一组交替进行（无交换 4 局 → 有交换 4 局 → ……），避免学习效应只落在后测的那一种条件上；每种条件里两人各当 6 次先手。每局记录：先手的第一手、后手是否交换、谁赢、后手说出的交换理由。事后由设计师对照程序算出的开局值表，标出两件事：后手选的边理论上是不是必胜方（第 ② 层），选了必胜方的人最后有没有赢（第 ③ 层）。
>
> 比较的指标是**座次胜率偏离 50% 的程度**：无交换条件看先手胜率离 50% 多远，有交换条件看后手胜率离 50% 多远，再把有交换条件的前 6 局和后 6 局分开看。假设成立的样子：有交换时的偏离明显小于无交换。推翻假设的样子：有交换时的偏离不比无交换小，或者后 6 局的偏离回到无交换的水平，只是方向换成了后手。注意，"后手从前 6 局赢 0 局变成后 6 局赢 3 局"是在**向 50% 靠近**，符合假设，不能当成推翻。交换理由变得具体（"那条斜线上的就换"）是学习的迹象，可以用来解释偏离为什么出现，但不能单独判定平衡假设被推翻。如果假设在 4×4 上被推翻，改用 5×5 再测。每种条件 12 局只够发现趋势，不够估计精确胜率。
>
> 评判标准：是否分清了"必胜策略存在""知道选哪边""会执行"三层；测试是否有无交换的对照，并按偏离 50% 的程度比较；是否记录了交换决策的理由和选边是否正确，而不只是胜负；推翻条件是否和假设方向一致。

> [!example]- 第 8 题（一个合格答案的样子）
> ① **假设**：移动让已经下错的牌可以挽回，中局会多出"补一子还是挪一子"的权衡，游戏变深。
>
> ② **新问题**（至少要看到前两个）：
> - **原有的终止性证明不再适用**：v0.2 一定结束，因为每手都会填掉一个空格，16 手之内必然满盘。加入"不放新牌、只移动"之后，这一手空格数不变，双方可以无限地来回挪。必须补规则（第 6 节第 3 条）。
> - **满盘连通定理仍然成立，失去的是"必然走到满盘"**：六角棋的定理说的是"任意一个填满的棋盘上恰好一方连通"，它只看最终盘面，不管盘面是怎么来的，所以允许移动并不推翻它。失去的是"游戏一定会走到满盘"这个保证。要分清两件事：游戏无限进行下去，是**没有终止**；如果你补一条"拖到某个条件就判平局"，那是**新规则判定的平局**，等于把平局又加了回来。
> - **策略窃取论证的前提要重新检查**：棋子能离开原位，"多一颗子永远不会有害"不再显然成立（第 03 章 5.3 节），先手优势要重新测。
>
> ③ **补的规则与测试**：先排除两个看起来可行的方案。
> - "放完自己的 8 张牌之后才允许移动"：移动阶段**永远不会发生**。红方第 15 手放完第 8 张，黑方第 16 手放完最后一张，棋盘正好填满；而任意满盘都恰好有一方连通（穷举 12,870 种满盘全部如此），所以对局最晚在第 16 手就已经分出胜负，红方等不到第 17 手【数学】。这不是"多数局提前结束"，而是每一局都如此。
> - "移动阶段最多若干手，之后仍无人连通则判平局"：能保证结束，但把平局加了回来，不满足"每局分出胜负"。
>
> 一个合格的方案是把"代替放牌"改成"放牌之前的附加动作"：**轮到你时，可以先把场上一张自己的牌移到相邻的空格（可选），然后必须放一张新牌；整个回合做完后检查你是否连通**。
>
> 为什么一定结束并分出胜负【数学】：移动腾出一格、占用一格，放牌再占一格，所以每个回合恰好减少一个空格，最多 16 个回合就满盘；每个回合都做得出来（总有空格可放，双方各自的 8 张牌正好在第 15、16 手放完）。你的回合只改变你自己的牌，对手的连通状态不会在你的回合里改变；而满盘时恰好一方连通，所以对局最晚在第 16 手以某一方连通结束，没有平局。移动从红方的第二个回合（第 3 手）起就可以用，确实发生在中盘。程序随机模拟 20,000 局，全部在 16 手内由一方连通结束。代价是移动不再是放牌的替代，而是附加；如果你坚持保留"不放新牌、只移动"的原版，就必须另写防循环的规则，并为它单独证明终止、说明它会不会引入平局。
>
> 测试：v0.2 与新版本各 6 局、交换先后手。每局记录：每次移动发生在第几手、移动的目的（接回自己的断链、挪过去堵对方、还是随手）、结局和总手数、各座次谁赢。因为新版本最多 16 手，它不会"变长"，要区分的是"变深"和"变乱"：如果移动几乎没人用，说明新动作没有改变决策；如果移动经常被用来做出有理由的攻防，并且双方都能复述对方为什么这样挪，倾向于"变深"；如果漏看对方立即获胜的次数明显比 v0.2 多，说明增加的主要是追踪负担，倾向于"变乱"。先手优势也要重新按座次统计。
>
> 评判标准：是否分别说明了"满盘连通定理仍成立"和"原有终止性证明不再适用"；是否把"无限进行"和"新规则判定的平局"分开；补上的规则是否能证明一定终止、不引入平局，而且移动阶段真的可达；测试是否能区分"变深"和"变乱"。
