# IAA 小游戏的数值设计：割草肉鸽与放置经营

> **面向对象**：想自己做一款微信/手机小游戏、靠广告变现的人。有工程背景，能读懂数学和写脚本。
> **品类重心**：**Roguelike / 割草生存** 与 **放置经营 / 模拟经营** 两条线，加上它们的共同内核。
> **商业模式**：**IAA（In-App Advertising，广告变现）为主**，混合少量 IAP。
> **学完之后你应该能够**：从零设计一款小游戏的完整数值——单局节奏、广告点位、构筑多样性、产出链比率、长线消耗速度——并用自动化仿真验证它既好玩又赚得回买量成本。

本课程编写于 **2026 年 8 月**，是 [`../game-numeric/`](../game-numeric/README.md)（F2P / SLG 长线数值）的**姊妹课程**。

## 0. 先把坐标定准：这门课在哪个格子里

游戏数值有两个**互相独立**的轴：**玩法是单人还是多人**，**收入是一次性还是流量**。

| | **单人玩法** | **多人 / 社交玩法** |
|---|---|---|
| **买断制** | Steam 独立游戏 | —— |
| **F2P（IAA / IAP）** | **微信小游戏 ← 本课** | SLG / MMO ← [game-numeric](../game-numeric/README.md) |

**本课在左下格。它从上下左右各继承一半：**

| 继承自 | 内容 | 为什么 |
|---|---|---|
| **单人玩法那一侧** | 单局节奏、构筑多样性、随机性、难度、失败设计 | 没有对手，没有生态，没有通胀 |
| **F2P 商业那一侧** | 留存、LTV、买量回本、投放与回收、指标体系 | **收入是流量，不是一次性事件** |

> ⚠️ **如果你之前按"买断制独立游戏"的直觉理解这门课，请重置。**
> 买断制里"玩家玩多久对收入没影响"；IAA 里**玩家多留一天 = 直接收入**，和 SLG 一模一样。
> 这条差异会贯穿全课。

### 0.1 IAA 独有的那一条：广告是一个资源龙头

这是本课最核心、也是两门姊妹课都没有的东西：

> **一个激励视频点位，本质上就是 [game-numeric 第 07 章](../game-numeric/07-faucets.md) 意义上的"资源龙头"。**
> 唯一的区别是：玩家掏的不是钱，是**30 秒注意力**。

于是 F2P 的整套投放/回收框架**完全适用**，只是货币换了：

| F2P（IAP） | IAA 小游戏 |
|---|---|
| 玩家花钱买资源 | 玩家花**注意力**买资源 |
| 付费率 × ARPPU | **渗透率 × 人均次数 × eCPM** |
| 定价（648 档位） | **广告倍率**（看一次广告 ×2 还是 ×3？） |
| 付费点位设计 | **广告点位设计**（复活 / 翻倍 / 加速 / 免费抽） |
| 首充、月卡 | 去广告礼包、免广告特权 |

**这个映射是本课阶段二的全部内容**，也是为什么你必须先有 F2P 的资源流直觉。

### 0.2 和 game-numeric 的分工

| | **game-numeric（F2P/SLG）** | **game-solo（IAA 小游戏，本课）** |
|---|---|---|
| 核心矛盾 | 怕玩家太快玩完 → 如何运转三年 | 怕玩家第一天就走 → **如何在 3 分钟内建立循环** |
| 时间单位 | **天**（日产出、留存、赛季） | **局**（1~5 分钟）+ **会话**（一次打开）+ **天** |
| 收入公式 | 付费率 × ARPPU | **IPU × eCPM ÷ 1000 × 分成** |
| 失败的地位 | 尽量避免，失败会流失 | **失败既是核心玩法，又是广告触发点**（见第 06 章） |
| 随机性的作用 | 付费杠杆（抽卡） | **内容生成器**，兼做广告点位（免费重抽） |
| 占优策略 | **灾难**（策略坍缩，全服玩法趋同） | **偶尔遇到超模组合恰恰是快感来源** |
| 经济 | 跨局累积 → 通胀是核心问题 | **三层**：局内清零 / 局外累积 / 广告注入 |
| 数值权威 | 服务端 | **客户端**（但埋点必须上报，否则无法调优） |

**"占优策略"那一行仍然是两门课最尖锐的分歧**，它不受商业模式影响：

> 《杀戮尖塔》的开发者在 GDC 2019 的分享里明确说过：**单机 roguelike 的一大优势是可以允许罕见的超模组合，因为它不会破坏其他玩家的体验。**

在多人 F2P 里，一个 55% 胜率的占优选项会让均衡使用率变成 100%，整个策略空间坍缩（`game-numeric` 第 16 章有模型证明）。而在单人游戏里，**"这局我摸到了神组合，爽翻了"正是玩家回来的理由**——注意，在 IAA 里"玩家回来"就是钱。

同一个数学结论，在两种玩法结构下价值判断完全相反。附录 A 有完整对照表。

## 1. 全景图：IAA 小游戏的数值在管什么

```
                 ┌────────────────────────────────────────────┐
                 │   收入 = DAU × IPU × eCPM ÷ 1000 × 分成      │
                 │        ↑            ↑                       │
                 │      留存决定      数值设计决定                │
                 └──────────────────┬─────────────────────────┘
                                    │
     ┌──────────────────────────────┼──────────────────────────────┐
     │                              │                              │
     ▼                              ▼                              ▼
┌──────────────┐         ┌────────────────────┐         ┌──────────────────┐
│ ① 单局体验    │         │  ② 广告点位设计      │         │ ③ 长线消耗速度     │
│              │         │                    │         │                  │
│ 一局 1~5 分钟 │         │ 玩家凭什么看这 30 秒？│         │ 内容够撑几天？     │
│ 会话 5~15 分钟│         │ 复活/翻倍/加速/免抽  │         │ 元进程 + 放置产出  │
│ 张力 & 失败   │         │ 渗透率 × 人均次数   │         │ 留存底盘由它决定    │
│ 【02、03 章】 │         │ 【04、05、06 章】   │         │ 【11、12 章】     │
└──────┬───────┘         └─────────┬──────────┘         └────────┬─────────┘
       │                           │                             │
       └───────────────────────────┼─────────────────────────────┘
                                   ▼
                   ┌───────────────────────────────┐
                   │  ④ 验证：好玩 + 赚得回买量吗？    │
                   │  仿真几万局 → 找 dominant build │
                   │  LTV / CPA > 1 ?               │
                   │  【13、14 章】                  │
                   └───────────────────────────────┘
```

**三个目标的关系，以及它们真实的冲突：**

| | 说明 | 和另外两个怎么打架 |
|---|---|---|
| **① 单局体验** | 决定次留 | 加广告点位会打断心流，**每一个点位都在拿体验换钱** |
| **② 广告点位** | 决定 ARPDAU | 点位给的资源太多 → 内容被跳过 → ③ 崩 |
| **③ 长线消耗速度** | 决定留存底盘，也就是 DAU | 内容做慢了没人玩，做快了你做不完 |

> **这门课教的就是在这个三角里做取舍**，而且它比买断制的三角更难——因为**②的每一次加码都同时伤害①和③，但它是唯一直接产生收入的一环。**

## 3. 怎么学

**这门课的目标是让你做出一款能上线赚钱的小游戏，所以它比 game-numeric 更实操。**

建议节奏（每天 1.5~2 小时）：

| 阶段 | 章节 | 用时 | 验收标准 |
|---|---|---|---|
| 一 | 01~02 | 3 天 | 能画出你这款游戏的局/会话/天三层节奏图 |
| 二 | 03~06 | 1 周 | **能算出你的 ARPDAU 和回本周期，并说出难度该定在哪** |
| 三 | 07~09 | 1 周 | 能设计一套 20 个道具的池子，并证明没有 dominant build |
| 四 | 10~11 | 5 天 | 能设计一条 4 层产出链并算清所有比率与离线折扣 |
| 五 | 12~15 | 1.5 周 | 能产出完整方案 + 自动化测试脚本 |

**五条学习原则：**

1. **先定一款游戏再学。** 第 01 章会让你写一页纸的游戏概念。之后每一章的作业都往这一页纸上加东西，到第 15 章它会变成完整方案。
2. **原型比方案重要。** 单人游戏的很多问题只有玩起来才知道。**能做出可玩原型的话，边做边学效率高 10 倍。**
3. **广告点位要和玩法一起设计，不能后加。** 这是 IAA 新手最大的坑——玩法做完再"找地方塞广告"，结果每个点位都很硌人。
4. **相信自动化测试，但不要只相信它。** 第 13 章的 agent 能告诉你"哪个 build 胜率异常"，但告诉不了你"这局好不好玩"。
5. **抄结构，不抄数字。** 和 game-numeric 同一条原则，在这里尤其重要——**eCPM 和买量成本每个季度都在变。**

## 4. 数字的可靠性约定

和 game-numeric 一致，本课的每个数字都会标注来源：

| 标记 | 含义 |
|---|---|
| **【实证】** | 官方文档或可公开验证的数据（如微信开放文档的分成比例） |
| **【行业口径】** | 业内公开分享的量级参考。**会随时间显著变化，务必自行核实** |
| **【推导】** | 我从公开信息反推的，可能有误 |
| 不标 | 教科书数学，自身成立 |

> ⚠️ **eCPM、买量成本、激励政策这三样变化最快。** 本课写于 2026 年 8 月，
> 所有具体金额都请当作"量级参考"，用之前去 [微信开放文档](https://developers.weixin.qq.com/minigame/introduction/commercialization/) 核对当期口径。
> **课程真正教的是公式和取舍结构，那部分不会过期。**

## 7. 开始

先做 [00 - 环境与第一个单局仿真](./00-setup.md)（十分钟，复用已有的 Python 环境），然后从 [01 - IAA 小游戏的数值在设计什么](./01-iaa-model.md) 开始。
