# 附录 A - 三种商业模式对照表

> 同一个数学工具，在**买断制**、**IAA**、**F2P/IAP** 三种模式下的用法常常完全不同，有时甚至相反。
> 这张表是全课"反转"的汇总，也是防止你把某一门课的直觉误用到另一门课的清单。

---

## 0. 先定坐标

游戏数值有两个**互相独立**的轴（[第 01 章](./01-iaa-model.md)）：

| | **单人玩法** | **多人 / 社交玩法** |
|---|---|---|
| **买断制** | Steam 独立游戏 | —— |
| **F2P** | **IAA 小游戏 ← 本课** | SLG / MMO ← [game-numeric](../game-numeric/README.md) |

**很多"反转"其实只取决于其中一个轴。** 下面每一条都标了它取决于哪个轴——**这比记住结论本身更有用。**

---

## 1. 基本结构

| | 买断制单机 | **IAA 小游戏** | F2P / IAP（SLG） | 取决于 |
|---|---|---|---|---|
| **收入形态** | 一次性事件 | **流量**（每天） | 流量 | 商业轴 |
| **玩家多留一天** | 对收入无直接影响 | **= 一个 ARPDAU** | = 一个 ARPDAU | 商业轴 |
| **单用户价值上限** | 售价，封顶 | **IPU × eCPM，封顶** | **无上限**（大 R） | 商业轴 |
| **收入分布** | 均匀 | **均匀** | 0.1% 贡献一半 | 商业轴 |
| **主要杠杆** | 销量 + 口碑 | **规模 + 四个线性因子** | **付费深度** | 商业轴 |
| **硬约束** | Steam 2 小时退款 | **3 秒 / 3 分钟 / 3 天** | 首日留存 | 商业轴 |

> **⇒ IAA 在商业结构上更接近 SLG，而不是独立游戏。** 这是本课最重要的定位。

---

## 2. 经济与投放回收

| | 买断制单机 | **IAA 小游戏** | F2P / IAP | 取决于 |
|---|---|---|---|---|
| **需要 sink 吗** | 局内不需要 | **局内不需要，局外需要** | 需要，且是核心 | 商业轴 |
| **通胀的表现** | 不适用 | **内容被提前消耗完** | 物价上涨、战力膨胀 | 商业轴 |
| **"存量÷日产出"温度计** | 不适用 | **局外适用** | 适用 | 商业轴 |
| **回收率 100% 意味着** | —— | **内容还没耗尽**（要看还能撑几天） | 经济健康 | 商业轴 |
| **玩家用什么换资源** | —— | **注意力**（30 秒） | 钱 | 商业轴 |
| **"定价"是什么** | 售价 | **广告倍率** | 档位（6/30/648） | 商业轴 |
| **投放能加不能减** | 不完全（版本可调） | **成立** | 成立 | 商业轴 |

**关键映射**（[第 01 章 §3](./01-iaa-model.md)）：

```
F2P 的"付费点位设计"  ≡  IAA 的"广告点位设计"
F2P 的"付费率 × ARPPU" ≡  IAA 的"渗透率 × 人均次数 × eCPM"
F2P 的"首充月卡"       ≡  IAA 的"去广告礼包"
```

## 3. 玩法与平衡

| | 买断制单机 | **IAA 小游戏** | F2P / IAP | 取决于 |
|---|---|---|---|---|
| **占优策略** | **罕见超模是快感来源** | **同左** | **灾难**（策略坍缩） | **玩法轴** |
| **目标胜率** | 远低于 50% | **28%~33%**（LTV 平顶） | 匹配到 50% | 玩法轴 |
| **失败的地位** | **核心玩法** | **核心玩法 + 广告触发点** | 尽量避免 | 混合 |
| **随机性的作用** | **内容生成器** | **内容生成器 + 广告点位** | 付费杠杆 | 混合 |
| **保底的目的** | 这局不开局就废 | **同左 + 控制广告边际收益** | 控制最坏付费 | 混合 |
| **数值权威** | 客户端 | **客户端 + 埋点上报** | 服务端 | 玩法轴 |

### 3.1 最尖锐的那一条：占优策略

**这条只取决于玩法轴，和商业模式无关：**

| | 多人 | **单人（含 IAA）** |
|---|---|---|
| 谁受影响 | **所有人**（你的强 = 别人的弱） | 只有你自己 |
| 出现频率 | 玩家主动构筑，**每局都用** | 依赖随机，**几十局遇到一次** |
| 情绪价值 | 别人被碾压 → 愤怒 | **"这局我摸到神了"→ 巅峰体验** |

> **IAA 还多一层**：巅峰体验是**分享行为**的主要触发点，而微信的社交裂变是最便宜的量。

**但"罕见"两个字是硬边界**（[第 07 章](./07-build-diversity.md)）：

```
✓ 触发率 5%~15% 的组合  → 罕见超模，可以留
✗ 触发率接近 100% 的道具 → 它不是惊喜，是新的基线，必须削
```

## 4. 验证与调优

| | 买断制单机 | **IAA 小游戏** | F2P / IAP |
|---|---|---|---|
| **能不能热更** | 主机/Steam 慢 | **能，随时** | 能 |
| **上线后调数值** | 玩家接受度高 | **广告奖励只能加不能减** | 同左 |
| **AB 实验** | 基本做不了 | **IPU 类做得起，留存类做不起** | 大厂做得起 |
| **主要风险** | 存档损坏、版本迁移 | **看不见玩家在哪流失**（埋点缺失） | 经济崩盘、作弊 |
| **防谁** | **防自己**（不可回滚的发布） | **防自己 + 防盲飞** | 防作弊者 |

## 6. 一句话记忆

> **IAA 小游戏 = 单人玩法的数值 × F2P 的商业数值。**
>
> **凡是关于"怎么玩"的，抄独立游戏；**
> **凡是关于"怎么赚"的，抄 SLG。**
>
> **而它独有的那一条是：广告是一个资源龙头，玩家用注意力付费。**
