# 02 - 单局与会话的节奏设计

> **本章目标**：设计三层节奏——**局 / 会话 / 天**——并解决第 00 章发现的那个问题：**玩家在进度 40% 时结局就大半注定，却要玩到 72% 才揭晓**。
> **本章最重要的一个转折**：同一份数据，在买断制下和在 IAA 下会得出**不同的设计选择**。第 5 节。
> **本章有模型**：`models/s02_session_pacing.py`

---

## 1. 三层节奏

买断制独立游戏只需要设计"一局"。**IAA 小游戏要同时设计三层**，因为收入公式里的每一项都挂在不同的层上：

| 层 | 尺度 | 玩家在做什么 | 接在收入公式的哪一项 |
|---|---|---|---|
| **局（run）** | 30 秒 ~ 5 分钟 | 一次完整的挑战 | **IPU**（死亡/结算 = 广告触发点） |
| **会话（session）** | 5 ~ 20 分钟 | 一次"打开到退出" | **IPU**（一个会话装得下几局） |
| **天（day）** | —— | 回来 or 不回来 | **DAU**（留存） |

> **新手最常犯的错**：只设计了"局"，然后发现玩家一个会话只玩两局就退了，
> 或者退了就再也不回来。**局设计得再好，装不进会话、接不上第二天，都白搭。**

### 1.1 一局多长

```
                微信小游戏的实际分布
    30s ────── 2min ────── 5min ────── 10min ──────►
     │           │           │            │
   超休闲      甜点区       深度肉鸽      基本不适合小游戏
   合成消除    割草/爬塔                  （会话装不下）
```

| 单局时长 | 一个 15 分钟会话能玩几局 | 适合 |
|---|---|---|
| **30 秒 ~ 2 分钟** | 8~25 局 | 超休闲、合成消除、跑酷 |
| **2 ~ 5 分钟** | **3~7 局（甜点区）** | **割草生存、爬塔肉鸽** |
| **5 ~ 10 分钟** | 1~3 局 | 深度肉鸽。**对小游戏偏长** |
| 无"局"的概念 | —— | 放置经营（以"上线一次"为单位，见第 11 章） |

**三条判断依据（和买断制不同）：**

**① 一次会话至少要能装下 3 局。**

这是本节最实用的一条经验：`单局时长 ≤ 会话时长 ÷ 3`。

为什么是 3？

| 第几局 | 玩家的状态 |
|---|---|
| 第 1 局 | 热身，大概率失败，还在理解机制 |
| 第 2 局 | 进入状态，开始有策略 |
| **第 3 局** | **"我知道怎么玩了，再来一把"——这才是留存被建立的时刻** |

**如果一个会话只装得下 1 局，玩家永远走不到第 3 局。**

**② IAA 的失败代价没有付费沉没成本兜底。**

买断制玩家输了 40 分钟会骂，但他付过钱了，多半还会再试。**小游戏玩家输了直接退出，成本为零。**

**③ 前 3 分钟必须走完一个完整闭环**（[第 01 章 §2②](./01-iaa-model.md)）。

如果单局是 5 分钟，玩家在前 3 分钟连一局都没打完——**他退出的时候还不知道你的游戏是什么。**

> **对小团队的建议：往短了做，比你以为的还要短。**
> 短单局同时降低开发量、失败代价、和"3 分钟没闭环"的风险，
> 而且——第 5 节会看到——**它还大幅提高了广告触发机会**。
> 你几乎总能在上线后加长（加新模式、加层数），但很难缩短。

### 1.2 一次会话长什么样

会话不是"局的简单重复"。一个设计良好的会话有自己的开头和结尾：

```
打开
 │
 ├─► 【钩子】领离线收益  ← 放置产出，可看广告翻倍（第 11 章）
 │
 ├─► 【日常】任务/签到    ← 给方向感，低强度
 │
 ├─► 【主体】打 3~6 局    ← 核心玩法，死亡处是复活广告点位
 │
 ├─► 【结算】攒够资源升级  ← **必须在会话内看到一次"变强"**
 │
 └─► 【留钩】下一个目标还差一点  ← 决定明天回不回来
```

**两条设计要求：**

| 要求 | 为什么 |
|---|---|
| **会话内必须发生至少一次"永久变强"** | 否则玩家会觉得这 15 分钟白玩了。局内的成长每局清零，**跨局的成长才是留存燃料**（第 12 章） |
| **退出时要欠着一点** | "再打两局就能解锁下一个角色"。**这是明天 DAU 的来源** |

> **这两条在 SLG 里叫"日常闭环"和"卡点"**（[game-numeric 第 20 章](../game-numeric/20-long-term-pacing.md)），
> 结构完全一样，只是尺度从"一天"压缩成"一次会话"。

## 2. 局内的张力曲线

第 00 章图 ① 的血量曲线是锯齿形的：持续下降 → 休息点回血 → 继续下降。**这个锯齿就是张力的呼吸。**

```
张力
 ▲                                              ┌─ Boss
 │                                          ┌───┘
 │                            ┌─ 精英 ──┐   │
 │              ┌─ 精英 ─┐    │        │   │
 │   ┌─ 小怪 ─┐ │       │    │        │   │
 │  ╱         ╲│        ╲___╱          ╲_╱
 │ ╱           休息        休息          休息
 └──────────────────────────────────────────────► 房间
   开局      前期         中期          后期
   低压     建立构筑    构筑成型      检验构筑
```

**四个阶段各自的数值任务：**

| 阶段 | 占比 | 数值任务 | 做错了会怎样 |
|---|---|---|---|
| **开局** | 前 10% | 低压力，让玩家先拿到 1~2 个构筑核心 | 太难 → 3 秒关直接失守 |
| **前期** | 10~40% | 提供大量选择，让构筑方向确定下来 | 选择太少 → 每局都一样 |
| **中期** | 40~75% | 难度追上来，检验构筑是否成立 | 太平缓 → 无聊；太陡 → 前期白玩 |
| **后期** | 75~100% | 高压力 + 高回报，Boss 检验 | 没有峰值 → 通关没有仪式感 |

**休息点（回血/升级/商店）的作用不只是补给，更是节奏的"换气"。** 它把连续的压力切成段，让玩家有机会重新评估自己的构筑。

**间隔怎么定**：模型里是每 8 房一次。经验做法是**让休息点出现在"玩家刚经历一次高压"之后**（精英怪后、Boss 前），而不是均匀分布。

> **IAA 的额外一条**：休息点是**除死亡以外最自然的广告点位**——
> 在玩家已经喘口气的时候提供"看广告多拿一件"，打断感最小。第 05 章展开。

## 3. 量化"无效时间"

```bash
cd models && python s02_session_pacing.py
```

模型用蒙特卡洛判定"这局还有没有戏"：从当前状态推演剩余流程，**通关概率 < 5% 就认为没戏**。从那一刻到实际结束之间的房间，就是**无效时间**。

```
结构                  通关率   主动重开   平均无效房间   无效时间占比   平均每局房间
------------------------------------------------------------------------
基线（50 房）          32.8%     0.0%        9.8        24.3%        40.3
A 缩短单局（25 房）    30.9%     0.0%        6.5        18.2%        35.4
B 加翻盘手段           52.9%     0.0%        6.3        14.9%        42.2
C 加早期信号           28.7%    71.1%        0.0         0.0%        29.1
```

（房间数已归一化到 50 房尺度，便于横向比较）

> **基线：玩家 24.3% 的游玩时间花在"已经赢不了"的状态里，平均每局白玩近 10 个房间。**

这不是模型的怪癖，是**所有指数赛跑型 roguelike 的固有问题**。

## 4. 三种解法，三种代价

### A. 缩短单局

把 50 房压缩成 25 房，**并重新标定难度使通关率不变**（模型里 `base_dmg × 2.42`，注意不是简单的 ×2——第 00 章那条"指数极度敏感"在这里又出现了一次）。

```
无效时间 24.3% → 18.2%
平均每局总时长 40.3 → 35.4 房（归一化口径）
真实单局时长   167 秒 → 77 秒
```

**它同时减少了浪费和总投入**，对小团队还额外省开发量。

**代价**：单局的内容展开空间变小。构筑要在 25 房内成型，意味着道具效果必须更强、更直给，**深度构筑（需要凑齐 4~5 个部件的组合）就做不了了**。

### B. 加翻盘手段

落后时给一个高风险高回报的机会（模型里：后半程强度比 < 1.0 时，25% 概率遇到"孤注一掷"，55% 成功大幅拉回、45% 掉血）。

```
无效时间 24.3% → 14.9%
但通关率从 32.8% 涨到了 52.9%
```

> **注意这个副作用：它降低无效时间的方式是"让更多局能赢"，而不是"让输局早点结束"。**

如果你不想让游戏整体变简单，就必须同步调高基础难度——**这时候翻盘手段的净效果是"把难度从平均分布，改成了两极分布"**。

**代价**：削弱前期决策的分量。玩家会想"反正后面能翻"，前期的谨慎就不值钱了。

**设计建议**：翻盘手段应该**有代价、有门槛、且不保证成功**。白送的翻盘等于取消了失败。

### C. 加早期信号

让玩家能判断"这局没戏"，从而主动重开。

```
无效时间归零，平均每局从 40.3 房降到 29.1 房（省了 28% 的时间）
但通关率从 32.8% 掉到 28.7%
```

**那 4.1 个百分点是被"误杀"的局**——它们的推演胜率低于 5%，但本来能赢。

> **阈值定得越激进，省的时间越多，误杀也越多。这是个必须权衡的旋钮。**

**实践中怎么给信号（从含蓄到直白）：**

| 手法 | 说明 |
|---|---|
| **可见的推荐强度** | 下一层显示"推荐战力 X"，玩家自己比 |
| **压力测试点** | 精英怪作为"你打不打得动"的探路石，且可以选择跳过 |
| **资源可见性** | 让玩家能算出"我还剩多少血、还有几个补给" |
| **明确的失败预告** | 直接提示"以当前配置很难通过"（最直白，也最容易冒犯） |

**前两种是主流做法**，因为它们把判断权留给玩家——**玩家自己得出"没戏"的结论，和游戏告诉他，感受完全不同。**

**注意 B 和 C 在设计上是互斥倾向的**：翻盘手段让"当前状态"无法预测最终结果，这正好摧毁了早期信号的依据。

## 5. 抬到会话层看：IAA 把排序洗牌了

**上面四小节的结论，对买断制独立游戏是完整的。对 IAA 不是。**

回到收入公式：

```
日收入 = DAU × IPU × eCPM ÷ 1000 × 分成
```

**死亡是复活广告最自然的触发点。** 所以：

> **每会话的死亡次数 ≈ 广告触发机会的上限**，它直接接在 IPU 上，也就是直接接在收入上。

模型的第二段（假设一房 4 秒、重开摩擦 6 秒、会话 15 分钟）：

```
结构                  单局时长   每会话局数   每会话死亡   触发机会指数
--------------------------------------------------------------
基线（50 房）           167s        5.4        3.6       1.00×
A 缩短单局（25 房）      77s       11.7        8.1       2.24×
B 加翻盘手段            175s        5.2        2.4       0.67×
C 加早期信号            122s        7.4        5.2       1.45×
```

**排序完全变了：**

| | 单局层（买断制视角） | 会话层（IAA 视角） |
|---|---|---|
| **A 缩短单局** | 好（省浪费省成本） | **最好，2.24×** |
| **B 加翻盘手段** | 好（无效时间最低） | **最差，0.67×** |
| **C 加早期信号** | 中（有误杀） | **好，1.45×** |

### 5.1 B 的问题，和它的解法

**B 在买断制里是个不错的选择，在 IAA 里却直接削减了收入面**——通关率涨了，死得少了，广告触发机会掉了三分之一。

**但这不是说 B 不能用。它指向一个更好的设计：**

> **把翻盘手段本身做成广告点位。**
> "你快撑不住了 —— 看个广告，获得一次孤注一掷的机会？"

这一改，B 从"减少广告触发"变成了"**新增一个广告点位**"，而且是**质量最高的那种**：玩家在最想要它的时刻，主动选择去看。

**这是 IAA 数值设计的一般方法，值得记住：**

> **当你发现某个玩法改动会减少广告触发，先别扔掉它——
> 想想能不能把这个改动本身变成一个广告点位。**

第 05 章会把这个方法用在五类点位上。

### 5.2 一个必须马上加的警告

**触发机会 ≠ 实际观看次数。**

A 把触发机会做到 8.1 次/会话，**不代表 IPU 就是 8.1**。玩家的意愿有上限，而且会疲劳：

```
实际观看次数 ≈ min(触发机会 × 单点位渗透率, 玩家当次会话的意愿上限)
```

**这有两个直接后果：**

| 后果 | 说明 |
|---|---|
| **触发机会有饱和点** | 堆到 15 次/会话，IPU 不会比 8 次高多少。**多出来的是浪费** |
| **超过饱和点会反噬** | "这游戏一直在让我看广告" → 留存掉 → **DAU 掉，收入净减** |

> **所以正确的目标不是"最大化触发机会"，是"刚好饱和玩家的意愿"。**
> **第 06 章会把玩家意愿建成模型，求出这个最优点。那是本课的招牌章节。**

### 5.3 怎么选

| 你的情况 | 建议 |
|---|---|
| **IAA 小游戏，首款产品** | **A（缩短单局）**。它在两个层上都是最优，没有之一 |
| 想做深度构筑 | **A + C**。用早期信号弥补 A 带来的"单局太短没法翻身" |
| 想强化戏剧性 | **B，但必须做成广告点位**（§5.1），且同步调高基础难度 |
| 买断制独立游戏 | 三个都可以，按 §4 的代价选。**不要用 §5 的排序** |

## 6. 失败的设计：既是循环，也是收入

单人 roguelike 的失败不是终点，是循环的一部分（[第 01 章 §2③](./01-iaa-model.md)）。**IAA 里它还多了一重身份：收入事件。**

**失败要满足三个条件，IAA 各加了一条：**

### ① 可归因

玩家要能说出"我这局是因为 X 输的"。

**数值上的抓手**：死亡结算界面应该展示——你在哪一层开始跟不上、你的强度比曲线、你放弃了哪些关键选择。

> **这就是第 00 章图 ③"强度比"的玩家可见版本。** 你在设计阶段用它调数值，玩家在结算时用它复盘。

**IAA 的加码**：**归因不了的失败，会被读成"游戏想坑我看广告"。** 这个误解一旦形成，复活广告的渗透率会断崖式下跌——玩家宁可退出也不给你这个满足。**可归因在 IAA 里是变现的前提，不只是体验问题。**

### ② 有收获

即使输了，也要带走点什么：

| 收获类型 | 说明 | 风险 |
|---|---|---|
| **知识** | 见到了新敌人、试了新组合 | 无。**最健康的一种** |
| **解锁** | 失败也推进图鉴/解锁进度 | 低 |
| **元货币** | 失败结算给永久强化的资源 | 中。给多了会让内容被跳过（第 12 章） |

**IAA 的加码**：**结算奖励是最经典的"翻倍广告"点位**——"本局获得 120 金币，看广告翻倍？"。所以**结算奖励的绝对值要设计得让翻倍显得值**，太小了没人看。第 05 章给量化判据。

### ③ 重开成本低

**从死亡到下一局开始，应该在 15 秒内。** 任何冗长的结算、动画、菜单，都会在玩家最脆弱的时刻（刚失败）制造摩擦。

> **一个具体建议：把"再来一局"做成死亡界面上最大的那个按钮。**

**IAA 的加码，也是本节最需要小心的一条**：

> **复活广告和"快速重开"抢的是同一个时刻。**

如果你把复活广告做成一个 5 秒倒计时的弹窗、"再来一局"按钮藏在角落，你确实能提高复活广告的点击率——**但你同时把 §5 算出来的"每会话 3.6 次死亡"打了折扣**，因为每次死亡都变慢了。

**这是本章最后一个权衡**：复活广告的摩擦，会减少一个会话内的总死亡次数。**你在用后面每一次触发机会，换这一次的转化率。** 第 06 章的模型会把这笔账算清楚。

## 7. 动手

### 7.1 改模型

**任务 A：调早期信号的阈值。** 把 `DOOM_THRESHOLD` 从 0.05 改成 0.02、0.10、0.20，画出"节省的时间"、"误杀率"、"每会话死亡次数"三条曲线。**在 IAA 口径下你会选哪个点？和买断制口径下选的一样吗？**

**任务 B：把 B 改成广告点位。** 让 `comeback_hook` 只在"玩家愿意看广告"时触发（加一个 `p_watch` 概率参数），并统计触发次数。跑 `p_watch = 0.3 / 0.6 / 0.9`，看通关率和每会话广告次数怎么变。

**任务 C：加复活摩擦。** 把 `RESTART_SECONDS` 从 6 秒改成 15 秒（模拟"复活广告弹窗 + 结算动画"），看每会话死亡次数掉多少。**这就是 §6③ 那笔账的一半。**

**任务 D：设计休息点位置。** 把 `heal_every` 从均匀的 8 改成不均匀的（比如在第 5、12、22、35、45 房），让休息点紧跟在精英房之后。通关率变了吗？
