# 03 - 三层经济：局内 / 局外 / 广告

> **本章目标**：把[第 01 章 §4](./01-iaa-model.md) 那张三层图变成可计算的模型，并搞清楚**每一层该看什么指标**——三层的健康标准完全不同，混为一谈是新手最大的坑。
> **本章的实用产出**：一条能直接指导广告点位排序的原则（§5）。
> **本章有模型**：`models/s03_three_economies.py`（用 game-numeric 的 [`econ.py`](../game-numeric/03-resource-flow.md) 引擎）

---

## 1. 三层各自的规则

```
┌─────────────────────────────────────────────────────────┐
│  ③ 广告层：注意力 → 资源                                   │
│     无限供给，受频次与体验约束                              │
│     **唯一产生收入的一层**                                 │
└────────────────────────┬────────────────────────────────┘
                         │ 注入
                         ▼
┌─────────────────────────────────────────────────────────┐
│  ② 局外经济：跨局累积（元货币、等级、放置产出）                │
│     **需要 sink，会通胀**                                  │
│     决定长线留存                                          │
└────────────────────────┬────────────────────────────────┘
                         │ 起始配置
                         ▼
┌─────────────────────────────────────────────────────────┐
│  ① 局内经济：每局清零（血量、金币、栏位）                     │
│     **不需要 sink** —— 结算就是终极 sink                    │
│     决定单局体验                                          │
└─────────────────────────────────────────────────────────┘
```

| 层 | 需要 sink？ | **健康指标** | 出问题的表现 |
|---|---|---|---|
| **① 局内** | 不需要 | **买得起比例**、**节奏点有效性** | 商店没意义 / 节奏点是死的 |
| **② 局外** | **需要，且是核心** | **回收率还能撑多少天** | 内容耗尽，玩家没目标了 |
| **③ 广告** | 不适用 | **每单位收入吃掉多少内容寿命** | 内容被提前烧光 |

**注意第 ② 层的指标写法很特别**——不是"回收率是多少"，是"回收率还能**撑多少天**"。§4 会看到为什么。

## 2. 局内经济：目标不是收支平衡

```bash
cd models && python s03_three_economies.py
```

模型跑一局 50 房的经济：每房掉金币，每 5 房一个商店（上架 4 件），价格和掉落同速增长。

```
商店定价   买得起比例   空手商店比例   结算剩余率   终局强度   判断
--------------------------------------------------------------------
 0.50×       100%          0%          4%      102.9   钱不是约束，选择没分量
 0.75×        65%          0%          7%       45.5   ← 健康区间
 1.00×        50%          0%          4%       32.1   ← 健康区间
 1.50×        30%          0%         16%       20.1   偏紧
 2.00×        25%          0%          4%       17.9   偏紧
 3.00×        15%         40%          1%       14.2   太多商店空手而归
```

> **局内经济的目标不是"收支平衡"，是让"买不起全部"成为常态。**

买得起比例落在 **40%~70%** 时，"这次买哪个"才是一个真决策——这正是[第 01 章](./01-iaa-model.md)说的：**真正稀缺的是玩家的决策次数。**

### 2.1 两个反直觉的发现

模型跑出来两件和我预期不符的事，都比原来的假设更有用。

**① "结算剩余率"不是一个好指标**（1%~16%，而且非单调）。

我本来以为定价越高，金币越花不掉，浪费越多。**错了。**

> **玩家买不起就攒着，攒够了照样买。钱最终总会花掉。**
> 所以浪费不体现在剩余金币上，而体现在**他在商店前站了几次却什么也没买**。

**② "空手商店比例"是个阶跃，不是渐变**（2.0× 时 0%，3.0× 时直接跳到 40%）。

原因很清楚：模型里价格与掉落**同速增长**，所以购买力恒定——要么每次都买得起一件，要么每隔一次才买得起，中间没有过渡。

**这本身就是一条重要的设计经验：**

> **当价格增速 = 产出增速时，局内经济的手感是"平的"——
> 从头到尾一样紧，而且调价不会平滑变化，会在某个点突然崩掉。**

**想要紧张感随深度递增，价格增速必须略快于产出增速。** 这就是 [game-numeric 第 04 章](../game-numeric/04-growth-curves.md) 的**成本/产出增速比**（健康区间 1.1~1.3），它在局内和局外一样适用，只是时间单位从"天"变成"房间"。

### 2.2 局内经济的检查清单

| 检查项 | 健康值 | 不健康的表现 |
|---|---|---|
| **买得起比例** | 40%~70% | >95% 选择消失；<30% 只买得起一件，等于没得选 |
| **空手节奏点比例** | <10% | 节奏点是死的，玩家白跑一趟 |
| **成本/产出增速比** | 1.1~1.3 | =1.0 手感全程一样紧，且调参会突然崩 |
| 结算剩余率 | 不用看 | —— |

## 3. 局外经济：唯一的 sink 是"内容"

局外经济和 SLG 的结构一模一样，[game-numeric 阶段二](../game-numeric/06-currency-system.md) 全套适用。但有一个 IAA 特有的性质：

> **局外经济里，几乎所有的 sink 最终都是"内容"。**
> 元进程升级、解锁角色、建筑升级——**它们既是回收，又是你做出来的东西。**
> 回收能力 = 内容量。**sink 用完了，就是内容做完了。**

这和 SLG 不同：SLG 可以靠"消耗品 + 战损 + 赛季重置"造出**不需要新内容的 sink**（[game-numeric 第 08 章](../game-numeric/08-sinks.md)、[第 22 章](../game-numeric/22-seasons-and-merges.md)）。**小游戏的 sink 大多是一次性的。**

## 4. 广告层：它吃掉的是内容寿命

模型的第二段：元进程共 100 级（= 你做出来的全部内容），每天玩 5 局，扫描广告注入量。

```
广告注入   日产出倍数   内容耗尽   第7天等级   第30天等级   寿命缩短
--------------------------------------------------------------
  0.0×       1.0×      79 天        11         44        0%
  0.5×       1.5×      53 天        16         62       33%
  1.0×       2.0×      40 天        21         79       49%
  1.5×       2.5×      33 天        25         94       58%
  2.0×       3.0×      28 天        30        100       65%
  3.0×       4.0×      21 天        39        100       73%
```

> **这就是 IAA 版的通胀。它的表现不是物价上涨，是"玩家提前把内容玩完了"。**

**注意它不是线性的**：日产出翻倍，寿命并没有减半（79 → 40 天差不多是减半，但 ×4 产出只减到 21 天而不是 20 天）。原因是升级成本指数增长：

```
产出多一倍，只够多推进 log(2) / log(1.035) ≈ 20 级
```

> **指数成本曲线是你的缓冲垫。** 它让"多放一点广告"的代价远小于直觉——
> **这也是为什么放置类小游戏敢把广告倍率做到 ×3 甚至更高。**

### 4.1 回收率崩塌：为什么要看"还能撑多少天"

模型最后对同一个经济（广告注入 1.0×，内容第 40 天耗尽）做了两次收支平衡表：

```
【A】只看前 39 天                【B】看满 180 天
  投放合计   241,509               投放合计  2,950,232
  回收合计   241,007               回收合计    258,783
  回收率       99.8%               回收率        8.8%   ← 回收不足
  期末存量       501               期末存量  2,691,449
```

**同一个经济，只因为多跑了 141 天，回收率就从 99.8% 崩到 8.8%。**

拐点就是内容耗尽的那一刻——升级是这个经济唯一的 sink，等级顶到 100 之后它彻底失效，**而投放一天没停**。

> **在 game-numeric 里，这张表读作"回收不足，会通胀"。**
> **在 IAA 里它读作另一句话：你的玩家从第 40 天起就没有目标了。**

**所以别被"回收率 100%"骗了**——那只说明玩家还在消耗内容。**真正要盯的是它还能保持多少天。那个天数就是你的留存天花板，也是 LTV 的天花板**（第 04 章接上）。

### 4.2 本章最该记住的一句话

> **广告注入量必须计入你的内容预算。**

你每加一个局外广告点位，都在缩短内容寿命；内容一旦耗尽，留存就断、DAU 就掉——**你用 IPU 换来的收入会被 DAU 吃回去。**

**这不是说少放广告。** 是说：**加广告点位的同时，必须同步加内容，或者同步拉长成本曲线。** 第 12 章讲怎么算这个预算。

## 5. 实用产出：广告点位该按什么顺序做

上面的模型直接推出一条可操作的原则。先把点位按"注入到哪一层"分类：

| 点位 | 玩家得到什么 | 注入哪一层 | **吃内容寿命吗** |
|---|---|---|---|
| **复活**（局内继续） | 这局多活一会 | ① 局内 | **几乎不吃**（间接：活得久 → 结算多一点） |
| **翻倍拾取**（局内金币 ×2） | 局内购买力 | ① 局内 | **不吃**（结算清零） |
| **重抽三选一** | 更好的构筑 | ① 局内 | **不吃** |
| **临时增益**（本局攻击 +30%） | 局内强度 | ① 局内 | **不吃** |
| 结算奖励翻倍 | 元货币 ×2 | ② 局外 | **吃，而且直接** |
| 离线收益翻倍 | 元货币 | ② 局外 | **吃，而且是大头** |
| 每日免费领 | 元货币 | ② 局外 | **吃** |

于是：

> **⭐ 局内广告点位是"便宜"的收入——它们几乎不消耗内容寿命。**
> **局外广告点位每一次都在吃你的内容预算。**
>
> **⇒ 先把局内点位做满，再考虑局外点位。**

**为什么这条不显然**：局外点位（结算翻倍、离线翻倍）是行业里最常见、最容易做的，新手往往先做它们。**但它们恰恰是最贵的**——你在用内容寿命买 IPU。

**当然有例外**，两条：

| 例外 | 说明 |
|---|---|
| **离线翻倍是最强的回访钩子** | 它买的不只是 IPU，还有 DAU。这笔账要单独算（第 11 章） |
| **局内点位受触达率限制** | 放在第 40 房的点位只有 40% 的局能走到（[第 00 章 §4](./00-setup.md)）。**算 IPU 时必须乘生存曲线** |

第 05 章会把这七类点位逐个建模定价。

## 6. 两个品类的映射

三层结构在两条产品线上长得不一样，但骨架相同：

| | **割草 / Roguelike** | **放置 / 模拟经营** |
|---|---|---|
| **① 局内** | 一局内的金币、血量、遗物栏位 | **一个"生产周期"**内的原料与产能 |
| **② 局外** | 元进程等级、解锁的角色/道具池 | 建筑等级、科技、prestige 层 |
| **③ 广告** | 复活、重抽、结算翻倍 | **离线翻倍、加速、免费资源** |
| **稀缺的是** | 每层只能选一次的机会 | **时间**（等产出） |
| **广告卖的是** | **容错**（再来一次的机会） | **时间**（跳过等待） |

> **最后一行是两个品类变现逻辑的根本差异**，第 05 章会分开定价：
> **卖容错的点位定价看"玩家有多不想重开"，卖时间的点位定价看"他还要等多久"。**

而共同内核仍然是那一句：**真正稀缺的是玩家的决策次数**。局内经济负责让每个决策有分量，局外经济负责让决策的累积有方向，广告层负责在玩家最想反悔的时刻出现。

**任务 B：把广告点位分成局内/局外两种。** 现在模型里"广告注入"是一条直接进局外的线。加一条只影响局内的（比如让 `run_inner` 的掉落 ×1.5），对比两者对内容寿命的影响。**验证 §5 那条原则。**

- 把 `MAX_LEVEL` 从 100 加到多少？

**跑出这两个数，并说出你会选哪条路、为什么。**（提示：第一条要做美术和策划，第二条免费但会让后期升级变慢——玩家会觉得"越来越肝"。）
