# 07 - 构筑多样性

> **本章目标**：搞清楚单人游戏的"平衡"到底是什么，并拿到一个**能自动报警的 dominant 判据**。
> **本章有模型**：`models/s07_build_diversity.py`
> **本章的一半内容其实是关于"怎么选指标"** —— 三个看起来合理的指标里，两个失灵了。

---

## 1. 单人游戏的"平衡"是什么

先把三个常见的错误定义排掉：

| 错误定义 | 为什么错 |
|---|---|
| "所有道具强度相同" | 那玩家选什么都一样，**构筑系统变成装饰品** |
| "胜率 50%" | 那是 PvP 的概念。单人游戏的目标通关率由[第 06 章](./06-difficulty-as-lever.md)决定，不是 50% |
| "没有人抱怨" | 玩家抱怨的是他输的那局，不是数值问题 |

**正确的定义：**

> **平衡 = 有多少条不同的路，能走到赢。**

这个定义可以直接量化，也正是本章模型要测的东西。

### 1.1 模型怎么接的

24 件道具、4 条协同线，每局三选一选 8 次。构筑决定强度，强度接回[第 00 章](./00-setup.md)的单局模型：

```
build_score = Σ道具价值 + Σ协同加成
power_gain  = 1.020 + (build_score − 8.95) × 0.0025
```

**这个接法能成立，靠的是第 00 章那条"指数赛跑对增长率极度敏感"**——构筑分差 1 分，通关率就能差几十个百分点。

## 2. 三种玩家策略

```bash
cd models && python s07_build_diversity.py
```

```
策略                 通关率   构筑分中位   构筑分P90   选取率基尼   零选取道具
------------------------------------------------------------------------
随机选               23.6%      8.47       9.00      0.014        0
贪心（看单件强度）    32.4%      8.88       9.40      0.418        0
凑协同               40.0%      9.25       9.87      0.417        1
```

> **"随机选"和"凑协同"的通关率差距（23.6% → 40.0%）就是技巧的空间。**

**如果这两个数差不多，说明你的构筑系统是装饰品**——玩家怎么选都一样。（回想[第 00 章](./00-setup.md)里 `dmg_exp = 1.0` 的情形：那时构筑好坏对结果几乎没影响。）

**"选取率基尼"衡量玩家的选择有多趋同**：0 = 每件被选概率相同，1 = 只有一件被选。它是个有用的整体指标——**但下一节会证明它抓不到"某一件超模"。**

## 3. 两种"超模"，和三个指标里的两个失灵

[第 01 章](./01-iaa-model.md)说过：**罕见的超模组合是 roguelike 的快感来源，但单个道具强到无脑选是灾难。** 现在把这句话变成数字。

模型造了两个坏/好版本：

- **A 单道具超模**：把其中一件道具的价值从 ~1.0 提到 1.85
- **B 稀有协同超模**：**一件道具的价值都不改**，只把"集齐 5 件同标签"的回报从 +1.2 拉到 +3.0

```
方案             通关率  构筑分P95  超模触发率  最高选取率  最高边际胜率  边际胜率离群度
--------------------------------------------------------------------------------
基线             32.8%     9.51        3%        90%        4.6%        1.2σ
A 单道具超模      49.1%    10.30       66%        90%       21.4%        4.9σ
B 稀有协同超模    44.3%    11.83       13%        89%        6.0%        1.1σ
```

**两个都把通关率推上去了。一个是灾难，一个是好设计。看哪个指标能分辨：**

### ❌ 选取率基尼：0.422 / 0.421 / 0.418

**完全没动，甚至 A 还更低。**

原因：基尼衡量**整体分布**的不均。24 件里有 1 件变强，影响被其余 23 件稀释掉了。

> **通用教训：聚合指标会掩盖单点异常。**

### ❌ 最高单件选取率：90% / 90% / 89%

**三者几乎一样，也分辨不出来。** 这个失灵更微妙：

> **在三选一里，全池最强的那件本来就该接近必选——哪怕它只强一点点。**
> 这个指标的基线值天生就很高，**没有区分度**。

（顺带一提：模型给贪心玩家加了 **15% 的 ε 噪声**，因为纯贪心时这个指标会直接钉死在 100%，连数字都不用看。**真实玩家不是完美贪心的，你的模型也不该是。**）

### ✅ 边际胜率的离群度：1.2σ / 4.9σ / 1.1σ

**干净地抓到了 A。**

```
边际胜率 = 含该道具的构筑通关率 − 不含它的构筑通关率
离群度   = (最大边际胜率 − 中位数) / (1.4826 × MAD)
```

用中位数和 MAD 而不是均值和标准差，是因为**要抓的就是极值，不能让极值污染基准线**。

A 那件道具的边际胜率 21.4%，池子里其他道具的中位数只有几个点。

## 4. 判据

> **① 单件的边际胜率离群度 > 3σ → dominant，必须削。**
>
> **② 超模状态的触发率**
> - 接近 100%（A 是 66%）→ 它不是惊喜，是**新的基线**
> - **5%~15%（B 是 13%）→ 这才叫"罕见超模"**，第 01 章说可以留的就是这种

**两个判据必须一起用：**

| 只用一个会漏掉什么 |
|---|
| 只看 ① → 漏掉"一堆平庸道具凑出的必胜套路"（每件都不离群，合起来无敌） |
| 只看 ② → 漏掉"人人必拿但不改变套路的那张卡" |

**还要加一条反向检查：**

> **边际胜率接近 0 且选取率 < 5% 的道具是废卡。** 它占着池子却从不被选，
> 等于把你的"三选一"变成了"二选一"——**这比超模更常见，也更隐蔽。**

### 4.1 一条通用教训

**本节三个指标里有两个是"看起来很合理"的，却都失灵了。**

> **做数值体检时，先用一个已知有问题的版本去检验你的指标能不能报警。**
> **指标本身也需要测试。**

第 13 章会把这件事做成自动化——**你的平衡测试套件里应该常驻一个"已知超模"的用例。**

## 5. 接回变现：构筑分布决定玩家落在 LTV 曲面的哪一片

[第 06 章](./06-difficulty-as-lever.md)证明 LTV 在通关率 28%~33% 的平顶上最优。**而构筑系统决定了你的玩家实际散落在通关率轴的哪一段。**

```
方案             P10通关率   中位    P90    落在健康带  太难(<20%)  太易(>45%)
--------------------------------------------------------------------------
基线              24.3%    31.8%  45.4%      80%         5%         15%
A 单道具超模       28.7%    51.8%  66.1%      35%         0%         65%
B 稀有协同超模     29.3%    41.4%  93.1%      70%         0%         30%
```

（健康带取 20%~45%，是把第 06 章的平顶放宽后的范围）

**读法：**

- **基线**：80% 的玩家落在健康带内——这是你想要的形状。
- **A 单道具超模**：整条分布被**平移**上去，65% 的玩家被推到"太易"。

> **注意 A 并没有让玩家之间的差距变小，它是把所有人一起抬高了。**
> **这正是"新基线"的含义：加成人人有份，等于没有加成，只是难度悄悄变低了。**

- **B 稀有协同超模**：P90 冲到 93.1%，**右尾明显长出去了**——那一小撮就是"这局我摸到神了"的玩家，**他们是分享和口碑的来源，而分享是 IAA 最便宜的量**（[第 04 章](./04-ad-revenue-math.md) §4.1）。

> ⚠️ **一个诚实的说明**：B 这一行用的是"凑协同"玩家，A 和基线用的是贪心玩家，
> 所以 B 的中位数本来就更高，**不能直接比中位数**。这一行该看的是**右尾**和**触发率 13%**。
> 想做干净对照就把 B 也换成贪心玩家跑一遍（动手任务 B）。

### 5.1 两条结论

> **一、超模道具的真正问题不是"太强"，是"人人都有"。**
>
> 人人都有的加成等价于调低难度，而难度该按第 06 章的方式定，**不该被一件道具偷偷改掉。**

> **二、构筑多样性不是玩法部门的事。**
>
> 它直接决定你的玩家分布在 LTV 曲面的哪一片。

第 12 章会回到这个问题：**元进程的作用之一，就是把掉到"太难"那一侧的玩家推回健康带。**

## 6. 实践：怎么设计一个 20~30 件的池子

**结构建议**（[第 01 章](./01-iaa-model.md)提到的"通用模块 + 传说件"路线）：

| 层 | 占比 | 特征 | 边际胜率目标 |
|---|---|---|---|
| **通用模块** | 60~70% | 数值型（+攻击、+攻速、+生命），可自由组合 | 2~6%，彼此接近 |
| **协同触发件** | 20~30% | 带标签，凑够数量才强 | 单件低，**成组高** |
| **传说件** | 5~10% | 改变规则的（"每次暴击回血"） | 单件可以高，但**必须稀有** |

**四条经验：**

1. **通用模块的价值要压得很平。** 它们的作用是"提供大量不是很重要的决策"，让玩家有节奏感。
2. **协同的门槛要够高。** 模型里 5 件同标签的触发率是 13%——**这是个好数字**。降到 3 件就变成人人都有了。
3. **传说件的数量 = 你的巅峰体验预算。** 太多就不稀有了。
4. **每个版本更新后跑一遍判据。** 新道具最容易造出意外的超模组合。

## 7. 动手

### 7.1 改模型

**任务 A：找出你能承受的最大离群度。** 把 A 的超模值从 1.85 逐步降到 1.2，找出离群度回到 3σ 以下的那个点。**那就是"可以留"的上限。**

**任务 B：做干净对照。** 把 B 也换成 `pick_greedy` 跑一遍（贪心玩家凑不齐协同）。**触发率掉到多少？右尾还在吗？** 这回答了一个真问题：**稀有协同只对会玩的人有价值吗？**

**任务 C：造一个"合起来无敌"的组合。** 挑 3 件道具，每件的边际胜率都不离群，但同时拥有时构筑分暴涨。**验证判据 ① 抓不到它、判据 ② 能不能抓到。** 想想还需要什么指标。

**任务 D：找废卡。** 打印所有道具的 (选取率, 边际胜率)，找出选取率 < 5% 的。**它们的共同特征是什么？** 是价值低，还是标签太冷门（协同凑不齐）？

**任务 E：池子大小。** 把 `N_ITEMS` 从 24 改成 12 和 48，重跑。**通关率分布的宽度怎么变？** 想一想：小团队该做大池子还是小池子？

<details>
<summary>参考思路</summary>

池子越大，单局能看到的比例越小 → **每局的构筑差异更大** → 分布更宽 → 重复可玩性更强。
但代价是：**玩家更难凑出协同**（想要的标签抽不到），挫败感上升。

小团队的实用做法：**池子不大，但把"每局只开放其中一部分"做成机制**
（比如按角色/关卡限制可用池）。这样用同样的内容量拿到更大的组合空间。
</details>
