# 如何检验模型：研究对象、证据边界与下一轮问题

适用背景：赛季制、联盟战争为主的 SLG。2026-09-22。

性质：计划
版本：2026-09-23
依据：[../research/theory-individual.md](../research/theory-individual.md)、[../research/theory-group.md](../research/theory-group.md)、[../research/evidence-games.md](../research/evidence-games.md)

本文是研究设计备忘录，不是已经验证的 SLG 结论，也不是功能排期。以下时间窗、问题措辞和分组均为研究起点，需按实际赛季节奏修订。

## 0. 一页结论

1. 研究单位是"玩家 × 一次失败事件 × 所属关系 × 时间"，不是"玩家是否流失"（§1）。
2. 结果拆成四个：体验恢复、熟人共同体延续、原联盟存续、产品留存；它们可能互相冲突（§2）。
3. "好友先走、本人后走"至少有五种竞争解释（共同冲击、选择相似、情绪影响、信息与规范影响、实际功能变化）；观察数据只能预测，不能直接识别情绪传染（§3）。
4. 调查要分开问"我想做、我认为别人想做、我认为别人会做、我能做"四件事（§4），采样要覆盖沉默者与已离开者（§6）。
5. 八条可证伪假设 H1–H8 与结论层的状态、原型对应见 §7.1；它们在 validation-ethics V3 中检验。

## 1. 最小研究单位：玩家 × 一次失败事件 × 所属关系 × 时间

不要只记录“这个玩家是否流失”。同一个人在不同战役、联盟、职位和赛季阶段可能作出相反选择。

建议将数据分为四张关联表：

| 层级 | 需要记录什么 | 最容易误判什么 |
|---|---|---|
| 事件 | 战前目标与预期、损失、恢复成本、是否失去战略通道、赛季剩余时间 | 战报输赢不等于玩家认可的失败 |
| 玩家 | 目标、损失承受能力、主观评估、情绪、真实偏好、实际行为 | 登录、付费、发言都不等于心理恢复 |
| 关系/组织 | 熟人小团、指挥依赖、资源依赖、盟内职位、发言权、盟外联系 | 盟内活跃度不等于真实朋友关系 |
| 赛季轨迹 | 当前战役参与、赛季后段行为、下一季回归及共同去向 | 本季休息不等于永久退游 |

“失败事件”的起点要同时保留客观与主观时间：城池失守的时刻，可能晚于玩家意识到本季无望的时刻；也可能早于他们真正改变预期的时刻。

## 2. 结果变量必须拆开

分别观察：继续原目标、调整目标、停止参战但继续游戏、退盟、同服换盟、跨服/下季随团迁移、暂时休息、下一季回归、持续不回归。这些行为可能连续发生，不宜压成一个互斥的永久标签。

区分四个目标：玩家体验恢复、熟人共同体延续、原联盟存续、产品层面留存。它们可能一致，也可能冲突。

例如：原联盟解散，成员一起加入新联盟继续玩，是原组织消失、关系延续、产品留存。原联盟仍在但成员迫于压力签到，是组织名义存续、体验未必恢复。

## 3. 集体流失至少有五种竞争解释

1. **共同冲击**：大家都遭受战败、奖励预期下降和规则约束，独立得出相似选择。
2. **选择相似**：原本就相似的人组成联盟，对损失和时间投入的容忍度也相似。
3. **情绪影响**：接触他人的愤怒、绝望和嘲讽，改变自己的情绪。
4. **信息与规范影响**：从别人言行推断局势、领导可信度、可接受的行动和“大家是不是都准备走”。
5. **实际功能变化**：指挥、外交、组织活动或关键战力离开后，继续玩的条件变差；退出可能是对新环境的合理反应。

好友先走、本人后走，只能支持存在时间关联。Shalizi 与 Thomas 说明，观察性网络中的同质性与影响通常难以区分；加入过去活跃度或普通匹配，并不会自动解决未观测混杂。[原文全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC3328971/)

因此，第一阶段可以建立预测模型，但不要把“能预测”写成“已识别情绪传染”。若将来评估干预，应考虑联盟内互相影响以及跨联盟外交联系，避免把每个玩家当成独立实验单位。

## 4. 不要只调查公开表态

至少分别问四件事：我想怎么做；我认为其他人想怎么做；我认为其他人会怎么做；我觉得自己能够怎么做。

四个回答可能相反。例如：“我想休战，但认为大家要死战；如果大家都留下我也留；我又没有权限谈和。”只问“支持战斗还是投降”会把偏好、信念、条件和能力混在一起。

“死撑到底”与“妥协”本身带有价值色彩，不适合作为中性研究选项。应询问具体目标、行动、条件和代价，例如继续争夺当前目标、缩小战线、暂停参战、谈判、调整下一季去向，并允许不确定和暂不表态。这里只在讨论测量，不意味着立即上线投票功能。

不应由盟主管理成员的原始研究答案，否则发声风险会改变测量结果。联盟很小时，即便不展示姓名，也可能从职位与时间推断身份；需要在研究设计中明确汇总粒度和可见范围。

## 5. 一组用于访谈的具体问题

这些是探索性访谈题，不是经过验证的心理量表；不能据此计算“心理健康分”。

| 想区分的机制 | 可问的问题 |
|---|---|
| 损失对象 | 这次失败最让你在意的损失是什么？如果只能拿回一种，会是什么？ |
| 预期落差 | 开战前你觉得什么结果可以接受？什么时候开始觉得目标变了？ |
| 可控与可修复 | 当时你觉得自己能改变什么？即使赢不回来，还有什么能够修复？ |
| 公平与承诺 | 你认为谁作了承诺？实际结果在哪一点违背了你的预期？ |
| 依附对象 | 如果原班朋友都在但联盟名字变了，你还想继续吗？反过来呢？ |
| 真实备选 | 你考虑过哪些去处？哪一步做不到：不知道、规则不允许、代价太高、没人接纳，还是不想丢下别人？ |
| 行为条件 | 在什么条件下你愿意继续？你需要看到谁先作出什么承诺或行动？ |
| 情绪与判断 | 是先不想玩，再觉得没希望；还是先判断没希望，才开始难受？是否经历反复？ |
| 赛季时间 | 停止本季参战，会让你更期待下一季、更不期待，还是没区别？为什么？ |
| 反事实 | 如果损失不变，但指挥解释不同／好友都留下／可一起转移，你的选择会改变吗？ |

反事实自述可帮助提出机制，但不是因果证明。采访者应先请玩家自由回忆，再追问候选解释，避免把研究者的理论塞给受访者。

## 6. 采样比多问几道题更重要

对照同一场战争中的不同职位和损失程度，也对照损失相似但后续轨迹不同的联盟。招募应覆盖继续打、改目标、迁移、沉默、休息和离开的玩家；只采访盟主或愿意回问卷的人，会漏掉最关键的人。

先做事件时间线访谈，重建“我何时改变想法—看到什么—与谁讨论—做了什么”。随后才开展重复短测，把一次性解释改造成动态证据。优先保留战前测量；若只能战后追忆，应标注回忆与事后合理化偏差。

可探索的测量节点是：开战/关键决策前、失败后、下一次联盟决策后、赛季结算和下一季组队后。无需假设所有玩家都按固定几个小时经历相同阶段。

分析时控制或分层考虑：原本的厌倦、现实时间变化、付费/战力差异、战争任务、赛季阶段、此前连败、联盟历史和服务器生态。也要检验反向因果：成员原本已减少投入，可能同时导致战败和后续流失。

## 7. 最值得优先区分的可证伪假设

以下全部是待验证的 SLG 假设。

| 假设 | 需要看到的现象 | 什么会削弱它 |
|---|---|---|
| H1 可恢复性比绝对损失更能解释退出 | 相近损失下，恢复前景变化先于退出倾向变化 | 预期与资源控制后，可恢复性没有额外解释力 |
| H2 熟人依附与联盟依附导向不同去向 | 两类依附相近总强度下，前者更愿随团换组织，后者更想保留原盟 | 两类依附无法被可靠区分，或不预测不同选择 |
| H3 可集体执行的备选改变归属与留存关系 | 高归属玩家有共同去处时更易一起留在产品内 | 有无共同去处不改变高归属者的行为轨迹 |
| H4 战略无望通过组织功能损失放大 | 指挥/外交等角色断供先于参战能力及活动机会下降 | 组织功能正常时出现同等幅度退出，且情绪路径解释更好 |
| H5 公开一致不代表偏好一致 | 私下偏好、公开表态及对他人偏好的估计明显不同 | 不同测量方式一致，且后续行动也稳定一致 |
| H6 赛季重置既可能缓冲，也可能削弱投入 | “未来可翻盘”与“本季不必再打”的预期同时存在 | 赛季时间和重置预期对这两种结果没有区分力 |
| H7 高归属会放大关系断裂的打击 | 熟人共同体解体时，高依附者退出风险上升更明显 | 控制既有行为和损失后，没有这种差异 |
| H8 持续参战包含不同心理状态 | 相同参战量中既有自主投入，也有责任压力与耗竭 | 主观测量和后续轨迹都无法区分两类情况 |

预测中的“先于”只是必要线索之一，并不足以识别因果。上述模型没有已估计系数，不应制作看似精确的流失概率评分。

## 10. 证据边界

- 本文所有假设（H1–H8）都是待验证的 SLG 推论，没有一条已在 SLG 数据中检验；原 §8 证据卡（现 research/supplementary-evidence-cards.md）来自其他情境（实验室、组织、临床），只提供机制和研究问题。
- 访谈题（§5）是探索性问题，不是验证过的量表，不能用来计算个人分数。
- §7.1 的对应关系是本文的推断（C），检验结果回写时以 [validation-ethics](validation-ethics.md) §2.1 和 [AGENTS.md](../AGENTS.md) 的规则为准。
