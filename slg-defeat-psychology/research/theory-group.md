# 联盟失败后的社会心理与组织社会学：研究备忘录

研究日期：2026-09-22。场景：赛季制 SLG，以联盟战争为主。范围：解释模型与用户分类，不提出产品功能。本文把“已有研究结果”“跨场景推断”“待验证预测”分开；尚未找到能直接证明现代移动 SLG 战争失败—情绪扩散—集体流失完整链条的因果研究。

性质：调研
版本：2026-09-22
依据：来源见文内

## 1. 最关键的建模修正

**分析单位应当是“玩家 × 所处关系和位置 × 本次失败阶段”，不能只给玩家贴稳定人格标签。** 同一个人在熟人小队是照顾者，在全联盟可能是沉默成员；今天是有信心的干部，连续失利后可能成为耗竭的离任者。这是本备忘录提出的分析框架，不是经过验证的玩家分类量表。

“集体失败”至少可能损害五种不同对象：个人资产、自己在群体中的地位、联盟实力、熟人关系、对游戏规则的信任。它们不一定同步崩溃。一个玩家可以放弃本次战争而继续玩，可以离开联盟却保留朋友，也可以保留原班朋友而离开整个游戏。

因此应区分五种结果：继续原战役；停止作战但留盟；个人换盟或换服；关系小团体共同迁移；游戏流失。短期在线时长下降还有恢复、现实事务和消极退出等多种解释，不能全部视为沮丧。

## 2. 可放入知识库的核心理论

### 2.1 社会认同：输了什么，以及“我们”到底是谁

Ellemers 等（1990）的实验显示，群体边界是否允许跨越、群体地位是否可能改变，会影响个体流动和集体改变策略；可渗透边界与个体流动倾向相关，不稳定地位能激发改变群体地位的意愿。[原论文与摘要](https://bpspsychub.onlinelibrary.wiley.com/doi/pdf/10.1111/j.2044-8309.1990.tb00902.x)

SLG 推断：不只问“归属强不强”，还要问归属对象。建议分别观察联盟旗号认同、熟人团依附、服务器认同、游戏认同。强熟人依附既可支撑留存，也可能支撑全体转移。上述实验是人工群体，不能直接给出真实付费游戏中的迁移概率。

### 2.2 集体行动：愤怒也可能带来行动，愉快不等于团结

van Zomeren、Postmes、Spears（2008）综合了 182 个效应，社会认同、不公感、效能信念各自与集体行动有关。研究对象主要是社会抗争，不能把抗争意愿直接当成 SLG 留存。[元分析摘要](https://pubmed.ncbi.nlm.nih.gov/18605818/)

SLG 推断：对外部不公的愤怒可能促成再战，对内部管理不公的愤怒可能促成换领导，对游戏规则不公的愤怒可能促成共同离开。情绪的**指向对象**比单一正负情绪评分更有解释力。愤怒和无望也应分开测量。

### 2.3 Exit / Voice / Loyalty：退出和发声不是互斥人格

Hirschman（1970）用退出、发声与忠诚解释组织衰退中的反应。这是理论框架，不是已建立的 SLG 因果定律。[原著预览](https://books.google.com/books/about/Exit_Voice_and_Loyalty.html?id=vYO6sDvjvcgC)

Dowding 等（2000）强调必须细分退出、发声和忠诚的不同形式，才能建立可检验假设。[理论修订论文](https://doi.org/10.1023/A:1007134730724)

研究时应把“是否发声”“是否离开”“是否减少贡献”分别编码：玩家可能先建议再退出，也可能边迁移边帮助盟友；留在联盟可能出于忠诚、无处可去或等待时机。**沉默留盟不能识别忠诚，激烈批评不能识别低归属。**

### 2.4 权力与依赖：盟主地位不等于实际影响力

Emerson（1962）把权力视为关系属性：一方越依赖另一方提供的重要目标、外部替代越少，依赖关系就越强。[原文，MIT 收藏](https://web.mit.edu/curhan/www/docs/Articles/15341_Readings/Power/Emerson_1962_Power-dependence_relations.pdf)

SLG 推断：正式干部、付费资源持有者、关键指挥、熟人团中心和跨盟联系人可能分别掌握不同权力。高战也可能受制于组织协作，普通成员也可能因为掌握重要关系而拥有议价力。应测量谁控制资源、信息、入口、认可和退出成本，不把权力归因于“强势性格”。此理论提供结构解释，不能单独证明行为方向。

### 2.5 威胁僵化：同一个领导者在失败后可能改变行为

Staw、Sandelands、Dutton（1981）提出，威胁可能限制信息处理并收紧控制；这在某些任务中有用，在需要适应新环境时可能失灵。论文是跨层次理论整合，不是“失败必然导致独裁”的实验结论。[原论文](https://strategy.sjsu.edu/www.stable/pdf/Staw%2C%20B%2C%20L%20E%20Sundelands%20and%20J%20E%20Dutton%2C%201981%2C%20Administrative%20Science%20Quarterly.%2026%20pp%20501-524.pdf)

SLG 推断：反复要求死战可能来自不同机制——掌握别人没有的情报、履行联盟约定、担心失去权威、思考范围收窄、无法承认先前决策错误。最后一种仅是候选解释，不能把“对先前决策负责”推成“必然继续投入”。单凭指令不能判断动机。领导研究应记录信息开放度、权力集中度、解释责任和退出约束，避免先分“善良管理者/独裁管理者”再解释一切。

### 2.6 心理安全：敢不敢说“我撑不住了”

Edmondson（1999）在 51 个工作团队中研究了心理安全、学习与绩效。心理安全是成员共同相信承担人际风险是安全的；它与团队学习行为相关。该研究不等于对任何团队的因果保证。[作者所在大学论文库](https://dash.harvard.edu/entities/publication/13a7b031-0fdd-45ec-a7e0-2b80e2bc679f)

SLG 推断：能否承认失误、提出停战、说明时间或资源不足，是不同于“聊天气氛好”的维度。亲密团队也可能不允许异议；允许异议的团队仍可能对胜率悲观。因此心理安全、团结和集体效能必须分别观察。

### 2.7 多元无知：大家都以为只有自己不想打

Prentice 与 Miller（1993）的四项校园饮酒研究发现，人们可能误判他人的态度；认为自己偏离规范还可能带来疏离感。[作者大学的研究记录](https://collaborate.princeton.edu/en/publications/pluralistic-ignorance-and-alcohol-use-on-campus-some-consequences-2/)

SLG 推断：个人真实意愿、对他人意愿的估计、公开表达可能三者不一致。全体口头支持再战，并不能证明全体私下愿意再战。也需区分多元无知与有意隐藏：前者是误判，后者可能明知大家反对仍因惩罚压力表态支持。校园研究只支持这种机制的可能性，不能证明它在 SLG 的比例。

### 2.8 集体效能：相信“我们能做到什么”

Stajkovic 等（2009）元分析覆盖 96 项研究、6,128 个群体，集体效能与群体绩效存在正相关；任务依赖程度会调节关系。相关性和元分析结构模型不能排除绩效反过来塑造效能。[论文摘要](https://pubmed.ncbi.nlm.nih.gov/19450017/)

SLG 推断：不要只问“你觉得能赢吗”。相信能夺冠、能守住核心资产、能有序撤退、能保住队伍，是不同的任务信念。这里的任务拆分是研究假设；不能声称改变信念就能弥补客观战力差。

### 2.9 群体情绪：存在传播，但集体流失未必由传播造成

Barsade（2002）通过实验中的情绪表达操纵，观察到群体情绪传染及合作、冲突等变化。它支持人际情绪影响的存在，但不是异步文字联盟频道中沮丧导致流失的直接证据。[原论文](https://web.mit.edu/curhan/www/docs/Articles/15341_Readings/Affect/Barsade_2002_The_ripple_effect.pdf)

Shalizi 与 Thomas（2011）指出，网络观察数据中的同质性选择、社会影响和其他因素通常混杂，不能靠“朋友先走、我后走”识别传播因果。[方法论原论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC3328971/)

在 SLG 中至少要区分四种相似表象：情绪影响；大家同时遭受损失；关键成员离开使协作客观失效；原本就打算共同迁移的熟人执行计划。只有第一类可以直接叫情绪传播。

### 2.10 游戏群体可以跨越游戏容器

Poor 与 Skoric（2014）对一个曾强盛、后衰退的七年 EverQuest 2 公会进行混合方法案例研究：压力跨个人、小团体、公会、游戏与公司层面；强小团体离开可使整体沿弱联系处分裂，关系又可在其他媒介延续。[原论文摘要](https://journals.sagepub.com/doi/10.1177/1555412014537401)

这为“关系仍在，组织或游戏已失去玩家”提供了直接游戏案例，但单案例不能估计现代 SLG 的普遍比例，也不能将其所有离开归因为战败。

## 3. 动态多轴分类：先记录维度，再检验是否存在类型

不建议一开始用“领袖型、忠诚型、投机型、脆弱型”等命名覆盖所有人。推荐建立以下状态向量；它们用于提出问题，尚不能直接当成玩家打分系统。

| 轴 | 要区分的内容 | 不能用什么简单替代 |
|---|---|---|
| 依附对象 | 朋友、联盟旗号、服务器、游戏分别有多重要 | 入盟时长不能替代认同 |
| 目标优先序 | 竞争成绩、成长资产、陪伴、管理责任、娱乐节奏 | 付费额不能替代全部动机 |
| 外部机会 | 别盟愿不愿接纳、迁移是否可行、朋友能否一起走 | 想走不能替代能走 |
| 实际依赖 | 资源、保护、指挥、认可、情报依赖谁 | 头衔不能替代关系权力 |
| 正式位置 | 盟主、干部、指挥、普通成员、受保护新人 | 相同官职未必相同工作 |
| 网络位置 | 朋友团中心、跨团桥梁、外围成员；联系是否集中 | 聊天数量不能替代信任 |
| 发声环境 | 说不的代价、建议被采纳的预期、惩罚风险 | 公开无异议不能替代共识 |
| 任务效能 | 对再战、守住、撤退、重建分别有多大把握 | 当前战力不能替代所有信念 |
| 可承受余量 | 时间、注意、资产与照顾他人的负担还剩多少 | 一次缺勤不能替代耗竭 |
| 当下情绪与归因 | 悲伤、羞耻、愤怒、无望、解脱；归咎对象 | 正负情绪一个分数不够 |

**类型是维度组合产生的暂时状态。** 例如，强熟人依附＋弱联盟认同＋强跨盟联系，可能形成“随熟人迁移”的路径；强联盟认同＋高发声安全＋尚有余量，可能形成“提出修复”的路径；强依赖＋低发声安全＋低余量，可能形成“沉默收缩”的路径。这些是待验证组合，不是人格断言，同一人会在路径间转移。

领导者也应单独记录行为维度：集中决策程度；是否公开信息；能否接受修正；如何分担损失；如何处理异议；是否允许退出；自身负荷。集中决策可以与信息透明、可追责并存；温和语气也可能与资源偏袒并存。无需先进行道德归类。

## 4. 一个可研究的多层过程模型

以下为整合假说，并非现成公认模型：

1. **事件层**：战败规模、可逆性、预期偏差、连续次数、责任争议、下一目标是否仍可行。
2. **个体评估层**：我损失了什么；这件事说明我/我们是什么样的人；谁应负责；我和我们还有什么选择。
3. **互动层**：领导如何解释；谁发言、谁沉默；大家如何估计他人意愿；朋友的行动透露了什么。
4. **组织层**：信息和资源如何分配；决策权是否集中；替代成员能否补充；核心关系是否断裂。
5. **行动与反馈层**：发声、休战、投入、减少贡献、换盟、集体迁移、离开游戏；这些又改变其他人的真实机会与信念。

重要反馈环示例：少数指挥退出 → 剩余玩家协调成本上升 → 即使心情不变，参战收益也下降 → 更多人停止参与。这个过程会呈现“雪崩”，却不需要把情绪传染作为主要原因。

另一条反馈环：失败 → 羞于承认疲惫 → 公开都说坚持 → 成员误以为只有自己退缩 → 更少发声 → 突然退出。此处“突然”可能是观测盲区，真实过程早已开始。

## 5. 可证伪的预测与研究分辨点

下表均为 SLG 待验证预测；它们的价值在于竞争性解释可被数据区分。

| 预测 | 怎样观察 | 什么结果会削弱该解释 |
|---|---|---|
| 熟人依附和联盟认同对迁移方向作用不同 | 失败前后分别测依附对象，并区分个人/整团迁移 | 在相同外部机会下，两者始终无法区分路径 |
| 低归属只有在外部选择可行时才更容易换盟留存 | 按接纳机会、转移成本、好友携带条件分层 | 机会变化不调节换盟与流失关系 |
| 低发声安全使公开意愿与私下意愿差距增大 | 比较自愿保密访谈、自报偏好、公开表达 | 在能充分保护隐私的测量中仍无差距 |
| 集中决策的利弊取决于任务是否仍熟悉有效 | 同一领导者不同失败阶段，记录策略变动需要 | 高新颖情境中集中化仍普遍改善适应且不伴信息收缩 |
| 网络中间人流失可能通过结构破坏影响参与 | 检查离开后的协调延迟、跨小团体连通与情绪 | 后续参与变化仅与共同损失同步，无结构变化 |
| 特定任务效能比“整体士气”更能解释行动方向 | 分别问再战、撤退、重建效能并跟踪实际行为 | 多任务区分对预测没有增量价值 |
| 同盟连续失利后的公开强硬可能伴随私下支持下降 | 重复测量同一批玩家，而非只看仍在发言者 | 排除退出者缺失后，私下支持与公开表达持续一致 |

研究时应以一次失败事件为起点，至少覆盖战前状态、战后初始反应、集体解释形成期和后续行动。时间窗口需按实际战争节奏定义，不预设“24 小时必然是某种心理阶段”。跨玩家样本需要覆盖留存者、沉默者、换盟者、离开者；只采访活跃干部会产生严重选择偏差。

对上述关联作因果解释前，要特别控制或讨论共同战损、赛季节点、现实时间约束、相似动机形成的朋友关系和未观察到的私下迁移计划。即使使用纵向日志和网络分析，也不能自动识别情绪传染。

## 6. 对初始直觉的具体保留与修正

- **保留**：玩家面对同一失败的反应会因位置和关系不同而异。**修正**：位置不只是盟主/成员，还包含非正式权力、网络桥梁和依赖。
- **保留**：弱归属玩家可能换盟而继续玩。**修正**：若没有接纳机会、已失去核心成长目标或本来就不喜欢游戏，也可能直接离开。
- **保留**：管理者影响集体恢复。**修正**：管理者也是受损者和负荷承担者，行为可能随威胁变化；不能仅凭“善良/独裁”推断。
- **保留**：了解成员真实意愿很重要。**修正**：公开表态和人数多数不等于真实偏好，也不等于承担成本的公平性；重度承担者与普通成员的损失分布需单独理解。
- **保留**：失败后的情绪可在人群中相互影响。**修正**：集体行动同步还可能源于共同处境、真实协调能力下降和有计划迁移。
- **增加**：情绪恢复、联盟存续、游戏留存是不同结果，三者可能冲突。知识库应保留这些区分，避免把“继续死战且在线”自动视为恢复成功。

## 7. 赛季制需要额外分开的三条时间线

以下是基于赛季背景的待验证推论，不能从上述一般研究直接读出结论。

1. **本次战争**：这场仗是否继续打、是否换目标。停止参战可能是战术调整。
2. **本赛季**：争冠目标失败后，玩家是否仍有其他重视的目标；是否休整等待赛季结算。当前贡献下降可能是重新分配投入。
3. **下赛季及之后**：与谁继续玩、用哪个联盟身份、到哪个服务器。对本季胜利无望，可能与对下季的具体计划同时存在。

因而“本季不活跃”“不再为原联盟出力”“下季不回归”应作为不同结果。联盟 ID 更换也未必是原团队瓦解；熟人团可能拆入多个联盟，或保持原有关系共同建立新盟。应区分制度容器连续性（联盟名称、干部架构）、关系连续性（熟人群和指挥关系）与游戏连续性（仍否玩该游戏）。

三项关键预测：同样的战败发生在季初与季末，因剩余恢复窗口不同，行动路径可能不同；对下季共同去向已有共识的熟人团，可能更能接受本季停战；若下季安排不透明或重要成员去向未知，不确定性可能比眼前战损更能预测关系解体。这些预测都需记录迁移规则和赛季奖励保留程度，不能把赛季重置当作完全归零。

## 8. 当前证据边界

本轮强项是跨学科机制覆盖：实验、元分析、组织实地研究、游戏群体案例和因果推断方法论互补。弱项是目标场景缺口：不同文化、货币化、迁服规则、异步战争与长周期资产损失可能明显改变机制权重。本文没有证明任何维度具有稳定分群阈值，也没有证明任一干预可以降低 SLG 战败流失。下一阶段应先用实际案例检验哪条机制存在，再讨论功能。
