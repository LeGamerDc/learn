# 工具箱①：识别与预警

用途：回答"怎么知道谁、哪个联盟正处于 [03 状态清单](03-state-taxonomy.md) 里的哪个状态"，以及"什么时候该动手、该给谁看"。本篇是工具箱的识别部分；拿到识别结果后怎么帮，见 [05 干预工具箱](05-toolbox-support.md)。埋点清单、逐状态规则、模型层与可行性评级等数据实现细节放在 [附录 A](A-sensing-spec.md)。证据等级 A/B/C 见 [README](README.md#证据等级)。

依据：[research/evidence-notes/N3-sensing.md](research/evidence-notes/N3-sensing.md)、[N4-support.md](research/evidence-notes/N4-support.md)、[N6-contagion.md](research/evidence-notes/N6-contagion.md)、[N7-alliance.md](research/evidence-notes/N7-alliance.md)、[N9-material-help.md](research/evidence-notes/N9-material-help.md)、[research/evidence-games.md](research/evidence-games.md)

## 0. 一页结论

1. 感知的目标不是"读出情绪"，而是输出三个可行动的量：**状态概率向量**（P01–P21）、**流失风险**（7/30 日/跨季）、**干预敏感度**（对某类帮助会不会有反应）。第三个量只能通过随机对照得到（Ascarza 2018，A），前两个可以从日志与微问卷得到。
2. 老玩家的留存由社交特征主导（Park 等 2017，A），所以识别的核心不是登录曲线，而是**关系网络与职务节点的完整性**。
3. 三层架构：规则层（可解释、即时、覆盖高风险节点）→ 模型层（日批，输出概率）→ 人工/半自动层（微问卷、盟主报告、客服分类）。规则层只用多数 SLG 已有的日志就能起步（§1）。
4. 联盟层：24 条健康度指标（§3）与红/黄预警规则（§4）；给盟主看的只能是聚合、任务导向的诊断，个人状态只给运营（§5）。
5. 误判也有代价：对盟主、指挥、桥节点只做被动准备，不做主动推送（§6）。合规红线见 [05](05-toolbox-support.md) §12。

## 1. 三层识别架构

| 层 | 做什么 | 输入 | 输出 | 优点 / 局限 | 细节 |
|---|---|---|---|---|---|
| 规则层 | 用阈值规则即时标记个人与联盟状态 | 登录、战斗、发言量、官职、付费、导航等日志 | 状态标记 + "为什么被标记"的理由 | 可解释、分钟级；高召回低精确，阈值全部待校准（C） | [附录 A](A-sensing-spec.md) §2 |
| 模型层 | 日批预测流失风险与多标签状态概率 | 家族 A–H 的 7/14/28 天窗口统计 + 战败事件字段 + 网络特征 | 7/30 日/跨季流失风险；P、A 状态概率 | 精度更高；需 1–2 个赛季积累标签 | [附录 A](A-sensing-spec.md) §3 |
| 人工/半自动层 | 补标签、复核高风险判定、接住规则看不见的信号 | 战后微问卷、盟主报告、客服工单、人工抽样 | 校准用标签；规则误判率 | 能覆盖外部渠道与 P13 这类规则看不出的状态；有人力成本 | [附录 A](A-sensing-spec.md) §4–5 |

三层的分工原则：规则层给"为什么"，模型层给"多大概率"，人工层给"对不对"。规则层的结果同时作为模型层的弱标签。

## 2. 战败事件的定义（识别的锚点）

所有状态推断都相对于一个**失败事件**计算。事件表字段：

| 字段 | 取值 | 说明 |
|---|---|---|
| 事件类型 | 失城 / 沦陷（主城被破）/ 被俘 / 关卡失守 / KvK-SvS 阶段失败 / 赛季目标确定不可达 / 联盟解散 / 关键成员离开 | 后三项是"主观时点"，需要规则触发（如排名差距超过阈值、盟主退盟） |
| 客观时间 | 结算时刻 | |
| 主观时间 | 玩家首次查看战报/失城提示的时刻 | 冲击期从这里起算 |
| 损失量 | 兵损、资源、建筑、土地、排名变化 | 分对象记录（对应 [01 失败心理机制](01-failure-psychology.md) §2 的五个变量） |
| 可恢复性 | 伤兵可救比例、重建成本、下次机会时间 | 决定 P07/P08 分岔 |
| 责任争议 | 是否有公开追责 | A05 先兆 |
| 赛季位置 | 剩余天数 / 结算前 | 影响所有阈值 |
| 联盟状态快照 | A01–A11 的上一期判定 | |

## 4. 联盟状态判定与预警规则

以 [03 状态清单](03-state-taxonomy.md) 的 A01–A11 为输出；每个联盟状态的判定规则草案见 [附录 A](A-sensing-spec.md) §2。三类预警：

**红色（24 小时内需动作）**
- 指标 3：盟主与指挥均 ≥48h 无发令/无操作 → A04 领导真空；≥72h 升级为最高优先级，启动代理指挥或禅让流程。
- 指标 10：≥3 名核心（含桥节点）出现迁移意向行为 → A06 集体迁移筹备。
- 指标 16：@ 点名/辱骂密度 ≥ 基线 3× 且伴随踢人 → A05 甩锅内讧。
- 指标 14：头部付费者 7 日付费归零 + 世界频道告别语义 → P19 高调退出风险。

**黄色（一周内需动作）**
- 指标 1 下降 10–30% 且指标 15 出现差距 → A02 表面动摇。
- 指标 21 分歧度高 → A03 分裂前兆。
- 指标 4 ≥ 2× 基线 → 领导耗竭前兆。
- 指标 9：任一小团 30 日保留率 <60% → 子群流失。

**结构性（赛季级）**
- 指标 8 桥节点 ≤2；指标 13/14 高度集中；指标 20 新人留存低。

阈值为起点，须用 [next/validation-ethics](next/validation-ethics.md) 的标注校准；预警只在运营端触发人工复核，不自动向盟主推送"你的联盟要散了"。每条预警对应的帮助见 [05](05-toolbox-support.md) §3。

## 5. 给玩家看的组织诊断 vs 只给运营看的诊断

| 内容 | 给盟主/管理看 | 只给运营看 | 理由 |
|---|---|---|---|
| 集结响应率、响应延迟（聚合） | 是 | 是 | 任务导向；已是行业自建考勤的替代 |
| 小团结构与桥节点 | 聚合（"有 3 个小团、2 个联络人"），不点名 | 点名 | 点名会被用于排挤 |
| 个人状态（P01–P21） | 否 | 是（30 日） | 隐私；发声风险（[next/research-design](next/research-design.md) §4：盟主不应看到成员原始答案） |
| 迁移意向 | 否（只显示"本周有成员咨询迁移规则"的总数） | 是 | 点名会触发提前驱逐或对立 |
| 匿名意愿投票结果 | 是（仅分布） | 是 | 打破多元无知的目的就是让盟主看到分布 |
| 领导者自身的负荷指标 | 是（私密） | 是 | 自我觉察；配减负工具 |
| 预警等级（红/黄） | 否 | 是 | 避免"变弱"反馈压低集体效能（Greenlees，B） |
| 建议动作清单（模板） | 是 | 是 | 自主导向帮助 |

原则：盟主端看到的是"下一步可以做什么"，运营端看到的是"谁处于什么风险"。

## 6. 误判成本与保护

- 高风险节点（盟主、指挥、桥节点）误判为"要走"并触发干预，可能反而提示其离开（Ascarza 等 2016 的反向效应，A）：对这些节点只做**被动准备**（准备好工具与信息），不做主动推送。
- 对普通成员的误判成本低，可容忍高召回。
- 任何干预推送必须记录"依据规则"，供事后复核与申诉。
- 外部渠道（微信/QQ/Discord）不可观测：以"盟主端自报 + 微问卷"补足，不试图抓取。

## 7. 证据边界

- **来自文献的部分**：社交特征主导老玩家留存（Park 等 2017，A）；按干预敏感度而非流失概率定向（Ascarza 2018，A）；主动干预可能反向（Ascarza 等 2016，A）；成员流失的邻居跟随（Ducheneaut 等 2007，B）；网络干预的四类策略（Valente 2012，A）；毒性最先驱离新人（Shores 等 2014，A）；"be first"的危机沟通原则（CERC，B）。这些只支持"看什么"，不支持具体阈值。
- **全部阈值都是 C**：本篇 §3–4 与附录 A §2 的数字（发言分位 60%、下降 50%、3×、48h/72h、≥3 名核心、60% 保留率等）都是待校准的起点。其中 A01 ≥80%、A02 10–30%、A08 >40%、A09 <20% 来自 03 状态清单的示例阈值，同样未经具体产品数据检验。
- **规则覆盖不到的状态**：P13 解脱只能靠问卷确认；P14 是残差状态；A10 需要补外交/官职埋点；P10、P21、A07 的规则只覆盖可见行为，核心信号在文本或产品外。
- **不可观测**：微信、QQ、Discord 等外部渠道，以及私聊内容（按合规不读取）。联盟的真实决策常发生在外部群里，规则层会系统性地晚于真实变化。
- **文本标签的精度未知**：中文反讽与黑话使情绪标签（埋点 #21）误判率较高，依赖它的规则（P03/P04、A03、A05）需要人工抽样校准后再用于触发动作。
- 微问卷回收率、生存模型 AUC 等外推值的边界见 [附录 A](A-sensing-spec.md) §7。
