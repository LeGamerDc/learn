# 赛季制 SLG 的战败心理与支撑工具箱

> **讲什么**：以联盟战争为主的赛季制 SLG 里，一场联盟战败之后，玩家和联盟在心理上会经历什么、为什么会引发退游潮，以及产品、运营和盟主可以用哪些工具识别、干预、切断扩散。
> **两部分**：**失败心理分析**（01–03：机制、玩家分类、状态清单）+ **政策工具箱**（04–05：识别与预警、干预）。正式文档只写结论；每条结论都标了证据等级，并链接到 `research/` 里的来源笔记，需要追溯时再翻。
> **读者**：游戏策划、运营、数据同学，以及想理解"玩家为什么输了就走"的人。不需要心理学背景，理论名词在 01 里解释。

## 核心结论

1. **多数人会自己恢复。** 对重大丧失，约 2/3 的人走韧性轨迹，1/5 恢复，1/10 慢性（Galatzer-Levy 等 2018，A）。设计不应对全员做"心理按摩"，而应找出慢性/延迟恢复的人和高传播节点。→ [01](01-failure-psychology.md) §3.10、[03](03-state-taxonomy.md)
2. **退游潮的引信是头部玩家的行动，不是普通成员的情绪。** 同事的求职行为预测离职（Felps 2009，A）；社区案例反复出现"鲸鱼第一次输就走""前 12 盟和领导层集体转服"。预警要盯节点，切断要减少不确定性。→ [01](01-failure-psychology.md) §4.4、[04](04-toolbox-sensing.md)
3. **同一场战败，不同的人失去的东西不同。** 选择最多的人（大R、外交掮客、老兵）最先离开，选择最少的人（新人、种田者、潜水者）最安静地离开；两端需要不同的识别与帮助。→ [02](02-player-typology.md)
4. **证据最硬的帮助是结构化复盘，不是安慰。** AAR d≈0.67–0.79；强制的单次情绪复盘无效甚至有害（Cochrane）；吐槽区增加攻击（Bushman 2002）。→ [01](01-failure-psychology.md) §5、[05](05-toolbox-support.md) §2
5. **补偿的四条规则**：按增量而非风险定向（Ascarza 2018）；部分补偿优于超额（Gelbrich 系列）；同类补偿（Roschk & Gelbrich 2014）；自主导向而非救济（Nadler）。并且只在玩家归因于"规则不公"时有效（Grewal 2008）。→ [05](05-toolbox-support.md) §6
6. **管理层耗竭是独立的解体路径。** 国产 SLG 社区证词与行业动向（减负工具、同盟俸禄）一致；这是产品最可控的杠杆之一。→ [01](01-failure-psychology.md) §4.7、[05](05-toolbox-support.md) §10
7. **关系是跨季资产。** 整盟同服/回归专服（率土）是行业里唯一把"关系延续"机制化的先例；社区反例（盟主离开一年后 300+ 人归队）说明强关系可以跨越败局。→ [01](01-failure-psychology.md) §4.1、[05](05-toolbox-support.md) §11

## 证据等级

| 等级 | 含义 | 怎么读 |
|---|---|---|
| **A** | 多项研究、元分析或验证量表 | 机制方向可信；效应量来自原研究情境，只用于方向与粗估 |
| **B** | 单项研究，或行业一手材料（官方公告、GDC、开发者访谈）、社区证词 | 可作依据，但要看原情境；社区证词有选择偏差 |
| **C** | 本知识库的推断，尚未在任何具体产品数据上检验 | 是"待校准的起点"，不是事实 |

大约一半的正式内容是 C 级：**所有阈值、原型的战败路径、状态的可观测标志、时间轴窗口、原型/调节器对帮助的修正**。它们来自理论推演和社区案例，使用前需要按 [next/validation-ethics](next/validation-ethics.md) 校准。

## 仍待验证的五件事

证据和可行性都较好、最值得先验证的五项干预（对应命题见 [next/validation-ethics](next/validation-ethics.md) §2.1）：

1. 结构化 AAR 包（学习导向、客观战报、去责任栏、盟主自评先行）。
2. 结算页的"验证句 + 事实句"与 30 分钟首条说明模板。
3. 自主导向补偿（玩家选投向的重建令）vs 同额直接发放。
4. 整团迁移/同服通道对产品层留存的影响。
5. 匿名意愿投票对公开表态-私下意愿差距与分裂概率的影响。

## 仍未回答的问题

- 具体产品中的状态分布与时间轴（需 V1 标签）。
- 原型能否在产品数据中区分（需 V2）。
- 头部玩家去向与平均情绪，哪个预测力更强（K1）。
- 赢家侧：败方留存对胜方留存的贡献（死服问题）尚无量化证据。
- 外部渠道（微信/QQ/Discord）承载的传播比例无法观测。

## 证据边界

- 心理与组织证据来自其他领域（临床、职场、体育、军队、MOBA/MMO），效应量只用于方向与粗估。
- 行业机制多来自官方公告与二手攻略，版本与数值以 [N5](research/evidence-notes/N5-mechanics.md) 标注的可靠度为准；单一来源的条目标为"待核实"。
- 社区案例有选择偏差：只听得到仍在发声的人，缺少沉默离开者与"输了但留下"的多数派。
- 直接针对 SLG 战败后心理干预的实验研究：未找到。
