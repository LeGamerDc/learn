# 03 状态清单：21 个个人状态、11 个联盟状态、一条时间轴

用途：回答"战败之后，人和联盟会经历什么"。给识别（[04](04-toolbox-sensing.md)）与干预（[05](05-toolbox-support.md)）一个共同的状态词表；机制背景见 [01 失败心理机制](01-failure-psychology.md)。证据等级 A/B/C 见 [README](README.md#证据等级)。

依据：[research/evidence-notes/N2-states.md](research/evidence-notes/N2-states.md)、[N8-community.md](research/evidence-notes/N8-community.md)、[research/theory-individual.md](research/theory-individual.md)、[research/theory-group.md](research/theory-group.md)

## 0. 一页结论

1. 骨架是 Klinger 的激励脱离周期（亢奋 → 攻击 → 低落 → 恢复，A）叠加 Bonanno 的四条轨迹（韧性 65.7% / 恢复 20.8% / 慢性 10.6% / 延迟发作，A）。翻译成 SLG：战败当晚大多数人会经历亢奋或愤怒，一周内约三分之二自然恢复；设计要抓的是慢性、延迟与高传播的少数。
2. 个人状态按"评估 → 情绪 → 行动倾向"三段定义，共 21 个；每个状态给出可观测标志。**状态是暂时的、可并存的、可回退的**，数据实现用概率而非单选。
3. 联盟状态按 Weitzel & Jonsson 五阶段 + Wergin 级联崩溃改写，共 11 个；关键先兆出现在"表面团结、私下动摇"与"甩锅内讧"两个阶段。
4. 时间轴上有三个分岔点：**T+6–48h 的领导说明（有/无）**、**T+2–7d 的头部玩家去向（留/走）**、**赛季末的共同去处（有/无）**。绝大多数干预窗口落在这三点之前。

## 1. 个人状态卡（P01–P21）

字段：触发评估｜主导情绪｜行动倾向｜典型时长｜前驱→后继（双向一致；"入口状态"指由战败事件或他人行为直接触发）｜可观测标志（行为 / 言语）｜高发原型（T1–T12，见 [02 玩家分类](02-player-typology.md)）｜风险（流失 / 传播）｜帮助方向（详见 [05 干预工具箱](05-toolbox-support.md) §2）。

分期按**首发期**归组，与 §3 时间轴一致；卡片编号不重排，所以组内编号不连续。状态可提前或延后出现（例如 P19 可在战败当晚即时发生），数据实现以触发事件与时间戳为准。

### 一、冲击与亢奋期（首发 T0–6h）

**P01 冲击/否认**
- 评估："这不可能/怎么会这样"。情绪：麻木、不真实感（Palomäki 叙事的第一阶段，B）。
- 行动：反复刷新战报、查看损失；或立刻离线。
- 时长：分钟到数小时。前驱：战败事件（入口状态）。后继：P02 / P03 / P05 / P11。
- 标志：战报页停留时间异常；战后 30 分钟内登出。言语："？？？""这就没了？"
- 高发：T8 新人边缘、T6 种田建设者。风险：流失中（离线者可能不再回来）；传播低。
- 帮助：验证句 + 事实句；不推任何内容（N4 E3 0–30 分钟窗）。

**P02 亢奋再战**
- 评估："马上打回来"。情绪：高唤醒、愤怒与兴奋混合（Klinger 亢奋期，A；Papini：存在替代行为时尤其明显）。
- 行动：立刻集结、追击、夜战。
- 时长：小时。前驱：P01。后继：若成功 → P14；若再败 → P03 / P12。
- 标志：战后 2 小时内出征次数飙升；兵损率上升。言语："干他""别怂"。
- 高发：T5 热血打手、T1 霸主大R。风险：流失低（短期）；传播高（带动全盟）。
- 帮助：给可赢的局部目标；不要在此刻复盘。

**P12 追损/tilt**
- 评估："必须把它赢回来"。情绪：高唤醒、控制受损（Palomäki 叙事的追损阶段，B）。
- 行动：连续出兵不计兵损；连续氪金；熬夜。
- 时长：小时到天。前驱：P02（再败）。后继：P09 耗竭 / P08（追损失败）/ P14。
- 标志：兵损率飙升；短时多笔付费；凌晨连续战斗；对提醒的忽略。言语："再来""不信邪"。
- 高发：T1 霸主大R、T5 热血打手、T9 中R追赶者。风险：短期付费上升但随后流失与懊悔风险高（Palomäki：事后失望/抑郁/失眠，B）；传播中。
- 帮助：冷却而非禁止（提醒兵损、限速）；给"体面的停"；不推付费礼包。

### 二、攻击期（首发 T+6–48h）

**P03 愤怒-外（敌方/规则/官方）**
- 评估："对面更氪 / 匹配不公 / 官方偏袒"。情绪：道德愤慨（Palomäki，B；van Zomeren 不公感→集体行动，A）。
- 行动：世界频道声讨、举报、要求官方说明；可能转为 P17 复仇或 P08 对游戏失望。
- 时长：天。前驱：P01 / P02（再败）。后继：P17 / P08 / P14。
- 标志：跨盟频道发言激增；客服工单；负面评价。言语："这游戏就是逼氪""匹配有黑幕"。
- 高发：T9 中R追赶者、T1 霸主大R。风险：流失中；传播高（谣言载体）。
- 帮助：CERC 式官方说明 + 判定依据公示；程序公正；补偿此时有效（Grewal 2008：归因于系统时补偿有效，A）。

**P04 愤怒-内（盟主/指挥/队友）**
- 评估："我们输在自己人"。情绪：愤怒 + 被辜负（Wu 等 2021：tilt 多由队友引发，B）。
- 行动：群内追责、点名、要求换指挥；或退盟。
- 时长：天。前驱：战败事件（入口状态；指挥失误可见时最常见）。后继：P10 被背叛 / P16 迁移准备 / A05 甩锅内讧。
- 标志：盟内 @ 点名激增；投票/弹劾申请；对指挥的私聊。言语："指挥是猪吗""谁让打的"。
- 高发：T5 热血打手（及 R4 过度竞争/自恋高者）。风险：流失中；传播极高（触发 A05）。
- 帮助：延后到冷却期的结构化 AAR；盟主先担责；禁"谁的责任"栏；对"卖队友"指控走证据路径（Kim 2004，A）。

**P05 羞耻-面子**
- 评估："我丢人了/我们成了笑话"。情绪：羞耻，指向整体自我或公众形象（Tangney，A；中国语境的面子，B）。
- 行动：减少可见性：退出频道、隐藏战报、不上语音；可修复时会尝试补救（Leach & Cidam 2015，A）。
- 时长：天到周。前驱：P01 / P06（被推责）。后继：P06（可修复）/ P18（不可修复）/ P19 高调退出（自恋型）。
- 标志：发言归零但登录仍在；改名/换头像；拒绝被 @。言语："不玩了丢不起人""别提了"。
- 高发：T1 霸主大R、T2 军师指挥（R3 条件性自我价值高者尤甚）。风险：流失高；传播低（沉默）。
- 帮助：具体行为的感谢（Grant & Gino，A）；自我慈悲框架（Breines & Chen，A）；不展示排名骤降；不做公开安抚。

**P06 内疚-补救**
- 评估："我这次失误害了大家"。情绪：内疚，指向具体行为（A）。
- 行动：道歉、加班铺路、自费补偿盟友。
- 时长：天。前驱：P05（可修复时）。后继：P14（被接纳）/ P09 耗竭（过度补偿）/ P05（被推责）。
- 标志：战后贡献/捐献激增；长文道歉；主动申请降职。言语："我的锅，下次我来守"。
- 高发：T2 军师指挥、T3 盟主管家。风险：流失中（若被推责则高）；传播低。
- 帮助：接受道歉并给修复路径；限制他的过度补偿（Hobfoll 拆小）；把失误改写为可控归因（AR，A）。

**P10 被背叛/契约违背**
- 评估："说好的不踢人/公平匹配/一起走，没有兑现"。情绪：违背感、不信任（Zhao 2007：中介于离职意向，A）。
- 行动：公开质问、退盟、向官方申诉。
- 时长：天到周，可长期存留。前驱：P04。后继：P19 / P16 / P08。
- 标志：引用旧承诺的发言；截图取证；退盟并在世界频道说明。言语："当初说好的""过河拆桥"。
- 高发：T6 种田建设者、T7 陪伴社交者（被门槛排斥的平民，N8 案例 20、21；跟随者）。风险：流失高；传播高（有叙事）。
- 帮助：按违背类型修复：能力型→道歉+修复提议；诚信型→证据/否认（Kim 2004，A）；不能用补偿代替说明。

### 三、低落与分化期（首发 T+2–7 天）

**P07 无望-本季**
- 评估："这赛季没戏了"。情绪：低落但有边界（归因于本季、非全局，区别于 P08；C）。
- 行动：降低投入，转向种田/活动，或等结算。
- 时长：到赛季末。前驱：战败事件（入口状态；战局判断后出现）。后继：P15 转向 / P08（若下季预期同样无望）。
- 标志：集结参与降但登录稳定；查看结算规则页；活动完成率维持。言语："等下赛季吧"。
- 高发：T11 目标收集者、T6 种田建设者、T10 老兵旅人。风险：流失低中；传播低。
- 帮助：替代目标清单；贡献档奖励；跨季组队确定性。

**P08 无望-游戏**
- 评估："以后也不会有机会"（稳定-全局归因，无望理论，A）。情绪：无望、疏离。
- 行动：停止投入、清空资源、告别。
- 时长：周。前驱：P03 / P07 / P10 / P12 / P16（迁移失败）/ P17。后继：P19 / 永久流失。
- 标志：资源赠送/清空；卸载前的设置页访问；告别帖。言语："这游戏没救了""平民永远是韭菜"。
- 高发：T9 中R追赶者、T6 种田建设者。风险：流失极高；传播中（告别帖）。
- 帮助：只有当"下季结构真的会变"时才有路径可给（希望=路径，A）；否则接受离开并保留回归通道（回归专服，B）。

**P09 耗竭**
- 评估："打不动了"。情绪：麻木、疲惫，不一定负面（Maslach 三维，A）。
- 行动：请假、挂机、交出职务。
- 时长：周。前驱：P06（过度补偿）/ P12。后继：P13 解脱 / P18 / 退游。
- 标志：在线时长断崖；深夜在线消失；响应 @ 的延迟；管理者的公告间隔拉长。言语："比上班还累""让我歇会"。
- 高发：T3 盟主管家、T2 军师指挥、T9 中R追赶者（被考勤者）。风险：流失高（管理层耗竭是解体独立路径，B）；传播中。
- 帮助：减刺激、安全期、不堆活动（Hobfoll，B）；管理减负工具；不在此刻复盘。

**P11 沉默观望/等信号**
- 评估："看大佬怎么办"。情绪：不确定、焦虑。
- 行动：不表态、少发言、维持最低参与；私下打听。
- 时长：天到周。前驱：P01 / P20。后继：跟随触发者 → P14 / P16 / P19。
- 标志：登录稳定、发言归零、私聊上升；查看他人主页/联盟列表。言语："先看看""再说吧"。
- 高发：T7 陪伴社交者、T8 新人边缘、T11 目标收集者、T4 外交掮客。风险：流失取决于阈值触发（Granovetter，A）；传播被动。
- 帮助：减少不确定性（时间表、状态标签）；匿名意愿收集打破多元无知（Prentice & Miller，A）；让稳定者先表态。

**P16 迁移准备**
- 评估："这里不行，别处可能行"。情绪：期待与不舍。
- 行动：探路、囤票、退盟前置、拉小团。
- 时长：天到周（受迁移窗口约束）。前驱：P04 / P10 / P11 / P20。后继：迁移 / 迁移失败后 P08。
- 标志：查看迁服/护照页面；联盟商店换票；跨盟私聊；资源清空以满足条件（ROK "把兵放进医院降战力"，B）。言语："哪个服收人"。
- 高发：T4 外交掮客、T1 霸主大R、T7 陪伴社交者（跟随）。风险：产品层流失中（"迁走→更糟→退游"链，B）；传播极高（Felps 求职行为效应，A）。
- 帮助：整团迁移通道（率土备战区，B）；迁移前的信息（目标服真实情况）；不隐藏但延迟广播。

**P17 复仇**
- 评估："让他们付出代价"。情绪：怨恨、兴奋。
- 行动：针对性打击、卖州、进对方盟做内应（率土"搅屎棍"攻略，B）。
- 时长：周。前驱：P03。后继：P14（若得手）/ P08（Carlsmith：复仇后更多反刍，A）。
- 标志：对同一目标的重复攻击；跨阵营行为异常。言语："记住你了"。
- 高发：T5 热血打手、T1 霸主大R（被羞辱后）。风险：流失低（短期）；传播中（引发对方报复循环）。
- 帮助：给合法的对抗出口（下一场）；限制无意义的互相沦陷；不做仪式化"敌人"叙事（Hobson：仪式可增群际偏见，B）。

**P19 高调退出（带走人）**
- 评估："我走，让你们知道后果"。情绪：愤怒 + 自我肯定。
- 行动：世界频道告别、清资源给朋友、拉人一起走、解散小团。
- 时长：即时。前驱：P05 / P08 / P10 / P11。后继：流失；带走 3–30 人。
- 标志：告别帖；资源大额赠送；小团成员同步退盟。言语："兄弟们走了""不伺候了"。
- 高发：T1 霸主大R、T2 军师指挥（被羞辱后）、T4 外交掮客。风险：产品流失高；传播极高（Felps；级联，A）。
- 帮助：私下一对一，给"体面的路"；快速的官方/盟主说明以隔离叙事；不公开对抗。

### 四、恢复与重组期（首发 T+1–3 周至赛季末；Klinger 的"恢复"）

**P13 解脱**
- 评估："终于不用熬了"。情绪：轻松，伴随一点内疚（C）。
- 行动：正常登录但拒绝新的战争承诺。
- 时长：周。前驱：P09。后继：P15 / P14 / 温和流失。
- 标志：登录规律化、深夜在线消失、活动完成率上升。言语："输了也好"。
- 高发：T3 盟主管家、T2 军师指挥（耗竭后）、T6 种田建设者。风险：流失中（若无新目标）；传播低。
- 帮助：承认解脱是正当的；提供低强度目标；不急着拉回战争。

**P14 接受-重建**
- 评估："输在哪我知道，能改"。情绪：平静、精熟取向（Morgan 团队韧性，B）。
- 行动：参与 AAR、承担新职能、补兵修城。
- 时长：持续。前驱：P02 / P03 / P06 / P11 / P12 / P13 / P17 / P20。后继：稳定。
- 标志：复盘工具使用；职能接受；贡献恢复。言语："下次集结提前 10 分钟"。
- 高发：T10 老兵旅人、T2 军师指挥（被接纳后）。风险：低；传播正向（是"正性源"）。
- 帮助：AAR 包；把他们放到值守/主持位置。

**P15 接受-转向**
- 评估："这条路不通，走别的路"（Wrosch 目标再投入，A）。情绪：平静。
- 行动：从争霸转向种田/收集/社交；或转到别的目标（守住 X、争 Y 州）。
- 时长：到赛季末。前驱：P07 / P13。后继：稳定或跨季回归。
- 标志：行为结构切换（战斗↓、建造/活动↑）；查看替代目标页。言语："这季躺了，攒资源"。
- 高发：T11 目标收集者、T6 种田建设者、T10 老兵旅人。风险：低；传播低。
- 帮助：替代目标清单；贡献档；结算规则透明。

**P18 被动放任（Neglect）**
- 评估："懒得管了"。情绪：疏离（EVLN 的忽视，A）。
- 行动：留在盟里但不集结、不回应、不投入。
- 时长：周到月。前驱：P05（不可修复）/ P09。后继：慢性流失。
- 标志：登录仍在、贡献归零、@ 无回应、护盾常开。言语：无。
- 高发：T6 种田建设者、T12 潜水搭便车者（及被排斥者）。风险：流失高且**最难感知**；传播低。
- 帮助：低门槛的小任务；一次具体的私下邀请（"缺一个守关的"）；不考勤施压。

**P20 幸存者综合征**
- 评估："他们走了，剩下我们"。情绪：内疚、焦虑；投入可能下降，也可能短期反而更卖力（Brockner：认同离开者且觉得他们被亏待时反应最负面，程序公正可缓冲，B）。
- 行动：观望是否跟随；参与下降。
- 时长：周。前驱：他人离开（入口状态；好友或小团成员退盟）。后继：P11 / P16 / P14。
- 标志：好友退盟后 7 日内自身活跃下降；私聊对象减少。言语："人都走了还打什么"。
- 高发：T7 陪伴社交者、T6 种田建设者。风险：流失高（Ducheneaut：邻居跟随，B；Felps，A）；传播中。
- 帮助：补位与重组小团（不打散剩余小团）；程序公正的解释"为什么他们走了"；让留下的人看到离开者被体面对待（告别、资源可转赠，不公开羞辱）；新的 20 人协作目标（任务凝聚，A）。

**P21 失去共同体的哀伤**
- 评估："那个盟没了"。情绪：哀伤（Stroebe 双过程，A）。
- 行动：在丧失与恢复之间摆动：怀旧发帖、寻找旧友、偶尔回归。
- 时长：周到月。前驱：A08 解体（入口状态，由联盟状态触发）。后继：跨季重组或长期离开。
- 标志：联盟解散后的登录节律不规则；访问旧盟页面；怀旧帖（"率土历程"，N8 案例 19）。言语："回不去了"。
- 高发：T10 老兵旅人、T7 陪伴社交者。风险：流失中；传播低。
- 帮助：仪式（退旗、联盟史，Norton & Gino，A）；回归专服与整盟同服（B）。

## 2. 联盟状态卡（A01–A11）

字段：定义｜判定（示例阈值，待校准起点，C）｜先兆｜时长｜前驱→后继｜个人状态分布｜高发（原型构成或 L2 角色）｜风险（流失 / 传播）｜帮助方向（详见 [05 干预工具箱](05-toolbox-support.md) §3 对应行）｜证据。时长、高发与风险三栏均为本文推断（C）。

**总览**

| 编号 | 状态 | 一句话定义 | 后继 |
|---|---|---|---|
| A01 | 团结再战 | 战败后仍按原目标协同，领导已说明 | A11 / 稳定 |
| A02 | 表面团结、私下动摇 | 公开表态与实际参与背离 | A03 / A06 / A09 |
| A03 | 主战/主和分裂 | 对"打不打"出现公开两派 | A05 / A04 |
| A04 | 领导真空 | 盟主与指挥同时缺位 | A09 / A08 |
| A05 | 甩锅内讧 | 公开追责与互相攻击密集出现 | A03 / A08 |
| A06 | 集体迁移筹备 | 多名核心同时准备离开 | A07 / A08 |
| A07 | 被吸收/合并 | 被强盟整编、缩编或设为分盟 | A09 / A08 |
| A08 | 解体 | 解散或大规模退盟 | 关系跨容器延续 |
| A09 | 僵尸联盟 | 名义存在、实际停摆 | A08 / 合服 |
| A10 | 归附/称臣 | 以附庸身份存续 | A11 / A09 |
| A11 | 重建期 | 有新的可达目标并完成职能重组 | 稳定 |

**A01 团结再战**
- 定义：战败后联盟仍按原目标或新目标协同行动，领导已给出说明。
- 判定：战败 48h 内集结响应率不低于战前 80%，领导有说明，无退盟潮。
- 先兆：领导 30 分钟内说明；核心值守。时长：48h 到 1 周。前驱：战败事件（领导及时说明）。后继：A11 / 稳定。
- 个人状态分布：P02、P14 为主。高发：T10 老兵旅人多、T2 军师指挥在位的盟。风险：流失低；传播正向。
- 帮助方向：不打扰，提供 AAR 包；30 分钟首条说明、48h 内复盘（[05](05-toolbox-support.md) §3 A01）。
- 证据：领导及时说明的作用（N4 E3；CERC，B）；判定阈值 C。

**A02 表面团结、私下动摇**
- 定义：公开发言支持再战，但实际参与与私下行为已经背离。
- 判定：公开发言支持再战，但私聊上升、集结响应率下降 10–30%，护盾开启率上升。
- 先兆：多元无知；沉默者增多。时长：天到周。前驱：战败事件（领导未及时说明）。后继：A03 / A06 / A09。
- 个人状态分布：P11、P18、P05。高发：大盟、沉默成员多的盟（T7 陪伴社交者、T11 目标收集者比例高）。风险：流失中（潜伏）；传播中。
- 帮助方向：匿名意愿投票、状态标签；决策时间表，让稳定者先表态（[05](05-toolbox-support.md) §3 A02）。
- 证据：多元无知（Prentice & Miller，A）；阈值 C。

**A03 主战/主和分裂**
- 定义：对"继续打还是收缩"出现公开两派，决策停滞。
- 判定：群内出现两派表态；投票/弹劾；发言极化。
- 先兆：领导未及时定调。时长：天。前驱：A02 / A05。后继：A05 / A04。
- 个人状态分布：P04、P03 vs P07、P13。高发：有多个 T1 霸主大R 或多名 T2 军师指挥、目标不一的盟。风险：流失中；传播高。
- 帮助方向：投票/决策工具与程序公正模板；把"打/不打"改成具体目标与条件的选择（[05](05-toolbox-support.md) §3 A03）。
- 证据：组织衰退"危机"阶段的内部分裂（Weitzel & Jonsson 1989，B）；阈值 C。

**A04 领导真空**
- 定义：盟主与指挥同时缺位，决策与日常管理无人承担。
- 判定：盟主与指挥均 ≥48h 无发令/无操作（≥72h 升级）；副职代行；申请无人处理。
- 先兆：管理耗竭（P09）。时长：48h 起，至交权或解体。前驱：A03 / 管理层 P09 耗竭。后继：A09 / A08。
- 个人状态分布：P11、P20。高发：依赖单一 T3 盟主管家或 T2 军师指挥的盟。风险：流失高；传播中。
- 帮助方向：代理指挥自动显示、不活跃自动禅让；副职预授权（[05](05-toolbox-support.md) §3 A04）。
- 证据：管理耗竭是解体独立路径（N8 案例 24，B）；率土 24h、Avatar RC 3 天禅让规则（B）；阈值 C。

**A05 甩锅内讧**
- 定义：战后公开追责、点名与互相攻击在短时间内密集出现。
- 判定：@ 点名、踢人、辱骂事件在 24h 内密集出现。
- 先兆：战后立即公开复盘。时长：24–72h，可反复。前驱：战败事件（战后立即公开复盘）/ A03 / 个人 P04。后继：A03 / A08。
- 个人状态分布：P04、P05、P10。高发：T5 热血打手多、R4 过度竞争/自恋高者集中的盟。风险：流失高；传播极高。
- 帮助方向：频道冷却、复盘模板去责任栏；盟主自评先行、感谢首个反馈者（[05](05-toolbox-support.md) §3 A05）。
- 证据：集体崩溃的级联触发（Wergin 等 2018/2019，B）；被举报者多在输方、举报多来自队友（Kwak 等 2015，B）；社区案例 10、16（B）；阈值 C。

**A06 集体迁移筹备**
- 定义：多名核心成员同时在为离开做准备。
- 判定：≥3 名核心（含桥节点）同时查看迁服/其他联盟；联盟商店换票激增。
- 先兆：掮客活动；头部表态。时长：天到周（受迁移窗口约束）。前驱：A02。后继：A07 / A08。
- 个人状态分布：P16、P11。高发：有 T4 外交掮客、T1 霸主大R 的盟。风险：流失极高；传播极高。
- 帮助方向：整团迁移通道与目标服信息；与掮客谈"带着人去哪"而非阻止（[05](05-toolbox-support.md) §3 A06）。
- 证据：同事求职行为的离职传染（Felps 等 2009，A）；公会成员跟随离开（Ducheneaut 等 2007，B）；阈值 C。

**A07 被吸收/合并**
- 定义：被强盟"整编"、NAP 缩编或设为分盟，失去独立决策。
- 判定：被强盟"整编"、NAP 缩编、设分盟。
- 先兆：战败后头部盟的威胁僵化（N8 案例 7、26）。时长：周到赛季末。前驱：A06。后继：A09 / A08。
- 个人状态分布：P10、P20。高发：邻接强盟的中小盟。风险：流失中；传播中。
- 帮助方向：限制赢家政治羞辱的强度与可见性；谈判附庸条件（[05](05-toolbox-support.md) §3 A07）。
- 证据：社区案例 7、26（B，选择偏差见 N8）；阈值 C。

**A08 解体**
- 定义：联盟解散，或成员大规模退出而实际失去组织功能。
- 判定：解散或 7 日内退盟 >40%。
- 先兆：A04–A07 任一。时长：即时到 7 日。前驱：A04 / A05 / A06 / A07 / A09。后继：关系可能跨容器延续。
- 个人状态分布：P21、P19。高发：由 A04–A07 发展而来的盟。风险：流失极高；传播高。
- 帮助方向：联盟史/纪念、回归通道、关系延续工具；交代去向（[05](05-toolbox-support.md) §3 A08）。
- 证据：组织衰退五阶段的终点（Weitzel & Jonsson 1989，B）；公会存活与结构密度（Ducheneaut 等 2007，B）；阈值 C。

**A09 僵尸联盟**
- 定义：联盟名义存在，但集结与管理基本停摆。
- 判定：名义存在，集结响应率 <20%，无公告。
- 先兆：A02 长期化。时长：周到月。前驱：A02 / A04 / A07 / A10。后继：A08 或合服。
- 个人状态分布：P18 为主。高发：T12 潜水搭便车者、T6 种田建设者比例高的盟。风险：流失高（慢性）；传播低。
- 帮助方向：合服/重组窗口、低门槛参与；交权或解散并保留史册（[05](05-toolbox-support.md) §3 A09）。
- 证据：死服迹象的社区证词（N8 案例 17、18，B）；阈值 C。

**A10 归附/称臣**
- 定义：以附庸身份存续：被俘、受保护或被胜方任命。
- 判定：以附庸身份存续（俘虏、受保护、被任命部长）。
- 先兆：战败 + 有接纳方。时长：由附庸条件决定，多在赛季内。前驱：战败事件（有接纳方）。后继：A11 或 A09。
- 个人状态分布：P07、P15。高发：中小盟；对手愿意接纳时。风险：流失中；传播低。
- 帮助方向：附庸期间的最低保障（免战、可赎）；明确期限与条件（[05](05-toolbox-support.md) §3 A10）。
- 证据：三战俘虏/赎身、WOS 胜方任命败方部长等机制（N5，B）；阈值 C。

**A11 重建期**
- 定义：有新的可达目标，职能委任完成，小队保持完整。
- 判定：有新的可达目标、职能委任完成、小队保持。
- 先兆：A01 或 A10 之后。时长：周到赛季末。前驱：A01 / A10。后继：稳定。
- 个人状态分布：P14、P15。高发：小队完整、T10 老兵旅人在位的盟。风险：流失低；传播正向。
- 帮助方向：职能委任面板、每周团队学习节点；一个 20 人协作目标（[05](05-toolbox-support.md) §3 A11）。
- 证据：任务凝聚优于社会凝聚（Mullen & Copper 1994，A）；团队韧性（Morgan，B）；阈值 C。

## 3. 时间轴与三个分岔

| 窗口 | 主导个人状态 | 联盟层 | 分岔点 | 证据 |
|---|---|---|---|---|
| T0–6h | P01 冲击、P02 亢奋、P12 追损（P19 高调退出偶发即时） | 高唤醒 | — | Klinger（A）；CERC be first（B） |
| T+6–48h | P03/P04 愤怒、P05 羞耻、P06 内疚、P10 被背叛 | A02 或 A05 形成 | **领导是否在 30 分钟内说明、48 小时内复盘**：有 → A01；无 → A02/A05 | N4 E3；Frantz & Bennigson（A）；社区案例 16 |
| T+2–7d | P07/P08 无望、P09 耗竭、P11 观望、P16 迁移准备、P17 复仇、P19 高调退出 | A03 / A06 / A04 | **头部玩家去向**：留 → A11；走 → A07/A08 | Felps（A）；N8 案例 1、15 |
| T+1–3w | P13 解脱、P14/P15 接受、P18 放任、P20 幸存者 | A09、A10 归附或 A11 | 是否出现"可达的新目标 + 小队完整" | Mullen & Copper（A）；Morgan（B） |
| 赛季末 | P15 转向、P21 哀伤、P16 迁移 | 重组窗口 | **共同去处**：整盟同服 → 关系延续；无 → 分散/退游 | 率土备战区（B）；Poor & Skoric（B） |

## 4. 使用规则

1. 状态用概率向量表示，不做单选；同一玩家可同时处于 P05 与 P11。
2. 状态判定必须带时间戳与触发事件；离开事件窗口 14 天后自动衰减。
3. 个人状态不对玩家展示；联盟状态只以聚合、任务导向的形式对盟主展示（见 [04 识别与预警](04-toolbox-sensing.md) §2–4）。
4. 每个状态的"帮助方向"只是索引，具体做法、时机与反作用见 [05 干预工具箱](05-toolbox-support.md)。

## 5. 证据边界

- 骨架（Klinger 周期、Bonanno 轨迹）为 A，但都来自一般丧失与挫折研究，不是 SLG 数据；比例（65.7% 等）不能直接当作具体产品的分布。
- 个人状态的情绪与机制多有 A/B 来源；**状态的可观测标志、首发期归组、前驱→后继关系和时间轴窗口均为本文推断（C）**，来自理论推演与 N8 社区案例（B，有选择偏差：只听得到发声者，听不到沉默离开者）。
- 联盟状态的判定阈值、时长、高发和风险全部为 C，是待校准起点；校准路径见 [next/validation-ethics.md](next/validation-ethics.md) V1。
- 高发原型（T1–T12）本身的战败路径即为 C（见 02 玩家分类 §6），此处的对应关系同样待验证。
- 未覆盖：外部渠道（微信/QQ/Discord）中的状态演变；跨赛季多次战败的累积效应；未成年玩家。
